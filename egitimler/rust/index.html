Rust Programlama

C ve C++'ın hızını bellek güvenliği garantisiyle birleştiren Rust'ı 7 günde, bol şemayla öğreten bir program. Değişkenlerden match ifadesine, Rust'ın kalbi olan sahiplik ve ödünç alma kurallarından koleksiyonlara ve yineleyicilere, struct ve enum'lardan Option ve Result ile hata yönetimine, trait'lere kadar ilerlersin. Her örnek rustc ile derlenip çalıştırılmış, çıktısı sayfadadır.

GÜN 01

Tanışma ve cargo

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Rust'ın neden geliştirildiğini ve nerede kullanıldığını bilecek, rustup ile kurulum yapıp cargo ile ilk projeni oluşturup çalıştırabilecek ve Rust derleyicisinin açıklayıcı hata mesajlarını okuyabileceksin. Süre yaklaşık 4 saat.

Bu kurs hakkında: Programlama Dilleri grubundaki bütün eğitimler aynı iskeleti izler ve 7. günde aynı envanter özeti projesiyle biter. Rust, diğer dillerde olmayan bir kavram içerir: sahiplik. 4. gün bu kursun kalbidir; acele etme.

1. Rust nerede? (30 dk)

Rust, Mozilla'da başlayıp 2015'te 1.0 sürümüne ulaştı. Amacı: C ve C++ kadar hızlı ve donanıma yakın, ama bellek hatalarını derleme anında imkânsız kılan bir dil.

C ve C++'ta güvenlik açıklarının büyük kısmı bellek hatalarından gelir (tampon taşması, serbest bırakılmış belleğe erişim, veri yarışı). Rust bunları çöp toplayıcı kullanmadan, derleyicinin sıkı kurallarıyla önler.

  • Sistem yazılımı: Linux çekirdeğine ve Windows'a Rust kodu ekleniyor; Android'in yeni bileşenleri.
  • Komut satırı araçları: ripgrep, fd, bat, uv (Python paket yöneticisi).
  • Web ve bulut: Cloudflare, Discord, AWS altyapı bileşenleri; WebAssembly.
  • Oyun ve gömülü sistemler.

Rust, Stack Overflow anketlerinde yıllardır "en sevilen dil" seçilir. Ama öğrenme eğrisi diktir: derleyici başta çok şeye "hayır" der. Her "hayır", çalışma anında çıkacak bir hatanın önceden yakalanmasıdır.

4. Derleyiciyle konuşmak (1 saat)

Rust derleyicisinin hata mesajları, yazılım dünyasının en açıklayıcıları arasındadır. Değiştirilemez bir değişkeni değiştirmeye çalışalım:

fn main() {
    let stok = 40;
    stok = 25;
    println!("{stok}");
}

Derleyici şöyle yanıt verir (kısaltılmış):

error[E0384]: cannot assign twice to immutable variable `stok`
 --> src/main.rs:3:5
  |
2 |     let stok = 40;
  |         ---- first assignment to `stok`
3 |     stok = 25;
  |     ^^^^^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut stok = 40;
  |         +++

Mesaj sorunun ne olduğunu, nerede olduğunu ve nasıl düzeltileceğini söylüyor. rustc --explain E0384 hatanın uzun açıklamasını verir. Rust öğrenirken en iyi öğretmenin derleyicinin kendisi olduğunu göreceksin: mesajları sonuna kadar oku.

Alıştırma: Adını ve doğum yılını değişkenlere yazıp yaşını hesaplayan bir program yaz. Sonra bir değişkeni kullanmadan bırak ve derleyicinin verdiği uyarıyı oku (unused variable).

GÜN 02

Değişkenler ve tipler

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Rust'ta let ve mut ile değişken tanımlayabilecek, gölgelemeyi kullanabilecek, tam sayı ve ondalık tiplerini, bool, char, demet ve dizileri, as ile tip dönüşümünü ve tam sayı taşmasının Rust'taki davranışını bileceksin. Süre yaklaşık 4 saat.

1. let, mut ve gölgeleme (1 saat)

fn main() {
    let fiyat = 12.5;
    let mut stok = 40;
    stok -= 15;
    println!("{fiyat} {stok}");

    let girdi = "42";
    let girdi: i32 = girdi.parse().unwrap();
    let girdi = girdi * 2;
    println!("{girdi}");

    const KDV: f64 = 0.20;
    println!("{}", 250.0 * (1.0 + KDV));
}

  • Rust'ta değişkenler varsayılan olarak değiştirilemez. Değişmesi gerekiyorsa açıkça mut yazılır. Bu, kodun hangi değerlerin değiştiğini bir bakışta göstermesini sağlar.
  • Gölgeleme (shadowing): aynı adla yeni bir let yazmak, öncekini gizleyen yeni bir değişken oluşturur; tipi bile farklı olabilir. "Metin olarak okudum, sayıya çevirdim" gibi dönüşümlerde yeni ad uydurmaktan kurtarır.
  • const derleme anında bilinen sabittir; tipi her zaman yazılır.
  • .unwrap() "başarılıysa değeri ver, değilse programı durdur" demektir; 6. günde doğru hata yönetimini göreceğiz.

2. Sayı tipleri (1 saat)

fn main() {
    let a: i32 = -42;
    let b: u8 = 255;
    let c: i64 = 85_000_000;
    let d: f64 = 0.1 + 0.2;

    let f = 7.0 / 2.0;

    println!("{} {} {}", 3.99_f64 as i32, -1_i32 as u8, 300_i32 as u8);
    println!("{:.3} {} {}", 2f64.sqrt(), 2_i32.pow(10), (17.5_f64).round());
}

3. match (1,5 saat)

match, bir değeri desenlerle karşılaştırır ve bütün olasılıkların ele alınmasını zorunlu kılar:

fn harf_notu(ort: f64, final_notu: f64) -> &'static str {
    match (ort, final_notu) {
        (_, f) if f < 50.0 => "FF",
        (o, _) if o >= 85.0 => "AA",
        (o, _) if o >= 70.0 => "BB",
        (o, _) if o >= 55.0 => "CC",
        (o, _) if o >= 45.0 => "DD",
        _ => "FF",
    }
}

fn kargo(kg: u32) -> String {
    match kg {
        0 => String::from("geçersiz"),
        1..=2 => String::from("60 TL"),
        3..=10 => String::from("95 TL"),
        fazla => format!("{} TL", 95 + (fazla - 10) * 12),
    }
}

fn main() {
    println!("{} {} {}", harf_notu(73.4, 81.0), harf_notu(90.0, 45.0), harf_notu(30.0, 60.0));
    println!("{} {} {}", kargo(1), kargo(7), kargo(14));

    let gun = "Pazar";
    let tur = match gun {
        "Cumartesi" | "Pazar" => "hafta sonu",
        "Pazartesi" | "Salı" | "Çarşamba" | "Perşembe" | "Cuma" => "iş günü",
        _ => "geçersiz",
    };
    println!("{tur}");

    let nokta = (0, 5);
    match nokta {
        (0, 0) => println!("orijin"),
        (0, y) => println!("y ekseninde, y = {y}"),
        (x, 0) => println!("x ekseninde, x = {x}"),
        (x, y) => println!("({x}, {y})"),
    }
}

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Rust'ın sahiplik kurallarını, taşıma ile kopyalama arasındaki farkı, clone'u, referanslarla ödünç almayı, &mut ile değiştirilebilir ödünç almayı, ödünç alma kurallarını ve String ile &str arasındaki farkı bileceksin. Bu, Rust'ın en önemli ve en özgün günüdür. Süre yaklaşık 4 saat.

1. Fonksiyonlar (30 dk)

fn kdv_dahil(tutar: f64, oran: f64) -> f64 {
    tutar * (1.0 + oran / 100.0)
}

fn min_max(sayilar: &[i32]) -> (i32, i32) {
    let mut min = sayilar[0];
    let mut max = sayilar[0];
    for &x in sayilar {
        if x < min { min = x; }
        if x > max { max = x; }
    }
    (min, max)
}

fn main() {
    println!("{}", kdv_dahil(1000.0, 20.0));
    let (enk, enb) = min_max(&[72, 85, 64, 91, 58]);
    println!("{enk} {enb}");
}

Parametre tipleri her zaman yazılır; dönüş tipi -> ile belirtilir. Son ifade (noktalı virgülsüz) dönüş değeridir; erken dönmek için return kullanılır. Varsayılan argüman ve aşırı yükleme yoktur.

2. Sahiplik kuralları (1 saat)

Rust belleği çöp toplayıcı olmadan, şu üç kuralla yönetir:

  1. Her değerin tek bir sahibi (değişken) vardır.
  2. Aynı anda sadece bir sahip olabilir.
  3. Sahip kapsamdan çıkınca değer otomatik olarak silinir (drop).
fn main() {
    let a = String::from("Kalem");
    let b = a;                       // sahiplik a'dan b'ye TAŞINDI
    println!("{b}");
    // println!("{a}");              // HATA: a artık geçerli değil

    let c = b.clone();               // derin kopya: iki ayrı String
    println!("{b} {c}");

    let x = 5;
    let y = x;                       // tam sayılar KOPYALANIR
    println!("{x} {y}");
}

  • String metni öbekte (heap) tutar. let b = a; metni kopyalamaz; sahipliği taşır ve a artık kullanılamaz. Böylece aynı bellek iki kez silinmeye çalışılmaz.
  • .clone() açıkça kopyalar; maliyetli olabileceği için Rust bunu sana gizlice yapmaz.
  • i32, f64, bool, char gibi küçük, yığında duran tipler Copy'dir: atama kopyalar, taşıma yoktur.

3. Ödünç alma: referanslar (1,5 saat)

Her seferinde sahipliği vermek pratik değildir. Bunun yerine değeri ödünç verirsin: & ile bir referans oluşturulur.

fn uzunluk(s: &String) -> usize {
    s.len()
}

fn ek_yap(s: &mut String) {
    s.push_str(" (stokta)");
}

fn main() {
    let mut ad = String::from("Kalem");
    let n = uzunluk(&ad);            // ödünç ver, sahiplik bende kalır
    println!("{ad} {n}");

    ek_yap(&mut ad);                 // değiştirilebilir ödünç
    println!("{ad}");

    let r1 = &ad;
    let r2 = &ad;                    // birden çok okuyucu: sorun yok
    println!("{r1} | {r2}");
    let r3 = &mut ad;                // r1 ve r2 artık kullanılmadığı için izinli
    r3.push('!');
    println!("{ad}");
}

1. struct ve impl (1 saat)

#[derive(Debug, Clone)]
struct Urun {
    ad: String,
    fiyat: f64,
    stok: u32,
}

impl Urun {
    fn yeni(ad: &str, fiyat: f64, stok: u32) -> Result<Urun, String> {
        if fiyat < 0.0 {
            return Err(format!("{ad}: fiyat negatif olamaz"));
        }
        Ok(Urun { ad: ad.to_string(), fiyat, stok })
    }

    fn deger(&self) -> f64 {
        self.fiyat * self.stok as f64
    }

    fn sat(&mut self, adet: u32) -> bool {
        if adet > self.stok {
            return false;
        }
        self.stok -= adet;
        true
    }
}

fn main() {
    let mut u = Urun::yeni("Kalem", 12.5, 40).unwrap();
    u.sat(15);
    let satildi = u.sat(100);
    println!("{} {} {} {}", u.ad, u.stok, u.deger(), satildi);
    println!("{:?}", u);
    println!("{:?}", Urun::yeni("X", -5.0, 1).err());
}

4. Result ve ? işlemi (1 saat)

Başarısız olabilecek işlemler Result<T, E> döndürür: Ok(değer) ya da Err(hata). Rust'ta istisna yoktur; hatalar değerdir ve görmezden gelinemez.

use std::fmt;
use std::num::ParseIntError;

#[derive(Debug)]
enum SiparisHatasi {
    Okunamadi(ParseIntError),
    Yetersiz { istenen: u32, stok: u32 },
}

impl fmt::Display for SiparisHatasi {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            SiparisHatasi::Okunamadi(e) => write!(f, "sayı okunamadı ({e})"),
            SiparisHatasi::Yetersiz { istenen, stok } => write!(f, "{istenen} istendi, stokta {stok} var"),
        }
    }
}

impl From<ParseIntError> for SiparisHatasi {
    fn from(e: ParseIntError) -> Self {
        SiparisHatasi::Okunamadi(e)
    }
}

fn siparis(stok: u32, girdi: &str) -> Result<u32, SiparisHatasi> {
    let adet: u32 = girdi.trim().parse()?;
    if adet > stok {
        return Err(SiparisHatasi::Yetersiz { istenen: adet, stok });
    }
    Ok(stok - adet)
}

fn main() {
    let mut stok = 10;
    for g in ["3", "x", "20", " 2 "] {
        match siparis(stok, g) {
            Ok(kalan) => { stok = kalan; println!("kalan {stok}"); }
            Err(e) => println!("hata: {e}"),
        }
    }
}

kalan 7
hata: sayı okunamadı (invalid digit found in string)
hata: 20 istendi, stokta 7 var
kalan 5
  • ? işlemi: Ok ise içindeki değeri verir, Err ise fonksiyondan hemen o hatayla döner. Go'daki if err != nil { return err } kalıbının tek karakterlik hâlidir.
  • From<ParseIntError> uygulaması sayesinde ?, parse hatasını otomatik olarak bizim hata tipimize çevirdi.
  • Display trait'i (yarın) hatanın kullanıcıya nasıl yazılacağını belirler.
  • Gerçek projelerde bu kalıp için thiserror (kütüphaneler) ve anyhow (uygulamalar) crate'leri yaygındır.
