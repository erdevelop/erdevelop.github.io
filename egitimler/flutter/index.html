GÜN 01

Flutter ve Dart'a giriş

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Flutter'ın ne olduğunu ve neden tek kodla birden çok platforma uygulama yazılabildiğini bilecek; Flutter'ı kurup flutter doctor ile kontrol edecek, ilk projeyi oluşturup emülatörde çalıştıracak, hot reload ile anında değişiklik görecek ve Dart dilinin temel yapılarını (değişkenler, null safety, fonksiyonlar, sınıflar, listeler, map'ler) kullanabileceksin. Süre yaklaşık 4 saat.

1. Flutter nedir? (30 dk)

Flutter, Google'ın açık kaynaklı arayüz kütüphanesidir. Dart diliyle yazılan tek bir kod tabanından Android, iOS, web, Windows, macOS ve Linux uygulaması üretir. Flutter, ekrandaki her pikseli kendi çizim motoruyla çizer; bu yüzden uygulama her platformda aynı görünür ve akıcı çalışır.

Flutter'ın temel fikri: her şey bir widget'tır. Bir yazı, bir boşluk, bir buton, bir sayfa, hatta uygulamanın kendisi birer widget'tır. Widget'lar iç içe geçerek bir ağaç oluşturur; ekran bu ağacın görüntüsüdür.

2. Kurulum ve ilk proje (1 saat)

  1. Flutter SDK'yı resmi sitedeki talimatla indir ve flutter/bin klasörünü PATH'e ekle.
  2. VS Code'a Flutter eklentisini kur (Dart eklentisi birlikte gelir).
  3. Android Studio'yu kur, içinden Android SDK'yı ve bir emülatör (Device Manager) oluştur.
  4. Terminalde kontrol et:
flutter doctor

Çıktıda her satırın yanında ✓ görmelisin; ✗ olan satır, eksik olanı ve nasıl düzeltileceğini söyler (Android lisanslarını kabul etmek için flutter doctor --android-licenses).

İlk proje:

flutter create santiye
cd santiye
flutter run

flutter run açık emülatörde (ya da bağlı telefonda) örnek sayaç uygulamasını başlatır. Proje klasöründe en önemli yerler:

Hot reload: Uygulama çalışırken main.dart'ta bir yazıyı değiştirip kaydet (ya da terminalde r tuşuna bas): değişiklik bir saniyeden kısa sürede ekrana gelir ve uygulamanın durumu korunur. R (büyük) uygulamayı baştan başlatır (hot restart).

3. Dart: değişkenler ve null safety (45 dk)

Dart'ı denemek için uygulamaya gerek yok: dartpad.dev tarayıcıda çalışır. Her Dart programı main fonksiyonundan başlar.

void main() {
  var proje = 'Kule A';          // tür çıkarımı: String
  int katSayisi = 24;
  double panelGenislik = 1.5;
  bool tamamlandi = false;
  final baslangic = DateTime.now(); // bir kez atanır, sonra değişmez
  const kdv = 0.20;                 // derleme anında bilinen sabit

  print('$proje: $katSayisi kat, ${katSayisi * 2} cephe yüzü');
}

final ve const ikisi de değişmez değerdir: const derleme anında bilinmelidir, final çalışırken bir kez atanır. Flutter'da mümkün olan her yerde const kullanmak performansı artırır.

Null safety: Dart'ta bir değişken varsayılan olarak null olamaz. Null olabilecekse türün sonuna ? konur:

void main() {
  String? notMetni;              // null olabilir (şu an null)
  print(notMetni?.length);       // null ise null döner, hata vermez
  print(notMetni ?? 'not yok');  // null ise varsayılan değer
  // int uzunluk = notMetni!.length;  // "kesinlikle null değil" — null ise çalışırken hata!
}

! işaretini kullanmaktan kaçın; ?. ve ?? çoğu durumda daha güvenlidir.

4. Fonksiyonlar, listeler ve map'ler (45 dk)

// isimli ve varsayılan parametreler (Flutter'da her yerde göreceksin)

5. Sınıflar (45 dk)

Uygulamadaki verileri sınıflarla modelleriz:

class Panel {
  final String kod;
  final int kat;
  bool montajEdildi;

  Panel({required this.kod, required this.kat, this.montajEdildi = false});

  String get etiket => '$kod (kat $kat)';

  void monteEt() {
    montajEdildi = true;
  }
}

void main() {
  final p = Panel(kod: 'P12', kat: 7);
  p.monteEt();
  print('${p.etiket}: ${p.montajEdildi ? "monte edildi" : "bekliyor"}');
}

required parametre zorunludur; this.kod yapıcıya gelen değeri doğrudan alana atar. get ile hesaplanan bir özellik (getter) tanımlanır.

Alıştırma: DartPad'de bir Cam sınıfı yaz: en, boy (metre) ve kalinlik (mm) alanları olsun; alan ve agirlik getter'ları (cam yoğunluğu 2,5 kg/m² mm) hesaplasın. 1,5 × 3,0 m ve 10 mm'lik bir cam için ağırlığı yazdır. (Yanıt: 4,5 m² × 10 × 2,5 = 112,5 kg.)

3. Row, Column ve Expanded (1 saat)

Column çocuklarını alt alta, Row yan yana dizer. Hizalama iki eksende yapılır: ana eksen (mainAxisAlignment: Column'da düşey, Row'da yatay) ve çapraz eksen (crossAxisAlignment).

Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    const Text('Kule A', style: TextStyle(fontSize: 22, fontWeight: FontWeight.bold)),
    const SizedBox(height: 8),
    Row(
      children: [
        const Icon(Icons.layers),
        const SizedBox(width: 8),
        const Expanded(child: Text('24 kat, 1 450 panel')),
        TextButton(onPressed: () {}, child: const Text('Aç')),
      ],
    ),
  ],
)

Expanded, Row ya da Column içinde kalan boşluğun tamamını alır; yazı uzunsa satır taşmaz, alt satıra geçer. Flutter'da en sık görülen hata ekranın kenarında sarı-siyah çizgili taşma uyarısıdır (“RenderFlex overflowed”): çoğu zaman bir çocuğu Expanded ya da Flexible ile sarmak çözer.

4. Kendi widget'ını yazmak (45 dk)

Tekrar eden bir parçayı ayrı bir widget yap:

class KatKarti extends StatelessWidget {
  final int kat;
  final int toplam;
  final int biten;

  const KatKarti({super.key, required this.kat, required this.toplam, required this.biten});

  @override
  Widget build(BuildContext context) {
    final oran = toplam == 0 ? 0.0 : biten / toplam;
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(12),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('Kat $kat', style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 8),
            LinearProgressIndicator(value: oran),
            const SizedBox(height: 4),
            Text('$biten / $toplam panel (%${(oran * 100).round()})'),
          ],
        ),
      ),
    );
  }
}

Theme.of(context) uygulamanın temasındaki yazı stillerini kullanır; böylece her yerde aynı görünüm sağlanır.

1. StatefulWidget ve setState (1 saat)

StatelessWidget bir kez çizilir ve kendi başına değişmez. Ekranda değişen bir şey (sayaç, seçim, girilen yazı) varsa durum gerekir:

class PanelSayaci extends StatefulWidget {
  const PanelSayaci({super.key});

  @override
  State<PanelSayaci> createState() => _PanelSayaciState();
}

class _PanelSayaciState extends State<PanelSayaci> {
  int _monteEdilen = 0;

  void _ekle() {
    setState(() {
      _monteEdilen++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        Text('Bugün monte edilen: $_monteEdilen', style: const TextStyle(fontSize: 24)),
        const SizedBox(height: 12),
        FilledButton.icon(onPressed: _ekle, icon: const Icon(Icons.add), label: const Text('Panel ekle')),
      ],
    );
  }
}
  • Widget ve durumu iki ayrı sınıftır: widget yapılandırmayı, State değişen veriyi tutar.
  • setState içinde veriyi değiştirirsin; Flutter build'i yeniden çağırır ve ekran güncellenir. setState olmadan değişken değişir ama ekran güncellenmez.
  • Alt çizgiyle başlayan adlar (_monteEdilen) dosyaya özeldir.

3. Form ve doğrulama (1 saat)

Birden çok alan varsa Form ve TextFormField kullan; her alanın bir doğrulayıcısı (validator) olur. Doğrulayıcı hata metni döndürürse alan kırmızı olur, null döndürürse geçerlidir.

class _CamFormState extends State<CamForm> {
  final _formKey = GlobalKey<FormState>();
  final _en = TextEditingController();
  final _boy = TextEditingController();
  String? _sonuc;

  String? _sayiKontrol(String? v) {
    final s = double.tryParse((v ?? '').replaceAll(',', '.'));
    if (s == null) return 'Sayı girin';
    if (s <= 0 || s > 6) return '0 ile 6 m arasında olmalı';
    return null;
  }

  void _hesapla() {
    if (!_formKey.currentState!.validate()) return;
    final en = double.parse(_en.text.replaceAll(',', '.'));
    final boy = double.parse(_boy.text.replaceAll(',', '.'));
    setState(() => _sonuc = 'Alan: ${(en * boy).toStringAsFixed(2)} m²');
  }

  @override
  void dispose() {
    _en.dispose();
    _boy.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Column(children: [
        TextFormField(controller: _en, decoration: const InputDecoration(labelText: 'En (m)'),
            keyboardType: const TextInputType.numberWithOptions(decimal: true), validator: _sayiKontrol),
        TextFormField(controller: _boy, decoration: const InputDecoration(labelText: 'Boy (m)'),
            keyboardType: const TextInputType.numberWithOptions(decimal: true), validator: _sayiKontrol),
        const SizedBox(height: 12),
        FilledButton(onPressed: _hesapla, child: const Text('Hesapla')),
        if (_sonuc != null) Padding(padding: const EdgeInsets.all(8), child: Text(_sonuc!)),
      ]),
    );
  }
}

Türkçe klavyede ondalık ayıraç virgül olabilir; replaceAll(',', '.') ile ikisini de kabul ediyoruz. keyboardType telefonda sayısal klavyeyi açar.

Future<List<Panel>> panelleriGetir() async {

class _PanelListesiState extends State<PanelListesi> {
  late Future<List<Panel>> _gelecek;

  @override
  void initState() {
    super.initState();
    _gelecek = panelleriGetir();   // build içinde değil, bir kez başlat

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<List<Panel>>(
      future: _gelecek,
      builder: (context, snap) {
        if (snap.connectionState != ConnectionState.done) {
          return const Center(child: CircularProgressIndicator());
        }
        if (snap.hasError) {
          return Center(child: Column(mainAxisSize: MainAxisSize.min, children: [
            Text('Yüklenemedi: ${snap.error}'),

          ]));

        final paneller = snap.data!;

          onRefresh: () async {

          },

4. shared_preferences ile kayıt (1 saat)

import 'dart:convert';
import 'package:shared_preferences/shared_preferences.dart';

const _anahtar = 'paneller';

Future<void> kaydet(List<Panel> paneller) async {
  final sp = await SharedPreferences.getInstance();
  final metin = jsonEncode(paneller.map((p) => p.toJson()).toList());
  await sp.setString(_anahtar, metin);
}

Future<List<Panel>> yukle() async {
  final sp = await SharedPreferences.getInstance();

2. ChangeNotifier (1 saat)

import 'package:flutter/foundation.dart';

class PanelDeposu extends ChangeNotifier {
  final List<Panel> _paneller = [];

  List<Panel> get paneller => List.unmodifiable(_paneller);
  int get toplam => _paneller.length;
  int get biten => _paneller.where((p) => p.durum == 'tamam').length;
  double get oran => toplam == 0 ? 0 : biten / toplam;

  void yukleListe(List<Panel> liste) {
    _paneller
      ..clear()
      ..addAll(liste);
    notifyListeners();
  }

  void durumDegistir(Panel p, String durum) {
    p.durum = durum;
    notifyListeners();
    kaydet(_paneller);        // 5. gündeki kayıt fonksiyonu
  }
}

import 'dart:convert';
import 'package:flutter/foundation.dart';
import 'package:shared_preferences/shared_preferences.dart';
import 'model.dart';

class PanelDeposu extends ChangeNotifier {
  static const _anahtar = 'santiye_paneller';
  List<Panel> _paneller = [];
  bool yuklendi = false;

  List<Panel> get paneller => _paneller;
  List<int> get katlar => (_paneller.map((p) => p.kat).toSet().toList()..sort());
  int get biten => _paneller.where((p) => p.tamam).length;
  double get oran => _paneller.isEmpty ? 0 : biten / _paneller.length;

  double katOrani(int kat) {
    final k = _paneller.where((p) => p.kat == kat).toList();
    return k.isEmpty ? 0 : k.where((p) => p.tamam).length / k.length;
  }

  Future<void> yukle() async {
    final sp = await SharedPreferences.getInstance();
    final metin = sp.getString(_anahtar);
    _paneller = metin == null
        ? List.generate(48, (i) => Panel(kod: 'P${i + 1}', kat: i ~/ 8 + 1))   // ilk açılış: örnek veri
        : (jsonDecode(metin) as List).map((e) => Panel.fromJson(e as Map<String, dynamic>)).toList();
    yuklendi = true;
    notifyListeners();
  }

  Future<void> _kaydet() async {
    final sp = await SharedPreferences.getInstance();
    await sp.setString(_anahtar, jsonEncode(_paneller.map((p) => p.toJson()).toList()));
  }

  void adimDegistir(Panel p, int adim, bool deger) {
    deger ? p.biten.add(adim) : p.biten.remove(adim);
    notifyListeners();
    _kaydet();
  }

  void notYaz(Panel p, String metin) {
    p.not = metin;
    _kaydet();          // yazarken her harfte yeniden çizmeye gerek yok
  }
}

          padding: const EdgeInsets.symmetric(vertical: 4),
          child: Row(children: [
            SizedBox(width: 56, child: Text('Kat $k')),
            Expanded(child: LinearProgressIndicator(value: depo.katOrani(k), minHeight: 10)),
          ]),
        ),
      const Divider(height: 32),
      Text('Yarım kalan paneller: ${eksik.length}', style: Theme.of(context).textTheme.titleMedium),
      for (final p in eksik) Text('${p.kod} (kat ${p.kat}): ${p.biten.length}/5'),
    ]);
  }
}

4. Simge, ad ve sürüm (30 dk)

  • Uygulama adı: android/app/src/main/AndroidManifest.xml içinde android:label, iOS'ta ios/Runner/Info.plist içinde CFBundleDisplayName.
  • Simge: 1024 × 1024 bir PNG hazırla, flutter_launcher_icons paketiyle tüm boyutları üret (dart run flutter_launcher_icons).
  • Sürüm: pubspec.yaml içinde version: 1.0.0+1 (görünen sürüm + yapı numarası). Her mağaza yüklemesinde yapı numarası artmalı.
  • Uygulama kimliği: android/app/build.gradle içindeki applicationId (örneğin io.github.erdevelop.santiye); mağazaya yüklendikten sonra değiştirilemez.

5. Yayın paketi ve mağaza (1 saat)

Android:

flutter build apk --release        # telefona doğrudan kurmak için tek dosya
flutter build appbundle --release  # Google Play için .aab

Play Store'a yüklemek için uygulama bir imza anahtarıyla (keystore) imzalanmalıdır: keytool ile anahtar oluşturulur, android/key.properties dosyasına yolu ve şifreleri yazılır, build.gradle'daki signingConfigs bu dosyayı okur. Anahtarı ve şifreleri kaybetme ve depoya yükleme (Git'e eklenmemeli). Play Console'da bir geliştirici hesabı (tek seferlik ücret), uygulama açıklaması, ekran görüntüleri, gizlilik politikası bağlantısı ve içerik derecelendirmesi gerekir; ilk sürüm önce dahili test kanalında denenir.

iOS: Mac ve Xcode gerekir. flutter build ipa ile paket üretilir, Apple Developer Program üyeliği (yıllık ücret) ile App Store Connect'e yüklenir ve TestFlight ile test edilir.

Alıştırma: (1) Panel detayına image_picker paketiyle fotoğraf çekme ekle; fotoğraf yolunu modelde sakla (path_provider ile uygulama klasörüne kopyala). (2) Özet sayfasına, yarım kalan panelleri metin olarak paylaşan bir buton ekle (share_plus paketi). Her iki pakette de Android ve iOS izinlerini paketlerin belgelerine göre ekle.
