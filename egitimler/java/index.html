1. Java nerede? (30 dk)

Java, 1995'te Sun Microsystems tarafından "bir kez yaz, her yerde çalıştır" sloganıyla yayımlandı. Bugün Oracle tarafından geliştirilir ve dünyanın en çok kullanılan dillerinden biridir:

  • Android: Uygulamaların büyük kısmı Java ya da Kotlin ile yazılır (ikisi de JVM dilidir).
  • Büyük veri: Hadoop, Kafka, Elasticsearch.
  • Masaüstü araçlar: IntelliJ IDEA, Minecraft (Java sürümü).

2. JDK, JRE, JVM (45 dk)

  1. javac derleyicisi .java kaynak dosyasını bytecode içeren .class dosyasına çevirir.
  2. JVM (Java Virtual Machine) bu bytecode'u çalıştırır; sık çalışan kısımları JIT ile makine koduna çevirir ve çöp toplamayla belleği yönetir.

Satır satır:

  1. Java'da her şey bir sınıfın içindedir. public class Main dosya adıyla (Main.java) aynı olmalıdır.
  2. Program public static void main(String[] args) metodundan başlar. static: nesne oluşturmadan çağrılabilir; void: bir şey döndürmez; args: komut satırı argümanları.
  3. System.out.println yazıp satır atlar, print atlamaz, printf biçimli yazar (%n satır sonu).
  4. + ile metin ve sayılar birleştirilir; ama dikkat: soldan sağa işlenir. "" + 1 + 2 → "12", 1 + 2 + "" → "3".

2. Sarmalayıcı tipler ve BigDecimal (45 dk)

Her ilkel tipin bir sarmalayıcı sınıfı vardır: int → Integer, double → Double, boolean → Boolean. Koleksiyonlar (5. gün) sadece nesne tuttuğu için List<Integer> yazılır; Java dönüşümü otomatik yapar (autoboxing).

import java.math.BigDecimal;
import java.math.RoundingMode;

public class Main {
    public static void main(String[] args) {
        int sayi = Integer.parseInt("42");
        double d = Double.parseDouble("12.5");
        System.out.println(sayi + 1 + " " + d * 2);

        BigDecimal a = new BigDecimal("0.10");
        BigDecimal b = new BigDecimal("0.20");
        System.out.println(a.add(b));
        BigDecimal fiyat = new BigDecimal("249.90");
        System.out.println(fiyat.multiply(new BigDecimal("1.20")).setScale(2, RoundingMode.HALF_UP));
    }
}

2. switch ifadesi (1,5 saat)

Java 14'ten beri switch bir ifade olarak kullanılabilir: değer üretir, -> ile yazılır ve düşme (fall-through) yoktur.

public class Main {
    static String gunTuru(String gun) {
        return switch (gun) {
            case "Cumartesi", "Pazar" -> "hafta sonu";
            case "Pazartesi", "Salı", "Çarşamba", "Perşembe", "Cuma" -> "iş günü";
            default -> "geçersiz";
        };
    }

    static String kargo(double kg) {
        if (kg <= 0) return "geçersiz";
        int kademe = kg <= 2 ? 1 : kg <= 10 ? 2 : 3;
        return switch (kademe) {
            case 1 -> "60 TL";
            case 2 -> "95 TL";
            default -> {
                long ek = Math.round((kg - 10) * 12);
                yield (95 + ek) + " TL";
            }
        };
    }

    public static void main(String[] args) {
        System.out.println(gunTuru("Pazar") + ", " + gunTuru("Salı") + ", " + gunTuru("Bayram"));
        System.out.println(kargo(1.5) + ", " + kargo(7) + ", " + kargo(14));

        Object deger = 3.5;
        String tur = switch (deger) {
            case Integer i -> "tam sayı " + i;
            case Double d when d > 0 -> "pozitif ondalık " + d;
            case String s -> "metin " + s;
            default -> "başka";
        };
        System.out.println(tur);
    }
}

hafta sonu, iş günü, geçersiz
60 TL, 95 TL, 143 TL
pozitif ondalık 3.5
  • case "Cumartesi", "Pazar" -> birden çok değeri tek kolda toplar.
  • Birden çok satırlık bir kol { ... yield değer; } ile değer döndürür.
  • Java 21'in desen eşleştirmeli switch'i (case Double d when ...) tipi kontrol edip değişkene açar.
  • switch metinlerle de çalışır (C'nin aksine). Eski case X: ... break; yazımını eski kodlarda görürsün; yeni kodda ok (->) yazımını tercih et.

GÜN 04

Metotlar ve diziler

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Java'da static metotlar yazıp aşırı yükleyebilecek, Java'nın her şeyi değerle geçirdiğini ve bunun nesneler için ne anlama geldiğini bilecek, dizilerle ve Arrays sınıfıyla çalışabileceksin. Süre yaklaşık 4 saat.

1. Metotlar (1 saat)

public class Main {
    static final double KDV = 0.20;

    static double kdvDahil(double tutar) {
        return kdvDahil(tutar, KDV);
    }

    static double kdvDahil(double tutar, double oran) {
        return Math.round(tutar * (1 + oran) * 100) / 100.0;
    }

    static double alan(double en, double boy) { return en * boy; }
    static double alan(double kenar) { return kenar * kenar; }

    static int topla(int... sayilar) {
        int t = 0;
        for (int s : sayilar) t += s;
        return t;
    }

    public static void main(String[] args) {
        System.out.println(kdvDahil(1000) + " " + kdvDahil(1000, 0.10) + " " + kdvDahil(249.9));
        System.out.println(alan(3, 4) + " " + alan(5));
        System.out.println(topla() + " " + topla(1, 2, 3) + " " + topla(10, 20));
    }
}

12.0 25.0
0 6 30
  • Java'da varsayılan argüman yoktur; aynı etkiyi aşırı yükleme ile sağlarsın (kdvDahil(tutar), kdvDahil(tutar, oran)).
  • static final bir sınıf sabitidir.
  • int... sayilar (varargs) değişken sayıda argüman alır; metot içinde bir dizidir.
  • Math.round(x * 100) / 100.0 iki ondalığa yuvarlamanın kısa yoludur (para için BigDecimal kullan).

2. Değerle geçirme (1 saat)

Java'da her şey değerle geçer; ama nesne değişkenlerinin "değeri" nesnenin adresidir (referansı).

import java.util.Arrays;

public class Main {
    static void artir(int x) { x++; }
    static void ilkiniSifirla(int[] d) { d[0] = 0; }
    static void yeniDiziAta(int[] d) { d = new int[]{7, 7, 7}; }

    public static void main(String[] args) {
        int sayi = 5;
        artir(sayi);
        int[] a = {1, 2, 3};
        ilkiniSifirla(a);
        yeniDiziAta(a);
        System.out.println(sayi + " " + Arrays.toString(a));

        int[] b = a;
        b[1] = 99;
        System.out.println(Arrays.toString(a));
    }
}

5 [0, 2, 3]
[0, 99, 3]
  1. artir: int'in kopyası gitti, dışarısı değişmedi.
  2. ilkiniSifirla: adresin kopyası gitti, ama aynı diziyi gösterdiği için dizinin içi değişti.
  3. yeniDiziAta: metot içindeki kopya adres yeni bir diziye yönlendirildi; dışarıdaki a etkilenmedi.
  4. b = a diziyi kopyalamaz; iki değişken aynı diziyi gösterir.

3. Diziler ve Arrays (1,5 saat)

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] notlar = {72, 85, 64, 91, 58};
        double[] fiyatlar = new double[3];             // {0.0, 0.0, 0.0}
        fiyatlar[0] = 12.5;

        System.out.println(notlar.length + " " + notlar[notlar.length - 1] + " " + Arrays.toString(fiyatlar));

        int[] kopya = Arrays.copyOf(notlar, notlar.length);
        Arrays.sort(kopya);
        System.out.println(Arrays.toString(kopya) + " " + Arrays.toString(notlar));
        System.out.println(Arrays.binarySearch(kopya, 85) + " " + Arrays.stream(notlar).sum() + " " + Arrays.stream(notlar).max().getAsInt());

        int[][] matris = {{1, 2, 3}, {4, 5, 6}};
        System.out.println(matris[1][2] + " " + Arrays.deepToString(matris));

        try {
            System.out.println(notlar[5]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("hata: " + e.getMessage());
        }
    }
}

  • new double[3] öğeleri varsayılan değerle (0, false, null) doldurur.
  • Dizi doğrudan yazdırılırsa anlamsız bir adres görünür; Arrays.toString kullan.
  • C'nin aksine Java sınır kontrolü yapar: dışına çıkmak ArrayIndexOutOfBoundsException fırlatır, belleği bozmaz.
  • Değişken boyutlu listeler için yarın ArrayList'i göreceğiz; günlük işlerde dizilerden daha sık kullanılır.

Koleksiyonlar ve Stream

1. ArrayList (1 saat)

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> sehirler = new ArrayList<>(List.of("Adana", "Bursa", "İzmir"));
        sehirler.add("Konya");
        sehirler.add(1, "Ankara");
        sehirler.remove("Adana");
        sehirler.remove(sehirler.size() - 1);
        System.out.println(sehirler.size() + " " + sehirler);
        System.out.println(sehirler.contains("Bursa") + " " + sehirler.indexOf("İzmir") + " " + sehirler.get(0));

        System.out.println(notlar + " max=" + Collections.max(notlar));

3. Stream API (1,5 saat)

Java 8 ile gelen Stream API, koleksiyonları döngü yazmadan işlemeyi sağlar (C#'taki LINQ'in karşılığı):

import java.util.*;
import java.util.stream.*;

public class Main {
    record Urun(String ad, String kategori, double fiyat, int stok) {
        double deger() { return fiyat * stok; }
    }

    public static void main(String[] args) {
        List<Urun> urunler = List.of(
            new Urun("Kalem", "kırtasiye", 12.5, 40),
            new Urun("Kulaklık", "elektronik", 850, 5),
            new Urun("Defter", "kırtasiye", 45, 25),
            new Urun("Mouse", "elektronik", 320, 12));

        List<String> pahalilar = urunler.stream().filter(u -> u.fiyat() > 40).map(Urun::ad).toList();
        System.out.println(pahalilar);

        String sirali = urunler.stream()
            .sorted(Comparator.comparingDouble(Urun::deger).reversed())
            .map(u -> u.ad() + ":" + u.deger())
            .collect(Collectors.joining(" "));
        System.out.println(sirali);

        double toplam = urunler.stream().mapToDouble(Urun::deger).sum();
        boolean azVar = urunler.stream().anyMatch(u -> u.stok() < 10);
        System.out.println(toplam + " " + azVar);

        Map<String, Double> kategori = urunler.stream()
            .collect(Collectors.groupingBy(Urun::kategori, TreeMap::new, Collectors.summingDouble(Urun::deger)));
        System.out.println(kategori);
    }
}

9715.0 true

İşlem Görevi
filter(x -> koşul) Süz
map(x -> ifade) Dönüştür
sorted(Comparator...) Sırala
toList(), collect(...) Sonucu topla

anyMatch, allMatch, findFirst Kontrol et, bul
Collectors.groupingBy Grupla

  • record (yarın ayrıntılı) veri taşıyan sınıfları tek satırda tanımlar.
  • Bir stream sadece bir kez kullanılabilir; tekrar gerekiyorsa koleksiyondan yeniden stream() al.

1. Sınıflar ve kapsülleme (1,5 saat)

public class Main {
    static class Urun {
        private final String ad;
        private final double fiyat;
        private int stok;

        Urun(String ad, double fiyat, int stok) {
            if (fiyat < 0) throw new IllegalArgumentException("Fiyat negatif olamaz.");
            this.ad = ad;
            this.fiyat = fiyat;
            this.stok = stok;
        }

        String getAd() { return ad; }
        int getStok() { return stok; }
        double deger() { return fiyat * stok; }
        void stokEkle(int adet) { stok += adet; }

        boolean sat(int adet) {
            if (adet > stok) return false;
            stok -= adet;
            return true;
        }

        @Override
        public String toString() { return ad + " (" + stok + ")"; }
    }

    public static void main(String[] args) {
        Urun u = new Urun("Kalem", 12.5, 40);
        u.sat(15);
        u.stokEkle(5);
        System.out.println(u + " değer: " + u.deger());
        System.out.println("100 satılabilir mi? " + u.sat(100));
        try {
            new Urun("X", -5, 1);
        } catch (IllegalArgumentException e) {
            System.out.println("hata: " + e.getMessage());
        }
    }
}

Kalem (30) değer: 375.0
100 satılabilir mi? false
hata: Fiyat negatif olamaz.
  • private alanlara sadece sınıf içinden erişilir; dışarıya getter metotlarıyla (getAd()) açılır. Java'da property yoktur; getter/setter geleneği vardır.
  • final alan bir kez atanır, sonra değişmez.
  • this.ad = ad; parametre ile alanın adı aynı olduğunda alanı belirtir.
  • toString() metodunu ezmek, nesnenin yazdırılınca okunur görünmesini sağlar. @Override derleyiciye "üst sınıftaki bir metodu eziyorum" der.
  • Sınıflar genelde ayrı dosyalarda (Urun.java) yazılır; burada tek dosyada tutmak için static class (iç içe sınıf) kullandık.

2. Kalıtım, abstract ve interface (1 saat)

import java.util.List;

public class Main {
    interface Sekil {
        double alan();
        default String ozet() { return getClass().getSimpleName() + ": " + String.format("%.2f", alan()); }
    }

    static class Dikdortgen implements Sekil {
        protected final double en, boy;
        Dikdortgen(double en, double boy) { this.en = en; this.boy = boy; }
        public double alan() { return en * boy; }
    }

    static class Kare extends Dikdortgen {
        Kare(double kenar) { super(kenar, kenar); }
    }

    record Daire(double r) implements Sekil {
        public double alan() { return Math.PI * r * r; }
    }

    public static void main(String[] args) {
        List<Sekil> sekiller = List.of(new Dikdortgen(2, 3), new Daire(1), new Kare(2));
        for (Sekil s : sekiller) System.out.println(s.ozet());
        System.out.printf("toplam: %.2f%n", sekiller.stream().mapToDouble(Sekil::alan).sum());
    }
}

Dikdortgen: 6.00
Daire: 3.14
Kare: 4.00
toplam: 13.14
  • interface bir sözleşmedir; implements ile uygulanır. Bir sınıf birden çok interface uygulayabilir. default metotlar interface içinde hazır bir uygulama sunar.
  • extends ile tek bir sınıftan kalıtım alınır; super(...) üst sınıfın kurucusunu çağırır.
  • protected alanlara alt sınıflar da erişebilir.
  • abstract class hem hazır kod hem de alt sınıfların doldurması gereken abstract metotlar içerebilir; doğrudan new ile oluşturulamaz.

3. record (30 dk)

public class Main {
    record Nokta(double x, double y) {
        Nokta {
            if (Double.isNaN(x) || Double.isNaN(y)) throw new IllegalArgumentException("NaN");
        }
        double uzaklik() { return Math.hypot(x, y); }
    }

    public static void main(String[] args) {
        Nokta a = new Nokta(3, 4);
        Nokta b = new Nokta(3, 4);
        System.out.println(a + " " + a.equals(b) + " " + (a == b) + " " + a.uzaklik() + " " + a.x());
    }
}

Nokta[x=3.0, y=4.0] true false 5.0 3.0

record (Java 16+) sadece veri taşıyan, değiştirilemez sınıflar içindir: kurucu, getter (a.x()), equals, hashCode ve toString otomatik üretilir. equals içeriği karşılaştırır, == ise aynı nesne mi diye bakar. Nokta { ... } biçimindeki kısa kurucu doğrulama eklemeyi sağlar.

import java.util.*;
import java.util.stream.*;

public class Main {
    record Urun(String ad, String kategori, double fiyat, int stok) {
        double deger() { return fiyat * stok; }
    }

    public static void main(String[] args) {
        List<Urun> urunler = List.of(
            new Urun("Kalem", "kırtasiye", 12.5, 40),
            new Urun("Defter", "kırtasiye", 45.0, 25),
            new Urun("Kulaklık", "elektronik", 850.0, 5),
            new Urun("Mouse", "elektronik", 320.0, 12),
            new Urun("Çay", "gıda", 95.0, 30));

        double toplam = urunler.stream().mapToDouble(Urun::deger).sum();
        System.out.printf(Locale.ROOT, "Toplam stok değeri: %.2f TL%n", toplam);

            Collectors.groupingBy(Urun::kategori, TreeMap::new, Collectors.summingDouble(Urun::deger)));
