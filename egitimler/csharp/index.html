GÜN 01

Tanışma ve .NET

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C#'ın nerede kullanıldığını, .NET'in nasıl çalıştığını bilecek, SDK'yı kurup dotnet komutuyla ilk projeni oluşturup çalıştırabilecek ve bir C# projesinin dosyalarını tanıyacaksın. Süre yaklaşık 4 saat.

Bu kurs hakkında: Programlama Dilleri grubundaki bütün eğitimler aynı iskeleti izler ve 7. günde aynı envanter özeti projesiyle biter. C#, CAD ve BIM dünyasında özellikle önemlidir: Revit, AutoCAD, Rhino ve SolidWorks'ün eklenti arayüzleri (API) C# ile kullanılır.

1. C# nerede? (30 dk)

C#, 2000'de Microsoft tarafından geliştirildi. Bugün açık kaynaklı ve Windows, macOS ve Linux'ta çalışan .NET platformunun ana dilidir.

  • Masaüstü uygulamaları: WinForms, WPF, .NET MAUI.
  • Web ve bulut: ASP.NET Core ile web siteleri ve API'ler.
  • Oyun: Unity oyun motorunun betik dili.
  • CAD / BIM eklentileri: Revit API, AutoCAD .NET API, Rhino RhinoCommon, SolidWorks API, Navisworks API.
  • Kurumsal yazılım: Bankacılık, ERP sistemleri.

C# hem güçlü bir tip sistemine sahiptir (hatalar derleme anında yakalanır) hem de bellek yönetimini otomatik yapar (çöp toplayıcı). Java'ya çok benzer; birini bilen diğerine kolayca geçer.

2. .NET nasıl çalışır? (30 dk)

  1. C# derleyicisi kodu doğrudan makine koduna değil, IL (Intermediate Language) adlı ara bir koda çevirir ve bir .dll dosyasına yazar.
  2. Program çalışırken CLR (Common Language Runtime), IL'yi o anda bulunduğu işlemcinin makine koduna çevirir (JIT, tam zamanında derleme).
  3. CLR ayrıca çöp toplama (kullanılmayan belleği otomatik temizleme), tip güvenliği ve istisna yönetimini üstlenir.

Bu yüzden aynı .dll, .NET kurulu her sistemde çalışır. Revit'e yüklediğin bir eklenti de böyle bir .dll'dir.

3. Kurulum ve ilk proje (1,5 saat)

4. null (30 dk)

null, "değer yok" demektir. Bir string değişkeni null ise üzerinde metot çağırmak programı NullReferenceException ile çökertir: C#'taki en yaygın hatadır.

Modern C#'ta (yeni projelerde varsayılan) tipler null olamaz; null olabileceklerse ? ile işaretlenir ve derleyici seni uyarır:

string? ad = null;
Console.WriteLine(ad?.Length);            // null güvenli erişim: ad null ise null döner
Console.WriteLine(ad ?? "isimsiz");       // null ise varsayılan değer
ad ??= "Ali";                             // null ise ata
Console.WriteLine($"{ad} {ad.Length}");
int? stok = null;
Console.WriteLine(stok.HasValue ? stok.Value : -1);

static string HarfNotu(double ort, double final) => (ort, final) switch
{

    (>= 70, _) => "BB",
    (>= 55, _) => "CC",
    (>= 45, _) => "DD",
    _ => "FF",
};

static string Kargo(double kg) => kg switch
{
    <= 0 => "geçersiz",
    <= 2 => "60 TL",
    <= 10 => "95 TL",
    _ => $"{95 + (kg - 10) * 12:F0} TL",
};

Console.WriteLine($"{HarfNotu(73.4, 81)} {HarfNotu(90, 45)} {HarfNotu(30, 60)}");
Console.WriteLine($"{Kargo(1.5)} {Kargo(7)} {Kargo(14)}");

object deger = 3.5;

1. Metotlar (1 saat)

C#'ta fonksiyonlara metot denir ve her metot bir sınıfa aittir. Üst düzey ifadelerin olduğu Program.cs'te dosyanın içinde yerel fonksiyon olarak da yazılabilirler:

Console.WriteLine(KdvDahil(1000m));
Console.WriteLine(KdvDahil(1000m, 10m));
Console.WriteLine(KdvDahil(oran: 1m, tutar: 500m));
Console.WriteLine(Geo.Alan(3, 4) + " " + Geo.Alan(5));

static decimal KdvDahil(decimal tutar, decimal oran = 20m)
{
    return Math.Round(tutar * (1 + oran / 100), 2);
}

static class Geo
{
    public static double Alan(double en, double boy) => en * boy;
    public static double Alan(double kenar) => kenar * kenar;
}

3. out ve ref (45 dk)

Bir metodun birden fazla sonuç döndürmesi gerekirse:

var notlar = new[] { 72, 85, 64, 91, 58 };
MinMax(notlar, out int enk, out int enb);
Console.WriteLine($"min={enk} max={enb}");

var (ort, gecen) = Ozet(notlar);
Console.WriteLine($"ort={ort:F1} geçen={gecen}");

int stok = 10;
Azalt(ref stok, 3);
Console.WriteLine($"stok={stok}");

static void MinMax(int[] d, out int min, out int max)
{
    min = max = d[0];
    foreach (int x in d) { if (x < min) min = x; if (x > max) max = x; }
}

static (double ortalama, int gecen) Ozet(int[] d)
{
    double t = 0; int g = 0;
    foreach (int x in d) { t += x; if (x >= 60) g++; }
    return (t / d.Length, g);
}

static void Azalt(ref int deger, int miktar) => deger -= miktar;

  • ref var olan bir değişkeni metoda referansla verir; metot onu değiştirebilir.
  • Modern C#'ta birden çok değer döndürmenin en okunur yolu demettir (tuple): (double ortalama, int gecen). Sonucu var (ort, gecen) = ... ile açarsın.

4. Metotları düzenlemek (30 dk)

Program büyüdükçe metotları sınıflara toplarsın. Static bir yardımcı sınıf:

Console.WriteLine(Hesap.CamAgirligi(1.5, 2.5, 8));
Console.WriteLine(Hesap.CamAgirligi(1.5, 2.5, 8, 6));

static class Hesap
{
    public const double CamYogunluk = 2.5;        // kg / (m² · mm)

    /// <summary>Cam panelin ağırlığını kg cinsinden hesaplar.</summary>
    public static double CamAgirligi(double en, double boy, params double[] kalinliklar)
    {
        double toplam = 0;
        foreach (var k in kalinliklar) toplam += k;
        return en * boy * toplam * CamYogunluk;
    }
}

GÜN 05

Koleksiyonlar ve LINQ

~4 saat · 0/4 kontrol

Hedef

Gün sonunda C#'ta dizi, List, Dictionary ve HashSet kullanabilecek, LINQ ile filtreleme, dönüştürme, sıralama, gruplama ve toplama işlemlerini tek satırda yapabileceksin. LINQ, Revit API'de elemanları süzerken de en sık kullanacağın araçtır. Süre yaklaşık 4 saat.

1. Dizi ve List (1 saat)

int[] notlar = { 72, 85, 64, 91, 58 };

3. LINQ (1,5 saat)

LINQ (Language Integrated Query), koleksiyonları SQL'e benzer bir dille sorgulamayı sağlar. Döngü yazmadan filtreler, dönüştürür, sıralar ve özetlersin:

var urunler = new[]
{
    new { Ad = "Kalem", Kategori = "kırtasiye", Fiyat = 12.5m, Stok = 40 },
    new { Ad = "Kulaklık", Kategori = "elektronik", Fiyat = 850m, Stok = 5 },
    new { Ad = "Defter", Kategori = "kırtasiye", Fiyat = 45m, Stok = 25 },
    new { Ad = "Mouse", Kategori = "elektronik", Fiyat = 320m, Stok = 12 },
};

var pahalilar = urunler.Where(u => u.Fiyat > 40).Select(u => u.Ad);
Console.WriteLine(string.Join(", ", pahalilar));

var sirali = urunler.OrderByDescending(u => u.Fiyat * u.Stok).Select(u => $"{u.Ad}:{u.Fiyat * u.Stok}");
Console.WriteLine(string.Join(" ", sirali));

Console.WriteLine($"toplam {urunler.Sum(u => u.Fiyat * u.Stok)}, ort. fiyat {urunler.Average(u => u.Fiyat):F2}");
Console.WriteLine($"az stok var mı? {urunler.Any(u => u.Stok < 10)}, ilk: {urunler.First(u => u.Stok < 10).Ad}");

foreach (var g in urunler.GroupBy(u => u.Kategori).OrderBy(g => g.Key))
    Console.WriteLine($"{g.Key}: {g.Count()} ürün, {g.Sum(u => u.Fiyat * u.Stok)}");

  • new { Ad = ..., ... } anonim tiptir: hızlı denemeler için. Gerçek programlarda record kullanacağız (yarın).
  • decimal değerleri yazdırırken ondalık basamakları korur: 12.5m * 40 sonucu 500.0 yazdı.
  • LINQ sorguları tembeldir: Where hemen çalışmaz, sonuç dolaşıldığında çalışır. Aynı sorguyu tekrar tekrar dolaşacaksan ToList() ile bir kez hesapla.

GÜN 06

Sınıflar, record ve interface

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C#'ta property ve kurucu içeren sınıflar yazabilecek, kapsüllemeyi uygulayabilecek, kalıtım ve interface ile çok biçimlilik kurabilecek, veri taşıyan tipler için record kullanabilecek ve istisnalarla hata yönetebileceksin. Süre yaklaşık 4 saat.

1. Sınıf, property ve kurucu (1,5 saat)

var u = new Urun("Kalem", 12.5m, 40);
u.Sat(15);
u.StokEkle(5);
Console.WriteLine($"{u.Ad}: {u.Stok} adet, {u.Deger} TL");
Console.WriteLine($"100 satılabilir mi? {u.Sat(100)}");
try { var hatali = new Urun("X", -5m, 1); }
catch (ArgumentException e) { Console.WriteLine($"hata: {e.Message}"); }

class Urun
{
    public string Ad { get; }
    public decimal Fiyat { get; }
    public int Stok { get; private set; }
    public decimal Deger => Fiyat * Stok;

    public Urun(string ad, decimal fiyat, int stok)
    {
        if (fiyat < 0) throw new ArgumentException("Fiyat negatif olamaz.");
        Ad = ad;
        Fiyat = fiyat;
        Stok = stok;
    }

    public void StokEkle(int adet) => Stok += adet;

    public bool Sat(int adet)
    {
        if (adet > Stok) return false;
        Stok -= adet;
        return true;
    }
}

Kalem: 30 adet, 375.0 TL
100 satılabilir mi? False
hata: Fiyat negatif olamaz.
  • Property ({ get; set; }), alan gibi kullanılan ama arkasında kod olabilen üyedir. { get; } salt okunur, { get; private set; } dışarıdan okunur ama sadece sınıf içinden değişir.
  • public decimal Deger => Fiyat * Stok; her okunduğunda hesaplanan bir property'dir.
  • Kurucu sınıfla aynı adı taşır ve new ile çağrılır. Geçersiz değerleri burada reddedersen nesne asla hatalı bir durumda olamaz.
  • Stok'a dışarıdan doğrudan yazılamadığı için negatife düşemez: kapsülleme.

Revit API'deki Wall, FamilyInstance, Parameter hepsi böyle sınıflardır; wall.Width, instance.Symbol.Name birer property'dir.

2. Kalıtım ve interface (1 saat)

var sekiller = new List<ISekil> { new Dikdortgen(2, 3), new Daire(1), new Kare(2) };
foreach (var s in sekiller) Console.WriteLine($"{s.Ad}: {s.Alan:F2}");
Console.WriteLine($"toplam: {sekiller.Sum(s => s.Alan):F2}");

interface ISekil
{
    string Ad { get; }
    double Alan { get; }
}

class Dikdortgen : ISekil
{
    public double En { get; }
    public double Boy { get; }
    public Dikdortgen(double en, double boy) { En = en; Boy = boy; }
    public virtual string Ad => "dikdörtgen";
    public double Alan => En * Boy;
}

class Kare : Dikdortgen
{
    public Kare(double kenar) : base(kenar, kenar) { }
    public override string Ad => "kare";
}

class Daire(double r) : ISekil
{
    public string Ad => "daire";
    public double Alan => Math.PI * r * r;
}

toplam: 13.14
  • interface, bir tipin hangi üyelere sahip olacağını söyleyen sözleşmedir; uygulamasını içermez. Adları gelenek olarak I ile başlar. Bir sınıf birden çok interface uygulayabilir.
  • Kalıtım (Kare : Dikdortgen): Kare, Dikdortgen'in her şeyini alır. : base(...) üst sınıfın kurucusunu çağırır. C#'ta bir sınıf sadece tek sınıftan türeyebilir.
  • virtual / override: alt sınıf, üst sınıfın davranışını değiştirebilir.
  • class Daire(double r) birincil kurucudur (C# 12): küçük sınıflarda kurucu yazmayı kısaltır.

Revit'te bir eklenti yazarken IExternalCommand interface'ini uygularsın: Revit, senin sınıfının Execute metodunu bu sözleşme sayesinde çağırabilir.

3. record (45 dk)

Sadece veri taşıyan tipler için record çok kısadır; eşitlik, yazdırma ve kopyalama hazır gelir:

var a = new Nokta(3, 4);
var b = new Nokta(3, 4);
var c = a with { Y = 10 };

record Nokta(double X, double Y)
{
    public double Uzaklik() => Math.Sqrt(X * X + Y * Y);

  • with bir kopyasını, istenen alanı değiştirerek oluşturur; orijinal değişmez.

2. async ve await (1 saat)

Dosya okumak, internetten veri çekmek ya da veritabanına sorgu göndermek zaman alır. Bu sırada programın (özellikle bir masaüstü arayüzün) donmaması için asenkron yazılır:

var sw = System.Diagnostics.Stopwatch.StartNew();
Task<int> a = HesaplaAsync("A", 300);
Task<int> b = HesaplaAsync("B", 300);
int[] sonuclar = await Task.WhenAll(a, b);
Console.WriteLine($"sonuç: {sonuclar.Sum()}, yaklaşık {(sw.ElapsedMilliseconds >= 300 && sw.ElapsedMilliseconds < 550 ? "300" : "?")} ms");

static async Task<int> HesaplaAsync(string ad, int ms)
{
    await Task.Delay(ms);          // gerçek hayatta: dosya, ağ, veritabanı
    Console.WriteLine($"{ad} bitti");
    return ms / 100;
}

Çıktı (A ile B'nin sırası değişebilir):

A bitti
B bitti
sonuç: 6, yaklaşık 300 ms
  • async metot bir Task (ya da Task<T>) döndürür; await sonucu beklerken iş parçacığını serbest bırakır.
  • İki 300 ms'lik iş aynı anda yürüdü; toplam 600 değil yaklaşık 300 ms sürdü.
  • .NET'in dosya, ağ ve veritabanı metotlarının çoğunun ...Async sürümü vardır: File.ReadAllLinesAsync, HttpClient.GetStringAsync.
  • Revit API asenkron değildir: Revit'in kendi nesnelerine sadece Revit'in ana iş parçacığından, Execute içinden erişilmelidir.
