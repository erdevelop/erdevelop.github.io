GÜN 01

Tanışma ve kurulum

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Go'nun nerede ve neden kullanıldığını, felsefesini bilecek, Go'yu kurup ilk programını go run ve go build ile çalıştırabilecek ve gofmt ile kod biçimlemeyi öğreneceksin. Süre yaklaşık 4 saat.

Bu kurs hakkında: Programlama Dilleri grubundaki bütün eğitimler aynı iskeleti izler ve 7. günde aynı envanter özeti projesiyle biter. Go bilerek küçük tutulmuş bir dildir: anahtar sözcükleri bir sayfaya sığar. Bu yüzden 7 günde dilin neredeyse tamamını görebiliriz.

1. Go nerede? (30 dk)

Go (Golang), 2009'da Google'da Robert Griesemer, Rob Pike ve Ken Thompson (C ve Unix'in yaratıcılarından) tarafından geliştirildi. Amaç: büyük ekiplerin, büyük sunucu yazılımlarını hızla yazıp hızla derleyebilmesi.

  • Bulut altyapısı: Docker, Kubernetes, Terraform, Prometheus Go ile yazılmıştır.
  • Web servisleri ve API'ler: Hızlı, az bellek kullanan sunucular.
  • Komut satırı araçları: GitHub CLI (gh), Hugo.

Go'nun felsefesi: sadelik. Tek bir döngü türü (for), istisna yok (hatalar değer olarak döner), kalıtım yok (bileşim var), tek bir resmî biçimleme stili (gofmt). Derleme saniyeler sürer ve sonuç, hiçbir şeye bağımlı olmayan tek bir çalıştırılabilir dosyadır.

2. Kurulum (30 dk)

go.dev/dl adresinden işletim sistemine uygun kurulum dosyasını indir. Kontrol: go version. VS Code'a resmî Go eklentisini kur; eklenti gerekli araçları (gopls, dlv) kurmayı önerir.

3. İlk program (1,5 saat)

merhaba.go:

package main

import "fmt"

func main() {
    ad := "Ayşe"
    adet := 3
    fiyat := 12.5
    fmt.Println("Merhaba", ad+"!")
    fmt.Printf("%d adet x %.1f TL = %.1f TL\n", adet, fiyat, float64(adet)*fiyat)
}

Merhaba Ayşe!

go run merhaba.go        derle ve hemen çalıştır
go build merhaba.go      merhaba (Windows'ta merhaba.exe) dosyasını üret
  1. Her Go dosyası bir paket bildirimiyle başlar. Çalıştırılabilir programlar package main olmalı ve bir func main() içermelidir.
  2. import "fmt" biçimli giriş-çıkış paketini getirir.
  3. := değişkeni tanımlar ve tipini değerden çıkarır.
  4. fmt.Println değerleri boşlukla ayırarak yazar ve satır atlar; fmt.Printf biçimli yazar.
  5. float64(adet): Go farklı tipleri asla otomatik dönüştürmez. adet * fiyat (int ile float64) derleme hatasıdır.
  6. Noktalı virgül yok; süslü parantez açılışı satır sonunda olmak zorunda.

GÜN 02

Tipler ve değişkenler

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Go'da değişkenleri var ve := ile tanımlayabilecek, temel tipleri ve sıfır değerlerini, sabitleri ve iota'yı, açık tip dönüşümünü, fmt.Printf biçimlerini, strings ve strconv paketlerini kullanabileceksin. Süre yaklaşık 4 saat.

1. Değişkenler ve sıfır değerleri (1 saat)

package main

import "fmt"

func main() {
    var adet int
    var fiyat float64
    var ad string
    var stokta bool
    fmt.Printf("%d %v %q %v\n", adet, fiyat, ad, stokta)

    var sehir string = "Bursa"
    plaka := 16
    x, y := 3, 4
    x, y = y, x
    fmt.Println(sehir, plaka, x, y)

    var nufus int64 = 85_000_000
    var harf rune = 'ş'
    var bayt byte = 'A'
    fmt.Println(nufus, harf, string(harf), bayt)
    fmt.Printf("%T %T %T\n", plaka, 3.5, harf)
}

Bursa 16 4 3

int float64 int32
  • var ad tip değişkeni tanımlar; değer verilmezse sıfır değeri alır: sayılar 0, metin "", bool false, işaretçi ve slice nil. Go'da "başlatılmamış değişken" diye bir şey yoktur.
  • := kısa tanımdır; sadece fonksiyon içinde kullanılır.
  • int platforma göre 32 ya da 64 bittir; boyutu belli tipler: int8 ... int64, uint8 ... uint64, float32, float64.
  • byte = uint8; rune = int32 ve bir Unicode karakterini tutar ('ş' = 351).
  • %v herhangi bir değeri, %q tırnaklı metni, %T tipi yazar.

3. Tip dönüşümü ve aritmetik (45 dk)

package main

import (
    "fmt"
    "math"
)

func main() {
    a, b := 7, 2
    fmt.Println(a/b, a%b, float64(a)/float64(b))
    fiyat := 12.5
    adet := 3
    fmt.Println(fiyat * float64(adet))
    d, x, y := 3.99, 0.1, 0.2
    fmt.Println(int(d), math.Round(3.5), math.Sqrt(2))
    fmt.Println(x+y == 0.3, math.Abs((x+y)-0.3) < 1e-9)
    var u8 uint8 = 255
    u8++
    fmt.Println(u8, math.MaxInt64)
}

Kontrol akışı

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Go'da if (ön ifadeli) ile karar verebilecek, Go'nun tek döngüsü olan for'u üç biçimiyle ve range ile kullanabilecek, switch'in Go'ya özgü davranışını bileceksin. Süre yaklaşık 4 saat.

1. if (1 saat)

package main

import (
    "fmt"
    "strconv"
)

func main() {
    stok, esik := 4, 10
    if stok == 0 {
        fmt.Println("Tükendi")
    } else if stok < esik {
        fmt.Println("Az kaldı:", stok)
    } else {
        fmt.Println("Yeterli")
    }

    if eksik := esik - stok; eksik > 0 {
        fmt.Println(eksik, "adet sipariş ver")
    }

    if n, err := strconv.Atoi("12a"); err != nil {
        fmt.Println("geçersiz sayı")
    } else {
        fmt.Println(n)
    }
}

  • Koşulun etrafında parantez yok, süslü parantez zorunlu.
  • Koşul bool olmalı; if stok {} derlenmez.
  • if tanım; koşul { } kalıbı çok yaygındır: değişken sadece if-else bloğunda yaşar. Özellikle if err := ...; err != nil biçiminde göreceksin.
  • Go'da üçlü işlem (? :) yoktur; bilerek konmamıştır. Basit bir if-else yazılır.

package main

GÜN 04

Fonksiyonlar ve hatalar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Go'da fonksiyon yazıp birden çok değer döndürebilecek, Go'nun hata yönetimini (error değerleri, errors.New, fmt.Errorf ve %w) kullanabilecek, defer'i, işaretçileri ve fonksiyon değerlerini bileceksin. Süre yaklaşık 4 saat.

1. Fonksiyonlar ve çoklu dönüş (1 saat)

package main

import "fmt"

func kdvDahil(tutar, oran float64) float64 {
    return tutar * (1 + oran/100)
}

func minMax(sayilar []int) (int, int) {
    min, max := sayilar[0], sayilar[0]
    for _, x := range sayilar {
        if x < min {
            min = x
        }
        if x > max {
            max = x
        }
    }
    return min, max
}

func bolKalan(a, b int) (bolum, kalan int) {
    bolum = a / b
    kalan = a % b
    return
}

func topla(sayilar ...int) int {
    t := 0
    for _, s := range sayilar {
        t += s
    }
    return t
}

func main() {
    fmt.Println(kdvDahil(1000, 20))
    enk, enb := minMax([]int{72, 85, 64, 91, 58})
    fmt.Println(enk, enb)
    b, k := bolKalan(17, 5)
    fmt.Println(b, k, topla(), topla(1, 2, 3))
}

1200
58 91
3 2 0 6
  • Parametre tipi addan sonra yazılır; aynı tipte ardışık parametreler kısaltılabilir: tutar, oran float64.
  • Go fonksiyonları birden çok değer döndürebilir: (int, int). Bu özellik hata yönetiminin temelidir.
  • Adlı sonuçlar (bolum, kalan int) fonksiyonun başında sıfır değeriyle tanımlanır; çıplak return onları döndürür. Kısa fonksiyonlarda okunur, uzunlarda karışıktır.
  • Go'da varsayılan argüman ve aşırı yükleme yoktur.
  • Büyük harfle başlayan adlar (KdvDahil) paket dışına açıktır (export); küçük harfle başlayanlar paket içine özeldir. Go'da public / private sözcükleri yoktur, bu kural vardır.

2. Hatalar değerdir (1,5 saat)

Go'da istisna (try/catch) yoktur. Hata verebilecek fonksiyonlar son değer olarak bir error döndürür; çağıran taraf hemen kontrol eder:

package main

import (
    "errors"
    "fmt"
    "strconv"
)

var ErrStokYok = errors.New("stok yetersiz")

func sat(stok, adet int) (int, error) {
    if adet <= 0 {
        return stok, fmt.Errorf("geçersiz adet: %d", adet)
    }
    if adet > stok {
        return stok, ErrStokYok
    }
    return stok - adet, nil
}

func siparisIsle(stok int, girdi string) (int, error) {
    adet, err := strconv.Atoi(girdi)
    if err != nil {
        return stok, fmt.Errorf("sipariş okunamadı: %w", err)
    }
    return sat(stok, adet)
}

func main() {
    stok := 10
    for _, g := range []string{"3", "x", "-1", "20"} {
        yeni, err := siparisIsle(stok, g)
        if err != nil {
            fmt.Println("hata:", err, "| stok yetersiz mi?", errors.Is(err, ErrStokYok))
            continue
        }
        stok = yeni
        fmt.Println("kalan stok:", stok)
    }
}

kalan stok: 7
hata: sipariş okunamadı: strconv.Atoi: parsing "x": invalid syntax | stok yetersiz mi? false
hata: geçersiz adet: -1 | stok yetersiz mi? false
hata: stok yetersiz | stok yetersiz mi? true
  • Başarıda hata değeri nil'dir. if err != nil { ... } Go kodunda en sık göreceğin satırdır.
  • errors.New sabit bir hata, fmt.Errorf biçimli bir hata üretir.
  • %w alttaki hatayı sarar: mesaj zincirlenir ve errors.Is(err, ErrStokYok) ile asıl nedeni sorgulayabilirsin.
  • Hataları yok sayma (_); en azından bir üst katmana bağlam ekleyerek döndür.

Gerçekten kurtarılamaz durumlar (programcı hatası) için panic vardır; günlük hata yönetiminde kullanılmaz.

defer, bir çağrıyı fonksiyon bitene kadar erteler; birden çok defer ters sırayla çalışır. Kaynak açar açmaz kapatmayı yazarsın: f, err := os.Open(ad); if err != nil {...}; defer f.Close(). Fonksiyon nereden ve nasıl biterse bitsin dosya kapanır.

4. İşaretçiler ve fonksiyon değerleri (45 dk)

package main

import "fmt"

func artir(x *int) { *x++ }

func uygula(liste []int, f func(int) int) []int {
    sonuc := make([]int, 0, len(liste))
    for _, x := range liste {
        sonuc = append(sonuc, f(x))
    }
    return sonuc
}

func carpanYap(k int) func(int) int {
    return func(x int) int { return x * k }
}

func main() {
    stok := 5
    artir(&stok)
    p := &stok
    *p += 10
    fmt.Println(stok, p != nil)

    fmt.Println(uygula([]int{1, 2, 3}, func(x int) int { return x * x }))
    uc := carpanYap(3)
    fmt.Println(uygula([]int{1, 2, 3}, uc))
}

16 true
[1 4 9]
[3 6 9]
  • Go'da argümanlar kopyalanarak geçer. Bir fonksiyonun dışarıdaki değişkeni değiştirmesi için işaretçi (*int) verilir: &stok adresi, *x gösterilen değer. C'nin aksine işaretçi aritmetiği yoktur ve bellek otomatik yönetilir (çöp toplayıcı).
  • Fonksiyonlar değerdir: parametre olarak verilebilir (f func(int) int), fonksiyondan döndürülebilir ve dışarıdaki değişkenleri hatırlar (closure).

GÜN 05

Slice ve map

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Go'da dizi ile slice farkını bilecek, slice'lara append ile eleman ekleyip dilimleyebilecek, uzunluk ve kapasite kavramlarını anlayacak, map ile anahtar-değer verisi tutabilecek ve slices, maps ve sort paketleriyle sıralama yapabileceksin. Süre yaklaşık 4 saat.

1. Dizi ve slice (1,5 saat)

package main

import "fmt"

func main() {
    var dizi [3]int
    dizi[0] = 7
    fmt.Println(dizi, len(dizi))

    notlar := []int{72, 85, 64}
    notlar = append(notlar, 91, 58)
    fmt.Println(notlar, len(notlar))
    fmt.Println(notlar[1:3], notlar[:2], notlar[3:])

    alt := notlar[1:3]
    alt[0] = 100
    fmt.Println(notlar)

    kopya := make([]int, len(notlar))
    copy(kopya, notlar)
    kopya[0] = 0
    fmt.Println(notlar[0], kopya[0])

    var bos []string
    fmt.Println(bos == nil, len(bos))
    bos = append(bos, "ilk")
    fmt.Println(bos)
}

  • Dizi ([3]int) sabit boyutludur ve boyutu tipinin parçasıdır; pratikte nadiren kullanılır.
  • Slice ([]int) bir dizinin bir penceresidir: altta bir dizi, bir başlangıç, bir uzunluk ve bir kapasite. Go'da liste denince slice anlaşılır.
  • append sona ekler ve yeni slice'ı döndürür: her zaman s = append(s, x) yaz.
  • s[a:b] dilimleme, alttaki diziyi paylaşır: alt[0] = 100 orijinali de değiştirdi. Bağımsız bir kopya için make + copy ya da slices.Clone.

package main

package main

import (
    "fmt"
    "maps"
    "slices"
    "sort"

    Ad    string
    Fiyat float64

}

GÜN 06

Struct ve interface

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Go'da struct tanımlayıp metot ekleyebilecek, değer ve işaretçi alıcı farkını bilecek, kalıtım yerine gömme (embedding) kullanabilecek, interface'lerin örtük olarak uygulandığını anlayıp Stringer ve error gibi standart interface'leri yazabileceksin. Süre yaklaşık 4 saat.

1. struct ve metotlar (1,5 saat)

package main

import (
    "errors"
    "fmt"
)

type Urun struct {
    Ad    string
    Fiyat float64
    stok  int
}

func YeniUrun(ad string, fiyat float64, stok int) (*Urun, error) {
    if fiyat < 0 {
        return nil, errors.New("fiyat negatif olamaz")
    }
    return &Urun{Ad: ad, Fiyat: fiyat, stok: stok}, nil
}

func (u Urun) Deger() float64 { return u.Fiyat * float64(u.stok) }
func (u Urun) Stok() int      { return u.stok }

func (u *Urun) Sat(adet int) bool {
    if adet > u.stok {
        return false
    }
    u.stok -= adet
    return true
}

func main() {
    u, err := YeniUrun("Kalem", 12.5, 40)
    if err != nil {
        fmt.Println(err)
        return
    }
    u.Sat(15)
    fmt.Println(u.Ad, u.Stok(), u.Deger(), u.Sat(100))
    _, err = YeniUrun("X", -5, 1)
    fmt.Println("hata:", err)

    nokta := struct{ X, Y int }{3, 4}
    fmt.Printf("%v %+v\n", nokta, *u)
}

Kalem 25 312.5 false
hata: fiyat negatif olamaz
{3 4} {Ad:Kalem Fiyat:12.5 stok:25}
  • type Urun struct { ... } yeni bir tip tanımlar. Go'da sınıf yoktur; struct ve ona bağlı metotlar vardır.
  • Metot, fonksiyon adından önce bir alıcı (receiver) yazılarak tanımlanır: func (u Urun) Deger().
  • Değer alıcı (u Urun) struct'ın kopyasıyla çalışır, sadece okur. İşaretçi alıcı (u *Urun) asıl struct'ı değiştirebilir. Değiştiren metotlar her zaman işaretçi alıcı kullanır.
  • Kurucu yoktur; gelenek YeniUrun gibi bir fabrika fonksiyonu yazmaktır.
  • stok küçük harfle başladığı için paket dışından görünmez: kapsülleme.
  • %+v alan adlarıyla yazdırır.

2. Gömme (45 dk)

Go'da kalıtım yoktur; bir struct'ı başka bir struct'ın içine gömerek alanlarını ve metotlarını "devralırsın":

3. interface (1,5 saat)

interface, bir tipin hangi metotlara sahip olması gerektiğini söyler. Go'da bir tip bir interface'i örtük olarak uygular: implements yazmana gerek yoktur; gerekli metotlar varsa uygulamış sayılır.

package main

import (
    "fmt"
    "math"
)

type Sekil interface {
    Alan() float64
}

type Dikdortgen struct{ En, Boy float64 }
type Daire struct{ R float64 }

func (d Dikdortgen) Alan() float64 { return d.En * d.Boy }
func (d Daire) Alan() float64      { return math.Pi * d.R * d.R }
func (d Daire) String() string     { return fmt.Sprintf("Daire(r=%g)", d.R) }

func toplamAlan(sekiller []Sekil) float64 {
    t := 0.0
    for _, s := range sekiller {
        t += s.Alan()
    }
    return t
}

func main() {
    sekiller := []Sekil{Dikdortgen{2, 3}, Daire{1}}
    for _, s := range sekiller {
        fmt.Printf("%v: %.2f\n", s, s.Alan())
    }
    fmt.Printf("toplam: %.2f\n", toplamAlan(sekiller))

    for _, s := range sekiller {
        if d, ok := s.(Daire); ok {
            fmt.Println("daire bulundu, yarıçap", d.R)
        }
    }
}

{2 3}: 6.00
Daire(r=1): 3.14
toplam: 9.14
daire bulundu, yarıçap 1
  • Dikdortgen ve Daire, Alan() metoduna sahip oldukları için Sekil sayılır.
  • fmt.Stringer standart bir interface'tir (String() string). Bir tip bunu uygularsa fmt onu yazdırırken kullanır: Daire(r=1).
  • error da bir interface'tir (Error() string); kendi hata tiplerini böyle yazarsın.
  • s.(Daire) tip iddiasıdır: interface'in içindeki gerçek tipi sorgular. Virgül ok kalıbıyla güvenle kullanılır.
  • Go'da interface'ler genelde küçüktür (bir ya da iki metot) ve onları kullanan tarafta tanımlanır: io.Reader, io.Writer, fmt.Stringer.

Eşzamanlılık ve proje

~4 saat · 0/5 kontrol

Hedef

Gün sonunda goroutine ve channel ile eşzamanlı programlar yazabilecek, sync.WaitGroup ile goroutine'leri bekleyebilecek, haftanın konularını birleştiren envanter özeti programını yazmış olacak ve go mod ile proje ve paket yönetimini bileceksin. Süre yaklaşık 4 saat.

1. goroutine (1 saat)

goroutine, Go'nun hafif iş parçacığıdır: bir fonksiyon çağrısının önüne go yazmak onu eşzamanlı çalıştırır. Bir program on binlerce goroutine çalıştırabilir; Go'nun web sunucularında bu kadar verimli olmasının sırrı budur.

package main

import (
    "fmt"
    "sync"
    "time"
)

func stokGetir(ad string, sonuc map[string]int, mu *sync.Mutex, wg *sync.WaitGroup) {
    defer wg.Done()
    time.Sleep(100 * time.Millisecond)
    mu.Lock()
    sonuc[ad] = len(ad) * 10
    mu.Unlock()
}

func main() {
    basla := time.Now()
    var wg sync.WaitGroup
    var mu sync.Mutex
    sonuc := map[string]int{}
    for _, ad := range []string{"Kalem", "Defter", "Mouse"} {
        wg.Add(1)
        go stokGetir(ad, sonuc, &mu, &wg)
    }
    wg.Wait()
    fmt.Println(sonuc["Kalem"], sonuc["Defter"], sonuc["Mouse"])
    fmt.Println("paralel mi?", time.Since(basla) < 250*time.Millisecond)
}

50 60 50
paralel mi? true
  • Üç 100 ms'lik iş aynı anda yürüdü; toplam süre 300 değil yaklaşık 100 ms.
  • sync.WaitGroup: Add ile beklenecek goroutine sayısını artır, her biri bitince Done, ana goroutine Wait ile hepsini bekler.
  • Birden çok goroutine aynı map'e yazarsa veri bozulur (yarış durumu); sync.Mutex ile Lock/Unlock korur. go run -race yarış durumlarını tespit eder.

2. channel (1 saat)

Go'nun sloganı: "Belleği paylaşarak iletişim kurma; iletişim kurarak belleği paylaş." channel, goroutine'ler arasında değer taşıyan tipli bir borudur:

package main

import "fmt"

type Sonuc struct {
    Ad    string
    Deger float64
}

func hesapla(ad string, fiyat float64, stok int, ch chan<- Sonuc) {
    ch <- Sonuc{ad, fiyat * float64(stok)}
}

func main() {
    ch := make(chan Sonuc)
    urunler := map[string][2]float64{"Kalem": {12.5, 40}, "Defter": {45, 25}, "Mouse": {320, 12}}
    for ad, v := range urunler {
        go hesapla(ad, v[0], int(v[1]), ch)
    }
    toplam := 0.0
    for range urunler {
        s := <-ch
        toplam += s.Deger
    }
    fmt.Println("toplam:", toplam)

    is := make(chan int, 3)
    is <- 1
    is <- 2
    close(is)
    for x := range is {
        fmt.Print(x, " ")
    }
    fmt.Println()
}

toplam: 5465
1 2
  • ch <- değer gönderir, <-ch alır. Tamponsuz channel'da gönderen, alan hazır olana kadar bekler: bu bekleme, goroutine'leri doğal olarak eşler.
  • make(chan int, 3) tamponlu channel'dır: 3 değere kadar beklemeden gönderilir.
  • close(ch) gönderimin bittiğini bildirir; for x := range ch channel kapanana kadar okur.
  • chan<- Sonuc sadece gönderilebilen bir channel tipidir; fonksiyonun ne yapabileceğini belgeler.
  • select ifadesi birden çok channel'ı aynı anda bekler (zaman aşımı kurmak için sık kullanılır).

package main
