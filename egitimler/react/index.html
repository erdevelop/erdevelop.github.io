GÜN 01

React ve modern JavaScript

~4 saat · 0/6 kontrol

Hedef

Gün sonunda React'in ne olduğunu ve hangi sorunu çözdüğünü bilecek, Vite ile ilk React projeni oluşturup çalıştıracak ve React kodunda sürekli göreceğin modern JavaScript yazımlarını (ok fonksiyonu, şablon metin, yapı bozma, yayma, map, filter, modüller) okuyup yazabileceksin. Süre yaklaşık 4 saat.

1. React nedir? (30 dk)

React, kullanıcı arayüzü yazmak için bir JavaScript kütüphanesidir. Meta (Facebook) tarafından geliştirildi ve bugün web arayüzlerinin en yaygın aracıdır.

Düz JavaScript ile bir arayüz yazarken "kullanıcı butona basınca şu elemanı bul, içindeki metni değiştir, şu listeye yeni satır ekle" gibi adımları tek tek yazarsın. Uygulama büyüdükçe ekranın her parçasının o anki veriyle uyumlu kalmasını sağlamak zorlaşır.

React'te bunun yerine şunu söylersin: "Veri buyken ekran böyle görünür." Veri değişince React ekranın neresinin değişmesi gerektiğini kendisi hesaplar ve sadece o kısmı günceller. Bu yaklaşıma bildirimsel (declarative) denir.

React'in üç temel fikri:

  1. Bileşen (component): Arayüz küçük, yeniden kullanılabilir parçalardan kurulur: PanelKarti, FiltreCubugu, OzetTablosu. Her biri bir JavaScript fonksiyonudur.
  2. JSX: Bileşenler, JavaScript'in içinde HTML'e benzeyen bir yazımla ne çizeceklerini söyler.
  3. Durum (state) ve tek yönlü veri akışı: Veri yukarıdan aşağı (üst bileşenden alt bileşenlere) akar; durum değişince ilgili bileşenler yeniden çizilir.

3. Modern JavaScript: değişkenler, fonksiyonlar, metin (45 dk)

React kodu, son yıllarda JavaScript'e eklenen yazımları yoğun kullanır. Bunları bilmeden React kodu okumak zordur. Örnekleri tarayıcı konsolunda (F12) ya da Node.js ile deneyebilirsin.

const ve let: var yerine kullanılır. Değeri değişmeyecekse const, değişecekse let.

Ok fonksiyonu: function kelimesinin kısa yazımı. Gövde tek bir ifadeyse süslü parantez ve return yazılmaz.

Şablon metin: Ters tırnak içinde ${...} ile değer yerleştirilir.

const birimFiyat = 2100;
let adet = 40;
adet = adet + 8;

function tutar1(a, f) {
  return a * f;
}
const tutar2 = (a, f) => a * f;
const kdvli = t => t * 1.2;

console.log(tutar1(adet, birimFiyat), tutar2(adet, birimFiyat));
console.log(`48 adet ısıcam: ${tutar2(adet, birimFiyat).toLocaleString("tr-TR")} TL, KDV dahil ${kdvli(100800).toLocaleString("tr-TR")} TL`);

48 adet ısıcam: 100.800 TL, KDV dahil 120.960 TL

toLocaleString("tr-TR") sayıyı Türkçe biçimde (nokta binlik ayracı) yazar.

4. Nesneler ve diziler: yapı bozma ve yayma (1 saat)

Yapı bozma (destructuring) bir nesnenin ya da dizinin parçalarını tek satırda değişkenlere çıkarır. React'te bileşenlerin aldığı değerler (props) hep böyle okunur.

const panel = { kod: "P-101", kat: 3, en: 1500, boy: 3200, durum: "montaj" };
const { kod, kat, durum = "tasarım", renk = "RAL 7016" } = panel;
console.log(kod, kat, durum, renk);

const [ilk, ikinci] = ["P-101", "P-102", "P-103"];
console.log(ilk, ikinci);

function etiket({ kod, en, boy }) {
  return `${kod}: ${en}×${boy} mm`;
}
console.log(etiket(panel));

P-101 3 montaj RAL 7016
P-101 P-102
P-101: 1500×3200 mm

durum = "tasarım" varsayılan değerdir; nesnede durum olduğu için kullanılmadı. renk nesnede olmadığı için varsayılanı aldı.

Yayma (spread) ... bir nesnenin ya da dizinin içini başka birinin içine açar. React'te durumu değiştirmeden yeni bir kopya oluşturmanın standart yoludur (3. günde nedenini göreceğiz):

const panel = { kod: "P-101", kat: 3, durum: "üretim" };
const guncel = { ...panel, durum: "montaj" };
console.log(panel.durum, "→", guncel.durum);

const liste = ["P-101", "P-102"];
const yeniListe = [...liste, "P-103"];
console.log(liste.length, yeniListe.length, yeniListe);

üretim → montaj
2 3 [ 'P-101', 'P-102', 'P-103' ]

Orijinal panel ve liste değişmedi; yeni nesne ve dizi oluşturduk.

5. Dizi metotları: map, filter, find, reduce (1 saat)

React'te listeleri ekrana çizmek map ile, süzmek filter ile yapılır. Döngü yazmazsın; bu metotlar yeni bir dizi döndürür.

const paneller = [
  { kod: "P-101", kat: 3, alan: 4.8, durum: "montaj" },
  { kod: "P-102", kat: 3, alan: 4.8, durum: "üretim" },
  { kod: "P-201", kat: 4, alan: 3.84, durum: "tasarım" },
  { kod: "P-202", kat: 4, alan: 3.84, durum: "montaj" },
];

const kodlar = paneller.map(p => p.kod);
const montajda = paneller.filter(p => p.durum === "montaj");
const bul = paneller.find(p => p.kod === "P-201");
const toplamAlan = paneller.reduce((top, p) => top + p.alan, 0);

console.log(kodlar);
console.log(montajda.map(p => p.kod).join(", "));
console.log(bul.kat, "kat");
console.log(toplamAlan.toFixed(2), "m²");
console.log(paneller.some(p => p.durum === "tasarım"), paneller.every(p => p.alan > 4));

[ 'P-101', 'P-102', 'P-201', 'P-202' ]
P-101, P-202
4 kat
17.28 m²
true false
  • map: her elemanı dönüştürüp aynı uzunlukta yeni dizi verir.
  • filter: koşulu sağlayanları verir.
  • find: koşulu sağlayan ilk elemanı (yoksa undefined) verir.
  • reduce: diziyi tek bir değere indirger; ikinci argüman başlangıç değeridir.
  • some / every: en az biri / hepsi koşulu sağlıyor mu?

=== (üç eşittir) hem değeri hem tipi karşılaştırır; JavaScript'te == yerine her zaman bunu kullan.

Zincirleme: Metotlar art arda yazılabilir. "4. kattaki panellerin kodları, alfabetik ters sırayla":

const paneller = [
  { kod: "P-201", kat: 4 }, { kod: "P-101", kat: 3 }, { kod: "P-202", kat: 4 },
];
console.log(paneller.filter(p => p.kat === 4).map(p => p.kod).sort().reverse());

6. Modüller: import ve export (30 dk)

Her bileşen genellikle kendi dosyasındadır. Bir dosyadaki fonksiyonu başka dosyada kullanmak için onu export eder, diğer dosyada import edersin.

// hesap.js
export const tutar = (adet, fiyat) => adet * fiyat;   // adlı dışa aktarma
export default function etiket(kod) {                 // varsayılan dışa aktarma (dosyada bir tane)
  return `Panel ${kod}`;
}

// App.jsx
import etiket, { tutar } from "./hesap.js";

Adlı dışa aktarmalar süslü parantezle ve aynı adla alınır; varsayılan dışa aktarma süslü parantezsiz ve istediğin adla alınır. React bileşenleri genellikle export default ile dışa aktarılır; import { useState } from "react" ise React'in adlı dışa aktarmalarından birini alır.

GÜN 02

JSX ve bileşenler

~4 saat · 0/6 kontrol

Hedef

Gün sonunda JSX'in kurallarını bilecek, kendi bileşenlerini yazıp birbirinin içinde kullanabilecek, props ile bileşenlere veri gönderebilecek; bir diziyi map ve key ile listeye çevirip koşula göre farklı şeyler gösterebileceksin. Süre yaklaşık 4 saat.

Örnekler hakkında: Her örnek src/App.jsx dosyasının tamamıdır; Vite projende bu dosyanın içeriğini değiştirip kaydedersen sonucu tarayıcıda görürsün. Örneklerin altındaki çıktı, bileşenin ürettiği HTML'dir (okunaklı olsun diye her etiket ayrı satıra yazıldı).

1. JSX (45 dk)

JSX, JavaScript'in içinde HTML'e benzeyen bir yazımdır. Tarayıcı JSX'i doğrudan anlamaz; Vite onu React.createElement(...) çağrılarına çevirir. Bir bileşen, JSX döndüren sıradan bir fonksiyondur:

export default function App() {
  const proje = "Kule A";
  const katSayisi = 24;
  return (
    <div className="kart">
      <h1>{proje} cephe takibi</h1>
      <p>Toplam {katSayisi} kat, {katSayisi * 4} cephe modülü.</p>
    </div>
  );
}

<div class="kart">
<h1>Kule A cephe takibi</h1>
<p>Toplam 24 kat, 96 cephe modülü.</p>
</div>

JSX'in kuralları:

  1. Tek kök: Bileşen tek bir eleman döndürmelidir. Birden çok elemanı sarmak için gereksiz bir div yerine boş etiket (fragment) <>...</> kullanılır.
  2. Süslü parantez: { } içine herhangi bir JavaScript ifadesi yazılır: değişken, hesap, fonksiyon çağrısı. if ve for gibi deyimler yazılamaz.
  3. Bütün etiketler kapanır: <br> değil <br />, <img> değil <img ... />.
  4. Bazı öznitelik adları farklıdır: class yerine className, for yerine htmlFor; çok kelimeli öznitelikler camelCase yazılır: onClick, tabIndex.
  5. style bir nesnedir: style={{ color: "red", fontSize: 18 }}. Dıştaki süslü parantez "JavaScript başlıyor", içteki nesnenin parantezidir.
export default function App() {
  const vurgu = { color: "#1f4e79", fontWeight: 600 };
  return (
    <>
      <label htmlFor="ara">Panel ara</label>
      <input id="ara" placeholder="P-101" />
      <br />
      <span style={vurgu}>3 panel bulundu</span>
    </>
  );
}

<label for="ara">Panel ara</label>
<input id="ara" placeholder="P-101"/>
<br/>
<span style="color:#1f4e79;font-weight:600">3 panel bulundu</span>

Fragment'in kendisi HTML'de görünmez.

3. Props: bileşene veri göndermek (1 saat)

Props (properties), bir bileşene dışarıdan verilen değerlerdir; HTML özniteliği gibi yazılır. Bileşen hepsini tek bir nesne olarak alır; genellikle yapı bozma ile açılır:

function PanelKarti({ kod, kat, durum, alan = 0 }) {
  return (
    <div className="panel">
      <strong>{kod}</strong> · {kat}. kat · {alan.toFixed(2)} m² · <em>{durum}</em>
    </div>
  );
}

export default function App() {
  return (
    <section>
      <PanelKarti kod="P-101" kat={3} durum="montaj" alan={4.8} />
      <PanelKarti kod="P-201" kat={4} durum="tasarım" />
    </section>
  );
}

<section>
<div class="panel">
<strong>P-101</strong> · 3. kat · 4.80 m² · <em>montaj</em>
</div>
<div class="panel">
<strong>P-201</strong> · 4. kat · 0.00 m² · <em>tasarım</em>
</div>
</section>

  • alan = 0 varsayılan değerdir: ikinci kartta verilmediği için 0 kullanıldı.
  • Props salt okunurdur: bileşen kendi props'unu değiştirmez. Değişen veri için 3. günde durum (state) kullanacağız.

4. Listeler ve key (45 dk)

Bir diziyi ekrana çizmek için map ile her elemanı bir JSX'e dönüştürürsün:

const PANELLER = [
  { kod: "P-101", kat: 3, durum: "montaj" },
  { kod: "P-102", kat: 3, durum: "üretim" },
  { kod: "P-201", kat: 4, durum: "tasarım" },
];

export default function App() {
  return (
    <ul>
      {PANELLER.map(p => (
        <li key={p.kod}>
          {p.kod} – {p.durum}
        </li>
      ))}
    </ul>
  );
}

<ul>
<li>P-101 – montaj</li>
<li>P-102 – üretim</li>
<li>P-201 – tasarım</li>
</ul>

Her liste elemanına bir key verilmelidir: React, liste değiştiğinde (eleman eklenince, silinince, sıra değişince) hangi elemanın hangisi olduğunu bu anahtarla takip eder. key kardeşler arasında benzersiz ve kalıcı olmalıdır; veritabanı kimliği ya da kod idealdir. Dizideki sıra numarasını (index) key yapmak, liste değiştiğinde yanlış elemanın güncellenmesine yol açabilir. Key HTML'e yazılmaz; sadece React içindir. Unutursan tarayıcı konsolunda bir uyarı görürsün.

5. Koşullu gösterim (45 dk)

JSX'te if yazılamaz ama üç yol vardır:

  1. Üçlü operatör koşul ? A : B: iki seçenekten biri.
  2. &&: koşul && A, koşul doğruysa A'yı gösterir, değilse hiçbir şey.
  3. Fonksiyonun başında if ile erken dönüş: JSX dışında normal JavaScript yazabilirsin.
function DurumEtiketi({ durum }) {
  if (!durum) return null;
  const renk = durum === "montaj" ? "yesil" : durum === "üretim" ? "sari" : "gri";
  return <span className={`etiket ${renk}`}>{durum}</span>;
}

function PanelSatiri({ kod, durum, hasarli }) {
  return (
    <li>
      {kod} <DurumEtiketi durum={durum} />
      {hasarli && <strong> ⚠ hasarlı</strong>}
    </li>
  );
}

export default function App() {
  const liste = [
    { kod: "P-101", durum: "montaj", hasarli: false },
    { kod: "P-102", durum: "üretim", hasarli: true },
    { kod: "P-103", durum: "" },
  ];
  return (
    <>
      <ul>{liste.map(p => <PanelSatiri key={p.kod} {...p} />)}</ul>
      <p>{liste.length > 0 ? `${liste.length} panel` : "Panel yok"}</p>
    </>
  );
}

<ul>
<li>P-101 <span class="etiket yesil">montaj</span>
</li>
<li>P-102 <span class="etiket sari">üretim</span>
<strong> ⚠ hasarlı</strong>
</li>
<li>P-103 </li>
</ul>
<p>3 panel</p>

return null hiçbir şey çizmez: P-103'ün durumu boş olduğu için etiket çıkmadı. {...p} nesnenin bütün alanlarını ayrı ayrı prop olarak verir (kod={p.kod} durum={p.durum} ...).

&& tuzağı: Sol taraf 0 olursa React 0 yazar. {adet && <p>...</p>} yerine {adet > 0 && <p>...</p>} yaz.

6. Bileşenleri dosyalara bölmek (30 dk)

Projede her bileşen genellikle kendi dosyasında olur ve export default ile dışa aktarılır:

// src/components/PanelKarti.jsx
export default function PanelKarti({ kod, kat, durum }) {
  return <div className="panel">{kod} · {kat}. kat · {durum}</div>;
}

// src/App.jsx
import PanelKarti from "./components/PanelKarti.jsx";

export default function App() {
  return <PanelKarti kod="P-101" kat={3} durum="montaj" />;

Hedef

Örnekler hakkında: Bugünkü örnekler etkileşimlidir. Her kodun altındaki çıktı, ilk görünümün ya da kodun üstünde yazan tıklama ve yazma adımlarından sonraki görünümün HTML'idir. Bu adımlar otomatik olarak, gerçek bir tarayıcı ortamını taklit eden jsdom ile uygulandı.

1. Neden durum gerekir? (30 dk)

Bir sayacı sıradan bir değişkenle yazmayı deneyelim:

export default function App() {
  let adet = 0;
  return <button onClick={() => { adet = adet + 1; console.log(adet); }}>Adet: {adet}</button>;
}

Butona basınca konsolda 1, 2, 3 yazar ama ekrandaki "Adet: 0" değişmez. İki neden var: React, bileşeni yeniden çizmesi gerektiğini bilmiyor; çizse bile fonksiyon baştan çalışacağı için adet yine 0 olacaktı. Bileşen fonksiyonundaki yerel değişkenler her çizimde sıfırlanır.

Çözüm durum (state): React'in çizimler arasında senin için sakladığı ve değiştiğinde bileşeni yeniden çizdiği bir değer.

3. Olaylar (30 dk)

Olay işleyiciler onClick, onChange, onSubmit, onMouseEnter gibi camelCase adlı props'lara bir fonksiyon olarak verilir:

<button onClick={kaydet}>Kaydet</button>          // doğru: fonksiyonu ver

import { useState } from "react";

const SIRA = ["tasarım", "üretim", "montaj"];

    { kod: "P-101", durum: "tasarım" },
    { kod: "P-102", durum: "üretim" },
  ]);

  function ekle() {
    const yeniKod = `P-${101 + paneller.length}`;
    setPaneller([...paneller, { kod: yeniKod, durum: "tasarım" }]);
  }
  function ilerlet(kod) {
    setPaneller(paneller.map(p => {
      if (p.kod !== kod) return p;
      const i = Math.min(SIRA.indexOf(p.durum) + 1, SIRA.length - 1);
      return { ...p, durum: SIRA[i] };

    setPaneller(paneller.filter(p => p.kod !== kod));
  }

  return (
    <div>
      <button onClick={ekle}>Panel ekle</button>
      <ul>

          </li>
        ))}
      </ul>
      <p>{paneller.filter(p => p.durum === "montaj").length} / {paneller.length} montajda</p>
    </div>
  );
}

Hedef

Gün sonunda React'te form yazmanın standart yolu olan kontrollü girdileri kullanabilecek; metin, sayı, seçim ve onay kutularını duruma bağlayabilecek, formu gönderip doğrulayabilecek ve girdilerden anında hesaplanan değerler gösterebileceksin. Süre yaklaşık 4 saat.

1. Kontrollü girdi (1 saat)

HTML'de bir <input> kendi değerini kendisi tutar. React'te ise değeri durumda tutar ve girdiye geri verirsin; girdi sadece değişiklik bildirir. Böylece "doğru değer" tek bir yerde (durumda) olur. Buna kontrollü girdi denir:

  1. value={durum}: girdi her zaman durumdaki değeri gösterir.

3. Formu göndermek ve doğrulamak (1 saat)

Butona basınca ya da girdide Enter'a basınca form submit olayı üretir. Tarayıcının sayfayı yeniden yüklemesini e.preventDefault() ile durdurur, veriyi işlersin. Göndermeden önce doğrulama yaparsın: hatalar bir nesnede toplanır ve ilgili alanın yanında gösterilir.

import { useState } from "react";

const BOS = { kod: "", en: "", boy: "" };

function dogrula({ kod, en, boy }) {
  const h = {};
  if (!/^P-\d{3}$/.test(kod)) h.kod = "Kod P-123 biçiminde olmalı";
  if (!(en >= 300 && en <= 3000)) h.en = "En 300–3000 mm arası olmalı";
  if (!(boy >= 300 && boy <= 4500)) h.boy = "Boy 300–4500 mm arası olmalı";
  return h;
}

export default function App() {
  const [form, setForm] = useState(BOS);
  const [hatalar, setHatalar] = useState({});
  const [paneller, setPaneller] = useState([]);

  const degistir = e => setForm({ ...form, [e.target.name]: e.target.value });

  function gonder(e) {
    e.preventDefault();
    const sayisal = { kod: form.kod.trim(), en: Number(form.en), boy: Number(form.boy) };
    const h = dogrula(sayisal);
    setHatalar(h);
    if (Object.keys(h).length > 0) return;
    setPaneller([...paneller, sayisal]);
    setForm(BOS);
  }

  return (
    <form onSubmit={gonder} noValidate>
      {["kod", "en", "boy"].map(ad => (
        <div key={ad}>
          <input name={ad} placeholder={ad} value={form[ad]} onChange={degistir} />
          {hatalar[ad] && <small className="hata">{hatalar[ad]}</small>}
        </div>
      ))}
      <button type="submit">Ekle</button>
      <ul>{paneller.map(p => <li key={p.kod}>{p.kod}: {p.en}×{p.boy}</li>)}</ul>
    </form>
  );
}

1. Yan etki nedir? (30 dk)

Bir bileşen fonksiyonunun asıl işi, props ve duruma bakıp JSX döndürmektir; bu hesap saf olmalıdır: aynı girdiye her zaman aynı çıktı, dışarıda hiçbir şey değiştirmeden. Ama bazı işler bileşenin dışındaki dünyaya dokunur:

  • sunucudan veri çekmek,
  • sayfa başlığını (document.title) değiştirmek,
  • zamanlayıcı kurmak, pencere boyutunu dinlemek,
  • localStorage'a yazmak.

Bunlara yan etki denir ve çizim sırasında değil, çizim bittikten sonra yapılmalıdır. useEffect tam olarak bunu sağlar.

import { useEffect, useState } from "react";

export default function App() {
  const [adet, setAdet] = useState(0);
  useEffect(() => {
    document.title = `${adet} panel seçildi`;
  }, [adet]);
  return (
    <div>
      <button onClick={() => setAdet(adet + 1)}>+</button>
      <p>{adet} panel · başlık: {typeof document === "undefined" ? "" : document.title}</p>
    </div>
  );
}

<div>
<button>+</button>
<p>2 panel · başlık: 1 panel seçildi</p>
</div>

Çıktıdaki başlık bir adım geride: çizim sırasında document.title henüz eski değerdedir, efekt çizimden sonra çalışıp onu günceller. Tarayıcı sekmesinde ise her zaman güncel değeri görürsün. Bu örnek, efektin ne zaman çalıştığını göstermek için var; normalde çizimde document.title okunmaz.

2. Bağımlılık dizisi (45 dk)

useEffect(fonksiyon, bağımlılıklar) ikinci argümana göre farklı zamanlarda çalışır:

Yazım Ne zaman çalışır
useEffect(f) Her çizimden sonra
useEffect(f, []) Sadece ilk çizimden sonra (bileşen ekrana gelince)
useEffect(f, [a, b]) İlk çizimden sonra ve a ya da b değiştiğinde

Kural: efektin içinde kullandığın, bileşenden gelen her değeri (props, durum, onlardan hesaplananlar) bağımlılık dizisine yaz. Eksik yazarsan efekt eski değerlerle çalışır. VS Code'daki ESLint eklentisi (react-hooks/exhaustive-deps kuralı) eksik bağımlılıkları otomatik gösterir; Vite şablonunda hazır gelir.

Efekte ihtiyacın olmayabilir. Yeni başlayanların en sık hatası, başka bir durumdan hesaplanabilen bir değeri efektle ayrı bir duruma kopyalamaktır:

// GEREKSİZ: iki durum, bir efekt, fazladan bir çizim
const [toplam, setToplam] = useState(0);
useEffect(() => { setToplam(paneller.length); }, [paneller]);

// DOĞRU: her çizimde hesapla
const toplam = paneller.length;

Efekt, React'in dışındaki bir şeyle senkronize olmak içindir; React'in içindeki verileri birbirinden hesaplamak için değil.

3. Temizlik (45 dk)

Bir efekt zamanlayıcı kurar ya da bir olayı dinlemeye başlarsa, bileşen ekrandan kalkınca (ya da efekt yeniden çalışmadan önce) onu durdurmalıdır; yoksa arka planda çalışmaya devam eder. Efektten bir temizlik fonksiyonu döndürülür:

import { useEffect, useState } from "react";

export default function App() {
  const [saniye, setSaniye] = useState(0);
  useEffect(() => {
    const id = setInterval(() => setSaniye(s => s + 1), 1000);
    return () => clearInterval(id);
  }, []);
  return <p>Sayfa {saniye} saniyedir açık</p>;
}

React temizlik fonksiyonunu bileşen kaldırılırken ve (bağımlılıklar değiştiyse) efekt yeniden çalışmadan hemen önce çağırır. Geliştirme modunda StrictMode, her efekti bilerek bir kez kurup temizleyip yeniden kurar; temizliği unuttuysan sayaç iki kat hızlı artar ve hatayı hemen fark edersin.

4. Veri çekmek: fetch (1 saat)

Sunucudan veri çekmek, en yaygın yan etkidir. Üç durum yönetilir: yükleniyor, hata, veri.

import { useEffect, useState } from "react";

export default function App() {
  const [paneller, setPaneller] = useState([]);
  const [yukleniyor, setYukleniyor] = useState(true);
  const [hata, setHata] = useState(null);

  useEffect(() => {
    fetch("/paneller.json")
      .then(cevap => {
        if (!cevap.ok) throw new Error(`Sunucu hatası: ${cevap.status}`);
        return cevap.json();

      .then(veri => setPaneller(veri))
      .catch(e => setHata(e.message))
      .finally(() => setYukleniyor(false));
  }, []);

  if (yukleniyor) return <p>Yükleniyor…</p>;
  if (hata) return <p className="hata">{hata}</p>;
  return (
    <ul>
      {paneller.map(p => <li key={p.kod}>{p.kod} · {p.kat}. kat · {p.durum}</li>)}
    </ul>

import { useEffect, useState } from "react";

function useVeri(adres) {
  const [veri, setVeri] = useState(null);
  const [hata, setHata] = useState(null);
  useEffect(() => {
    let iptal = false;
    setVeri(null);
    setHata(null);
    fetch(adres)
      .then(c => { if (!c.ok) throw new Error(c.status); return c.json(); })
      .then(v => { if (!iptal) setVeri(v); })
      .catch(e => { if (!iptal) setHata(e.message); });
    return () => { iptal = true; };
  }, [adres]);
  return { veri, hata, yukleniyor: !veri && !hata };
}

  );

Hedef

Gün sonunda birbirine bağlı birçok durum güncellemesini useReducer ile tek bir yerde toplayabilecek, uygulamanın derinlerindeki bileşenlere Context ile veri ulaştırabilecek, bileşenleri CSS sınıflarıyla biçimlendirebilecek ve React Router ile birden çok sayfalı bir uygulamanın nasıl kurulduğunu bileceksin. 1. useReducer (1 saat 15 dk)

3. günde panel listesi için ekle, ilerlet, sil fonksiyonları yazdık ve hepsi bileşenin içinde setPaneller(...) çağırıyordu. İşlem sayısı arttıkça durum değiştirme mantığı bileşenin her yerine dağılır. useReducer bu mantığı bileşenin dışına, tek bir fonksiyona toplar.

Bir reducer, o anki durumu ve bir eylemi (action) alıp yeni durumu döndüren saf bir fonksiyondur: (durum, eylem) => yeniDurum. Eylem, ne olduğunu anlatan bir nesnedir: { tip: "ekle", panel: {...} }.

Reducer sıradan bir JavaScript fonksiyonu olduğu için React'siz test edilebilir:

export const BASLANGIC = { paneller: [], suzgec: "hepsi" };
const SIRA = ["tasarım", "üretim", "montaj"];

export function panelReducer(durum, eylem) {
  switch (eylem.tip) {
    case "ekle":
      if (durum.paneller.some(p => p.kod === eylem.panel.kod)) return durum;
      return { ...durum, paneller: [...durum.paneller, { durum: "tasarım", ...eylem.panel }] };
    case "ilerlet":
      return {
        ...durum,
        paneller: durum.paneller.map(p => p.kod !== eylem.kod ? p
          : { ...p, durum: SIRA[Math.min(SIRA.indexOf(p.durum) + 1, SIRA.length - 1)] }),
      };
    case "sil":
      return { ...durum, paneller: durum.paneller.filter(p => p.kod !== eylem.kod) };
    case "suz":
      return { ...durum, suzgec: eylem.deger };
    default:
      throw new Error(`Bilinmeyen eylem: ${eylem.tip}`);
  }
}

Bileşende useReducer(reducer, başlangıç) iki şey döndürür: durum ve dispatch fonksiyonu. Bileşen artık durumu nasıl değiştireceğini bilmez; sadece "ne olduğunu" bildirir:

2. Context: prop delme sorunu (1 saat)

Tema (açık/koyu), dil ya da oturum açmış kullanıcı gibi bilgileri uygulamanın birçok yerindeki bileşen kullanır. Bunları props ile en üstten en alta, aradaki her bileşenden geçirerek taşımak (prop delme, prop drilling) hem yorucu hem kırılgandır: aradaki bileşenler kullanmadıkları props'ları sadece iletmek için alır.

Context, bir değeri ağacın bir noktasında sağlar ve altındaki herhangi bir bileşenin doğrudan okumasına izin verir:

  1. createContext(varsayılan) ile bir context oluştur.
  2. Bir üst bileşende <Context value={...}> ile değeri sağla.
  3. Alttaki bileşenlerde useContext(Context) ile oku.
import { createContext, useContext, useState } from "react";

const TemaContext = createContext("acik");

function Baslik() {
  const tema = useContext(TemaContext);
  return <h2 className={`baslik ${tema}`}>Kule A ({tema} tema)</h2>;
}

function Kart() {
  return (
    <section>
      <Baslik />
      <p>Kart, temayı bilmiyor ve props olarak geçirmiyor.</p>

}

export default function App() {
  const [tema, setTema] = useState("acik");
  return (
    <TemaContext value={tema}>
      <button onClick={() => setTema(t => (t === "acik" ? "koyu" : "acik"))}>Temayı değiştir</button>
      <Kart />
    </TemaContext>
  );
}

Reducer ve Context birlikte: Büyük uygulamalarda dispatch fonksiyonu Context ile bütün ağaca verilir; derindeki bir buton doğrudan dispatch({ tip: "sil", kod }) çağırabilir. Yarınki projede bu kalıbı kullanacağız.

Context'i her şey için kullanma. Sadece iki seviye aşağı inen bir değer için props daha açıktır: bileşene bakınca neye ihtiyaç duyduğunu görürsün.

Hedef

Kursun son gününde öğrendiklerini birleştirip bir cephe paneli takip uygulaması yazacaksın: panel ekleme formu, durum ilerletme ve silme, süzme ve arama, kat bazında özet ve tarayıcıyı kapatıp açınca kaybolmayan veri. 1. Planlamak: ekrandan bileşen ağacına (30 dk)

Kod yazmadan önce ekranı kâğıda çiz ve kutulara böl. Her kutu bir bileşen adayıdır:

  1. Başlık ve özet: toplam panel, toplam alan, durum dağılımı.
  2. Form: kod, kat, en, boy, tip; "Ekle" butonu.
  3. Süzgeç çubuğu: duruma göre süz, koda göre ara.
  4. Tablo: her satırda panel bilgisi, "İlerlet" ve "Sil" butonları.

Sonra durumu belirle. Kendine şu soruyu sor: "Bu bilgi zamanla değişiyor mu ve başka bir şeyden hesaplanabiliyor mu?"

3. Veri katmanı: veri.js (45 dk)

Reducer ve hesaplar React'ten bağımsız, saf JavaScript'tir:

export const DURUMLAR = ["tasarım", "üretim", "montaj"];
export const BOS = { paneller: [], suzgec: "hepsi", arama: "" };

export const alan = p => (p.en * p.boy) / 1e6;

export function reducer(d, e) {
  switch (e.tip) {
    case "ekle":
      if (d.paneller.some(p => p.kod === e.panel.kod)) return d;
      return { ...d, paneller: [...d.paneller, { ...e.panel, durum: "tasarım" }] };
    case "ilerlet":
      return {
        ...d,
        paneller: d.paneller.map(p => {
          if (p.kod !== e.kod) return p;
          const i = Math.min(DURUMLAR.indexOf(p.durum) + 1, DURUMLAR.length - 1);
          return { ...p, durum: DURUMLAR[i] };
        }),
      };
    case "sil":
      return { ...d, paneller: d.paneller.filter(p => p.kod !== e.kod) };
    case "suz":
      return { ...d, suzgec: e.deger };
    case "ara":
      return { ...d, arama: e.deger };
    default:
      throw new Error(`Bilinmeyen eylem: ${e.tip}`);
  }
}

export function gorunenler({ paneller, suzgec, arama }) {
  const a = arama.trim().toUpperCase();
  return paneller
    .filter(p => suzgec === "hepsi" || p.durum === suzgec)
    .filter(p => !a || p.kod.includes(a))
    .toSorted((x, y) => x.kat - y.kat || x.kod.localeCompare(y.kod));
}

export function ozet(paneller) {
  const sayi = Object.fromEntries(DURUMLAR.map(s => [s, 0]));
  for (const p of paneller) sayi[p.durum]++;
  const toplamAlan = paneller.reduce((t, p) => t + alan(p), 0);
  return { adet: paneller.length, toplamAlan, sayi };
}

4. Context ve kalıcılık: PanelContext.jsx (45 dk)

Sağlayıcı bileşen reducer'ı kurar, durumu localStorage'dan yükler ve her değişiklikte geri yazar. localStorage, tarayıcının siteye ayırdığı küçük (yaklaşık 5 MB) bir anahtar–değer deposudur; sadece metin saklar, bu yüzden JSON'a çeviririz.

import { createContext, useContext, useEffect, useReducer } from "react";
import { BOS, reducer } from "./veri.js";

const ANAHTAR = "panel-takip-v1";
const PanelContext = createContext(null);

function yukle() {
  try {
    const kayit = JSON.parse(localStorage.getItem(ANAHTAR));
    return kayit ? { ...BOS, paneller: kayit } : BOS;
  } catch {
    return BOS;
  }
}

export function PanelSaglayici({ children }) {
  const [durum, dispatch] = useReducer(reducer, undefined, yukle);
  useEffect(() => {
    localStorage.setItem(ANAHTAR, JSON.stringify(durum.paneller));
  }, [durum.paneller]);
  return <PanelContext value={{ durum, dispatch }}>{children}</PanelContext>;
}

export function usePaneller() {
  const deger = useContext(PanelContext);
  if (!deger) throw new Error("usePaneller, PanelSaglayici içinde kullanılmalı");
  return deger;
}
  • useReducer(reducer, undefined, yukle): üçüncü argüman tembel başlatıcıdır; localStorage sadece ilk çizimde bir kez okunur.
  • Sadece paneller saklanıyor; süzgeç ve arama her açılışta sıfırlanır.
  • try/catch: kayıt bozuksa uygulama çökmesin, boş başlasın. Kayıt biçimini ileride değiştirirsen anahtar adındaki v1'i artırırsın.
  • usePaneller özel hook'u, bileşenlerin Context'i yanlış yerde kullanmasını anlaşılır bir hatayla yakalar.

import { useState } from "react";
import { usePaneller } from "./PanelContext.jsx";

const BOS_FORM = { kod: "", kat: "", en: "1500", boy: "3200", tip: "cam" };

export default function PanelForm() {
  const { durum, dispatch } = usePaneller();
  const [f, setF] = useState(BOS_FORM);
  const [hata, setHata] = useState("");
  const degistir = e => setF({ ...f, [e.target.name]: e.target.value });

  function gonder(e) {
    e.preventDefault();
    const kod = f.kod.trim().toUpperCase();
    if (!/^P-\d{3}$/.test(kod)) return setHata("Kod P-123 biçiminde olmalı");
    if (durum.paneller.some(p => p.kod === kod)) return setHata(`${kod} zaten var`);
    if (!(Number(f.kat) > 0)) return setHata("Kat girilmeli");
    dispatch({ tip: "ekle", panel: { kod, kat: Number(f.kat), en: Number(f.en), boy: Number(f.boy), tip: f.tip } });
    setF({ ...BOS_FORM, kat: f.kat, tip: f.tip });
    setHata("");
  }

  return (
    <form onSubmit={gonder} className="form">
      <input name="kod" placeholder="Kod (P-101)" value={f.kod} onChange={degistir} />
      <input name="kat" type="number" placeholder="Kat" value={f.kat} onChange={degistir} />
      <input name="en" type="number" value={f.en} onChange={degistir} />
      <input name="boy" type="number" value={f.boy} onChange={degistir} />
      <select name="tip" value={f.tip} onChange={degistir}>
        <option value="cam">Cam</option>
        <option value="kompozit">Kompozit</option>
        <option value="taş">Taş</option>
      </select>
      <button type="submit">Ekle</button>
      {hata && <small className="hata">{hata}</small>}
    </form>
  );
}
