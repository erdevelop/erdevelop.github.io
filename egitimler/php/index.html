Tanışma ve kurulum

Hedef

Gün sonunda PHP'nin nerede kullanıldığını bilecek, PHP'yi kurup komut satırında ve yerleşik web sunucusuyla çalıştırabilecek, echo ile çıktı verebilecek ve PHP'yi HTML içine yerleştirebileceksin. Süre yaklaşık 4 saat.

1. PHP nerede? (30 dk)

PHP, 1994'te Rasmus Lerdorf'un kişisel ana sayfası için yazdığı küçük araçlardan doğdu. Bugün sunucu tarafı dili bilinen web sitelerinin büyük çoğunluğunda PHP çalışır.

  • WordPress: Web sitelerinin yaklaşık beşte biri (ve kurumsal içerik sitelerinin çoğu).
  • Laravel ve Symfony: Modern, büyük web uygulamaları için çatılar.
  • E-ticaret: WooCommerce, Magento, OpenCart; Türkiye'deki birçok e-ticaret altyapısı.
  • Wikipedia (MediaWiki) ve Facebook'un ilk sürümü PHP'ydi.

PHP'nin çalışma biçimi: tarayıcı bir sayfa ister → sunucu PHP kodunu çalıştırır → ortaya çıkan HTML tarayıcıya gider. Kullanıcı PHP kodunu hiç görmez.

PHP 7 ve 8 ile dil çok değişti: hız birkaç kat arttı, tip bildirimleri, match, enum'lar, readonly özellikler geldi. İnternette gördüğün eski PHP örneklerinin (mysql_query, tipsiz kod) çoğu artık önerilmez.

Windows: En kolay yol XAMPP ya da Laragon kurmaktır; PHP, Apache ve MySQL birlikte gelir. Ya da php.net'ten yalnızca PHP'yi indirip klasörünü PATH'e ekle. macOS: brew install php. Linux: sudo apt install php-cli.

  • PHP kodu <?php ile başlar. Sadece PHP içeren dosyalarda kapanış ?> yazılmaz.
  • Değişkenler $ ile başlar; tip yazılmaz.
  • Her ifade noktalı virgülle biter.

4. HTML içinde PHP (1 saat)

index.php:

<!DOCTYPE html>
<html lang="tr">
<body>
  <h1>Ürünler</h1>
  <?php $urunler = ["Kalem", "Defter", "Mouse"]; ?>
  <ul>
    <?php foreach ($urunler as $u): ?>
      <li><?= $u ?></li>
    <?php endforeach; ?>
  </ul>
  <p>Saat: <?= date("H:i") ?></p>
</body>
</html>

Klasörde php -S localhost:8000 çalıştır ve tarayıcıda http://localhost:8000 aç. Sayfanın kaynağına bakarsan sadece HTML görürsün.

  • <?= ifade ?> kısaltması <?php echo ifade; ?> demektir.
  • foreach (...): ... endforeach; HTML ile karışık kodda okunurluğu artıran alternatif yazımdır.
  • Gerçek projelerde mantık ve görünüm ayrı dosyalarda tutulur (Laravel'in Blade şablonları gibi).

Alıştırma: Adını ve doğum yılını değişkenlere yazıp yaşını date("Y") ile hesaplayan bir sayfa yap ve yerleşik sunucuda aç.

GÜN 04

Fonksiyonlar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda PHP'de tip bildirimli fonksiyonlar yazabilecek, varsayılan ve adlı argümanları, nullable ve birleşik tipleri, değişken sayıda parametreyi, referansla geçirmeyi, ok fonksiyonlarını ve closure'ları kullanabileceksin. Süre yaklaşık 4 saat.

1. Fonksiyonlar ve tipler (1,5 saat)

<?php
declare(strict_types=1);

function kdvDahil(float $tutar, float $oran = 20): float {
    return $tutar * (1 + $oran / 100);
}

function etiket(string $ad, int $adet = 1, string $birim = "adet"): string {
    return "$ad: $adet $birim";
}

function minMax(array $sayilar): array {
    return [min($sayilar), max($sayilar)];
}

function topla(int ...$sayilar): int {
    return array_sum($sayilar);
}

function bul(array $liste, string $aranan): ?int {
    $i = array_search($aranan, $liste, true);
    return $i === false ? null : $i;
}

function goster(int|string $x): string {
    return gettype($x) . ":" . $x;
}

echo kdvDahil(1000), " ", kdvDahil(1000, 10), "\n";
echo etiket("Kablo", birim: "metre", adet: 50), "\n";
[$enk, $enb] = minMax([72, 85, 64, 91, 58]);
echo "$enk $enb ", topla(), " ", topla(1, 2, 3), " ", topla(...[4, 5]), "\n";
var_dump(bul(["Adana", "Bursa"], "Bursa"), bul(["Adana"], "Rize"));
echo goster(5), " ", goster("beş"), "\n";

  • Parametre tipi addan önce, dönüş tipi ): tip biçiminde yazılır.
  • Adlı argümanlar (PHP 8): etiket("Kablo", birim: "metre", adet: 50).
  • ?int: int ya da null (nullable). int|string: birleşik tip. Değer döndürmeyen fonksiyon : void.
  • ...$sayilar değişken sayıda argümanı dizi olarak toplar; ...[4, 5] diziyi açarak verir.
  • [$a, $b] = dizi; diziyi değişkenlere açar.
  • array_search(..., true) katı karşılaştırma yapar; bulamazsa false döndürür. 0 (ilk indeks) ile false'u karıştırmamak için === şarttır.

3. Ok fonksiyonları ve closure'lar (1,5 saat)

<?php
$ikiKati = fn(int $x): int => $x * 2;
echo $ikiKati(21), "\n";

$kdv = 1.2;
$kdvli = fn($x) => $x * $kdv;
echo $kdvli(250), "\n";

$sayac = 0;
$say = function () use (&$sayac) {
    $sayac++;
};
$say();
$say();
echo $sayac, "\n";

function carpanYap(int $k): Closure {
    return fn($x) => $x * $k;
}
$ucKati = carpanYap(3);

$notlar = [72, 85, 64, 91, 58];
echo implode(" ", array_map($ucKati, [1, 2, 3])), "\n";
echo implode(" ", array_filter($notlar, fn($n) => $n >= 70)), "\n";
usort($notlar, fn($a, $b) => $b <=> $a);
echo implode(" ", $notlar), "\n";
$fonk = 'strtoupper';
echo $fonk("bursa"), " ", implode(",", array_map(strlen(...), ["ab", "abc"])), "\n";

  • Ok fonksiyonu fn($x) => ifade tek ifadelik isimsiz fonksiyondur ve dışarıdaki değişkenleri ($kdv) otomatik yakalar (değer olarak).
  • function () use ($x) { } çok satırlı closure'dır; dışarıdan ne alacağı use ile yazılır. Değiştirmek için use (&$sayac).
  • <=> (uzay gemisi) karşılaştırma işlemidir: -1, 0 ya da 1 döndürür; sıralama fonksiyonlarında kullanılır.
  • strlen(...) bir fonksiyonu değer olarak verir (PHP 8.1).

Sınıflar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda PHP'de sınıf yazıp kurucu özellik tanıtımı ve readonly özellikleri kullanabilecek, kalıtım, soyut sınıf ve interface ile çalışabilecek, PHP 8.1 enum'larını tanımlayabilecek, static üyeleri bilecek ve istisnaları fırlatıp yakalayabileceksin. Süre yaklaşık 4 saat.

1. Sınıflar (1,5 saat)

<?php
declare(strict_types=1);

class Urun
{
    private int $stok;

    public function __construct(
        public readonly string $ad,
        private float $fiyat,
        int $stok = 0,
    ) {
        if ($fiyat < 0) {
            throw new InvalidArgumentException("$ad: fiyat negatif olamaz");
        }
        $this->stok = $stok;
    }

    public function getStok(): int { return $this->stok; }

    public function deger(): float { return $this->fiyat * $this->stok; }

    public function sat(int $adet): bool
    {
        if ($adet > $this->stok) return false;
        $this->stok -= $adet;
        return true;
    }

    public function __toString(): string { return "{$this->ad} ({$this->stok} adet)"; }
}

$u = new Urun("Kalem", 12.5, 40);
$u->sat(15);
echo $u, " ", $u->deger(), " ", var_export($u->sat(100), true), "\n";
try {
    $u->ad = "X";
} catch (Error $e) {
    echo get_class($e), "\n";
}
try {
    new Urun("X", -5);
} catch (InvalidArgumentException $e) {
    echo "hata: ", $e->getMessage(), "\n";
}

Error
hata: X: fiyat negatif olamaz
  • Nesne new ile oluşturulur; üyelere -> ile erişilir, sınıf içinde $this->.
  • Kurucu özellik tanıtımı (PHP 8): kurucu parametresinin önüne public/private yazmak, aynı adla bir özellik tanımlar ve atar.
  • readonly (PHP 8.1): bir kez atanır, sonra değiştirilemez; değiştirmeye çalışmak Error fırlatır.
  • private sınıf dışından erişilemez; dışarıya metotlarla (getStok) açılır: kapsülleme.
  • __toString nesnenin echo ile nasıl yazılacağını belirler. Metinde {$this->ad} süslü parantezle yazılır.

2. Kalıtım ve interface (1 saat)

<?php
interface Sekil
{
    public function alan(): float;
}

abstract class TemelSekil implements Sekil
{
    public function aciklama(): string
    {
        return static::class . ": " . number_format($this->alan(), 2);
    }
}

class Dikdortgen extends TemelSekil
{
    public function __construct(private float $en, private float $boy) {}
    public function alan(): float { return $this->en * $this->boy; }
}

final class Daire extends TemelSekil
{
    public function __construct(private float $r) {}
    public function alan(): float { return M_PI * $this->r ** 2; }
}

$sekiller = [new Dikdortgen(2, 3), new Daire(1)];
foreach ($sekiller as $s) {
    echo $s->aciklama(), "\n";
}
echo number_format(array_sum(array_map(fn(Sekil $s) => $s->alan(), $sekiller)), 2), "\n";
var_dump($sekiller[1] instanceof Sekil);

bool(true)

  • abstract class doğrudan örneklenemez; ortak kodu taşır. extends ile türetilir (PHP'de tek kalıtım vardır).

4. İstisnalar (30 dk)

<?php
class StokYetersiz extends Exception
{
    public function __construct(public readonly int $istenen, public readonly int $stok)
    {
        parent::__construct("$istenen istendi, stokta $stok var");
    }
}

function siparis(int $stok, string $girdi): int
{
    if (!ctype_digit(trim($girdi))) {
        throw new InvalidArgumentException("sayı değil: $girdi");
    }
    $adet = (int) $girdi;
    if ($adet > $stok) {
        throw new StokYetersiz($adet, $stok);
    }
    return $stok - $adet;
}

$stok = 10;
foreach (["3", "x", "20", " 2 "] as $g) {
    try {
        $stok = siparis($stok, $g);
        echo "kalan $stok\n";
    } catch (StokYetersiz $e) {
        echo "stok hatası: ", $e->getMessage(), "\n";
    } catch (InvalidArgumentException $e) {
        echo "geçersiz: ", $e->getMessage(), "\n";
    } finally {
        // her durumda çalışır (bağlantı kapatma vb.)
    }
}

geçersiz: sayı değil: x
stok hatası: 20 istendi, stokta 7 var

throw new ... fırlatır, try/catch yakalar, finally her durumda çalışır. Kendi istisna sınıfın Exception'dan türer.

2. PDO ve hazırlanmış ifadeler (1 saat)

<?php
$db = new PDO("sqlite::memory:", options: [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

$ekle = $db->prepare("INSERT INTO urun VALUES (:ad, :fiyat, :stok)");
foreach ([["Kalem", 12.5, 40], ["Kulaklık", 850, 5], ["Mouse", 320, 12]] as [$ad, $fiyat, $stok]) {
