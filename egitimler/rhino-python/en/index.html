Python in Rhino

A 7-day programme for automating repetitive work in Rhino with a few lines of Python. You write your first script in Rhino 8's ScriptEditor, create points, curves and surfaces with rhinoscriptsyntax, get selections and values from the user, and organise layers and object information. You get to know RhinoCommon's geometry classes and write a tool that divides a façade surface into panels, numbers them and writes the panel list to CSV. In the last two days you use the same knowledge in Grasshopper's Python component and, without opening Rhino, with the rhino3dm library.

Architects, façade and product designers using Rhino who want to automate repetitive modelling and numbering. Basic Rhino knowledge is enough; no Python knowledge needed, the necessary part is explained on the first day. The Rhino and Grasshopper courses are good preparation.

DAY 01

Introduction to Python in Rhino

~4 hours · 0/6 checks

Goal

By the end of the day you will open the ScriptEditor in Rhino 8 and write your first Python script, know the difference between Python 3 and IronPython, understand what rhinoscriptsyntax is and learn the Python basics you will use every day when scripting (variables, lists, loops, conditions, functions). Time about 4 hours.

About this course: The examples are chosen from common tasks in façade and product design: generating panels, numbering, sorting into layers, producing lists. Code blocks are of two kinds. Those running inside Rhino you paste into the ScriptEditor and run; no output is shown below them, you see the result in Rhino. The outputs under pure Python examples are real run results.

1. Why Python? (30 min)

In Rhino every task is done with a command, but running the same command one by one for 300 panels is both tiring and error-prone. A script:

  • does repetitive tasks in seconds: numbering 300 panels, colouring by layer, listing the lengths of all curves;
  • creates rule-based geometry: dividing a surface into panels of given sizes, arraying brackets along a curve;
  • performs checks: finding non-planar panels and dimensions exceeding limits;
  • extracts data: transferring the panel list to Excel, an order list or fabrication drawings.

Grasshopper does similar work with visual programming. Python is text-based: it is more comfortable for conditional and repetitive logic, file operations and tools that talk to the user on screen. They are not rivals; on day 6 we will also use Python inside Grasshopper.

2. ScriptEditor and Python versions (45 min)

In Rhino 8 type ScriptEditor in the command line. In the window that opens:

  1. Create a new script with the + at the top left and choose Python 3 as the language.
  2. Write the code.
  3. Press the Run button (green triangle) or F5. print output appears in the console below.
  4. Save the script as .py. You can later run the saved script with the RunPythonScript command or a toolbar button.

Rhino 8 has two Pythons:

This course uses Python 3. If you use Rhino 7, the EditPythonScript command opens the IronPython editor; the rhinoscriptsyntax and RhinoCommon parts of the course work largely unchanged there, you only need to watch the Python 2 syntax differences.

3. First script (45 min)

Type this in the ScriptEditor and run it:

#! python3
import rhinoscriptsyntax as rs

point = rs.AddPoint([0, 0, 0])
line = rs.AddLine([0, 0, 0], [3000, 0, 0])
circle = rs.AddCircle([1500, 0, 0], 500)
print("Added:", point, line, circle)

A point, a 3000-unit line and a 500-unit-radius circle in its middle appear on screen. In the console you see three long identities; these are the unique numbers Rhino gives every object (GUID). In the next steps we will reach objects through these identities.

  • rhinoscriptsyntax (rs for short) is a set of easy-to-use Python functions close to Rhino's commands. rs.AddLine is the script equivalent of Rhino's Line command.
  • Points are given as a list of three numbers in the form [x, y, z].
  • Units are the document's units. Façade files usually use millimetres, so dimensions in the examples are mm.

Ctrl+Z in Rhino is enough to undo: everything the script did is a single undo step.

4. Python basics: variables and lists (45 min)

Knowing a small part of Python is enough to write scripts. The examples in this section don't need Rhino; they give the same output in the ScriptEditor or in any Python on your computer.

width = 1500          # integer (int)
height = 3200.0       # decimal number (float)
kind = "glass"        # text (str)
urgent = False       # boolean (bool)

area = width * height / 1_000_000
print(kind, "panel:", width, "x", height, "mm =", area, "m²")
print(f"{kind} panel {area:.2f} m², urgent: {urgent}")

glass panel 4.80 m², urgent: False

f"..." is formatted text: the value in curly braces is inserted, :.2f means two decimal places. 1_000_000 is one million; the underscore is only for readability.

6. Functions (30 min)

You put repeated calculations into a function. It is defined with def and returns a value with return. Arguments with default values use the default if not given in the call:

def panel_area(width, height):
    """Returns the panel area in m² (dimensions in mm)."""
    return width * height / 1_000_000


def glass_weight(width, height, total_thickness=12):
    """Glass weight about 2.5 kg / m² / mm."""
    return panel_area(width, height) * total_thickness * 2.5


print(round(panel_area(1500, 3200), 2))
print(round(glass_weight(1500, 3200), 1), "kg")
print(round(glass_weight(1500, 3200, total_thickness=16), 1), "kg")

4.8
144.0 kg
192.0 kg

The triple-quoted text (docstring) describes what the function does; the ScriptEditor shows it when you hover over the function.

Now combine what you learned in Rhino. The script below puts a point at the corner of each panel and a line on each floor for a 5-floor × 4-axis façade grid:

#! python3
import rhinoscriptsyntax as rs

PANEL_WIDTH = 1500
FLOOR_HEIGHT = 3200

rs.EnableRedraw(False)
for floor in range(5):
    z = floor * FLOOR_HEIGHT
    rs.AddLine([0, 0, z], [4 * PANEL_WIDTH, 0, z])
    for axis in range(5):
        rs.AddPoint([axis * PANEL_WIDTH, 0, z])
rs.EnableRedraw(True)
print("Grid done")

rs.EnableRedraw(False) stops redrawing the screen each time an object is added; it noticeably speeds up scripts adding many objects. Don't forget to set it to True at the end.

1. Points and polylines (45 min)

In rhinoscriptsyntax a point is a [x, y, z] list. Functions that add points and draw curves take lists of points:

Function Rhino command What it creates
rs.AddPoint(p) Point Point
rs.AddPoints(items) Points Several points
rs.AddLine(a, b) Line Line
rs.AddPolyline(items) Polyline Polyline; closed if the first point is repeated at the end
rs.AddCurve(items, degree) Curve NURBS curve from control points
rs.AddInterpCurve(items) InterpCrv Curve through points
rs.AddCircle(center, r) Circle Circle
rs.AddRectangle(plane, width, height) Rectangle Rectangle

A function drawing the outer frame of a façade panel as a closed polyline:

#! python3
import rhinoscriptsyntax as rs


def draw_panel(x, z, width, height):
    p1 = [x, 0, z]
    p2 = [x + width, 0, z]
    p3 = [x + width, 0, z + height]
    p4 = [x, 0, z + height]
    return rs.AddPolyline([p1, p2, p3, p4, p1])


guid = draw_panel(0, 0, 1500, 3200)
print("closed:", rs.IsCurveClosed(guid), "length:", rs.CurveLength(guid))

In the console you should see closed: True length: 9400.0 (closed?, length; perimeter: 2 × (1500 + 3200)). Functions return the GUID of the object they create; query functions such as rs.IsCurveClosed and rs.CurveLength also take this identity.

Check dimensions before the script. If you write calculations that don't need Rhino (corner points, lengths) in a separate function, you can try them without opening Rhino:

def panel_corners(x, z, width, height):
    return [[x, 0, z], [x + width, 0, z], [x + width, 0, z + height], [x, 0, z + height]]


def perimeter(points):
    total = 0.0
    for a, b in zip(points, points[1:] + points[:1]):
        total += sum((b[i] - a[i]) ** 2 for i in range(3)) ** 0.5
    return total


k = panel_corners(0, 0, 1500, 3200)
print(k)
print("perimeter:", perimeter(k))

[[0, 0, 0], [1500, 0, 0], [1500, 0, 3200], [0, 0, 3200]]
perimeter: 9400.0

points[1:] + points[:1] shifts the list by one; with zip each corner is paired with the next and the last corner connects to the first. The distance between two points is the square root of the sum of the squares of the coordinate differences.

2. Arraying along a curve (1 hour)

Dividing a curve into equal parts and placing an object at each point is a very common task: anchor brackets along an edge, posts along a balustrade. rs.DivideCurve(curve, n) divides the curve into n parts and returns n + 1 points (for an open curve):

#! python3
import rhinoscriptsyntax as rs

curve = rs.GetObject("Select the curve for brackets", rs.filter.curve)
if curve:
    length = rs.CurveLength(curve)
    spacing = 1200
    count = max(1, int(round(length / spacing)))
    points = rs.DivideCurve(curve, count)
    rs.EnableRedraw(False)
    for p in points:
        bracket = rs.AddBox([[p[0] - 60, p[1] - 40, p[2] - 100], [p[0] + 60, p[1] - 40, p[2] - 100],
                            [p[0] + 60, p[1] + 40, p[2] - 100], [p[0] - 60, p[1] + 40, p[2] - 100],
                            [p[0] - 60, p[1] - 40, p[2]], [p[0] + 60, p[1] - 40, p[2]],
                            [p[0] + 60, p[1] + 40, p[2]], [p[0] - 60, p[1] + 40, p[2]]])
    rs.EnableRedraw(True)
    print(f"{len(points)} brackets, actual spacing {length / count:.0f} mm")
  • rs.GetObject asks the user to select an object (we will see it in detail tomorrow); rs.filter.curve allows only curves to be selected.
  • Instead of hitting the spacing exactly we rounded the count; the actual spacing varies slightly with curve length. This is also the method used on site: brackets are equally spaced.
  • rs.AddBox takes eight corner points (four bottom, four top).

Let's try the count and spacing calculation without Rhino:

def bracket_count(length, target_spacing):
    count = max(1, int(round(length / target_spacing)))
    return count + 1, length / count


for L in [5000, 7300, 12450]:
    n, a = bracket_count(L, 1200)
    print(f"{L} mm curve → {n} brackets, spacing {a:.1f} mm")

5000 mm curve → 5 brackets, spacing 1250.0 mm
7300 mm curve → 7 brackets, spacing 1216.7 mm
12450 mm curve → 11 brackets, spacing 1245.0 mm

A curved façade surface from two different curves at the bottom and top:

#! python3
import rhinoscriptsyntax as rs

bottom = rs.AddInterpCurve([[0, 0, 0], [6000, 1200, 0], [12000, 0, 0]])
top = rs.AddInterpCurve([[0, 0, 12800], [6000, 2000, 12800], [12000, 0, 12800]])
facade = rs.AddLoftSrf([bottom, top])
if facade:
    print("surface:", facade[0], "area:", round(rs.SurfaceArea(facade[0])[0] / 1e6, 1), "m²")

rs.AddLoftSrf returns a list (a loft can create several surfaces); that's why we used facade[0]. rs.SurfaceArea also returns a [area, error] list. This surface will be the façade we divide into panels on day 5; don't forget to save it.

Extruding a profile along a straight path (for example a mullion section):

#! python3
import rhinoscriptsyntax as rs

section = rs.AddRectangle(rs.WorldXYPlane(), 60, 150)
mullion = rs.ExtrudeCurveStraight(section, [0, 0, 0], [0, 0, 3200])
rs.CapPlanarHoles(mullion)
print("solid:", rs.IsPolysurfaceClosed(mullion))

CapPlanarHoles closes the open ends and turns the object into a closed solid.

4. Layers, colours and names (45 min)

Keeping the created objects organised is at least as important a job for a script as the geometry. rs.AddLayer(name, color) creates a layer (leaves it untouched if it exists); :: is the sub-layer separator:

#! python3
import rhinoscriptsyntax as rs

LAYERS = {
    "FACADE::Panel::Glass": (120, 170, 220),
    "FACADE::Panel::Composite": (180, 180, 180),
    "FACADE::Bracket": (220, 120, 40),
}
for name, color in LAYERS.items():
    if not rs.IsLayer(name):
        rs.AddLayer(name, color)

panel = rs.AddPolyline([[0, 0, 0], [1500, 0, 0], [1500, 0, 3200], [0, 0, 3200], [0, 0, 0]])
rs.ObjectLayer(panel, "FACADE::Panel::Glass")
rs.ObjectName(panel, "P-101")
print(rs.ObjectLayer(panel), rs.ObjectName(panel))

In rhinoscriptsyntax many functions do two jobs: with one argument they read (rs.ObjectLayer(id) returns the layer name), with two arguments they write (rs.ObjectLayer(id, "name")). rs.ObjectColor(id, (r, g, b)) gives the object a colour independent of its layer; most of the time taking colour from the layer (the default) is tidier.

Collecting layer names and colours in one dictionary means writing the team's layer standard into the script: every script creates the same layers with the same names.

5. Keeping GUIDs and using them later (30 min)

As the script progresses you keep the objects you create in a list, to group them, move them to a layer or delete them at the end:

#! python3
import rhinoscriptsyntax as rs

created = []
for i in range(4):
    x = i * 1500
    created.append(rs.AddPolyline([[x, 0, 0], [x + 1500, 0, 0], [x + 1500, 0, 3200], [x, 0, 3200], [x, 0, 0]]))

group = rs.AddGroup("axis_A")
rs.AddObjectsToGroup(created, group)
rs.SelectObjects(created)
print(len(created), "panels grouped and selected")

GUIDs are valid during a session and are saved with the file. But if an object is deleted and recreated it gets a new identity; so for a permanent link (for example a panel code) a name or user text (tomorrow) is used instead of the identity.

1. Asking for objects (45 min)

Most scripts start with "let the user select something and I'll work with it":

Function What it returns
rs.GetObject(message, filter_) A single GUID, or None if cancelled
rs.GetObjects(message, filter_) List of GUIDs or None
rs.GetPoint(message) The point clicked or None
rs.SelectedObjects() Currently selected objects

Filters: rs.filter.point, rs.filter.curve, rs.filter.surface, rs.filter.polysurface, rs.filter.mesh, rs.filter.annotation. Multiple filters are combined with +: rs.filter.surface + rs.filter.polysurface.

#! python3
import rhinoscriptsyntax as rs

ids = rs.GetObjects("Select panels", rs.filter.curve, preselect=True)
if not ids:
    print("Nothing selected.")
else:
    closed = [i for i in ids if rs.IsCurveClosed(i) and rs.IsCurvePlanar(i)]
    total = sum(rs.CurveArea(i)[0] for i in closed) / 1e6
    print(f"{len(ids)} curves selected, {len(closed)} closed and planar, total {total:.2f} m²")
  • preselect=True: if the user selected objects before running the script, they are used without asking again.
  • If the user presses Esc the function returns None. Always check; otherwise you get an error on the next line.
  • rs.CurveArea gives the area of a closed planar curve as [area, error].

2. Getting numbers and options (45 min)

#! python3
import rhinoscriptsyntax as rs

spacing = rs.GetReal("Bracket spacing (mm)", 1200, 300, 3000)
count = rs.GetInteger("Number of floors", 5, 1, 60)

3. Batch renaming (1 hour)

The most common order when numbering panels: by floor (z), then by axis (x). First let's write and test the sorting logic without Rhino. Suppose the centroid coordinates of each panel are given:

def number_panels(centers, prefix="P", floor_height=3200, tolerance=50):
    """centers: [(id, x, y, z), ...] -> {id: code}. Floor by z, order by x."""
    def floor_no(z):
        return int((z + tolerance) // floor_height) + 1

    ordered = sorted(centers, key=lambda m: (floor_no(m[3]), m[1]))
    codes = {}
    counter = {}
    for pid, x, y, z in ordered:
        k = floor_no(z)
        counter[k] = counter.get(k, 0) + 1
        codes[pid] = f"{prefix}-{k}{counter[k]:02d}"
    return codes


sample = [("a", 3000, 0, 1600), ("b", 0, 0, 1600), ("c", 1500, 0, 4800),
         ("d", 1500, 0, 1590), ("e", 0, 0, 4810), ("f", 4500, 0, 1600)]
for pid, code in number_panels(sample).items():
    print(pid, code)

b P-101
d P-102
a P-103
f P-104
e P-201
c P-202
  • sorted(..., key=lambda m: (floor, x)) sorts first by floor, then by x within the floor.
  • tolerance (tolerance) is there because the centres of panels on the same floor may differ by a few millimetres (panel d is at 1590 but still on floor 1).
  • Code format P-101: the floor number and a two-digit position within the floor.

Let's apply the same logic to curves selected in Rhino. rs.CurveAreaCentroid is used for the centre:

#! python3
import rhinoscriptsyntax as rs


def number_panels(centers, prefix="P", floor_height=3200, tolerance=50):
    def floor_no(z):
        return int((z + tolerance) // floor_height) + 1
    ordered = sorted(centers, key=lambda m: (floor_no(m[3]), m[1]))
    codes, counter = {}, {}
    for pid, x, y, z in ordered:
        k = floor_no(z)
        counter[k] = counter.get(k, 0) + 1
        codes[pid] = f"{prefix}-{k}{counter[k]:02d}"
    return codes


ids = rs.GetObjects("Select panels to number", rs.filter.curve, preselect=True)
if ids:
    centers = []
    for i in ids:
        c = rs.CurveAreaCentroid(i)[0]
        centers.append((i, c[0], c[1], c[2]))
    codes = number_panels(centers, prefix="P", floor_height=3200)
    rs.EnableRedraw(False)
    for pid, code in codes.items():
        rs.ObjectName(pid, code)
        rs.AddTextDot(code, rs.CurveAreaCentroid(pid)[0])
    rs.EnableRedraw(True)
    print(len(codes), "panels numbered")

rs.AddTextDot places a small label at the centre of each panel that always faces the screen; very useful for checking. When done you can find them all with rs.ObjectsByType(8192) (the text dot type) and delete them.

4. User text: adding information to objects (45 min)

An object's name is a single text. To store a panel's type, colour, order status and supplier, user text (UserText, Attribute User Text) is used: key–value pairs added to the object. It appears in the Attribute User Text tab of Rhino's Properties panel and is saved with the .3dm file.

#! python3
import rhinoscriptsyntax as rs

ids = rs.GetObjects("Select panels to annotate", rs.filter.curve, preselect=True)
if ids:
    for i in ids:

1. Dividing the surface: parameter and length (45 min)

As we saw yesterday, every point of a surface is addressed by (u, v) parameters. The simplest division is splitting the u and v domains into equal parts. But careful: equal parameter steps do not mean equal length on curved surfaces. So we first calculate how many panels are needed from the surface's edge lengths, then divide the edge curve into equal lengths and use the parameters of the points found.

The panel count calculation can be written without Rhino:

import math


def panel_count(length, target, max_size=None):
    """Integer count closest to the target size without exceeding it. max_size: largest allowed panel size."""
    n = max(1, round(length / target))
    if max_size:
        n = max(n, math.ceil(length / max_size))
    return n, length / n


for L in [12400, 11240, 13600]:
    n, a = panel_count(L, 1500, max_size=1600)
    print(f"edge {L} mm → {n} panels × {a:.1f} mm")

edge 12400 mm → 8 panels × 1550.0 mm
edge 11240 mm → 8 panels × 1405.0 mm
edge 13600 mm → 9 panels × 1511.1 mm

On the 12400 and 13600 mm edges the count closest to the target already stays below the 1600 mm limit. At 11240 mm, however, the closest count would be 7 and the panel would be 1605.7 mm; because that exceeds the limit, the script raised the count to 8. Such rules always exist in façade design: glass size, transport size, sheet width.

2. Planarity check (45 min)

On a curved surface a four-cornered panel is usually not planar: the fourth corner is slightly outside the plane defined by the first three. For flat glass and sheet panels this deviation must not exceed a certain limit (for example a few millimetres, depending on the system and panel size); if it does, the panel needs cold bending, triangular division or curved fabrication.

Deviation calculation: find the normal of the plane through the first three points (cross product) and measure the distance of the fourth point from this plane. In pure Python:

def diff(a, b):
    return [a[i] - b[i] for i in range(3)]


def cross(u, v):
    return [u[1] * v[2] - u[2] * v[1], u[2] * v[0] - u[0] * v[2], u[0] * v[1] - u[1] * v[0]]


def plane_deviation(p1, p2, p3, p4):
    """Distance of p4 from the p1-p2-p3 plane (same units)."""
    n = cross(diff(p2, p1), diff(p3, p1))
    height = sum(c * c for c in n) ** 0.5
    return abs(sum(n[i] * (p4[i] - p1[i]) for i in range(3))) / height


flat = plane_deviation([0, 0, 0], [1500, 0, 0], [1500, 0, 3200], [0, 0, 3200])
skewed = plane_deviation([0, 0, 0], [1500, 40, 0], [1500, 0, 3200], [0, 0, 3200])
print(f"flat panel: {flat:.2f} mm, panel with a corner 40 mm off: {skewed:.2f} mm")

flat panel: 0.00 mm, panel with a corner 40 mm off: 39.98 mm

In the second panel one corner is 40 mm off and almost all of the deviation was measured. This simple method puts the whole deviation on the fourth corner. A real check looks at the best-fit plane through the four points (Plane.FitPlaneToPoints in RhinoCommon); in a warped quadrilateral each corner deviates from this plane by about a quarter. Here we used the simple method to see the logic. Inside Rhino rs.PlaneFromPoints and rs.DistanceToPlane do the same job.

3. Generating the panels (1 hour)

The tool's flow: select the surface → get target sizes → calculate counts → set up the (u, v) grid → evaluate four corners for each cell → draw, check, number and annotate the panel.

#! python3
"""Divides a facade surface into panels, checks and numbers them."""
import math
import rhinoscriptsyntax as rs
import Rhino.Geometry as rg
import scriptcontext as sc

LAYER_OK = "PANEL::OK"
LAYER_WARN = "PANEL::Check"


def panel_count(length, target, max_size=None):
    n = max(1, round(length / target))
    if max_size:
        n = max(n, math.ceil(length / max_size))
    return n


def equal_parameters(edge, n):
    """Divides the edge curve into n equal lengths and returns the parameters."""
    return list(edge.DivideByCount(n, True))


def main():
    guid = rs.GetObject("Select the facade surface", rs.filter.surface, preselect=True)
    if not guid:
        return
    target_width = rs.GetReal("Target panel width (mm)", 1500, 300, 4000)
    target_height = rs.GetReal("Target panel height (mm)", 3200, 300, 6000)
    limit = rs.GetReal("Planarity limit (mm)", 3, 0.1, 50)
    if None in (target_width, target_height, limit):
        return

    surface_ = rs.coercebrep(guid).Faces[0].UnderlyingSurface()
    bottom_edge = surface_.IsoCurve(0, surface_.Domain(1).Min)    # in u direction, v = min
    left_edge = surface_.IsoCurve(1, surface_.Domain(0).Min)    # in v direction, u = min
    nu = panel_count(bottom_edge.GetLength(), target_width, max_size=target_width * 1.07)
    nv = panel_count(left_edge.GetLength(), target_height)
    us = equal_parameters(bottom_edge, nu)
    vs = equal_parameters(left_edge, nv)

    for name, color in [(LAYER_OK, (90, 160, 210)), (LAYER_WARN, (220, 80, 60))]:
        if not rs.IsLayer(name):
            rs.AddLayer(name, color)

    tol = sc.doc.ModelAbsoluteTolerance
    rows = []
    rs.EnableRedraw(False)
    try:
        for j in range(nv):
            for i in range(nu):
                k = [surface_.PointAt(us[i], vs[j]), surface_.PointAt(us[i + 1], vs[j]),
                     surface_.PointAt(us[i + 1], vs[j + 1]), surface_.PointAt(us[i], vs[j + 1])]
                plane = rg.Plane(k[0], k[1], k[2])
                deviation = abs(plane.DistanceTo(k[3]))
                width = k[0].DistanceTo(k[1])
                height = k[0].DistanceTo(k[3])
                code = f"P-{j + 1}{i + 1:02d}"
                panel = rs.AddPolyline(k + [k[0]])
                rs.ObjectName(panel, code)
                is_ok = deviation <= limit
                rs.ObjectLayer(panel, LAYER_OK if is_ok else LAYER_WARN)
                for key, value in [("code", code), ("width_mm", f"{width:.0f}"), ("height_mm", f"{height:.0f}"),
                                       ("deviation_mm", f"{deviation:.2f}")]:
                    rs.SetUserText(panel, key, value)
                rows.append((code, j + 1, i + 1, width, height, deviation, is_ok))
    finally:
        rs.EnableRedraw(True)

    warnings = sum(1 for s in rows if not s[6])
    print(f"{nu} × {nv} = {len(rows)} panels, {warnings} panels exceed the planarity limit (tolerance {tol})")
    sc.sticky["last_panels"] = rows


main()

New parts:

  • UnderlyingSurface() is the surface beneath a Brep face; IsoCurve(direction, param) extracts a constant u or v curve from the surface. We measured edge lengths from these curves.
  • rg.Plane(a, b, c) gives a plane through three points, DistanceTo a signed distance.
  • The check result is reflected in the layer: panels exceeding the limit are on the red PANEL::Check layer.
  • We stored the results in sc.sticky; the next script (writing CSV) will use them.
  • Putting the code in a main() function and exiting early with return is more readable than nested ifs.

3. Item, list and tree access (1 hour)

In Grasshopper data flows in a tree structure: branches and a list in each branch. A Python component can receive an input in three ways (right-click the input):

Item (default) A single value Once for each item in the list
List A Python list Once per branch

4. Parametric façade with an attractor (1 hour)

A classic parametric façade rule: the opening (for example a hole or glazed opening) is small in panels near an attractor point and large in panels further away. The rule is pure mathematics; let's first write it in pure Python:

def opening(distance, smallest=0.15, largest=0.85, influence=6000):
    """Opening ratio 0–1 by distance to the attractor. influence: distance (mm) at which the ratio reaches its maximum."""
    t = min(distance / influence, 1.0)
    t = t * t * (3 - 2 * t)          # smooth transition (smoothstep)
    return smallest + (largest - smallest) * t


attractor = (4500, 0, 6400)
for floor in range(4):
    row = []
    for axis in range(6):
        center = (axis * 1500 + 750, 0, floor * 3200 + 1600)
        d = sum((center[i] - attractor[i]) ** 2 for i in range(3)) ** 0.5
        row.append(f"{opening(d):.2f}")
    print(f"floor {floor + 1}: " + " ".join(row))

floor 1: 0.85 0.82 0.78 0.78 0.82 0.85
floor 2: 0.68 0.46 0.30 0.30 0.46 0.68
floor 3: 0.68 0.46 0.30 0.30 0.46 0.68
floor 4: 0.85 0.82 0.78 0.78 0.82 0.85

The attractor sits between floors 2 and 3, on the boundary of axes 3 and 4; these four panels have the smallest ratio (0.30), growing with distance. The table is symmetric because the attractor is exactly in the middle. The smoothstep function gives a curve that eases at the start and end instead of a linear transition; it looks more natural on a façade.

In Grasshopper: inputs panel (List access, type hint Curve: closed panel frames), attractor (attractor; Item, Point3d), influence (influence; Item, float). Output a: an opening curve at the centre of each panel, scaled by the ratio.

import Rhino.Geometry as rg


def opening(distance, smallest=0.15, largest=0.85, influence=6000):
    t = min(distance / influence, 1.0)
    t = t * t * (3 - 2 * t)
    return smallest + (largest - smallest) * t


openings = []
ratios = []
for p in panel:
    area = rg.AreaMassProperties.Compute(p)
    if area is None:
        continue
    center = area.Centroid
    ratio = opening(center.DistanceTo(attractor), influence=influence)
    copy_ = p.DuplicateCurve()
    copy_.Transform(rg.Transform.Scale(center, ratio ** 0.5))
    openings.append(copy_)
    ratios.append(ratio)

a = openings
b = ratios
  • AreaMassProperties.Compute(curve) gives the area and centroid of a closed planar curve.
  • For the opening's area to follow the ratio, the linear scale must be the square root of the ratio (area grows with the square of the scale).
  • We also added a b output: the ratios. You can connect them to a Gradient component to colour the panels or write them to a list as on day 5.

As you drag the attractor point in Rhino, the façade updates instantly. You can generate the panel frames with Grasshopper's Divide Domain² + Isotrim components or reference the panels you drew in Rhino on day 5 in a Curve parameter.

  • Keeping code outside: You can keep long code not inside the component but in a .py file and import it in the component. In Rhino 8 a module created in the ScriptEditor can be shared by components; changes are made in one place.
  • User object: Right-click the component › Create User Object to put it in your own tab; everyone on the team uses it with its name, description and icon.
  • Errors: If the component turns red, the balloon above it shows the error and the line number. Writing intermediate values to the out output with print is the fastest debugging method.

1. What is rhino3dm? (30 min)

rhino3dm is the Python version of McNeel's open-source openNURBS library. It lets you read and write .3dm files on a computer without Rhino, on a server or in a Docker container. Installation:

What it can and cannot do:

Can Cannot
Read and write .3dm (Rhino 4–8 versions) Boolean, intersection, offset, fillet
Layers, object attributes, user text Meshing (mesh from surface)
Point, curve, NURBS surface, Brep, mesh objects Run Rhino commands
Evaluating points on curves and surfaces (PointAt) Some calculations such as curve length and area

Heavy geometry operations need McNeel's Rhino.Compute server (which offers Rhino's calculation engine as a web service) or Rhino itself. But rhino3dm is enough for extracting data, producing reports and writing simple rule-based geometry.

Caution: the classes in rhino3dm resemble RhinoCommon but are not identical. For example you cannot subtract Point3d objects with the minus sign; you calculate with the coordinates (.X, .Y, .Z).

4. Project: dividing a curved façade into panels (1 h 15 min)

This time we generate ourselves something similar to the curved façade we made with a loft on day 2: a ruled surface formed by straight lines between a bottom and a top curve. Then, as on day 5, panels, planarity check and a list. Save the script below as facade.py:

"""Divides a curved facade into panels; writes .3dm and CSV (no Rhino needed)."""
import csv
import rhino3dm as r3

WIDTH_TARGET, HEIGHT_TARGET, LIMIT_MM = 1500, 3200, 3.0


def point_diff(a, b):
    return [a.X - b.X, a.Y - b.Y, a.Z - b.Z]


def distance(a, b):
    return sum(c * c for c in point_diff(a, b)) ** 0.5


def deviation(p1, p2, p3, p4):
    u, v = point_diff(p2, p1), point_diff(p3, p1)
    n = [u[1] * v[2] - u[2] * v[1], u[2] * v[0] - u[0] * v[2], u[0] * v[1] - u[1] * v[0]]
    height = sum(c * c for c in n) ** 0.5
    w = point_diff(p4, p1)
    return abs(sum(n[i] * w[i] for i in range(3))) / height


def curve_length(curve, sample=200):
    d = curve.Domain
    points = [curve.PointAt(d.T0 + (d.T1 - d.T0) * i / sample) for i in range(sample + 1)]
    return sum(distance(a, b) for a, b in zip(points, points[1:]))


def facade_surface():
    bottom = [r3.Point3d(0, 0, 0), r3.Point3d(6000, 900, 0), r3.Point3d(12000, 0, 0)]
    top = [r3.Point3d(p.X, p.Y * 0.9, 12800) for p in bottom]
    a = r3.Curve.CreateControlPointCurve(bottom, 2)
    b = r3.Curve.CreateControlPointCurve(top, 2)
    return r3.NurbsSurface.CreateRuledSurface(a, b), a, b


def main():
    surface_, bottom_curve, left_height = facade_surface()
    L = curve_length(bottom_curve)
    nu = max(1, round(L / WIDTH_TARGET))
    nv = max(1, round(12800 / HEIGHT_TARGET))
    du, dv = surface_.Domain(0), surface_.Domain(1)
    us = [du.T0 + (du.T1 - du.T0) * i / nu for i in range(nu + 1)]
    vs = [dv.T0 + (dv.T1 - dv.T0) * j / nv for j in range(nv + 1)]

    model = r3.File3dm()
    model.Settings.ModelUnitSystem = r3.UnitSystem.Millimeters
    layer = {}
    for name, color in [("Facade", (200, 200, 200)), ("Panel_OK", (90, 160, 210)),
                     ("Panel_Check", (220, 80, 60)), ("Label", (40, 40, 40))]:
        k = r3.Layer()
        k.Name, k.Color = name, (*color, 255)
        layer[name] = model.Layers.Add(k)

    attr = r3.ObjectAttributes()
    attr.LayerIndex = layer["Facade"]
    model.Objects.AddSurface(surface_, attr)

    rows = []
    for j in range(nv):
        for i in range(nu):
            k = [surface_.PointAt(us[i], vs[j]), surface_.PointAt(us[i + 1], vs[j]),
                 surface_.PointAt(us[i + 1], vs[j + 1]), surface_.PointAt(us[i], vs[j + 1])]
            s = deviation(*k)
            code = f"P-{j + 1}{i + 1:02d}"
            width, height = distance(k[0], k[1]), distance(k[0], k[3])
            is_ok = s <= LIMIT_MM
            pl = r3.Polyline()
            for p in k + [k[0]]:
                pl.Add(p.X, p.Y, p.Z)
            attr = r3.ObjectAttributes()
            attr.LayerIndex = layer["Panel_OK" if is_ok else "Panel_Check"]
            attr.Name = code
            for key, value in [("floor", str(j + 1)), ("axis", str(i + 1)), ("width_mm", f"{width:.0f}"),
                                   ("height_mm", f"{height:.0f}"), ("deviation_mm", f"{s:.2f}")]:
                attr.SetUserString(key, value)
            model.Objects.AddPolyline(pl, attr)
            et = r3.ObjectAttributes()
            et.LayerIndex = layer["Label"]
            m = surface_.PointAt((us[i] + us[i + 1]) / 2, (vs[j] + vs[j + 1]) / 2)
            model.Objects.AddTextDot(code, m, et)
            rows.append([code, j + 1, i + 1, round(width), round(height), round(s, 2), "ok" if is_ok else "CHECK"])

    model.Write("facade_panels.3dm", 8)
    with open("facade_panels.csv", "w", newline="", encoding="utf-8-sig") as f:
        write = csv.writer(f, delimiter=";")
        write.writerow(["code", "floor", "order", "width_mm", "height_mm", "deviation_mm", "status"])
        write.writerows(rows)
    check = sum(1 for s in rows if s[-1] != "ok")
    print(f"bottom edge {L:.0f} mm → {nu} × {nv} = {len(rows)} panels, {check} panels need checking")
    print("written: facade_panels.3dm, facade_panels.csv")


if __name__ == "__main__":
    main()

New parts:

  • rhino3dm has no curve length method; curve_length samples the curve at 200 points and sums the short straight segments. This is an approximation, but with 200 samples it is accurate to below a millimetre.
  • The top curve's curvature is slightly (10%) less than the bottom one. Because the bottom and top curves are not parallel, the straight lines between them rotate slightly and the surface is twisted; this is why the panels are not planar.
  • Floor and axis numbers were also written to the user text; the report won't have to parse them from the name.
  • This version divides parameters equally (instead of equal length as on day 5). This is enough for a simple curve; we will see the small difference between panels in the table.

5. Reading the report back (30 min)

The second script opens the .3dm file and produces a summary by floor. Even if someone changes the panels' user text in Rhino, the report reads the latest state of the file:

"""Per-axis summary from the panel .3dm file."""
import collections
import sys
import rhino3dm as r3

path = sys.argv[1] if len(sys.argv) > 1 else "facade_panels.3dm"
model = r3.File3dm.Read(path)
axes = collections.defaultdict(list)
for n in model.Objects:
    attr = n.Attributes
    if not attr.GetUserString("axis"):
        continue
    layer = model.Layers[attr.LayerIndex].Name
    axes[int(attr.GetUserString("axis"))].append((attr.Name, float(attr.GetUserString("deviation_mm")), layer))

print(f"{path}: {sum(len(v) for v in axes.values())} panels")
print("axis  panel    check  max deviation")
for axis in sorted(axes):
    items = axes[axis]
    check = sum(1 for _, _, k in items if k == "Panel_Check")
    worst = max(items, key=lambda x: x[1])
    print(f"{axis:>3}  {len(items):>5}  {check:>7}  {worst[1]:6.2f} mm ({worst[0]})")

With this information the design team can decide on narrower panels, cold bending or triangular division only for the end axes; the middle panels stay flat glass.

The report read floor and axis information from user text, not from the panel name. A good habit: store information explicitly in user text rather than parsing it from the name; the code won't break even if the name format changes or the number of floors exceeds 9.
