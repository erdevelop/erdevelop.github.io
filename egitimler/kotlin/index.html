Kotlin Programlama

Android'in resmî dili ve Java'nın modern, kısa ve güvenli alternatifi Kotlin'i 7 günde, bol şemayla öğreten bir program. Değişkenlerden Kotlin'in en önemli özelliği olan null güvenliğine, when ifadesinden lambda'lara ve koleksiyon işlemlerine, data class ve sealed class'lardan eklenti fonksiyonlarına kadar ilerlersin. GÜN 01

Tanışma ve kurulum

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Kotlin'in nerede kullanıldığını ve Java'yla ilişkisini bilecek, IntelliJ IDEA'da bir Kotlin projesi oluşturup ilk programını çalıştırabilecek ve string şablonlarıyla çıktı yazabileceksin. Süre yaklaşık 4 saat.

Bu kurs hakkında: Programlama Dilleri grubundaki bütün eğitimler aynı iskeleti izler ve 7. günde aynı envanter özeti projesiyle biter. Java eğitimini aldıysan Kotlin'in aynı işleri ne kadar kısa yaptığını karşılaştırarak görebilirsin.

1. Kotlin nerede? (30 dk)

Kotlin, IntelliJ IDEA'yı geliştiren JetBrains tarafından 2011'de duyuruldu. JVM üzerinde çalışır ve Java'yla tam uyumludur: Kotlin kodu Java kütüphanelerini doğrudan kullanır, aynı projede Java ve Kotlin dosyaları birlikte yaşar.

  • Android: Google 2019'dan beri Android'i "Kotlin öncelikli" geliştiriyor. Jetpack Compose arayüz kütüphanesi Kotlin'le yazılır.
  • Sunucu: Spring Boot Kotlin'i tam destekler; Ktor JetBrains'in kendi web çatısıdır.
  • Çoklu platform: Kotlin Multiplatform ile aynı iş mantığı Android, iOS, masaüstü ve web'de paylaşılır.

Java'ya göre başlıca farklar: noktalı virgül yok, tipler çoğu yerde çıkarılır, null hataları derleme anında önlenir, data class tek satırda veri sınıfı üretir, fonksiyonlar sınıf dışında yazılabilir.

2. Kurulum (45 dk)

  1. IntelliJ IDEA Community Edition'ı indir ve kur (ücretsiz). Android Studio da IntelliJ tabanlıdır ve Kotlin içerir.
  2. New Project → dil olarak Kotlin, derleme sistemi Gradle (Kotlin DSL), JDK olarak 21 seç (yoksa IntelliJ indirmeyi önerir).
  3. src/main/kotlin/Main.kt dosyası oluşur; main'in yanındaki yeşil ▶ ile çalıştır.

Kurulum yapmadan denemek için play.kotlinlang.org tarayıcıda Kotlin çalıştırır. Bu kursun bütün örnekleri orada da çalışır (7. gündeki coroutine örneği hariç).

Hedef

3. Null güvenliği (1,5 saat)

Java'da en sık görülen çalışma hatası NullPointerException'dır. Kotlin bunu tip sisteminde çözer: bir değişken null olabiliyorsa, tipinin sonunda ? vardır.

fun main() {
    var ad: String = "Ayşe"
    // ad = null                       // derleme hatası: String null olamaz

    var takma: String? = null
    println(takma?.length)             // güvenli çağrı: null ise null
    println(takma?.length ?: 0)        // Elvis: null ise varsayılan

    takma = "Ay"
    if (takma != null) {
        println(takma.length)          // akıllı dönüşüm: burada String
    }

    val girdiler = listOf("12", "x", "30")
    val toplam = girdiler.sumOf { it.toIntOrNull() ?: 0 }
    println(toplam)

    val kesin: String? = "Bursa"
    println(kesin!!.length)            // !!: "eminim null değil", değilse çöker
    println(ad.length)
}

İşlem Anlamı
String? null olabilen tip
x?.uzunluk Güvenli çağrı: x null ise sonuç null
x ?: varsayılan Elvis: x null ise sağdaki değer
if (x != null) { ... } Akıllı dönüşüm: blok içinde x null olmayan tip sayılır
x!! Null değil iddiası; null ise NullPointerException. Kaçın.
x?.let { ... } x null değilse bloğu çalıştır

String ile String? farklı tiplerdir: null olabilen bir değeri, kontrol etmeden null olamayan bir yere veremezsin. Böylece null hataları programı çalıştırmadan önce yakalanır.

GÜN 03

Kontrol akışı

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Kotlin'de if'i ifade olarak kullanabilecek, switch'in güçlü hâli olan when ile karar verebilecek, aralıklarla for döngüsü yazabilecek ve while, repeat, break ve etiketleri bileceksin. Süre yaklaşık 4 saat.

1. if bir ifadedir (45 dk)

fun main() {
    val stok = 4
    val esik = 10
    if (stok == 0) {
        println("Tükendi")
    } else if (stok < esik) {
        println("Az kaldı: $stok")
    } else {
        println("Yeterli")
    }

    val karar = if (stok in 1 until esik) "sipariş ver" else "bekle"
    println(karar)
}

Az kaldı: 4
sipariş ver
  • if bir ifadedir ve değer döndürür; bu yüzden Kotlin'de üçlü işlem (? :) yoktur.
  • stok in 1 until esik "1 ≤ stok < esik" demektir.

2. when (1,5 saat)

when, Java'nın switch'inin çok daha güçlü hâlidir:

fun harfNotu(ort: Double, finalNotu: Double): String = when {
    finalNotu < 50 -> "FF"
    ort >= 85 -> "AA"
    ort >= 70 -> "BB"
    ort >= 55 -> "CC"
    ort >= 45 -> "DD"
    else -> "FF"
}

fun kargo(kg: Int): String = when (kg) {
    0 -> "geçersiz"
    in 1..2 -> "60 TL"
    in 3..10 -> "95 TL"
    else -> "${95 + (kg - 10) * 12} TL"
}

fun tanimla(x: Any): String = when (x) {
    is Int -> "tam sayı, iki katı ${x * 2}"
    is String -> "metin, ${x.length} harf"
    else -> "bilinmiyor"
}

fun main() {
    println("${harfNotu(73.4, 81.0)} ${harfNotu(90.0, 45.0)}")
    println("${kargo(1)} ${kargo(7)} ${kargo(14)}")
    println("${tanimla(21)} | ${tanimla("Bursa")} | ${tanimla(2.5)}")
    val gun = "Pazar"
    println(when (gun) {
        "Cumartesi", "Pazar" -> "hafta sonu"
        else -> "iş günü"
    })
}

  • Her kol koşul -> sonuç biçimindedir; ilk eşleşen çalışır, break gerekmez.
  • when (x) değere göre: virgülle birden çok değer, in 1..2 aralık, is Int tip kontrolü (ve kolda akıllı dönüşüm: x * 2).
  • Argümansız when { } uzun if-else zincirlerinin yerine geçer.
  • when bir ifadedir; değer döndürürken else zorunludur (ya da bütün durumlar kapsanmalıdır; 6. gün sealed class).
  • fun f(...): String = when { ... } tek ifadeli fonksiyondur (4. gün).

GÜN 04

Fonksiyonlar ve lambda'lar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Kotlin'de fonksiyon yazıp tek ifadeli biçimini, varsayılan ve adlı argümanları, vararg'ı kullanabilecek, lambda'ları ve yüksek mertebeden fonksiyonları yazabilecek ve Kotlin'e özgü eklenti fonksiyonlarıyla mevcut tiplere metot ekleyebileceksin. Süre yaklaşık 4 saat.

1. Fonksiyonlar (1,5 saat)

fun kdvDahil(tutar: Double, oran: Double = 20.0): Double {
    return tutar * (1 + oran / 100)
}

fun kare(x: Int) = x * x

fun minMax(sayilar: List<Int>): Pair<Int, Int> = Pair(sayilar.min(), sayilar.max())

fun etiket(ad: String, adet: Int = 1, birim: String = "adet") = "$ad: $adet $birim"

fun topla(vararg sayilar: Int): Int = sayilar.sum()

fun main() {
    println("${kdvDahil(1000.0)} ${kdvDahil(1000.0, 10.0)} ${kare(9)}")
    val (enk, enb) = minMax(listOf(72, 85, 64, 91, 58))
    println("$enk $enb")
    println(etiket("Kalem"))
    println(etiket("Kablo", birim = "metre", adet = 50))
    println("${topla()} ${topla(1, 2, 3)} ${topla(*intArrayOf(4, 5))}")
}

  • fun ad(parametre: Tip): DönüşTipi { }. Tip addan sonra yazılır.
  • Tek ifadeli fonksiyon: fun kare(x: Int) = x * x; dönüş tipi çıkarılır.
  • Varsayılan argümanlar (oran: Double = 20.0) Java'daki aşırı yükleme kalabalığını gereksiz kılar.
  • Adlı argümanlar (birim = "metre") okunurluğu artırır ve sırayı serbest bırakır.
  • Pair iki değer taşır; val (a, b) = ... ile açılır (destructuring).
  • vararg değişken sayıda argüman alır; dizi * ile açılarak verilir.

2. Lambda'lar ve yüksek mertebeden fonksiyonlar (1,5 saat)

fun uygula(liste: List<Int>, f: (Int) -> Int): List<Int> {
    val sonuc = mutableListOf<Int>()
    for (x in liste) sonuc.add(f(x))
    return sonuc
}

fun carpanYap(k: Int): (Int) -> Int = { x -> x * k }

fun main() {
    val ikiKati: (Int) -> Int = { x -> x * 2 }
    println(ikiKati(21))
    println(uygula(listOf(1, 2, 3)) { it * it })
    println(uygula(listOf(1, 2, 3), carpanYap(10)))

    val notlar = listOf(72, 85, 64, 91, 58)
    println(notlar.filter { it >= 70 }.map { it + 5 })
    println(notlar.count { it < 60 })
    var sayac = 0
    notlar.forEach { if (it > 80) sayac++ }
    println(sayac)
}

  • Tek parametreli lambda'da parametre adı yazılmazsa it kullanılır.
  • Son parametre lambda ise parantezin dışına yazılabilir: uygula(liste) { it * it }. Kotlin kütüphanelerinin "kendi dilini" bu kural oluşturur.
  • Lambda dışarıdaki değişkenleri okuyup değiştirebilir (sayac).

  • Kotlin'in standart kütüphanesinin büyük kısmı (filter, map, uppercase...) eklenti fonksiyonlarıdır.
  • Eklentiler sınıfı gerçekten değiştirmez; sadece öyle çağrılabilen bir fonksiyon tanımlar.

4. Kapsam fonksiyonları (15 dk)

Kotlin kodunda sık göreceğin beş küçük fonksiyon: let, apply, also, run, with. En yaygın ikisi:

fun main() {
    val liste = mutableListOf<String>().apply {
        add("Kalem")
        add("Defter")
    }
    val uzunluk = liste.firstOrNull()?.let { it.length } ?: 0
    println("$liste $uzunluk")
}

[Kalem, Defter] 5

apply nesneyi yapılandırıp kendisini döndürür; let null olmayan değerle bir iş yapıp sonucu döndürür.

Koleksiyonlar

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Kotlin'de salt okunur ve değiştirilebilir listeler, kümeler ve haritalar kullanabilecek, filter, map, sumOf, groupBy, sortedBy gibi koleksiyon işlemleriyle döngü yazmadan veri işleyebileceksin. Süre yaklaşık 4 saat.

1. List ve MutableList (1 saat)

fun main() {
    val sabit = listOf("Adana", "Bursa", "İzmir")
    // sabit.add("Rize")             // derlenmez: List salt okunurdur
    val sehirler = mutableListOf("Adana", "Bursa")
    sehirler.add("İzmir")
    sehirler.add(1, "Ankara")
    sehirler.remove("Adana")
    println("$sehirler ${sehirler.size} ${sehirler[0]} ${sehirler.last()}")
    println("${"Bursa" in sehirler} ${sehirler.indexOf("İzmir")} ${sehirler.getOrNull(10)}")

    println("${notlar.sum()} ${notlar.average()} ${notlar.max()}")
    println(sabit + "Rize")
}

data class Urun(val ad: String, val kategori: String, val fiyat: Double, val stok: Int)

Sınıflar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Kotlin'de birincil kurucuyla sınıf yazabilecek, özellikleri ve init bloğunu kullanabilecek, data class ile veri sınıfı tanımlayabilecek, open ile kalıtım ve interface kullanabilecek, sealed class ile kapalı tip hiyerarşileri kurabilecek ve object ile tekil nesneyi bileceksin. Süre yaklaşık 4 saat.

1. Sınıflar (1,5 saat)

class Urun(val ad: String, fiyat: Double, stok: Int = 0) {
    var fiyat: Double = fiyat
        set(deger) {
            require(deger >= 0) { "fiyat negatif olamaz" }
            field = deger
        }

    var stok: Int = stok
        private set

    init {
        require(fiyat >= 0) { "$ad: fiyat negatif olamaz" }
    }

    val deger: Double get() = fiyat * stok

    fun sat(adet: Int): Boolean {
        if (adet > stok) return false
        stok -= adet
        return true
    }

    override fun toString() = "$ad ($stok adet)"
}

fun main() {
    val u = Urun("Kalem", 12.5, 40)
    u.sat(15)
    println("$u ${u.deger} ${u.sat(100)}")
    // u.stok = 99                   // derlenmez: set private
    u.fiyat = 15.0
    println(u.deger)
    try {
        Urun("X", -5.0)
    } catch (e: IllegalArgumentException) {
        println("hata: ${e.message}")
    }
}

375.0
hata: X: fiyat negatif olamaz
  • class Urun(val ad: String, ...) birincil kurucudur: parantezdeki val/var parametreler doğrudan özellik olur. Java'daki alan + kurucu + getter + setter kalabalığı tek satıra iner.
  • Özellikler (var fiyat) arka planda getter/setter'dır; özel set ile doğrulama eklenir (field asıl değerdir).
  • private set dışarıdan okunur ama değiştirilemez yapar: kapsülleme.
  • init bloğu nesne oluşurken çalışır; require koşul sağlanmazsa IllegalArgumentException fırlatır.
  • val deger: Double get() = ... her okunduğunda hesaplanan özelliktir.
  • new anahtar sözcüğü yoktur: Urun(...).

3. Kalıtım, interface ve sealed class (1,5 saat)

Kotlin'de sınıflar varsayılan olarak kapalıdır (final); kalıtıma açmak için open yazılır.

interface Sekil {
    fun alan(): Double
    fun ad(): String = "şekil"
}

class Dikdortgen(val en: Double, val boy: Double) : Sekil {
    override fun alan() = en * boy
    override fun ad() = "dikdörtgen"
}

class Daire(val r: Double) : Sekil {
    override fun alan() = Math.PI * r * r
}

open class Calisan(val ad: String, val maas: Double) {
    open fun prim() = maas * 0.10
}

class Yonetici(ad: String, maas: Double) : Calisan(ad, maas) {
    override fun prim() = super.prim() + 5000
}

sealed class Sonuc {
    data class Basarili(val deger: Double) : Sonuc()
    data class Hata(val mesaj: String) : Sonuc()
    object Bekliyor : Sonuc()
}

fun yaz(s: Sonuc) = when (s) {
    is Sonuc.Basarili -> "tamam: ${s.deger}"
    is Sonuc.Hata -> "hata: ${s.mesaj}"
    Sonuc.Bekliyor -> "bekliyor"
}

fun main() {
    val sekiller: List<Sekil> = listOf(Dikdortgen(2.0, 3.0), Daire(1.0))
    for (s in sekiller) println("${s.ad()}: ${"%.2f".format(s.alan())}")
    println(listOf(Calisan("Ayşe", 40000.0), Yonetici("Can", 60000.0)).map { it.prim() })
    println(listOf(Sonuc.Basarili(12.5), Sonuc.Hata("bağlantı yok"), Sonuc.Bekliyor).map { yaz(it) })
}

dikdörtgen: 6.00
şekil: 3.14
[4000.0, 11000.0]
[tamam: 12.5, hata: bağlantı yok, bekliyor]
  • : Sekil interface uygular, : Calisan(ad, maas) sınıftan türer. Geçersiz kılınan metotlarda override zorunludur.
  • interface'ler varsayılan gövdeli metot içerebilir (ad()).
  • sealed class: alt sınıfları aynı dosyada sınırlı ve bilinen bir hiyerarşidir. when bütün alt tipleri kapsadığında else gerekmez; yeni bir alt tip eklenirse derleyici eksik when'leri gösterir. Ağ isteği sonucu, ekran durumu gibi "şunlardan biri" verileri için idealdir.
  • object tekil (singleton) nesnedir: sınıf ve tek örneği birlikte tanımlanır.

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Kotlin'de hataları try ifadesi ve runCatching ile yönetebilecek, coroutine'lerin ne olduğunu bilecek, haftanın konularını birleştiren envanter özeti programını yazmış olacak ve Gradle ile kütüphane eklemeyi bileceksin. Süre yaklaşık 4 saat.

1. Hatalar (1 saat)

class StokYetersiz(val istenen: Int, val stok: Int) : Exception("$istenen istendi, stokta $stok var")

fun siparis(stok: Int, girdi: String): Int {
    val adet = girdi.trim().toIntOrNull() ?: throw IllegalArgumentException("sayı değil: $girdi")
    require(adet > 0) { "adet pozitif olmalı" }
    if (adet > stok) throw StokYetersiz(adet, stok)
    return stok - adet
}

fun main() {
    var stok = 10
    for (g in listOf("3", "x", "-1", "20", " 2 ")) {
        try {
            stok = siparis(stok, g)
            println("kalan $stok")
        } catch (e: StokYetersiz) {
            println("stok hatası: ${e.message}")
        } catch (e: IllegalArgumentException) {
            println("geçersiz: ${e.message}")
        }
    }

    val sayi = try { "42".toInt() } catch (e: NumberFormatException) { 0 }
    val sonuc = runCatching { siparis(5, "9") }
    println("$sayi ${sonuc.isFailure} ${sonuc.getOrDefault(-1)}")
}

geçersiz: sayı değil: x
geçersiz: adet pozitif olmalı
stok hatası: 20 istendi, stokta 7 var
kalan 5
42 true -1
  • Kotlin istisnaları Java'dakiyle aynıdır, ama kontrollü istisna (checked exception) yoktur: throws yazmak zorunlu değildir.
  • try bir ifadedir: değer döndürür.
  • ?: throw ... "null ise hata fırlat" kalıbıdır.
  • runCatching { } sonucu bir Result içine sarar: isSuccess, getOrNull, getOrDefault.

2. Coroutine'ler (1 saat)

Coroutine, askıya alınıp devam ettirilebilen hafif bir iştir; Android'de ağ istekleri ve veritabanı işlemleri arayüzü dondurmadan böyle yapılır. Coroutine'ler kotlinx.coroutines kütüphanesindedir (Gradle'a eklenir; aşağıya bak). Bu örnek o kütüphaneyle çalışır:

import kotlinx.coroutines.*

suspend fun stokGetir(ad: String): Int {
    delay(100)                      // iş parçacığını bloklamadan bekler
    return ad.length * 10
}

fun main() = runBlocking {
    val baslangic = System.currentTimeMillis()
    val a = async { stokGetir("Kalem") }
    val b = async { stokGetir("Defter") }
    val c = async { stokGetir("Mouse") }
    println("${a.await()} ${b.await()} ${c.await()}")
    println("süre ~${(System.currentTimeMillis() - baslangic) / 100 * 100} ms")
}

Çıktı: 50 60 50 ve yaklaşık 100 ms. Üç 100 ms'lik iş aynı anda yürüdü.

  • suspend fonksiyon askıya alınabilir; sadece başka bir coroutine ya da suspend fonksiyon içinden çağrılır.
  • delay iş parçacığını meşgul etmeden bekler (Thread.sleep'in aksine).
  • async { } bir iş başlatır, await() sonucunu bekler. launch { } sonuç döndürmeyen işler içindir.
  • Android'de viewModelScope.launch { } ile kullanılır; ekran kapanınca işler otomatik iptal edilir.

3. Envanter özeti (1 saat)

data class Urun(val ad: String, val kategori: String, val fiyat: Double, val stok: Int) {
    val deger get() = fiyat * stok
}

fun Double.iki() = "%.2f".format(java.util.Locale.ROOT, this)

fun main() {
    val urunler = listOf(
        Urun("Kalem", "kırtasiye", 12.5, 40),
        Urun("Defter", "kırtasiye", 45.0, 25),
        Urun("Kulaklık", "elektronik", 850.0, 5),
        Urun("Mouse", "elektronik", 320.0, 12),
        Urun("Çay", "gıda", 95.0, 30),
    )

    println("Toplam stok değeri: ${urunler.sumOf { it.deger }.iki()} TL")
    urunler.groupBy { it.kategori }
        .mapValues { (_, liste) -> liste.sumOf { it.deger } }
        .toSortedMap()
        .forEach { (k, t) -> println("$k: ${t.iki()}") }
    urunler.filter { it.stok < 10 }.forEach { println("Az stok: ${it.ad} (${it.stok})") }
}
