1. C++ nerede? (30 dk)

C++, 1985'te Bjarne Stroustrup tarafından C'ye sınıflar eklenerek geliştirildi. Bugün hız ve donanım kontrolünün kritik olduğu her yerde kullanılır:

  • Oyun motorları: Unreal Engine, oyunların çoğunun çekirdeği.
  • CAD ve 3D: AutoCAD, SolidWorks, Rhino, Revit gibi programların çekirdekleri ve eklenti SDK'ları (ObjectARX, Rhino C++ SDK).
  • Tarayıcılar ve ofis yazılımları: Chrome, Firefox, Office.
  • Finans, bilimsel hesap, robotik, gömülü sistemler.

C++'ın felsefesi: "kullanmadığın şeyin bedelini ödemezsin". Yüksek seviyeli soyutlamalar (sınıflar, şablonlar) C kadar hızlı çalışacak şekilde tasarlanmıştır.

Tipler, auto ve string

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C++'ın temel tiplerini, auto ile tip çıkarımını, const ve constexpr'i, std::string işlemlerini, std::cin ve getline ile girdi almayı ve güvenli tip dönüşümünü bileceksin. Süre yaklaşık 4 saat.

1. Temel tipler ve auto (1 saat)

C++, C'nin bütün temel tiplerini (int, double, char, bool) içerir. Ek olarak auto ile derleyicinin tipi kendisinin çıkarmasını sağlayabilirsin:

#include <iostream>
#include <string>
#include <typeinfo>

int main() {
    auto adet = 42;            // int
    auto fiyat = 12.5;         // double
    auto ad = std::string("Kalem");
    auto stokta = adet > 0;    // bool

    std::cout << adet << " " << fiyat << " " << ad << " " << std::boolalpha << stokta << "\n";
    std::cout << sizeof(int) << " " << sizeof(double) << " " << sizeof(long long) << "\n";

    int a = 7, b = 2;
    std::cout << a / b << " " << static_cast<double>(a) / b << "\n";
    return 0;
}

42 12.5 Kalem true
4 8 8
3 3.5
  • auto tipi derleme anında belirler; değişken yine sabit tipli olur. Uzun tip adlarında (std::map<std::string, std::vector<int>>::iterator) hayat kurtarır.
  • std::boolalpha, bool'ları 1/0 yerine true/false yazdırır.
  • Tam sayı bölmesi C'deki gibidir. Dönüşüm için C'nin (double)a yazımı yerine static_cast<double>(a) tercih edilir: daha görünür ve daha güvenlidir.

Süslü parantezle başlatma daralan dönüşümleri yakalar:

int x = 3.9;     // derlenir, x = 3 (sessizce kesildi)
int y{3.9};      // HATA: double'dan int'e daralan dönüşüm

        case 'E': std::cout << "Ekle\n"; break;
        case 'L': std::cout << "Listele\n"; break;
        default:  std::cout << "?\n";

    return 0;

3. std::vector (1 saat)

vector, C++'ın varsayılan liste yapısıdır: öğeleri bellekte yan yana tutar (dizi gibi hızlı), gerektikçe büyür (Python listesi gibi).

#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> sehirler = {"Adana", "Bursa", "İzmir"};
    sehirler.push_back("Konya");                 // sona ekle
    sehirler.insert(sehirler.begin() + 1, "Ankara");
    sehirler.pop_back();                         // sondan sil
    sehirler.erase(sehirler.begin());            // baştan sil

    std::cout << sehirler.size() << " şehir, ilk: " << sehirler.front()
              << ", son: " << sehirler.back() << "\n";
    for (std::size_t i = 0; i < sehirler.size(); ++i)
        std::cout << i << ":" << sehirler[i] << " ";
    std::cout << "\n" << sehirler.at(1) << "\n";
    return 0;
}

4. Aralık tabanlı for (45 dk)

Bir koleksiyonun bütün öğelerini dolaşmanın en temiz yolu:

#include <iostream>
#include <vector>

int main() {
    std::vector<int> notlar = {72, 85, 64, 91, 58};

    for (int n : notlar) std::cout << n << " ";          // kopya
    std::cout << "\n";

    for (int& n : notlar) n += 5;                        // referans: değiştir
    for (const int& n : notlar) std::cout << n << " ";   // salt okunur
    std::cout << "\n";

    int en_buyuk = notlar[0];
    for (int n : notlar) if (n > en_buyuk) en_buyuk = n;
    std::cout << "en büyük: " << en_buyuk << "\n";
    return 0;
}

72 85 64 91 58 
77 90 69 96 63 
en büyük: 96
  • for (int n : v) her öğenin kopyasını alır; değiştirmek orijinali etkilemez.
  • for (int& n : v) referans alır; değişiklik orijinale yansır. (Referansları yarın ayrıntılı göreceğiz.)
  • Büyük öğeleri (std::string, struct) okurken const auto& kullan: kopyalama maliyetinden kurtulursun.

Alıştırma: Kullanıcıdan 0 girene kadar sayı okuyup bir vector'a ekleyen, sonra ortalamayı, ortalamanın üstündeki sayıları ve en küçüğü yazan bir program yaz.

2. Referanslar (1,5 saat)

Referans, var olan bir değişkenin ikinci adıdır. İşaretçinin daha güvenli ve kullanımı kolay hâlidir: NULL olamaz, başka bir şeye yönlendirilemez, * ile takip etmek gerekmez.

#include <iostream>
#include <string>
#include <vector>

void artir_kopya(int x) { x += 1; }
void artir_ref(int& x) { x += 1; }

double toplam(const std::vector<double>& v) {    // kopyalamadan, salt okunur
    double t = 0;
    for (double x : v) t += x;
    return t;
}

void takas(std::string& a, std::string& b) {
    std::string g = a; a = b; b = g;
}

int main() {
    int sayi = 5;
    artir_kopya(sayi);
    std::cout << sayi << " ";
    artir_ref(sayi);
    std::cout << sayi << "\n";

    std::vector<double> fiyatlar(1'000'000, 1.5);
    std::cout << toplam(fiyatlar) << "\n";

    std::string x = "sol", y = "sağ";
    takas(x, y);
    std::cout << x << " " << y << "\n";
    return 0;
}

5 6
1.5e+06
sağ sol

Parametre geçirme kuralları (modern C++'ın en önemli alışkanlığı):

Durum Yazım
Küçük tip (int, double, char), sadece okuma Değerle: int x
Büyük tip (string, vector, sınıf), sadece okuma const referans: const std::string& s
Fonksiyon değiştirecek Referans: std::string& s

Bir milyon öğelik vector'u değerle geçirseydik her çağrıda 8 MB kopyalanırdı. const& hiçbir şey kopyalamaz ve fonksiyonun yanlışlıkla değiştirmesini de engeller.

Tehlike: Yerel bir değişkene referans döndürme. Fonksiyon bitince değişken yok olur ve referans geçersiz bir yeri gösterir.

4. Şablon fonksiyonlar (45 dk)

Aynı algoritmayı int, double ve std::string için ayrı ayrı yazmak yerine şablon (template) yazılır; derleyici her tip için ayrı bir sürüm üretir:

#include <iostream>
#include <string>
#include <vector>

template <typename T>
T en_buyuk(const std::vector<T>& v) {
    T eb = v.at(0);
    for (const T& x : v) if (x > eb) eb = x;
    return eb;
}

template <typename T>
void yazdir(const std::vector<T>& v) {
    for (const auto& x : v) std::cout << x << " ";
    std::cout << "\n";
}

int main() {
    std::vector<int> a = {3, 9, 2};
    std::vector<double> b = {1.5, 0.2};
    std::vector<std::string> c = {"elma", "armut", "kiraz"};
    std::cout << en_buyuk(a) << " " << en_buyuk(b) << " " << en_buyuk(c) << "\n";
    yazdir(c);
    return 0;
}

9 1.5 kiraz
elma armut kiraz

T bir tip parametresidir. en_buyuk ancak > işlemini destekleyen tiplerle çalışır; desteklemeyen bir tiple çağırırsan derleme hatası alırsın. C++20'nin concepts özelliği bu şartı açıkça yazmayı sağlar (template <std::totally_ordered T>).

Aslında std::vector<int> de bir şablondur: vector her tip için ayrı üretilir. STL'nin (yarın) gücü buradan gelir.

Alıştırma: Bir std::vector<T> içindeki öğelerin ortalamasını döndüren template <typename T> double ortalama(const std::vector<T>& v) şablonunu yaz ve int ile double vector'larla dene.

GÜN 05

STL: koleksiyonlar ve algoritmalar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda STL'nin temel koleksiyonlarını (vector, map, unordered_map, set) ve algoritmalarını (sort, find_if, count_if, accumulate) kullanabilecek, lambda ifadeleri yazabilecek ve hangi koleksiyonun ne zaman uygun olduğunu bileceksin. Süre yaklaşık 4 saat.

1. map ve unordered_map (1 saat)

#include <iostream>
#include <map>
#include <unordered_map>
#include <string>

int main() {
    std::map<std::string, int> plaka = {{"İzmir", 35}, {"Ankara", 6}, {"Bursa", 16}};
    plaka["Konya"] = 42;                 // ekle ya da güncelle
    plaka["Ankara"] = 6;

    for (const auto& [sehir, no] : plaka)
        std::cout << sehir << "=" << no << " ";
    std::cout << "\n";

    if (auto it = plaka.find("Bursa"); it != plaka.end())
        std::cout << "Bursa: " << it->second << "\n";
    std::cout << "Rize var mı? " << plaka.contains("Rize") << "\n";

    std::unordered_map<std::string, int> sayac;
    for (std::string k : {"elma", "armut", "elma", "kiraz", "elma"}) sayac[k]++;
    std::cout << "elma: " << sayac["elma"] << "\n";
    return 0;
}

  • std::map anahtarları sıralı tutar (içeride bir dengeli ağaç): işlemler O(log n). "İzmir"in sona gelmesi, İ harfinin UTF-8 baytlarının büyük olmasındandır.
  • std::unordered_map bir hash tablosudur: sırasız ama ortalama O(1). Sadece arama ve sayma için genelde daha hızlıdır.
  • const auto& [sehir, no] yapısal bağlamadır: her çiftin anahtarını ve değerini ayrı adlara açar.
  • m[anahtar] anahtar yoksa varsayılan değerle ekler (sayaç kalıbında işe yarar). Sadece bakmak istiyorsan find ya da contains kullan.

2. Lambda ifadeleri (45 dk)

Lambda, yerinde tanımlanan isimsiz fonksiyondur. Algoritmalara "nasıl karşılaştıracağını" ya da "neyi arayacağını" söylemek için kullanılır:

#include <iostream>

int main() {
    auto kare = [](int x) { return x * x; };
    std::cout << kare(7) << "\n";

    double kdv = 0.20;
    auto kdvli = [kdv](double t) { return t * (1 + kdv); };     // kdv'yi yakala
    std::cout << kdvli(250) << "\n";

    int sayac = 0;
    auto say = [&sayac]() { ++sayac; };                          // referansla yakala
    say(); say(); say();
    std::cout << sayac << "\n";
    return 0;
}

Köşeli parantez yakalama listesidir: lambda'nın dışarıdaki hangi değişkenleri kullanacağını söyler. [kdv] kopyalar, [&sayac] referans alır.

3. Algoritmalar (1,5 saat)

<algorithm> ve <numeric> başlıkları, döngü yazmadan sık yapılan işleri yapan onlarca hazır fonksiyon sunar:

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <numeric>

struct Urun { std::string ad; double fiyat; int stok; };

int main() {
    std::vector<Urun> u = {{"Kalem", 12.5, 40}, {"Kulaklık", 850, 5}, {"Defter", 45, 25}, {"Mouse", 320, 12}};

    std::sort(u.begin(), u.end(), [](const Urun& a, const Urun& b) { return a.fiyat > b.fiyat; });
    for (const auto& x : u) std::cout << x.ad << " ";
    std::cout << "\n";

    auto it = std::find_if(u.begin(), u.end(), [](const Urun& x) { return x.stok < 10; });
    if (it != u.end()) std::cout << "az stok: " << it->ad << "\n";

    auto pahali = std::count_if(u.begin(), u.end(), [](const Urun& x) { return x.fiyat > 100; });
    double deger = std::accumulate(u.begin(), u.end(), 0.0,
                                   [](double t, const Urun& x) { return t + x.fiyat * x.stok; });
    std::cout << pahali << " pahalı ürün, stok değeri " << deger << "\n";

    std::vector<int> v = {5, 3, 8, 1};
    std::ranges::sort(v);                                       // C++20 kısa yazım
    std::cout << v.front() << ".." << v.back() << " max=" << *std::ranges::max_element(v) << "\n";
    return 0;
}

az stok: Kulaklık
2 pahalı ürün, stok değeri 9715
1..8 max=8
  • Algoritmalar koleksiyonla değil yineleyici (iterator) çiftiyle çalışır: begin() başı, end() sonun bir ötesini gösterir. Böylece aynı sort vector'da, dizide ve başka yapılarda çalışır.
  • find_if bulamazsa end() döndürür; her zaman kontrol et.
  • accumulate'in başlangıç değeri 0.0 olmalı; 0 yazarsan toplam int olarak hesaplanıp ondalıklar kaybolur.
  • C++20 ranges sürümleri (std::ranges::sort(v)) begin/end yazmadan çalışır.

GÜN 06

Sınıflar ve RAII

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C++'ta sınıf tanımlayıp kurucu, üye fonksiyon ve erişim belirteçlerini kullanabilecek, kalıtım ve sanal fonksiyonlarla çok biçimlilik kurabilecek, RAII ilkesini ve akıllı işaretçileri (unique_ptr, shared_ptr) öğreneceksin. Süre yaklaşık 4 saat.

1. Sınıflar ve kapsülleme (1,5 saat)

#include <iostream>
#include <string>
#include <stdexcept>

class Urun {
public:
    Urun(std::string ad, double fiyat, int stok)
        : ad_(std::move(ad)), fiyat_(fiyat), stok_(stok) {
        if (fiyat < 0) throw std::invalid_argument("fiyat negatif olamaz");
    }

    const std::string& ad() const { return ad_; }
    int stok() const { return stok_; }
    double deger() const { return fiyat_ * stok_; }

    void stok_ekle(int adet) { stok_ += adet; }
    bool sat(int adet) {
        if (adet > stok_) return false;
        stok_ -= adet;
        return true;
    }

private:
    std::string ad_;
    double fiyat_;
    int stok_;
};

int main() {
    Urun u("Kalem", 12.5, 40);
    u.sat(15);
    u.stok_ekle(5);
    std::cout << u.ad() << ": " << u.stok() << " adet, " << u.deger() << " TL\n";
    std::cout << "100 satılabilir mi? " << u.sat(100) << "\n";
    return 0;
}

Kalem: 30 adet, 375 TL
100 satılabilir mi? 0
  • public üyeler dışarıdan, private üyeler sadece sınıfın içinden erişilebilir. Veriyi gizleyip sadece kontrollü metotlarla değiştirmeye kapsülleme denir: stok hiçbir zaman negatif olamaz, çünkü stok_'a dışarıdan dokunulamaz.
  • Kurucu (constructor) nesne oluşturulurken çalışır. : ad_(...), fiyat_(...) başlatma listesidir; üyeleri doğrudan başlatır.
  • Sonu const olan metotlar nesneyi değiştirmeyeceğine söz verir; const bir nesne üzerinde sadece bunlar çağrılabilir.
  • Özel üyelerin sonuna _ koymak yaygın bir adlandırma geleneğidir.
  • struct ile class arasındaki tek fark, varsayılan erişimin struct'ta public olmasıdır. Sadece veri tutan basit tipler için struct kullanılır.

2. Kalıtım ve sanal fonksiyonlar (1 saat)

#include <iostream>
#include <memory>
#include <vector>
#include <numbers>

class Sekil {
public:
    virtual ~Sekil() = default;
    virtual double alan() const = 0;          // saf sanal: alt sınıflar yazmak zorunda
    virtual std::string ad() const { return "şekil"; }
};

class Dikdortgen : public Sekil {
public:
    Dikdortgen(double en, double boy) : en_(en), boy_(boy) {}
    double alan() const override { return en_ * boy_; }
    std::string ad() const override { return "dikdörtgen"; }
private:
    double en_, boy_;
};

class Daire : public Sekil {
public:
    explicit Daire(double r) : r_(r) {}
    double alan() const override { return std::numbers::pi * r_ * r_; }
    std::string ad() const override { return "daire"; }
private:
    double r_;
};

int main() {
    std::vector<std::unique_ptr<Sekil>> sekiller;
    sekiller.push_back(std::make_unique<Dikdortgen>(2, 3));
    sekiller.push_back(std::make_unique<Daire>(1));
    double toplam = 0;
    for (const auto& s : sekiller) {
        std::cout << s->ad() << ": " << s->alan() << "\n";
        toplam += s->alan();
    }
    std::cout << "toplam: " << toplam << "\n";
    return 0;
}

dikdörtgen: 6
daire: 3.14159
toplam: 9.14159
  • virtual fonksiyonlar, çağrının nesnenin gerçek tipine göre seçilmesini sağlar: listenin tipi Sekil olsa da her nesne kendi alan'ını çalıştırır (çok biçimlilik).
  • = 0 saf sanal fonksiyondur; Sekil bu yüzden soyut bir sınıftır ve doğrudan oluşturulamaz.
  • override derleyiciye "üst sınıftaki bir sanal fonksiyonu eziyorum" der; adı ya da imzayı yanlış yazarsan hata verir. Her zaman yaz.
  • Kalıtımla kullanılacak sınıfların yıkıcısı virtual olmalıdır.

3. RAII ve akıllı işaretçiler (1 saat)

RAII (Resource Acquisition Is Initialization), C++'ın en önemli fikridir: bir kaynak (bellek, dosya, kilit) bir nesnenin kurucusunda alınır, yıkıcısında (destructor) bırakılır. Nesne kapsamdan çıktığında yıkıcı otomatik çalışır; hata ya da erken return olsa bile.

#include <iostream>
#include <memory>

class Kaynak {
public:
    explicit Kaynak(int no) : no_(no) { std::cout << "aç " << no_ << "\n"; }
    ~Kaynak() { std::cout << "kapat " << no_ << "\n"; }
private:
    int no_;
};

int main() {
    {
        Kaynak a(1);
        auto b = std::make_unique<Kaynak>(2);      // tek sahip
        std::cout << "blok içinde\n";
    }                                              // b ve a burada otomatik kapanır
    auto c = std::make_shared<Kaynak>(3);          // paylaşılan sahiplik
    {
        auto d = c;
        std::cout << "sahip sayısı: " << c.use_count() << "\n";
    }
    std::cout << "sahip sayısı: " << c.use_count() << "\n";
    return 0;
}

1. Envanter özeti (1,5 saat)

C'deki aynı programın modern C++ hâli. Kategorileri sıralı tutmak için std::map yeterli; elle sıralama ya da arama gerekmiyor:

#include <iostream>
#include <iomanip>
#include <map>
#include <string>
#include <vector>

struct Urun {
    std::string ad;
    std::string kategori;
    double fiyat;
    int stok;
    double deger() const { return fiyat * stok; }
};

int main() {
    const std::vector<Urun> urunler = {
        {"Kalem", "kırtasiye", 12.5, 40},
        {"Defter", "kırtasiye", 45.0, 25},
        {"Kulaklık", "elektronik", 850.0, 5},
        {"Mouse", "elektronik", 320.0, 12},
        {"Çay", "gıda", 95.0, 30},
    };

    double toplam = 0;
    std::map<std::string, double> kategori;
    for (const auto& u : urunler) {
        toplam += u.deger();
        kategori[u.kategori] += u.deger();
    }

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Toplam stok değeri: " << toplam << " TL\n";
    for (const auto& [ad, t] : kategori) std::cout << ad << ": " << t << "\n";
    for (const auto& u : urunler)
        if (u.stok < 10) std::cout << "Az stok: " << u.ad << " (" << u.stok << ")\n";
    return 0;
}

2. İstisnalar (45 dk)

#include <iostream>
#include <stdexcept>
#include <string>

double guvenli_bol(double a, double b) {
    if (b == 0) throw std::invalid_argument("sıfıra bölme");
    return a / b;
}

int main() {
    try {
        std::cout << guvenli_bol(10, 4) << "\n";
        std::cout << std::stoi("12a") + std::stoi("abc") << "\n";
    } catch (const std::invalid_argument& e) {
        std::cout << "geçersiz: " << e.what() << "\n";
    }
    try {
        guvenli_bol(1, 0);
    } catch (const std::exception& e) {
        std::cout << "hata: " << e.what() << "\n";
    }
    return 0;
}
