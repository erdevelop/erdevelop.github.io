Rhino ve Grasshopper için C#

Grasshopper kullanan ve bileşenlerin yetmediği yerde kendi aracını yazmak isteyen cephe tasarımcıları için 7 günlük yoğun program. Hafta sonunda panelize eden, katlara ayıran, düzlemsellik ve ankraj kontrolü yapan bileşenlerden oluşan, Rhino komutuyla birlikte Package Manager'dan dağıtılabilen kendi Cephe Araçları eklentin olur.

Grasshopper'ı rahat kullanan, betik yazmaya başlamak ya da Python betiklerini hızlı ve dağıtılabilir araçlara dönüştürmek isteyen tasarımcılar. Programlama bilgisi şart değil ama bu sitedeki Python eğitimini bitirdiysen işin çok kolaylaşır. Örnekler Grasshopper eğitimindeki cephe panelleri üzerinden ilerler.

C# temelleri

~5 saat · 0/6 kontrol

Hedef ve C#'ın yeri

Gün sonunda Rhino 8'in betik editöründe C# yazıp çalıştırabilecek, dilin temel yapılarını (türler, listeler, döngüler, metotlar) bilecek ve panel ölçülerinden alan ve ağırlık hesaplayan ilk betiğin olacak. Süre yaklaşık 5 saat. Dosya: gun1.cs.

Neden C#? Rhino ve Grasshopper .NET üzerine kuruludur ve RhinoCommon API'si C# için yazılmıştır. Python ile aynı işleri yapabilirsin; C#'ın farkı: büyük tanımlamalarda belirgin şekilde hızlıdır, tür denetimi hataları yazarken yakalar ve kendi Grasshopper bileşenini (.gha) ve Rhino komutunu yazmanın standart yoludur (6-7. gün).

Ön bilgi: Bu sitedeki Grasshopper eğitiminin temel seviyesi. Python eğitimini bitirdiysen kavramlar tanıdık gelecek.

1. Ortam (45 dk)

  1. Rhino 8'de ScriptEditor komutunu yaz. File > New > C# (ya da dil seçicisinden C#).
  2. Betik .cs dosyası olarak kaydedilir. Çalıştırma: F5 ya da yeşil oynat düğmesi. Çıktı alttaki Terminal panelinde görünür.

Hedef

Gün sonunda RhinoCommon'ın geometri sınıflarını tanıyacak, Rhino modelinden nesne seçen, alan ve merkez hesaplayan ve panelleri numaralayıp Rhino'ya yazı etiketi ve nesne adı ekleyen bir betiğin olacak. Süre yaklaşık 5 saat. Dosya: gun2.cs.

1. RhinoCommon geometrisi (1,5 saat)

Tür Ne Örnek
Point3d Nokta (değer türü) new Point3d(0, 0, 3200)
Vector3d Yön Vector3d.ZAxis, p2 - p1
Plane Düzlem: orijin + X, Y eksenleri Plane.WorldXY, new Plane(p, normal)
Line İki nokta arası doğru new Line(p1, p2)
Curve Bütün eğrilerin temel sınıfı NurbsCurve, PolylineCurve, ArcCurve
Surface Yüzey NurbsSurface, PlaneSurface
Brep Sınır gösterimi: kırpılmış yüzey, katı, çoklu yüzey Brep.CreateFromSurface(srf) 
using System;
using Rhino;
using Rhino.Geometry;

var p0 = new Point3d(0, 0, 0);
var p1 = new Point3d(1500, 0, 0);
var p2 = new Point3d(1500, 0, 3200);
var p3 = new Point3d(0, 0, 3200);

var kontur = new Polyline(new[] { p0, p1, p2, p3, p0 });
Brep panel = Brep.CreateFromCornerPoints(p0, p1, p2, p3, RhinoDoc.ActiveDoc.ModelAbsoluteTolerance);

var amp = AreaMassProperties.Compute(panel);
Console.WriteLine($"Alan: {amp.Area / 1e6:F2} m², merkez: {amp.Centroid}");
Console.WriteLine($"Çevre: {kontur.Length} mm");

  3. Hesap fonksiyonları başarısız olursa genellikle null döner: if (amp == null) ....

2. Belgeye yazmak ve okumak (1,5 saat)

3. Panel numaralama betiği (1,5 saat)

// gun2.cs - seçilen panelleri kata ve x'e göre numaralar
using System;
using System.Collections.Generic;
using System.Linq;
using Rhino;
using Rhino.Commands;
using Rhino.DocObjects;
using Rhino.Geometry;
using Rhino.Input;

var doc = RhinoDoc.ActiveDoc;
const double KatTolerans = 100;   // mm

if (RhinoGet.GetMultipleObjects("Cam panellerini seç", false,
        ObjectType.Surface | ObjectType.PolysrfFilter, out ObjRef[] secilen) != Result.Success)
    return;

var paneller = new List<(ObjRef Ref, Point3d M, double Alan)>();
foreach (var r in secilen)
{
    Brep b = r.Brep();
    var amp = b == null ? null : AreaMassProperties.Compute(b);
    if (amp == null) continue;
    paneller.Add((r, amp.Centroid, amp.Area / 1e6));
}

// cephe XZ düzleminde: önce kat (z), sonra x
var sirali = paneller.OrderBy(p => Math.Round(p.M.Z / KatTolerans))
                     .ThenBy(p => p.M.X)
                     .ToList();

for (int i = 0; i < sirali.Count; i++)
{
    string no = $"P-{i + 1:000}";
    RhinoObject obj = sirali[i].Ref.Object();
    obj.Attributes.Name = no;          // nesne adına yaz
    obj.CommitChanges();
    doc.Objects.AddTextDot(no, sirali[i].M);
}
doc.Views.Redraw();
Console.WriteLine($"{sirali.Count} panel, toplam {sirali.Sum(p => p.Alan):F2} m²");
  1. (ObjRef Ref, Point3d M, double Alan): adlandırılmış tuple; ayrı bir sınıf yazmadan üç değeri bir arada tutar.
  2. OrderBy(...).ThenBy(...): iki ölçütlü sıralama. Python ve AutoLISP kurslarındaki "önce kat, sonra soldan sağa" kuralının C# hali.
  3. obj.Attributes.Name = no; obj.CommitChanges();: öznitelik değişikliği CommitChanges ile belgeye işlenir. Rhino'da SelName P-012 ile paneli bulabilirsin; ad Revit'e ve IFC'ye taşınır.
  4. Cephen XY düzlemindeyse M.Z yerine M.Y kullan.

Gün sonunda Grasshopper'ın C# Script bileşeninde girdi ve çıktı tanımlayabilecek, bir cephe yüzeyini istenen panel genişliğine ve kat yüksekliğine göre bölen ve derz boşluklu paneller üreten kendi panelizasyon bileşenin olacak. Süre yaklaşık 5 saat. Dosya: gun3.gh.

1. C# Script bileşeni (1,5 saat)

  1. Grasshopper'da tuvale çift tıkla, C# Script yaz. (Rhino 8'de yeni betik bileşeni; eski sürümlerde de aynı adla vardır.)

  3. Her girdinin sağ tık menüsünde: - Type Hint: girdinin türü (Surface, double, int, Curve…). Tür verirsen kodda doğrudan o türle gelir. - Item / List / Tree Access: tek değer mi, liste mi, veri ağacı mı.
  4. Bileşene çift tıkla: kod editörü açılır. Kodun yazıldığı yer RunScript metodudur:
private void RunScript(Surface srf, double gen, double kat, double derz,
                       ref object paneller, ref object bilgi)
{
    // kod buraya
}
  1. Girdiler metodun parametreleri, çıktılar ref object parametreleridir: çıktıya değer atamak için paneller = liste; yazarsın.
  2. Print("..."): bileşenin out çıktısına mesaj yazar (hata ayıklama için).

2. Panelizasyon bileşeni (2,5 saat)

Girdiler: srf (Surface, Item), gen (double, panel genişliği, varsayılan 1500), kat (double, kat yüksekliği, 3600), derz (double, panel arası boşluk, 20). Çıktılar: paneller, bilgi.

private void RunScript(Surface srf, double gen, double kat, double derz,
                       ref object paneller, ref object bilgi)
{
    if (srf == null || gen <= 0 || kat <= 0) return;

    Interval u = srf.Domain(0), v = srf.Domain(1);
    double uUzunluk = srf.IsoCurve(0, v.Min).GetLength();   // u yönünde (yatay) uzunluk
    double vUzunluk = srf.IsoCurve(1, u.Min).GetLength();   // v yönünde (düşey) uzunluk

    int nu = Math.Max(1, (int)Math.Round(uUzunluk / gen));
    int nv = Math.Max(1, (int)Math.Round(vUzunluk / kat));

    var sonuc = new List<Brep>();
    for (int j = 0; j < nv; j++)
    {
        for (int i = 0; i < nu; i++)
        {
            var du = new Interval(u.ParameterAt((double)i / nu), u.ParameterAt((double)(i + 1) / nu));
            var dv = new Interval(v.ParameterAt((double)j / nv), v.ParameterAt((double)(j + 1) / nv));
            Surface parca = srf.Trim(du, dv);
            if (parca == null) continue;

            Brep b = parca.ToBrep();
            if (derz > 0)
                b = KenardanIceri(parca, derz / 2) ?? b;   // her kenardan derz/2 içeri
            sonuc.Add(b);
        }
    }
    paneller = sonuc;
    bilgi = $"{nu} x {nv} = {sonuc.Count} panel · gerçek genişlik ≈ {uUzunluk / nu:F0} mm";
}

// Yüzeyin parametre alanını, kenar uzunluğuna oranla daraltarak derz açar
private Brep KenardanIceri(Surface s, double d)
{
    Interval u = s.Domain(0), v = s.Domain(1);
    double lu = s.IsoCurve(0, v.Mid).GetLength(), lv = s.IsoCurve(1, u.Mid).GetLength();
    if (lu <= 2 * d || lv <= 2 * d) return null;
    var du = new Interval(u.ParameterAt(d / lu), u.ParameterAt(1 - d / lu));
    var dv = new Interval(v.ParameterAt(d / lv), v.ParameterAt(1 - d / lv));
    return s.Trim(du, dv)?.ToBrep();
}
  1. Domain(0) u, Domain(1) v parametre aralığıdır. ParameterAt(0.25): aralığın %25'indeki parametre.
  2. IsoCurve(0, v.Min): v sabitken u boyunca giden eğri (yüzeyin alt kenarı). Uzunluğu panel sayısını belirler.
  3. Panel sayısı yuvarlanır; gerçek genişlik uUzunluk / nu olur ve bilgi çıktısında yazılır. 9000 mm cephede 1500 mm → 6 panel; 9200 mm'de yine 6 panel, gerçek genişlik ≈ 1533 mm.
  4. Parametrik bölme: Yüzeyin parametrizasyonu düzgün değilse eşit parametre aralıkları eşit uzunluk vermez. Düzlemsel ve tek eğrilikli cephelerde fark ihmal edilebilir; serbest yüzeylerde önce Rebuild ya da yay uzunluğuna göre bölme (Curve.DivideByLength) kullan.
  5. ?. (null koşullu): Trim null dönerse ToBrep çağrılmaz, sonuç null olur. ?? b: soldaki null ise sağdakini kullan.
  6. KenardanIceri yardımcı metodu RunScript'in dışında, aynı sınıfın içine yazılır (editörde RunScript'in kapanış parantezinden sonra). Derz, parametre alanı kenar uzunluğu oranında daraltılarak açılır; düzlemsel ve hafif eğrili panellerde yeterli bir yaklaşımdır.

3. Hata ve uyarı (45 dk)

GÜN 04

Veri ağaçları

~5 saat · 0/6 kontrol

Hedef

Gün sonunda Grasshopper veri ağaçlarını (DataTree) C#'ta okuyup yazabilecek ve panelleri katlara göre dallara ayıran, her kat için dikme ve kayıt hatlarını üreten, standart ve özel panelleri sınıflandıran bir bileşenin olacak. Süre yaklaşık 5 saat. Dosya: gun4.gh.

1. Veri ağaçları (1,5 saat)

Grasshopper'da veriler yollarla (path) ayrılmış dallarda durur: {0}, {1}, {0;3}… Her dal bir listedir. Katlara göre ayrılmış paneller için doğal yapı: her kat bir dal.

using Grasshopper;
using Grasshopper.Kernel.Data;

var agac = new DataTree<Point3d>();
agac.Add(new Point3d(0, 0, 0), new GH_Path(0));       // {0} dalına
agac.Add(new Point3d(1500, 0, 0), new GH_Path(0));
agac.Add(new Point3d(0, 0, 3600), new GH_Path(1));    // {1} dalına

int dalSayisi = agac.BranchCount;                     // 2
List<Point3d> kat0 = agac.Branch(0);                  // {0} dalının listesi
GH_Path yol = agac.Path(1);                           // {1}

Ağaç girdisi okumak: Girdiyi Tree Access yap, Type Hint ver. Kodda DataTree<Brep> p olarak gelir:

for (int i = 0; i < p.BranchCount; i++)
{
    GH_Path yol = p.Path(i);
    List<Brep> dal = p.Branch(i);
    Print($"{yol}: {dal.Count} öğe");
}
İşlem C#
Yeni ağaç new DataTree<T>()
Dala ekle agac.Add(deger, new GH_Path(k))
Dalı listeyle ekle agac.AddRange(liste, new GH_Path(k))
Dal sayısı / dal BranchCount, Branch(i)
Yolu al Path(i)
Bütün öğeler AllData()

2. Katlara ayırmak ve sıralamak (1,5 saat)

Girdi: p (Brep, List Access): 3. günün panelleri. tol (double, 100). Çıktılar: katlar (ağaç: her kat bir dal, soldan sağa), no (ağaç: panel numaraları).

private void RunScript(List<Brep> p, double tol, ref object katlar, ref object no)
{
    if (tol <= 0) tol = 100;
    var kayit = new List<(Brep B, Point3d M)>();
    foreach (var b in p)
    {
        if (b == null) continue;
        var amp = AreaMassProperties.Compute(b);
        if (amp != null) kayit.Add((b, amp.Centroid));
    }

    var gruplar = kayit.GroupBy(k => Math.Round(k.M.Z / tol))
                       .OrderBy(g => g.Key)
                       .ToList();

    var agac = new DataTree<Brep>();
    var noAgac = new DataTree<string>();
    int sayac = 0;
    for (int kat = 0; kat < gruplar.Count; kat++)
    {
        var yol = new GH_Path(kat);
        foreach (var k in gruplar[kat].OrderBy(k => k.M.X))
        {
            agac.Add(k.B, yol);
            noAgac.Add($"K{kat + 1}-P{++sayac:000}", yol);
        }
    }
    katlar = agac;
    no = noAgac;
}
  1. GroupBy(k => Math.Round(k.M.Z / tol)): merkezleri birbirine 100 mm'den yakın paneller aynı gruba (kata) düşer.
  2. Her grup ayrı bir dala yazılır; dal içinde x'e göre sıralı.
  3. ++sayac: önce artır, sonra kullan. Numaralar kat önekiyle: K1-P001, K2-P009…
  4. Çıktıyı bir Param Viewer'a bağla: dalları ve öğe sayılarını gör.

3. Dikme ve kayıt hatları (1 saat)

Her panelin dikey kenarları dikme, yatay kenarları kayıt hattıdır. Komşu panellerin ortak kenarları tek hat olmalı.

// girdi: p (List<Brep>)  çıktı: dikme, kayit
var dikmeler = new List<Line>();
var kayitlar = new List<Line>();
double tol = RhinoDoc.ActiveDoc.ModelAbsoluteTolerance;

foreach (var b in p)
{
    foreach (BrepEdge e in b.Edges)
    {
        var l = new Line(e.PointAtStart, e.PointAtEnd);
        Vector3d d = l.Direction;
        d.Unitize();
        bool dusey = Math.Abs(d.Z) > 0.99;
        var hedef = dusey ? dikmeler : kayitlar;
        // aynı hat (iki yönde de) daha önce eklendiyse ekleme
        if (!hedef.Any(h => (h.From.DistanceTo(l.From) < 1 && h.To.DistanceTo(l.To) < 1) ||
                            (h.From.DistanceTo(l.To) < 1 && h.To.DistanceTo(l.From) < 1)))
            hedef.Add(l);
    }
}
dikme = dikmeler;
kayit = kayitlar;
  1. Line.Direction yön vektörüdür; birim vektöre çevirince Z bileşeni ±1'e yakınsa doğru düşeydir.
  2. Değer türü tuzağı: l.Direction.Unitize() diye yazsaydık, Vector3d değer türü olduğu için birim vektöre çevrilen şey Direction'ın geçici bir kopyası olurdu ve sonraki l.Direction.Z hâlâ eski uzunlukta kalırdı. Bu yüzden önce d değişkenine alıp onu birim vektöre çeviriyoruz. C#'ın en sık şaşırtan davranışlarındandır.
  3. Derz açılmış panellerde kenarlar çakışmaz; bu durumda dikme hattını iki komşu kenarın ortası olarak kur (bonus).
  4. Toleranslı tekrar kontrolü (1 mm) küçük modellerde yeterli; binlerce kenarda daha hızlı bir yöntem için noktaları yuvarlayıp anahtar yapan bir HashSet kullan.

4. Standart ve özel paneller (45 dk)

// her panelin ölçüsünü 5 mm'ye yuvarlayıp say; en sık görülen ölçü standarttır
var olcu = p.Select(b => b.GetBoundingBox(true))
            .Select(bb => $"{Math.Round(bb.Diagonal.X / 5) * 5}x{Math.Round(bb.Diagonal.Z / 5) * 5}")
            .ToList();
string standart = olcu.GroupBy(o => o).OrderByDescending(g => g.Count()).First().Key;
var tip = olcu.Select(o => o == standart ? "STANDART" : "OZEL").ToList();

GÜN 05

Üretilebilirlik kontrolleri

~5 saat · 0/6 kontrol

Hedef

Gün sonunda cephe panellerinin üretilebilirliğini kontrol eden bir bileşenin olacak: panelin düzlemsellikten sapması (soğuk bükme), kendi düzleminde ölçülen gerçek boyutları, cam ağırlığı ve döşeme hatlarıyla kesişen ankraj noktaları. Süre yaklaşık 5 saat. Dosya: gun5.gh.

1. Düzlemsellik ve soğuk bükme (2 saat)

Serbest formlu cephelerde dört köşeli bir panelin dört köşesi aynı düzlemde olmayabilir. Düz cam, belirli bir sapmaya kadar yerinde bükülerek (soğuk bükme) monte edilebilir; sınır cam türüne, ölçüsüne ve üreticiye bağlıdır. Tasarımın her aşamasında bu sapmayı bilmek gerekir.

// girdi: p (List<Brep>), sinir (double, mm)  çıktı: sapma, duzlemsel, renk
private void RunScript(List<Brep> p, double sinir, ref object sapma, ref object duzlemsel, ref object renk)
{
    var sapmalar = new List<double>();
    var durum = new List<bool>();
    var renkler = new List<System.Drawing.Color>();

    foreach (var b in p)
    {
        var koseler = b.Vertices.Select(v => v.Location).ToList();
        if (koseler.Count < 3) { sapmalar.Add(double.NaN); durum.Add(false); renkler.Add(System.Drawing.Color.Gray); continue; }

        Plane.FitPlaneToPoints(koseler, out Plane uygun);
        double enBuyuk = koseler.Max(k => Math.Abs(uygun.DistanceTo(k)));

        sapmalar.Add(Math.Round(enBuyuk, 2));
        bool ok = enBuyuk <= sinir;
        durum.Add(ok);
        renkler.Add(ok ? System.Drawing.Color.SteelBlue
                       : enBuyuk <= 2 * sinir ? System.Drawing.Color.Orange
                                              : System.Drawing.Color.Firebrick);
    }
    sapma = sapmalar; duzlemsel = durum; renk = renkler;
}
  1. Plane.FitPlaneToPoints: noktalara en iyi uyan düzlemi bulur. Köşelerin bu düzleme en büyük uzaklığı sapmadır.
  2. Dört köşeli panelde köşeler düzleme simetrik sapar; bazı kaynaklar "bir köşenin diğer üçünün düzleminden uzaklığını" kullanır. Bu değer, uydurulmuş düzlem sapmasının yaklaşık dört katıdır. Hangi tanımı kullandığını üreticiyle aynı tut.
  3. renk çıktısını Custom Preview'a bağla: mavi uygun, turuncu sınırda, kırmızı yeniden bölme gerektiren paneller.
  4. sinir için başlangıç değeri projeye ve cam üreticisine göre belirlenir; burada kontrol mantığını kuruyoruz.

2. Panel düzleminde ölçü ve ağırlık (1,5 saat)

Eğik ya da dönmüş panelde dünya eksenlerindeki sınır kutusu yanıltıcıdır. Panelin kendi düzleminde ölçmek gerekir:

// girdi: b (Brep, Item), t (double, cam kalınlığı mm)  çıktı: g, y, kg
Plane.FitPlaneToPoints(b.Vertices.Select(v => v.Location), out Plane pl);
// düzlemin X ekseni panelin alt kenarına paralel olsun
var alt = b.Edges.OrderBy(e => (e.PointAtStart.Z + e.PointAtEnd.Z) / 2).First();
Vector3d xEksen = alt.PointAtEnd - alt.PointAtStart;
Vector3d yEksen = Vector3d.CrossProduct(pl.ZAxis, xEksen);   // düzlem içinde, X'e dik
pl = new Plane(pl.Origin, xEksen, yEksen);

BoundingBox kutu = b.GetBoundingBox(pl);     // düzleme göre sınır kutusu
g = Math.Round(kutu.Diagonal.X);
y = Math.Round(kutu.Diagonal.Y);
var amp = AreaMassProperties.Compute(b);
kg = amp == null ? 0 : Math.Round(amp.Area / 1e6 * t / 1000 * 2500, 1);
  1. GetBoundingBox(Plane): geometriyi o düzlemin koordinatlarında ölçer.
  2. Düzlemin X ekseni alt kenara hizalanır; böylece genişlik ve yükseklik camın sipariş ölçüsüne karşılık gelir.
  3. Vector3d.CrossProduct(a, b) iki vektöre dik vektörü verir: düzlemin normali ile alt kenarın çarpımı, panel düzleminde alt kenara dik (yukarı ya da aşağı bakan) Y eksenini verir. Ölçü için yön önemli değildir; görsel kontrol için düzlemi bir Plane parametresinde önizle.

3. Ankraj noktaları: kesişimler (1 saat)

Dikme hatları (4. gün) ile döşeme kenarları (Rhino.Inside.Revit eğitiminin 2. günü ya da Rhino'da çizilmiş çizgiler) nerede kesişiyorsa orada ankraj vardır.

// girdi: dikme (List<Curve>), doseme (List<Curve>)  çıktı: nokta, ad
// dosyanın başındaki using satırlarına ekle: using Rhino.Geometry.Intersect;

double tol = RhinoDoc.ActiveDoc.ModelAbsoluteTolerance;
var noktalar = new List<Point3d>();
var adlar = new List<string>();
for (int k = 0; k < doseme.Count; k++)
{
    for (int a = 0; a < dikme.Count; a++)
    {
        var x = Intersection.CurveCurve(dikme[a], doseme[k], 1.0, tol);
        if (x == null) continue;
        foreach (IntersectionEvent ev in x)
        {
            noktalar.Add(ev.PointA);
            adlar.Add($"B-K{k + 1}-D{a + 1:00}");
        }
    }
}
nokta = noktalar; ad = adlar;
  1. CurveCurve(a, b, tolerans, örtüşmeToleransı): iki eğrinin kesişimlerini verir. Burada tolerans 1 mm: dikme ile döşeme kenarı tam aynı düzlemde değilse (cephe döşemeden 150 mm uzakta) kesişim bulunmaz.
  2. Bu yüzden önce döşeme kenarlarını cephe düzlemine taşı (öteleme ya da cephe yüzeyine izdüşüm: Curve.ProjectToBrep) ya da dikme hatlarını döşeme kotunda yatay düzlemle kes: Intersection.CurvePlane(dikme, new Plane(new Point3d(0, 0, kot), Vector3d.ZAxis), tol). Cephe işinde ikincisi daha sağlamdır.
  3. Adlar kat ve dikme numarasını taşır: B-K2-D05. Revit'e aile olarak yerleştirirken bu ad parametre olur.

Gün sonu kontrolü (15 dk)

Hepsini işaretleyebiliyorsan 6. güne geçebilirsin.

Bonus: Sınırı aşan panelleri otomatik iki üçgen panele böl (köşegen boyunca): Brep.CreateFromCornerPoints ile üç köşeden iki yeni panel. Cephe tasarımında sık kullanılan bir çözüm; görsel etkisini mimarla konuşmak gerekir.

Şablonun oluşturduğu bileşen dosyasını şöyle değiştir:

using System;
using System.Collections.Generic;
using System.Linq;
using Grasshopper.Kernel;
using Rhino.Geometry;

namespace CepheAraclari
{
    public class PanelNumaraComponent : GH_Component
    {
        public PanelNumaraComponent()
          : base("Panel Numara", "PNum",
                 "Panelleri kata ve soldan sağa sıralar, numaralar ve alanlarını verir.",
                 "Cephe", "Panel")
        { }

        protected override void RegisterInputParams(GH_Component.GH_InputParamManager pManager)
        {
            pManager.AddBrepParameter("Paneller", "P", "Panel yüzeyleri", GH_ParamAccess.list);
            pManager.AddNumberParameter("Tolerans", "T", "Aynı kat sayılacak z farkı (mm)", GH_ParamAccess.item, 100.0);
            pManager.AddTextParameter("Önek", "O", "Numara öneki", GH_ParamAccess.item, "P");
        }

        protected override void RegisterOutputParams(GH_Component.GH_OutputParamManager pManager)
        {
            pManager.AddBrepParameter("Sıralı", "S", "Sıralı paneller", GH_ParamAccess.list);
            pManager.AddTextParameter("No", "N", "Panel numaraları", GH_ParamAccess.list);
            pManager.AddPointParameter("Merkez", "M", "Alan merkezleri", GH_ParamAccess.list);
            pManager.AddNumberParameter("Alan", "A", "Alan (m²)", GH_ParamAccess.list);
        }

        protected override void SolveInstance(IGH_DataAccess DA)
        {
            var paneller = new List<Brep>();
            double tol = 100;
            string onek = "P";
            if (!DA.GetDataList(0, paneller)) return;
            DA.GetData(1, ref tol);
            DA.GetData(2, ref onek);
            if (tol <= 0)
            {
                AddRuntimeMessage(GH_RuntimeMessageLevel.Error, "Tolerans pozitif olmalı.");
                return;
            }

            var kayit = new List<(Brep B, Point3d M, double A)>();
            foreach (var b in paneller)
            {
                var amp = b == null ? null : AreaMassProperties.Compute(b);
                if (amp == null)
                {
                    AddRuntimeMessage(GH_RuntimeMessageLevel.Warning, "Alanı hesaplanamayan bir panel atlandı.");
                    continue;
                }
                kayit.Add((b, amp.Centroid, amp.Area / 1e6));
            }

            var sirali = kayit.OrderBy(k => Math.Round(k.M.Z / tol)).ThenBy(k => k.M.X).ToList();

            DA.SetDataList(0, sirali.Select(k => k.B));
            DA.SetDataList(1, sirali.Select((k, i) => $"{onek}-{i + 1:000}"));
            DA.SetDataList(2, sirali.Select(k => k.M));
            DA.SetDataList(3, sirali.Select(k => Math.Round(k.A, 3)));
        }

        protected override System.Drawing.Bitmap Icon => null;   // 24x24 PNG kaynağı eklenebilir

        public override Guid ComponentGuid => new Guid("3f6b2c1e-8a4d-4c7e-9b1a-2d5e7f0a9c31");
    }
}

  2. DA.GetDataList(0, liste): 0 numaralı girdiyi listeye okur, veri yoksa false döner.
  3. Erişim list ise bileşen listeyi tek seferde alır; item olsaydı Grasshopper bileşeni her öğe için ayrı çalıştırırdı.
  4. Select((k, i) => ...): öğe ile birlikte sırasını da verir; numara üretmek için.

3. Derleme ve yükleme (1 saat)

  1. Derle (Ctrl+Shift+B): bin klasöründe CepheAraclari.gha oluşur. .gha, adı değiştirilmiş bir .NET kütüphanesidir.

Rhino komutu ve dağıtım

~5 saat · 0/6 kontrol

Hedef

1. Rhino komutu (2 saat)

Grasshopper bilmeyen bir ekip arkadaşı da panelleri numaralayabilsin. Rhino eklentisi şablonuyla (dotnet new rhino -n CepheKomutlari ya da Visual Studio'da Rhino Plug-In) yeni bir proje aç. Şablon bir eklenti sınıfı ve bir örnek komut oluşturur. Komutu şöyle değiştir:

using System;
using System.Linq;
using Rhino;
using Rhino.Commands;
using Rhino.DocObjects;
using Rhino.Geometry;
using Rhino.Input.Custom;

namespace CepheKomutlari
{
    public class CephePanelNoCommand : Command
    {
        public override string EnglishName => "CephePanelNo";

        protected override Result RunCommand(RhinoDoc doc, RunMode mode)
        {
            var go = new GetObject();
            go.SetCommandPrompt("Cam panellerini seç");
            go.GeometryFilter = ObjectType.Surface | ObjectType.PolysrfFilter;
            var onek = new OptionToggle(true, "K", "P");          // false: "K", true: "P"
            var tol = new OptionDouble(100, 1, 1000);
            go.AddOptionToggle("Onek", ref onek);
            go.AddOptionDouble("Tolerans", ref tol);

            while (true)
            {
                var r = go.GetMultiple(1, 0);
                if (r == Rhino.Input.GetResult.Option) continue;   // seçenek değişti, tekrar sor
                if (r != Rhino.Input.GetResult.Object) return Result.Cancel;
                break;
            }

            var paneller = go.Objects()
                .Select(o => (Ref: o, Amp: o.Brep() is Brep b ? AreaMassProperties.Compute(b) : null))
                .Where(x => x.Amp != null)
                .OrderBy(x => Math.Round(x.Amp.Centroid.Z / tol.CurrentValue))
                .ThenBy(x => x.Amp.Centroid.X)
                .ToList();

            string on = onek.CurrentValue ? "P" : "K";
            for (int i = 0; i < paneller.Count; i++)
            {
                string no = $"{on}-{i + 1:000}";
                var obj = paneller[i].Ref.Object();
                obj.Attributes.Name = no;
                obj.CommitChanges();
                doc.Objects.AddTextDot(no, paneller[i].Amp.Centroid);
            }
            doc.Views.Redraw();
            RhinoApp.WriteLine($"{paneller.Count} panel numaralandı.");
            return Result.Success;
        }
    }
}
  1. EnglishName: komut satırına yazılan ad (CephePanelNo). Rhino, komut adlarında İngilizce karakter bekler.
  2. GetObject + seçenekler: komut satırında Onek=P Tolerans=100 gibi tıklanabilir seçenekler çıkar. Kullanıcı seçeneği değiştirince GetResult.Option döner ve seçim yeniden istenir.
  3. o.Brep() is Brep b ? ... : null: desen eşleme (pattern matching); geometri Brep ise b adıyla kullan.
  4. Derlenen eklenti .rhp uzantılıdır. Elle yüklemek için Rhino'da PlugInManager > Install ya da .rhp dosyasını Rhino penceresine sürükle.
  5. Komut her Rhino oturumunda kullanılabilir; araç çubuğuna bir düğme olarak ! _CephePanelNo makrosuyla eklenir.
