Swift Programlama

Apple'ın iPhone, iPad, Mac ve Apple Watch uygulamaları için geliştirdiği Swift'i 7 günde, bol şemayla öğreten bir program. Değişkenlerden Swift'in güvenlik temeli olan optional'lara, switch ve closure'lardan koleksiyonlara, struct ile class arasındaki önemli farktan enum ve protokollere, hata yönetiminden async/await'e kadar ilerlersin. SwiftUI'ye geçmeden önce dilin kendisini sağlam öğrenirsin.

Tanışma ve Xcode

Hedef

1. Swift nerede? (30 dk)

Swift, Apple tarafından 2014'te Objective-C'nin yerine geçmek üzere duyuruldu ve 2015'te açık kaynak oldu.

  • iOS ve iPadOS uygulamaları: App Store'daki yeni uygulamaların büyük çoğunluğu Swift'le yazılıyor.
  • macOS, watchOS, tvOS, visionOS: Aynı dil ve büyük ölçüde aynı arayüz kütüphanesi (SwiftUI).
  • Sunucu: Vapor gibi çatılarla Linux'ta da çalışır.

Swift'in tasarım hedefleri: güvenli (null hatalarını optional'larla önler, dizilerde sınır kontrolü yapar), hızlı (derlenir), okunur (argüman etiketleriyle cümle gibi okunan çağrılar).

2. Kurulum (45 dk)

Mac'te:

  1. App Store'dan Xcode'u kur (büyük bir indirmedir).
  2. Xcode → File → New → Playground → Blank. Playground, yazdığın kodu anında çalıştırıp sonuçları sağ kenarda gösteren bir denemelik alandır.
  3. Gerçek bir uygulama için: File → New → Project → iOS → App, arayüz olarak SwiftUI.

Windows ve Linux'ta: swift.org/install adresinden Swift'i kur, VS Code'a Swift eklentisini ekle. Komut satırında:

swift --version
swift main.swift                 tek dosyayı çalıştırır
swift package init --type executable
swift run

iOS uygulaması derlemek ve App Store'a göndermek için Mac şarttır; ama dili her platformda öğrenebilirsin.

3. Optional'lar (1,5 saat)

Swift'te bir değer yoksa bu nil ile ifade edilir, ve sadece tipinin sonunda ? olan değişkenler nil olabilir:

var takma: String? = nil
print(takma?.count as Any)
print(takma?.count ?? 0)

takma = "Ay"
if let t = takma {
    print("takma ad: \(t), \(t.count) harf")
}

if let sayi = Int("12a") {
    print(sayi)
} else {
    print("geçersiz sayı")
}

let girdiler = ["12", "x", "30"]
var toplam = 0
for g in girdiler {
    toplam += Int(g) ?? 0
}
print(toplam)

let kesin: String? = "Bursa"
print(kesin!.count)

nil
0
takma ad: Ay, 2 harf
geçersiz sayı
42

İşlem Anlamı
String? Değeri olmayabilen (optional) tip
x?.count Optional zincirleme: x nil ise sonuç nil
x ?? varsayılan Nil birleştirme: x nil ise sağdaki değer
if let v = x { } Optional bağlama: değer varsa açıp kullan
guard let v = x else { return } Değer yoksa erken çık
x! Zorla aç; nil ise program çöker. Kaçın.

String ve String? farklı tiplerdir: bir optional'ı açmadan normal bir String gibi kullanamazsın. Böylece "boş değere erişme" hatası programı çalıştırmadan önce yakalanır.

4. guard (30 dk)

func siparisAdedi(_ girdi: String) -> Int {
    guard let adet = Int(girdi), adet > 0 else {
        print("geçersiz: \(girdi)")
        return 0
    }
    return adet
}

print(siparisAdedi("5"))
print(siparisAdedi("x"))
print(siparisAdedi("-2"))

5
geçersiz: x
0
geçersiz: -2
0

guard, "şu koşul sağlanmıyorsa hemen çık" demektir. guard let ile açılan değişken (adet) fonksiyonun geri kalanında kullanılabilir. Bu, iç içe if let piramidini önler; Swift kodunda çok yaygındır.

        return "BB"
    case (55..<70, _):
        return "CC"
    case (45..<55, _):
        return "DD"
    default:
        return "FF"
    }
}

Fonksiyonlar ve closure'lar

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Swift'te argüman etiketli fonksiyonlar yazabilecek, varsayılan değerleri, demet dönüşünü, inout parametreleri kullanabilecek ve closure'ları kısaltılmış biçimleriyle yazabileceksin. Süre yaklaşık 4 saat.

1. Fonksiyonlar ve argüman etiketleri (1,5 saat)

func kdvDahil(_ tutar: Double, oran: Double = 20) -> Double {
    return tutar * (1 + oran / 100)
}

func etiket(for ad: String, adet: Int = 1, birim: String = "adet") -> String {
    "\(ad): \(adet) \(birim)"
}

func minMax(_ sayilar: [Int]) -> (min: Int, max: Int) {
    var enk = sayilar[0], enb = sayilar[0]
    for x in sayilar {
        if x < enk { enk = x }
        if x > enb { enb = x }
    }
    return (enk, enb)
}

func topla(_ sayilar: Int...) -> Int {
    sayilar.reduce(0, +)
}

print(kdvDahil(1000), kdvDahil(1000, oran: 10))
print(etiket(for: "Kalem"))
print(etiket(for: "Kablo", adet: 50, birim: "metre"))
let sonuc = minMax([72, 85, 64, 91, 58])
print(sonuc.min, sonuc.max)
print(topla(), topla(1, 2, 3))

1200.0 1100.0
Kalem: 1 adet
Kablo: 50 metre
58 91
0 6
  • Her parametrenin bir argüman etiketi (çağıran tarafta yazılan) ve bir parametre adı (fonksiyon içinde kullanılan) vardır. for ad: String → çağrıda etiket(for: "Kalem"), içeride ad. Bu, çağrıların cümle gibi okunmasını sağlar.
  • _ etiketi kaldırır: kdvDahil(1000).
  • Etiket ayrıca yazılmazsa parametre adı etiket olur: oran: 10.
  • Varsayılan değerler (oran: Double = 20) ve adlı demet dönüşü ((min: Int, max: Int)) vardır.
  • Tek ifadeli fonksiyonda return yazılmayabilir.
  • Int... değişken sayıda argüman alır.

3. Closure'lar (1,5 saat)

Closure, isimsiz fonksiyondur. Swift'te aynı closure, tip çıkarımı sayesinde adım adım kısaltılabilir:

let notlar = [72, 85, 64, 91, 58]

let a = notlar.sorted(by: { (x: Int, y: Int) -> Bool in return x > y })
let b = notlar.sorted(by: { x, y in x > y })
let c = notlar.sorted { $0 > $1 }
let d = notlar.sorted(by: >)
print(a == b, b == c, c == d, d)

func uygula(_ liste: [Int], _ f: (Int) -> Int) -> [Int] {
    var sonuc: [Int] = []
    for x in liste { sonuc.append(f(x)) }
    return sonuc
}

func carpanYap(_ k: Int) -> (Int) -> Int {
    return { x in x * k }
}

print(uygula([1, 2, 3]) { $0 * $0 })
let ucKati = carpanYap(3)
print(uygula([1, 2, 3], ucKati))

var sayac = 0
let say = { sayac += 1 }
say(); say()
print(sayac)

true true true [91, 85, 72, 64, 58]
[1, 4, 9]
[3, 6, 9]
2
Biçim
{ (x: Int, y: Int) -> Bool in return x > y } Tam yazım
{ x, y in x > y } Tipler çıkarılır, tek ifadede return yok
{ $0 > $1 } Kısa parametre adları
sorted(by: >) İşlem doğrudan fonksiyon olarak
sorted { $0 > $1 } Sondaki closure: son argüman parantez dışında

Closure'lar dışarıdaki değişkenleri yakalar (sayac). SwiftUI'de düğme eylemleri, ağ isteği tamamlanınca çalışacak kod hep closure'dır.

GÜN 06

struct, class, enum, protokol

~4 saat · 0/4 kontrol

Hedef

Gün sonunda Swift'te struct ve class arasındaki temel farkı (değer ve referans tipi) bilecek, mutating metotlar yazabilecek, ilişkili değerli enum'lar kullanabilecek, protokol tanımlayıp uygulayabilecek ve extension ile mevcut tiplere özellik ekleyebileceksin. Süre yaklaşık 4 saat.

1. struct (1 saat)

struct Urun {
    let ad: String
    var fiyat: Double
    private(set) var stok: Int

    var deger: Double { fiyat * Double(stok) }

    init?(ad: String, fiyat: Double, stok: Int = 0) {
        guard fiyat >= 0 else { return nil }
        self.ad = ad
        self.fiyat = fiyat
        self.stok = stok
    }

    mutating func sat(_ adet: Int) -> Bool {
        guard adet <= stok else { return false }
        stok -= adet
        return true
    }
}

var u = Urun(ad: "Kalem", fiyat: 12.5, stok: 40)!
_ = u.sat(15)
let satildi = u.sat(100)
print(u.ad, u.stok, u.deger, satildi)
print(Urun(ad: "X", fiyat: -5) == nil)

true
  • struct özellikler (let/var), hesaplanan özellikler (var deger: Double { ... }) ve metotlar içerir.
  • init? başarısız olabilen kurucudur: geçersiz veride nil döndürür, sonuç optional'dır.
  • struct'ı değiştiren metotlar mutating olarak işaretlenir.
  • private(set) dışarıdan okunur ama değiştirilemez yapar.
  • Kendi init'ini yazmazsan Swift, bütün özellikleri alan bir kurucuyu otomatik üretir (dünkü Urun örneğindeki gibi).
  • _ = ... dönüş değerini bilerek yok saymaktır.

4. Protokoller ve extension (1 saat)

import Foundation

protocol Sekilli {
    var alan: Double { get }
    func aciklama() -> String
}

extension Sekilli {
    func aciklama() -> String { "alan \(alan)" }
}

struct Dikdortgen: Sekilli {
    let en, boy: Double
    var alan: Double { en * boy }
}

struct Kare: Sekilli, CustomStringConvertible {
    let a: Double
    var alan: Double { a * a }
    var description: String { "Kare(\(a))" }
}

extension Double {
    var tl: String { String(format: "%.2f TL", self) }
}

let liste: [any Sekilli] = [Dikdortgen(en: 2, boy: 3), Kare(a: 2)]
for s in liste {
    print(s.aciklama())
}
print(Kare(a: 3), liste.reduce(0) { $0 + $1.alan })
print(12565.0.tl)

  • protocol, bir tipin sahip olması gereken özellik ve metotları tanımlar (diğer dillerdeki interface).
  • extension, mevcut bir tipe (hatta Double gibi standart tiplere) özellik ve metot ekler. Protokol extension'ı varsayılan uygulama sağlar.

Hatalar, async ve proje

~4 saat · 0/5 kontrol

Hedef

Gün sonunda Swift'te throws, do-catch ve try? ile hata yönetebilecek, async/await'in ne işe yaradığını bilecek, haftanın konularını birleştiren envanter özeti programını yazmış olacak ve Swift Package Manager ile SwiftUI'ye geçiş yolunu bileceksin. Süre yaklaşık 4 saat.

1. Hata yönetimi (1,5 saat)

import Foundation

enum SiparisHatasi: Error {
    case gecersiz(String)
    case yetersiz(istenen: Int, stok: Int)
}

func siparis(stok: Int, girdi: String) throws -> Int {
    guard let adet = Int(girdi.trimmingCharacters(in: .whitespaces)), adet > 0 else {
        throw SiparisHatasi.gecersiz(girdi)
    }
    guard adet <= stok else {
        throw SiparisHatasi.yetersiz(istenen: adet, stok: stok)
    }
    return stok - adet
}

var stok = 10
for g in ["3", "x", "20", " 2 "] {
    do {
        stok = try siparis(stok: stok, girdi: g)
        print("kalan", stok)
    } catch SiparisHatasi.yetersiz(let istenen, let mevcut) {
        print("\(istenen) istendi, stokta \(mevcut) var")
    } catch {
        print("hata:", error)
    }
}

let sonuc = try? siparis(stok: 5, girdi: "9")
print(sonuc as Any)

kalan 7
hata: gecersiz("x")

nil
  • Hatalar Error protokolünü uygulayan tiplerdir; genelde bir enum.
  • Hata fırlatabilen fonksiyon throws ile işaretlenir; çağırırken try yazmak zorunludur. Böylece hangi satırın hata verebileceği kodda açıkça görünür.
  • do { try ... } catch { } hatayı yakalar; catch kolları desenlerle eşleşebilir. Desensiz catch içinde hata error adıyla gelir.
  • try? hatayı nil'e çevirir; sonuç optional olur.
  • trimmingCharacters Foundation'dan gelir.

2. async/await (45 dk)

Ağdan veri çekmek gibi uzun işler arayüzü dondurmamalıdır. Swift bunu async/await ile çözer:

func stokGetir(_ ad: String) async throws -> Int {
    try await Task.sleep(for: .milliseconds(100))
    return ad.count * 10
}

func hepsiniGetir() async throws {
    async let a = stokGetir("Kalem")
    async let b = stokGetir("Defter")
    async let c = stokGetir("Mouse")
    let sonuclar = try await [a, b, c]
    print(sonuclar)                       // [50, 60, 50]
}
  • async fonksiyon askıya alınabilir; çağrısı await ile yapılır.
  • async let işleri aynı anda başlatır; üç 100 ms'lik iş toplam yaklaşık 100 ms sürer.
  • SwiftUI'de .task { try await hepsiniGetir() } ile ekran açılınca çalıştırılır. Ağ isteği için URLSession.shared.data(from: url) de bir async fonksiyondur.
