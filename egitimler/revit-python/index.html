1. Revit API ve Python (30 dk)

Revit, kendi içindeki bütün nesnelere (duvar, kapı, seviye, görünüş, parametre) programla erişilebilen bir API (uygulama programlama arayüzü) sunar. Bu API .NET üzerinde yazılmıştır; doğal dili C#'tır. Python'u Revit'e bağlamanın yolları:

Araç Ne Ne zaman

C# eklenti Visual Studio ile derlenen eklenti Satılacak ürün, en yüksek performans

Hepsinde aynı Revit API kullanılır: bu kursta öğrendiğin FilteredElementCollector, Transaction ve Parameter bilgisi Dynamo'nun Python düğümünde de, C#'ta da geçerlidir.

Neler yapılabilir? Yüzlerce panele konumuna göre numara vermek, bir parametreyi başka parametrelerden hesaplayıp doldurmak, ölçüsü sınırı aşan elemanları bulmak, eleman listelerini Excel'e aktarmak, görünüş ve pafta oluşturmak, aile yerleştirmek. Bir insanın fareyle yapabildiği hemen her şey.

2. pyRevit'i kurmak (30 dk)

  1. Revit'i kapat.
  2. pyrevitlabs.io adresinden (ya da GitHub'daki pyrevitlabs/pyRevit sürümler sayfasından) güncel pyRevit yükleyicisini indir. Yönetici yetkin yoksa “Admin” olmayan yükleyiciyi seç.
  3. Kurulumu tamamla ve Revit'i aç. Şeritte pyRevit sekmesi görünmeli. İlk açılışta eklentinin yüklenmesine izin ver.

pyRevit sekmesinde işine yarayacak birkaç şey:

  • Settings: Ayarlar. Kendi eklenti klasörünü buradan ekleyeceğiz.
  • Reload: Eklentileri yeniden yükler. Yeni bir düğme ya da klasör eklediğinde gerekir; sadece bir script.py'nin içeriğini değiştirdiğinde gerekmez, düğmeye her basışta dosya baştan okunur.
  • Hazır gelen araçlar (Select, Modify, Analysis…) da Python'la yazılmıştır ve kaynak kodları okunabilir: öğrenmek için çok iyi örnekler.

# -*- coding: utf-8 -*-
"""Modeldeki duvar ve seviye sayısını gösterir."""
from pyrevit import revit, DB

doc = revit.doc

duvarlar = DB.FilteredElementCollector(doc) \
    .OfCategory(DB.BuiltInCategory.OST_Walls) \
    .WhereElementIsNotElementType() \
    .ToElements()

seviyeler = DB.FilteredElementCollector(doc).OfClass(DB.Level).ToElements()

print("Belge: {}".format(doc.Title))
print("Duvar sayısı: {}".format(len(duvarlar)))
print("Seviye sayısı: {}".format(len(seviyeler)))

Sonra pyRevit sekmesinde Settings → Custom Extension Directories bölümüne C:\RevitAraclari klasörünü ekle, kaydet ve Reload'a bas. Şeritte Cephe sekmesi ve içinde Merhaba düğmesi belirir. Düğmeye bas: pyRevit'in çıktı penceresi açılır ve print satırlarını gösterir.

  • Dosyanın en üstündeki docstring ("""...""") düğmenin üzerine gelince görünen ipucu olur.
  • from pyrevit import revit, DB: revit pyRevit'in yardımcılarıdır (revit.doc, revit.uidoc, revit.get_selection()); DB, Revit API'nin Autodesk.Revit.DB ad alanıdır. pyRevit kullanmasaydık from Autodesk.Revit.DB import * yazardık.
  • Satır sonundaki \ uzun bir ifadeyi alt satırda sürdürmeye yarar. Parantez içindeyse gerekmez.

Deneme modeli: Revit'te mimari şablonla yeni bir proje aç. İki seviye (Level 1, Level 2) zaten vardır. Wall komutunda tip olarak Curtain Wall seç ve 10–15 m uzunluğunda iki giydirme cephe çiz. Tipin özelliklerinde dikey ızgarayı 1500 mm, yatay ızgarayı 1200 mm aralıkla “Fixed Distance” yap ki paneller oluşsun. Birkaç da normal duvar çiz. Bütün kurs boyunca bu modeli kullanacağız.

5. IronPython 2.7 ile yazmak (45 dk)

pyRevit'in varsayılan Python motoru IronPython 2.7'dir: .NET üzerinde çalışan bir Python 2.7. Revit API ile en sorunsuz çalışan motor budur; pyRevit 5 ile deneysel IronPython 3.4 ve CPython 3 motorları da gelir ama bazı araçlarla sorun çıkarabilir. Bu kursta bütün Revit kodunu hem Python 2.7'de hem Python 3'te çalışacak biçimde yazıyoruz. Dikkat edilecekler:

Konu Yapma Yap
Biçimli metin f"Adet: {n}" (2.7'de sözdizimi hatası) "Adet: {}".format(n)

Saf Python kısımlarını bilgisayarındaki Python 3 ile deneyip hatasız gördükten sonra Revit'e taşıyacağız. Örneğin, bir duvar uzunluğundan panel sayısını hesaplayan küçük bir fonksiyon:

# -*- coding: utf-8 -*-
from __future__ import division
import math


def panel_sayisi(uzunluk_mm, aks_mm):
    """Verilen uzunluğa aks aralığıyla kaç panel sığar (son panel kısa olabilir)."""
    return int(math.ceil(uzunluk_mm / aks_mm))


def panel_olculeri(uzunluk_mm, aks_mm):
    n = panel_sayisi(uzunluk_mm, aks_mm)
    olculer = [aks_mm] * (n - 1)
    olculer.append(round(uzunluk_mm - aks_mm * (n - 1), 1))
    return olculer


if __name__ == "__main__":
    for uzunluk in (12000, 13250, 1400):
        o = panel_olculeri(uzunluk, 1500)
        print("{} mm -> {} panel, son panel {} mm".format(uzunluk, len(o), o[-1]))

6. Çıktı penceresi (30 dk)

pyRevit'in çıktı penceresi düz print'ten fazlasını yapabilir:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB, script

output = script.get_output()
output.print_md("# Seviyeler")

seviyeler = DB.FilteredElementCollector(revit.doc).OfClass(DB.Level).ToElements()
seviyeler = sorted(seviyeler, key=lambda s: s.Elevation)

for s in seviyeler:
    kot_mm = DB.UnitUtils.ConvertFromInternalUnits(s.Elevation, DB.UnitTypeId.Millimeters)
    print("{} : {} mm  {}".format(s.Name, round(kot_mm), output.linkify(s.Id)))

  • output.linkify(eleman_id) tıklanabilir bir bağlantı üretir: tıklayınca Revit o elemanı seçer ve gösterir. Kontrol araçlarında çok işe yarar.
  • s.Elevation feet cinsindendir; Revit API'nin iç birimi her zaman feet'tir. Çevirmeyi 3. günde ayrıntılı göreceğiz. UnitTypeId Revit 2021'den beri vardır; daha eski sürümlerde DisplayUnitType kullanılırdı.

Hedef

Süre yaklaşık 4 saat.

1. Revit'in nesne modeli (45 dk)

Revit'te modeldeki her şey bir Element'tir: duvar, kapı, seviye, görünüş, pafta, malzeme, hatta bir aile tipi. Her elemanın:

  • belgede benzersiz bir ElementId'si vardır (eleman.Id);
  • bir Category'si vardır (Walls, Doors, Curtain Panels…); kategori olmayan elemanlar da vardır (bazı iç ayarlar);
  • parametreleri vardır (yarın);
  • belirli bir .NET sınıfı vardır: Wall, FamilyInstance, Level, View…

Tip ve örnek (type / instance): Modele yerleştirdiğin her kapı bir örnektir (FamilyInstance); “Single-Flush 900×2100” ise bir tiptir (FamilySymbol). Duvarlarda örnek Wall, tip WallType'tır. Tipler de elemandır ve aynı kategoride durur; eleman toplarken çoğu zaman sadece örnekleri isteriz.

Bir elemandan diğerlerine geçmek:

İstediğin Kod
Elemanın tipi doc.GetElement(eleman.GetTypeId())
Seviyesi doc.GetElement(eleman.LevelId)
Kategori adı eleman.Category.Name
Id'den elemana doc.GetElement(eleman_id)
Kimlik sayısı eleman.Id.Value (Revit 2024+), eski sürümlerde eleman.Id.IntegerValue

ElementId Revit 2024'te 64 bitlik sayıya geçti; IntegerValue önce kullanımdan kaldırıldı, sonraki sürümlerde silindi. Birden fazla sürümde çalışacak kod için küçük bir yardımcı yazalım:

# -*- coding: utf-8 -*-
def id_sayi(eid):
    """ElementId'nin sayı değeri; Revit 2024 öncesi ve sonrası için."""
    return eid.Value if hasattr(eid, "Value") else eid.IntegerValue

2. FilteredElementCollector (1 saat 15 dk)

Belgedeki elemanlara ulaşmanın ana yolu FilteredElementCollector'dır. Kalıp hep aynıdır: belgeyi (ya da bir görünüşü) ver, filtreleri zincirle, sonucu al.

# -*- coding: utf-8 -*-
from pyrevit import revit, DB

doc = revit.doc

# 1) Kategoriye göre, sadece örnekler
paneller = DB.FilteredElementCollector(doc) \
    .OfCategory(DB.BuiltInCategory.OST_CurtainWallPanels) \
    .WhereElementIsNotElementType() \
    .ToElements()

# 2) Sınıfa göre: bütün duvarlar (Wall sınıfı)
duvarlar = DB.FilteredElementCollector(doc).OfClass(DB.Wall).ToElements()

# 3) Sadece tipler: projedeki bütün duvar tipleri
duvar_tipleri = DB.FilteredElementCollector(doc).OfClass(DB.WallType).ToElements()

# 4) Bir görünüşte görünen elemanlar
gorunuste = DB.FilteredElementCollector(doc, doc.ActiveView.Id) \
    .WhereElementIsNotElementType() \
    .GetElementCount()

print("Panel: {}  Duvar: {}  Duvar tipi: {}".format(len(paneller), len(duvarlar), len(duvar_tipleri)))
print("Aktif görünüşte eleman: {}".format(gorunuste))
  • OfCategory(BuiltInCategory.OST_...) kategoriye göre süzer. Sık kullanılanlar: OST_Walls, OST_Doors, OST_Windows, OST_Floors, OST_CurtainWallPanels, OST_CurtainWallMullions, OST_GenericModel, OST_StructuralColumns, OST_Levels, OST_Grids.
  • OfClass(Sınıf) .NET sınıfına göre süzer. OfClass(DB.Wall) giydirme cepheleri de getirir, çünkü onlar da birer Wall'dır.
  • WhereElementIsNotElementType() tipleri dışarıda bırakır; WhereElementIsElementType() sadece tipleri alır.
  • Sonuç: .ToElements() eleman listesi, .ToElementIds() id listesi, .FirstElement() ilki, .GetElementCount() sadece sayı.
  • Toplayıcı tek kullanımlıktır; ikinci bir sorgu için yenisini oluştur.

Duvar mı, giydirme cephe mi? İkisi de Wall sınıfındadır; farkı tipin Kind özelliği söyler:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB

doc = revit.doc
cepheler, normal = [], []
for w in DB.FilteredElementCollector(doc).OfClass(DB.Wall):
    if w.WallType.Kind == DB.WallKind.Curtain:
        cepheler.append(w)
    else:
        normal.append(w)
print("Giydirme cephe: {}  Diğer duvar: {}".format(len(cepheler), len(normal)))

Toplayıcı doğrudan bir döngüde de kullanılabilir; ToElements() demek şart değil.

3. Hızlı ve yavaş filtreler (45 dk)

Revit filtreleri ikiye ayırır:

  • Hızlı filtreler (OfCategory, OfClass, WhereElementIsNotElementType, ElementLevelFilter…) elemanı belleğe tam yüklemeden, veritabanının kaydına bakarak eler.
  • Yavaş filtreler (ElementParameterFilter, BoundingBoxIntersectsFilter…) elemanı açıp içine bakmak zorundadır.

Kural: önce hızlı filtrelerle daralt, sonra yavaşları ya da Python'daki koşulları uygula. Büyük bir modelde FilteredElementCollector(doc).WhereElementIsNotElementType() ile yüz binlerce eleman alıp Python'da kategori kontrolü yapmak dakikalar sürebilir.

Belirli bir seviyedeki paneller:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB

doc = revit.doc
seviye = DB.FilteredElementCollector(doc).OfClass(DB.Level) \
    .WhereElementIsNotElementType().FirstElement()

seviye_filtresi = DB.ElementLevelFilter(seviye.Id)
duvarlar = DB.FilteredElementCollector(doc) \
    .OfCategory(DB.BuiltInCategory.OST_Walls) \
    .WhereElementIsNotElementType() \
    .WherePasses(seviye_filtresi) \
    .ToElements()
print("{} seviyesindeki duvar: {}".format(seviye.Name, len(duvarlar)))

Python tarafında ek koşul eklemek de serbesttir; toplayıcıyı daralttıktan sonra liste kavrayışı (list comprehension) en okunur yoldur:

uzun_duvarlar = [w for w in duvarlar
                 if w.Location and w.Location.Curve.Length > 10.0]   # feet!

Burada 10.0 feet'tir (≈3,05 m). Yarın birimleri düzgün çevireceğiz.

4. Seçimi okumak (30 dk)

Kullanıcının önceden seçtiği elemanlar uidoc.Selection üzerinden okunur:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB, forms

doc = revit.doc
secili = [doc.GetElement(i) for i in revit.uidoc.Selection.GetElementIds()]
if not secili:
    forms.alert("Önce eleman seç.", exitscript=True)

kategoriler = {}
for e in secili:
    ad = e.Category.Name if e.Category else "(kategorisiz)"
    kategoriler[ad] = kategoriler.get(ad, 0) + 1

for ad in sorted(kategoriler):

1. Parametre nedir? (30 dk)

# -*- coding: utf-8 -*-
def deger(eleman, parametre):
    """parametre: BuiltInParameter ya da ad (metin). Değeri saklama tipine göre döndürür."""
    if isinstance(parametre, str):
        p = eleman.LookupParameter(parametre)
    else:
        p = eleman.get_Parameter(parametre)
    if p is None or not p.HasValue:
        return None
    st = p.StorageType
    if st == DB.StorageType.String:
        return p.AsString()
    if st == DB.StorageType.Double:
        return p.AsDouble()
    if st == DB.StorageType.Integer:
        return p.AsInteger()
    return p.AsElementId()

~4 saat · 0/7 kontrol

Hedef

Gün sonunda Revit'te modeli değiştiren her işlemin neden bir Transaction içinde olması gerektiğini bilecek; parametre yazacak; toplu değişiklikleri tek bir geri alma adımında toplayacak; hata olursa değişiklikleri geri alacak ve giydirme cephe panellerini kat kat, soldan sağa numaralandıran ilk gerçek aracını yazacaksın. Süre yaklaşık 4,5 saat.

1. Transaction: neden ve nasıl (45 dk)

Revit modeli okurken serbestsin, ama değiştirmek için (parametre yazmak, eleman oluşturmak, silmek) bir Transaction (işlem) açmak zorundasın. Açmazsan Revit şu hatayı verir: “Attempt to modify the model outside of transaction.”

Transaction'ın üç işi vardır:

  • Değişikliklerin hepsini tek bir geri alma (Undo) adımı yapar. Kullanıcı Ctrl+Z'ye bir kez basınca betiğin yaptığı 300 değişiklik birden geri gelir.
  • Geri alma listesinde görünen adı belirler.
  • Bir şey ters giderse hiçbiri olmamış gibi geri alınabilir (RollBack).

Revit API'nin kendi yazımı:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB

doc = revit.doc
panel = revit.get_selection().elements[0]

t = DB.Transaction(doc, "Panele yorum yaz")
t.Start()
try:
    p = panel.get_Parameter(DB.BuiltInParameter.ALL_MODEL_INSTANCE_COMMENTS)
    p.Set("kontrol edildi")
    t.Commit()
except Exception as hata:
    t.RollBack()
    print("Geri alındı: {}".format(hata))

pyRevit aynı kalıbı bir bağlam yöneticisi (with) olarak sunar; bloktan hata çıkarsa kendisi geri alır:

# -*- coding: utf-8 -*-
from pyrevit import revit, DB

panel = revit.get_selection().elements[0]
with revit.Transaction("Panele yorum yaz"):
    panel.get_Parameter(DB.BuiltInParameter.ALL_MODEL_INSTANCE_COMMENTS).Set("kontrol edildi")

Bu kursta bundan sonra with revit.Transaction(...) kullanacağız. İki kural:

  • Transaction'ı döngünün dışına koy. 300 panel için 300 Transaction açmak hem yavaştır hem geri alma listesini doldurur.
  • Transaction içinde kullanıcıya soru sorma (seçim, form). Önce bütün girdileri al, sonra işlemi aç.

2. Parametre yazmak (45 dk)

Parameter.Set(değer) saklama tipine uygun değer ister:

Yazmadan önce kontrol edilecekler: parametre var mı (None değil mi), salt okunur mu (p.IsReadOnly), tipi doğru mu. Örnek: seçili elemanların Comments parametresine kullanıcının yazdığı metni toplu olarak yazmak.

3. Numaralandırma mantığı: saf Python (1 saat)

Cephe işinde en sık istenen iş: panellere kat ve sıra numarası vermek. İstenen düzen:

  • Her yatay panel sırası bir kattır; alttan üste 01, 02, 03…
  • Her katta paneller cephe boyunca soldan sağa 001, 002…
  • Numara biçimi: P-01-003 (1. kat, 3. panel).

Revit tarafını yazmadan önce mantığı saf Python'da kuralım. Her panel için iki sayıya ihtiyacımız var: cephe boyunca yatay konum u ve yükseklik z (ikisi de mm). Modelde paneller tam aynı z'de olmayabilir (0,0001 mm'lik farklar, eğimli cepheler), bu yüzden z'leri bir tolerans içinde aynı kata gruplayacağız:

# -*- coding: utf-8 -*-
from __future__ import division


def katlara_ayir(paneller, tolerans=50.0):
    """paneller: [{'id', 'u', 'z'}]. z'ye göre, tolerans içinde olanları aynı kata koyar."""
    katlar = []
    for p in sorted(paneller, key=lambda p: p["z"]):
        if katlar and abs(p["z"] - katlar[-1][0]["z"]) <= tolerans:
            katlar[-1].append(p)
        else:
            katlar.append([p])
    return katlar


def numarala(paneller, onek="P", tolerans=50.0):
    """{id: numara} sözlüğü döndürür."""
    sonuc = {}
    for k, kat in enumerate(katlara_ayir(paneller, tolerans), 1):
        for s, p in enumerate(sorted(kat, key=lambda p: p["u"]), 1):
            sonuc[p["id"]] = "{}-{:02d}-{:03d}".format(onek, k, s)
    return sonuc


if __name__ == "__main__":
    ornek = [
        {"id": 901, "u": 3000.0, "z": 0.0},
        {"id": 902, "u": 0.0, "z": 0.0001},
        {"id": 903, "u": 1500.0, "z": -0.0002},
        {"id": 904, "u": 1500.0, "z": 1200.0},
        {"id": 905, "u": 0.0, "z": 1199.9998},
        {"id": 906, "u": 3000.0, "z": 1200.0},
        {"id": 907, "u": 750.0, "z": 2400.0},
    ]
    numaralar = numarala(ornek)
    for pid in sorted(numaralar, key=numaralar.get):
        print("{} -> {}".format(pid, numaralar[pid]))

4. Revit'ten u ve z'yi almak (45 dk)

Bir panelin merkezini BoundingBox'ından alabiliriz: eleman.get_BoundingBox(None) modeldeki en küçük kutuyu (Min ve Max köşeleri) verir. u, merkezin cephe duvarının başlangıç noktasından duvar doğrultusundaki uzaklığıdır: iki vektörün nokta çarpımı (dot product).

# -*- coding: utf-8 -*-
from pyrevit import DB

FT_MM = 304.8


def panel_konumu(panel, duvar):
    """Panelin cephe boyunca u ve yükseklik z değerlerini mm olarak döndürür."""
    kutu = panel.get_BoundingBox(None)
    merkez = (kutu.Min + kutu.Max) / 2.0
    egri = duvar.Location.Curve
    bas = egri.GetEndPoint(0)
    yon = (egri.GetEndPoint(1) - bas).Normalize()
    u = (merkez - bas).DotProduct(yon)
    return {"id": panel.Id, "u": u * FT_MM, "z": merkez.Z * FT_MM}
  • XYZ nesneleri toplanır, çıkarılır ve sayıya bölünebilir; Normalize() birim vektör, DotProduct nokta çarpımı verir. Yarın XYZ'yi ayrıntılı göreceğiz.
  • Bu yöntem düz giydirme cephelerde doğrudur. Eğri cephelerde u için egri.Project(merkez).Parameter kullanılır.
  • Panel sınırlarını tam veren yol panel.Transform ve geometridir; numaralandırma için kutu merkezi yeterli ve hızlıdır.

# -*- coding: utf-8 -*-
from __future__ import division
import math


class V(object):
    """Revit XYZ'nin küçük bir benzeri (mm ile çalışıyoruz)."""

    def __init__(self, x, y, z=0.0):
        self.x, self.y, self.z = x, y, z

    def __add__(self, o):
        return V(self.x + o.x, self.y + o.y, self.z + o.z)

    def __sub__(self, o):
        return V(self.x - o.x, self.y - o.y, self.z - o.z)

    def __mul__(self, k):
        return V(self.x * k, self.y * k, self.z * k)

    def uzunluk(self):
        return math.sqrt(self.x ** 2 + self.y ** 2 + self.z ** 2)

    def birim(self):
        u = self.uzunluk()
        return V(self.x / u, self.y / u, self.z / u)

    def nokta(self, o):
        return self.x * o.x + self.y * o.y + self.z * o.z

    def capraz(self, o):
        return V(self.y * o.z - self.z * o.y, self.z * o.x - self.x * o.z, self.x * o.y - self.y * o.x)

    def __repr__(self):
        return "V({:.1f}, {:.1f}, {:.1f})".format(self.x, self.y, self.z)


if __name__ == "__main__":
    bas, son = V(0, 0), V(12000, 5000)
    yon = (son - bas).birim()
    print("uzunluk: {:.1f} mm".format((son - bas).uzunluk()))
    print("yön: {}".format(yon))
    print("4000 mm ilerisi: {}".format(bas + yon * 4000))

4. Braket yerleşimi: saf Python (45 dk)

Problem: Her dikey dikmenin her kat döşemesiyle kesiştiği yere bir ankraj braketi konacak. Braket, cephe yüzünden içeri doğru 120 mm kaydırılacak (döşeme alnına). En alttaki döşemede de braket var; en üst kotun üstündeki seviyeler (çatı parapeti gibi) hariç.

# -*- coding: utf-8 -*-
from __future__ import division
from vektor import V


def braket_noktalari(bas, son, u_listesi, kotlar, iceri=120.0, ust_sinir=None):
    """Her dikme (u) ile her kotun kesişiminde, cephe yüzünden iceri mm kaydırılmış noktalar."""
    yon = (son - bas).birim()
    ic = V(0, 0, 1).capraz(yon)          # cepheye dik, içeri
    noktalar = []
    for z in sorted(kotlar):
        if ust_sinir is not None and z > ust_sinir:
            continue
        for u in sorted(u_listesi):
            p = bas + yon * u + ic * iceri
            noktalar.append((u, z, V(p.x, p.y, z)))
    return noktalar

    """Bir panelin ölçülerini (mm) kontrol eder; sorunların listesini döndürür."""
    sorunlar = []

    if yukseklik < sinir["yuk_min"] - TOL:
        sorunlar.append("yükseklik {:.0f} < {:.0f}".format(yukseklik, sinir["yuk_min"]))
    if yukseklik > sinir["yuk_max"] + TOL:

# -*- coding: utf-8 -*-
from __future__ import division
import codecs


def hucre(deger):
    """Bir değeri Türkçe Excel'in beklediği metne çevirir."""
    if deger is None:
        return ""
    if isinstance(deger, float):
        return ("{:.1f}".format(deger)).replace(".", ",")
    metin = u"{}".format(deger)
    if ";" in metin or '"' in metin or "\n" in metin:
        metin = u'"{}"'.format(metin.replace('"', '""'))
    return metin


def csv_yaz(yol, basliklar, satirlar):
    with codecs.open(yol, "w", "utf-8-sig") as f:
        f.write(u";".join(basliklar) + u"\r\n")
        for satir in satirlar:
            f.write(u";".join(hucre(d) for d in satir) + u"\r\n")
    return len(satirlar)

    return sonuc

def varsayilan_yol():
    kok = os.environ.get("APPDATA") or os.path.expanduser("~")
    return os.path.join(kok, "ERD-Cephe", "ayarlar.json")


def oku(yol=None):
    yol = yol or varsayilan_yol()
    ayar = json.loads(json.dumps(VARSAYILAN))          # derin kopya
    try:
        with codecs.open(yol, "r", "utf-8") as f:
            kayitli = json.load(f)
    except (IOError, OSError, ValueError):
        return ayar
    for k, v in kayitli.items():
        if isinstance(v, dict) and isinstance(ayar.get(k), dict):
            ayar[k].update(v)
        else:
            ayar[k] = v
    return ayar


def yaz(ayar, yol=None):
    yol = yol or varsayilan_yol()
    klasor = os.path.dirname(yol)
    if not os.path.isdir(klasor):
        os.makedirs(klasor)
    with codecs.open(yol, "w", "utf-8") as f:
        f.write(json.dumps(ayar, indent=2, ensure_ascii=False, sort_keys=True))
    return yol

# -*- coding: utf-8 -*-
"""Revit API'ye bağlı ortak yardımcılar. Sadece Revit içinde import edilir."""
from pyrevit import revit, DB, script
from Autodesk.Revit.UI.Selection import ISelectionFilter, ObjectType
from Autodesk.Revit.Exceptions import OperationCanceledException

FT_MM = 304.8


class CepheFiltresi(ISelectionFilter):
    def AllowElement(self, e):
        return isinstance(e, DB.Wall) and e.WallType.Kind == DB.WallKind.Curtain

    def AllowReference(self, r, p):
        return False


def cephe_sec(mesaj="Giydirme cepheleri seç"):
    """Önceden seçili cepheleri ya da kullanıcının yeni seçimini döndürür; Esc'te betiği bitirir."""
    secili = [e for e in revit.get_selection().elements
              if isinstance(e, DB.Wall) and e.WallType.Kind == DB.WallKind.Curtain]
    if secili:
        return secili
    try:
        refs = revit.uidoc.Selection.PickObjects(ObjectType.Element, CepheFiltresi(), mesaj)
    except OperationCanceledException:
        script.exit()
    return [revit.doc.GetElement(r.ElementId) for r in refs]


def paneller(duvar):
    doc = revit.doc
    return [doc.GetElement(i) for i in duvar.CurtainGrid.GetPanelIds()]


def panel_olcu(panel):
    """(genişlik, yükseklik) mm; ölçüsüz panelde (kapı vb.) None."""
    g = panel.get_Parameter(DB.BuiltInParameter.CURTAIN_WALL_PANELS_WIDTH)
    y = panel.get_Parameter(DB.BuiltInParameter.CURTAIN_WALL_PANELS_HEIGHT)
    if g is None or y is None:
        return None
    return g.AsDouble() * FT_MM, y.AsDouble() * FT_MM


def panel_konumu(panel, duvar):
    kutu = panel.get_BoundingBox(None)
    if kutu is None:
        return None
    merkez = (kutu.Min + kutu.Max) / 2.0
    egri = duvar.Location.Curve
    bas = egri.GetEndPoint(0)
    yon = (egri.GetEndPoint(1) - bas).Normalize()
    return {"id": panel.Id, "u": (merkez - bas).DotProduct(yon) * FT_MM, "z": merkez.Z * FT_MM}


def mark(eleman):
    return eleman.get_Parameter(DB.BuiltInParameter.ALL_MODEL_MARK)
