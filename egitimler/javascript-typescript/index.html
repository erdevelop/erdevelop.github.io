Web'in dili JavaScript'i ve onun tipli hâli TypeScript'i, tarayıcıdan bağımsız olarak dilin kendisine odaklanarak 7 günde öğreten bol şemalı bir program. Değişkenlerden fonksiyonlara, dizilerin güçlü metotlarından asenkron programlamaya, sınıflardan modüllere ve sonunda TypeScript'in tip sistemine kadar ilerlersin. Her örnek Node.js ile çalıştırılmış, çıktısı sayfadadır.

GÜN 01

Tanışma ve Node.js

~4 saat · 0/5 kontrol

Hedef

Gün sonunda JavaScript'in nerede çalıştığını (tarayıcı ve Node.js), dilin standardını, Node.js'i kurup ilk programını çalıştırmayı ve tarayıcı konsolunu deneme alanı olarak kullanmayı bileceksin. Süre yaklaşık 4 saat.

Bu kurs hakkında: Programlama Dilleri grubundaki bütün eğitimler aynı iskeleti izler ve 7. günde aynı envanter özeti projesiyle biter. Bu kurs JavaScript'in dilin kendisine odaklanır: sayfa elemanlarıyla (DOM) çalışmak Web Araçları ve İnternet Programcılığı eğitimlerinde anlatılır. Son gün, JavaScript'e tip sistemi ekleyen TypeScript'e geçeriz.

1. JavaScript nerede? (30 dk)

JavaScript 1995'te Netscape tarayıcısı için 10 günde tasarlandı. Bugün dünyanın en yaygın programlama dilidir, çünkü her tarayıcıda çalışan tek dildir:

  • Web sayfaları: Her etkileşimli site (React, Vue, Angular gibi kütüphanelerle).
  • Sunucu: Node.js, Deno, Bun ile API'ler ve web sunucuları.
  • Mobil: React Native.
  • Masaüstü: Electron (VS Code, Slack, Discord bu şekilde yazılmıştır).
  • Betikler ve otomasyon: Google Apps Script, Photoshop ve birçok programın betik dili.

Java ile ilgisi yoktur; isim benzerliği o yılların pazarlama tercihidir. Dilin resmî standardının adı ECMAScript'tir (ES). 2015'teki büyük güncellemeden (ES6 / ES2015) beri her yıl yeni bir sürüm çıkar. Bu kurs modern JavaScript'i (ES2022+) kullanır.

2. Tarayıcı ve Node.js (45 dk)

JavaScript'i çalıştıran programa motor denir: Chrome ve Edge'de V8, Firefox'ta SpiderMonkey, Safari'de JavaScriptCore. Node.js, V8 motorunu tarayıcıdan çıkarıp bilgisayarda çalıştırır ve ona dosya, ağ ve işletim sistemi erişimi ekler.

Hedef

3. Fonksiyonlar değerdir (1 saat)

JavaScript'te fonksiyonlar sayı ya da metin gibi değerdir: değişkene atanabilir, başka fonksiyona argüman olarak verilebilir, fonksiyondan döndürülebilir.

console.log(uygula(["ali", "ece"], s => s.toUpperCase()));

const islemler = { topla: (a, b) => a + b, carp: (a, b) => a * b };
for (const [ad, f] of Object.entries(islemler)) console.log(ad, f(6, 7));

4. Closure (1 saat)

Bir fonksiyon, tanımlandığı yerdeki değişkenleri hatırlar; dış fonksiyon bitmiş olsa bile. Buna closure (kapanım) denir:

function sayacYap(baslangic = 0) {
    let sayi = baslangic;
    return {
        artir: () => ++sayi,
        deger: () => sayi,
    };
}
const a = sayacYap();
const b = sayacYap(100);
a.artir(); a.artir();
b.artir();
console.log(a.deger(), b.deger());

function carpanYap(k) {
    return x => x * k;
}
const iki = carpanYap(2), kdv = carpanYap(1.2);
console.log(iki(21), kdv(250));

2 101
42 300
  • sayacYap bittiği hâlde döndürdüğü fonksiyonlar sayi değişkenine erişmeye devam ediyor; her sayaç kendi sayi'sine sahip.
  • sayi dışarıdan doğrudan değiştirilemez: closure, veriyi gizlemenin (kapsüllemenin) bir yoludur.
  • carpanYap gibi fonksiyon üreten fonksiyonlar, yapılandırılmış küçük araçlar üretmek için kullanılır.

Alıştırma: Bir fonksiyonu sadece bir kez çalıştıran birKez(f) fonksiyonunu closure ile yaz: dönen fonksiyon ilk çağrıda f'yi çalıştırıp sonucu saklasın, sonraki çağrılarda aynı sonucu döndürsün.

GÜN 05

Diziler ve nesneler

~4 saat · 0/5 kontrol

Hedef

Gün sonunda dizilerin map, filter, reduce, find, some ve sort metotlarını kullanabilecek, yapı bozma (destructuring) ve spread ile dizi ve nesneleri açıp birleştirebilecek, JSON'a dönüştürebilecek ve Map ile Set'in ne zaman gerektiğini bileceksin. Süre yaklaşık 4 saat.

1. Dizi metotları (1,5 saat)

GÜN 06

Async, sınıflar ve modüller

~4 saat · 0/5 kontrol

Hedef

Gün sonunda JavaScript'in olay döngüsünü ve tek iş parçacıklı yapısını, setTimeout'un çalışma sırasını, Promise ve async/await ile asenkron kod yazmayı, sınıf tanımlamayı ve modüllerle kodu dosyalara bölmeyi bileceksin. Süre yaklaşık 4 saat.

1. Olay döngüsü (1 saat)

JavaScript tek iş parçacığında çalışır: aynı anda tek bir kod satırı işlenir. Ama ağ isteği, zamanlayıcı ya da dosya okuma gibi beklemeli işler arka planda yürür; bittiklerinde geri çağırmaları bir kuyruğa girer ve ana kod boşalınca sırayla çalışır. Bu düzene olay döngüsü (event loop) denir.

console.log("1: başla");
setTimeout(() => console.log("4: zamanlayıcı (0 ms)"), 0);
Promise.resolve().then(() => console.log("3: promise"));
console.log("2: bitir");

1: başla
2: bitir
3: promise
4: zamanlayıcı (0 ms)
  • Senkron kod (1, 2) her zaman önce biter.
  • Sonra mikro görevler (Promise'ler), sonra makro görevler (zamanlayıcılar) çalışır.
  • 0 ms'lik zamanlayıcı bile mevcut kodun bitmesini bekler.

Sonuç: Uzun süren senkron bir döngü (milyarlarca tur) sayfayı ya da sunucuyu tamamen dondurur, çünkü olay döngüsü başka hiçbir şeyi işleyemez.

2. Promise ve async/await (1,5 saat)

Promise, gelecekte hazır olacak bir değeri temsil eder: bekliyor, başarılı (değer) ya da başarısız (hata) olabilir. async / await Promise'leri sıradan kod gibi yazmayı sağlar:

const bekle = (ms, deger) => new Promise(coz => setTimeout(() => coz(deger), ms));

async function stokGetir(ad) {
    await bekle(100);
    if (ad === "Yok") throw new Error(`${ad} bulunamadı`);
    return { ad, stok: ad.length * 10 };
}

async function main() {
    const t0 = Date.now();
    const kalem = await stokGetir("Kalem");
    console.log(kalem);

    const hepsi = await Promise.all(["Defter", "Mouse", "Çay"].map(stokGetir));
    console.log(hepsi.map(u => `${u.ad}:${u.stok}`).join(" "));
    console.log("paralel süre ~100 ms mi?", Date.now() - t0 < 350);

    try {
        await stokGetir("Yok");
    } catch (e) {
        console.log("hata:", e.message);
    }

    const sonuclar = await Promise.allSettled([stokGetir("Kalem"), stokGetir("Yok")]);
    console.log(sonuclar.map(s => s.status));
}
main();

{ ad: 'Kalem', stok: 50 }
Defter:60 Mouse:50 Çay:30
paralel süre ~100 ms mi? true
hata: Yok bulunamadı
[ 'fulfilled', 'rejected' ]
  • async fonksiyon her zaman bir Promise döndürür; içinde await ile başka Promise'leri bekleyebilirsin.
  • Hatalar normal try/catch ile yakalanır.
  • Promise.all işleri aynı anda başlatır, hepsini bekler; biri hata verirse hepsi hata sayılır. Promise.allSettled hepsinin sonucunu ayrı ayrı verir.
  • Döngü içinde tek tek await yazmak işleri sırayla yapar; birbirinden bağımsız işler için Promise.all çok daha hızlıdır.
  • Tarayıcıdaki ve Node'daki fetch(url) de bir Promise döndürür: const veri = await (await fetch(url)).json();.

3. Sınıflar (45 dk)

class Urun {
    #stok;                                   // özel alan
    static sayac = 0;

    constructor(ad, fiyat, stok) {
        if (fiyat < 0) throw new RangeError("Fiyat negatif olamaz.");
        this.ad = ad;
        this.fiyat = fiyat;
        this.#stok = stok;
        Urun.sayac++;
    }
    get stok() { return this.#stok; }
    get deger() { return this.fiyat * this.#stok; }
    sat(adet) {
        if (adet > this.#stok) return false;
        this.#stok -= adet;
        return true;
    }
    toString() { return `${this.ad} (${this.#stok})`; }
}

class IndirimliUrun extends Urun {
    constructor(ad, fiyat, stok, oran) {
        super(ad, fiyat * (1 - oran), stok);
        this.oran = oran;
    }
    toString() { return `${super.toString()} %${this.oran * 100} indirimli`; }
}

const u = new Urun("Kalem", 12.5, 40);
u.sat(15);
const i = new IndirimliUrun("Kulaklık", 850, 5, 0.1);
console.log(`${u}`, u.deger, u.stok, u.sat(100));
console.log(`${i}`, i.fiyat, Urun.sayac, i instanceof Urun);

Kalem (25) 312.5 25 false
Kulaklık (5) %10 indirimli 765 2 true
  • #stok gibi # ile başlayan alanlar gerçekten özeldir; sınıf dışından erişilemez.
  • get ile tanımlanan getter, metot gibi değil alan gibi okunur (u.deger).
  • extends ve super kalıtımı sağlar; static üyeler sınıfa aittir.

GÜN 07

TypeScript ve proje

~4 saat · 0/5 kontrol

Hedef

Gün sonunda TypeScript'in ne kazandırdığını bilecek, tip açıklamaları, interface, birleşim tipleri ve generics yazabilecek, tsc ile derleyebilecek, envanter özeti programını TypeScript ile yazmış olacak ve npm ile paket yönetimini öğreneceksin. Süre yaklaşık 4 saat.

1. Neden TypeScript? (30 dk)

JavaScript esnektir ama hatalar ancak kod çalışırken ortaya çıkar: bir alan adını yanlış yazmak, sayı yerine metin göndermek. TypeScript, JavaScript'e tip sistemi ekler; derleyici (tsc) kodu çalıştırmadan önce kontrol edip düz JavaScript'e çevirir.

  • Hatalar yazarken yakalanır; VS Code daha iyi otomatik tamamlama yapar.
  • Büyük projelerde ve ekiplerde vazgeçilmezdir: Angular, VS Code, birçok büyük şirket kodu TypeScript'tir.
  • Her geçerli JavaScript kodu aynı zamanda geçerli TypeScript'tir; adım adım geçilebilir.

Kurulum: npm install -g typescript. Derleme: tsc dosya.ts (dosya.js üretir), sonra node dosya.js.

2. Tipler, interface ve birleşim (1,5 saat)

let adet: number = 3;
const ad: string = "Kalem";
const etiketler: string[] = ["ofis", "kırtasiye"];

interface Urun {
    ad: string;
    fiyat: number;
    stok: number;
    renk?: string;                     // isteğe bağlı
}

type Durum = "stokta" | "az" | "tükendi";

function durum(u: Urun): Durum {
    if (u.stok === 0) return "tükendi";
    return u.stok < 10 ? "az" : "stokta";
}

function biçimle(deger: number | string): string {
    return typeof deger === "number" ? deger.toFixed(2) : deger.toUpperCase();
}

const kalem: Urun = { ad, fiyat: 12.5, stok: adet };
console.log(durum(kalem), biçimle(12.5), biçimle("tl"), etiketler.length, kalem.renk ?? "-");

az 12.50 TL 2 -
  • : tip ile değişken, parametre ve dönüş tipleri yazılır. Çoğu zaman TypeScript tipi kendisi çıkarır; her yere yazmak gerekmez.
  • interface bir nesnenin şeklini tanımlar; ? isteğe bağlı alandır.
  • Birleşim tipi (number | string, "stokta" | "az" | "tükendi") birden çok olası tipi ya da değeri ifade eder. durum fonksiyonu yanlışlıkla "bitti" döndürmeye çalışırsa derleme hatası olur.
  • typeof deger === "number" kontrolünden sonra TypeScript, o dalda deger'in sayı olduğunu bilir (daraltma).

Bir hatayı derleyicinin nasıl yakaladığını gör:

interface Urun { ad: string; fiyat: number; }
const u: Urun = { ad: "Kalem", fiyta: 12.5 };

x.ts(2,32): error TS2561: Object literal may only specify known properties, but 'fiyta' does not exist in type 'Urun'. Did you mean to write 'fiyat'?

JavaScript'te bu yazım hatası sessizce undefined üretip çok daha sonra garip bir hataya yol açardı.

3. Generics (45 dk)

function ilk<T>(liste: T[]): T | undefined {
    return liste[0];
}

function grupla<T, K extends string>(liste: T[], anahtar: (x: T) => K): Record<K, T[]> {
    const sonuc = {} as Record<K, T[]>;
    for (const x of liste) (sonuc[anahtar(x)] ??= []).push(x);
    return sonuc;
}

const n = ilk([3, 1, 2]);
const s = ilk(["a", "b"]);
const g = grupla(["elma", "armut", "erik", "kiraz"], x => x[0]);
console.log(n, s, g);

3 a { e: [ 'elma', 'erik' ], a: [ 'armut' ], k: [ 'kiraz' ] }

<T> bir tip parametresidir: fonksiyon her tiple çalışır ama tip bilgisi kaybolmaz; n'nin tipi number | undefined, s'ninki string | undefined olur. Array<T>, Promise<T>, Map<K, V> hep generic tiplerdir.
