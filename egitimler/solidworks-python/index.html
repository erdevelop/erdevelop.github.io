SolidWorks Python Eğitimi

SolidWorks'ü Python ile otomatikleştirmek için 7 günlük yoğun program. İlk gün Python'u kurup SolidWorks'e dışarıdan bağlanırsın. Hafta sonunda Excel tablosundan parça ailesi üreten, sıfırdan plaka modelleyen, montaj metrajını biçimli Excel'e yazan, bir klasördeki bütün resimleri PDF'e çeviren ve projedeki eksikleri bulan, ekibine tek .exe olarak verebileceğin bir aracın olur.

Kimler için

SolidWorks'ü iyi kullanan ve tekrar eden işleri Python ile otomatikleştirmek isteyen cephe, metal ve makine tasarımcıları. Python'u hiç kullanmadıysan 1. gündeki kısa giriş bu hafta için yeter. SolidWorks VBA eğitimini yaptıysan konular tanıdık gelecek: aynı API'yi bu kez Python'dan kullanıyoruz. Örnekler bu sitedeki SolidWorks eğitiminin plaka ve montajlarını kullanır.

  • Python 3.11+ (64 bit) ve VS Code. Kurulum 1. günde.
  • Paketler: pywin32, openpyxl; 7. günde pyinstaller.
  • Bir ankraj plakası, bir montaj ve birkaç teknik resim (yoksa 4. günde plakayı betik oluşturur).

GÜN 01

Python ve SolidWorks bağlantısı

~5 saat · 0/5 kontrol

Hedef: Python'dan SolidWorks'e ulaşmak

Gün sonunda Python'u kurmuş, SolidWorks'e dışarıdan bağlanmış ve açık belgenin adını, türünü ve yolunu okuyan ilk betiğini çalıştırmış olacaksın. Süre yaklaşık 5 saat. Dosya: gun1.py.

SolidWorks'ün içinde VBA gelir; Python gelmez. Python betiği SolidWorks'ün dışında çalışır ve Windows'un COM köprüsüyle çalışan SolidWorks'e bağlanır. VBA makrolarının kullandığı API'nin aynısını kullanırsın; fark, yanında Python'un bütün kütüphanelerinin (Excel, CSV, pandas, dosya işlemleri, arayüz) gelmesidir. Bu yüzden Python, özellikle SolidWorks dışındaki verilerle (Excel tablosu, klasördeki yüzlerce dosya, rapor) çalışan işlerde çok rahattır.

1. Kurulum (1 saat)

  1. Python 3.11 veya üstü, 64 bit: python.org'dan indir. Kurulumda Add python.exe to PATH kutusunu işaretle.
  2. VS Code ve içinde Python eklentisi (Microsoft).
  3. Bir proje klasörü aç (ör. C:\Proje\swpy), içinde sanal ortam kur ve paketleri yükle:
cd C:\Proje\swpy
python -m venv .venv
.venv\Scripts\activate
pip install pywin32 openpyxl
  • pywin32: COM köprüsü. openpyxl: Excel okuma ve yazma (3. ve 5. gün).
  • VS Code sağ altta yorumlayıcı olarak .venv'i seç. Terminalde satırın başında (.venv) görmelisin.
  • Kurumsal bilgisayarda yükleme izni yoksa BT'den Python ve bu iki paketi iste; yönetici hakkı gerekmez.

2. Ortak modül: sw.py (45 dk)

Her betiğin başında aynı satırları yazmamak için bağlantıyı, sabitleri ve küçük yardımcıları tek dosyada topla. Hafta boyunca bütün betikler from sw import * ile başlayacak.

# sw.py · ortak modül
import sys
import pythoncom
import win32com.client as win32
from win32com.client import VARIANT

# swconst sabitleri (VBA'daki adlarıyla)
swDocPART, swDocASSEMBLY, swDocDRAWING = 1, 2, 3
swCustomInfoText = 30
swCustomPropertyReplaceValue = 2
swOpenDocOptions_Silent = 1
swSaveAsCurrentVersion = 0
swSaveAsOptions_Silent, swSaveAsOptions_Copy = 1, 2
swDefaultTemplatePart = 8
swEndCondBlind, swStartSketchPlane = 0, 0
swIsometricView = 7
swExportPdfData = 1
swExportData_ExportSpecifiedSheets = 3

def baglan():
    app = win32.Dispatch("SldWorks.Application")
    app.Visible = True
    return app

def ref_int():  return VARIANT(pythoncom.VT_BYREF | pythoncom.VT_I4, 0)
def ref_str():  return VARIANT(pythoncom.VT_BYREF | pythoncom.VT_BSTR, "")
def ref_bool(): return VARIANT(pythoncom.VT_BYREF | pythoncom.VT_BOOL, False)
def bos_nesne(): return VARIANT(pythoncom.VT_DISPATCH, None)   # VBA'daki Nothing

def aktif_belge(app, tur=None):
    m = app.ActiveDoc
    if m is None:
        sys.exit("Açık belge yok.")
    if tur is not None and m.GetType != tur:
        sys.exit("Bu betik için doğru türde belge aç.")
    return m

3. ByRef çıktılar (45 dk)

Bazı API metotları sonucu dönüş değeri yerine parametreye yazar. VBA'da bunlara düz değişken verirsin; Python'da değişkenler bu şekilde doldurulamaz. Çözüm, VARIANT ile içi değiştirilebilir bir kutu vermek ve çağrıdan sonra .value okumaktır:

from sw import *

swApp = baglan()
swModel = aktif_belge(swApp, swDocPART)

db = ref_str()                                   # çıktı kutusu
ad = swModel.GetMaterialPropertyName2("", db)    # "" = aktif konfigürasyon
print("Malzeme:", ad, "· Kütüphane:", db.value)
  • VT_BSTR metin, VT_I4 tam sayı (hata kodları), VT_BOOL doğru/yanlış, VT_R8 ondalık sayı.
  • VBA'da Nothing verilen nesne parametrelerine Python'da düz None çoğu zaman çalışmaz; bos_nesne() kullan.

4. Özel özellik yazmak ve okumak (1 saat)

# gun2.py
from sw import *

swApp = baglan()
swModel = aktif_belge(swApp)
cpm = swModel.Extension.CustomPropertyManager("")      # "" = belge geneli

for ad, deger in {"ProjeNo": "C-2026-014", "Yuzey": "RAL 7016 mat", "Tasarimci": "E.Ü."}.items():
    cpm.Add3(ad, swCustomInfoText, deger, swCustomPropertyReplaceValue)

def oku(cpm, ad):
    deger, cozulmus, cozuldu, bagli = ref_str(), ref_str(), ref_bool(), ref_bool()
    cpm.Get6(ad, False, deger, cozulmus, cozuldu, bagli)
    return cozulmus.value

for ad in cpm.GetNames or ():
    print(f"{ad:12} = {oku(cpm, ad)}")
  1. CustomPropertyManager("") belge geneli özelliklerdir; konfigürasyona özel özellik için tırnak içine konfigürasyon adını yaz.
  2. Add3(ad, tür, değer, seçenek): tür 30 metin, seçenek 2 "varsa değerini değiştir".
  3. Get6'nın dört çıktısı var: yazılan değer, çözülmüş değer (ör. "SW-Mass@..." formülünün sonucu), çözüldü mü, bağlı mı.
  4. GetNames özellik yoksa None döner; or () bu durumda boş demetle devam etmeyi sağlar.

5. Malzeme ve kütleyi özelliğe yazmak (1 saat)

from sw import *

swApp = baglan()
swModel = aktif_belge(swApp, swDocPART)

malzeme = swModel.GetMaterialPropertyName2("", ref_str()) or "TANIMSIZ"
mp = swModel.Extension.CreateMassProperty          # parametresiz → parantez yok
kg = mp.Mass                                       # kg
alan = mp.SurfaceArea                              # m²

cpm = swModel.Extension.CustomPropertyManager("")
cpm.Add3("Malzeme", swCustomInfoText, malzeme, swCustomPropertyReplaceValue)
cpm.Add3("Agirlik", swCustomInfoText, f"{kg:.2f} kg", swCustomPropertyReplaceValue)
cpm.Add3("BoyaAlani", swCustomInfoText, f"{alan:.3f} m2", swCustomPropertyReplaceValue)
print(f"{malzeme} · {kg:.2f} kg · {alan:.3f} m²")
  • API kütleyi kg, uzunluğu m, alanı m² verir.
  • Malzeme atanmamışsa ad boş gelir ve kütle SolidWorks'ün varsayılan yoğunluğuyla hesaplanır; betik bunu TANIMSIZ olarak işaretliyor.
  • Değişikliği kalıcı yapmak için belgeyi kaydet: swModel.Save3(1, hata, uyari) (6. günde toplu olarak yapacağız).

Ölçüler ve Excel'den parça ailesi

~5 saat · 0/5 kontrol

Hedef

Gün sonunda ölçüleri koddan değiştirebilecek ve bir Excel tablosundaki her satır için ayrı parça dosyası (parça ailesi) üretebileceksin. Dosya: gun3.py, plakalar.xlsx.

1. Ölçü adları (1 saat)

Her ölçünün tam adı ÖlçüAdı@UnsurAdı biçimindedir: D1@Sketch1, D1@Boss-Extrude1. Türkçe arayüzde unsur adları da Türkçe olabilir (D1@Çizim1); kod, ağaçta gördüğün adı kullanmalıdır.

  1. Ölçüye tıkla, PropertyManager'da Primary Value kutusundaki adı Genislik yap. Tam ad Genislik@Sketch1 olur.
  2. Plakanın genişlik, yükseklik, delik çapı ve kalınlık ölçülerine sırayla Genislik, Yukseklik, Delik, Kalinlik adlarını ver. Anlamlı adlar betiği okunur ve sağlam yapar.
  3. Ölçü adlarını bulmanın kolay yolu: ağaçta Annotations sağ tık > Show Feature Dimensions, sonra ölçüye tıkla.

2. Ölçü okumak ve değiştirmek (1 saat)

4. Tablodan parça ailesi üretmek (1,5 saat)

# gun3.py
from pathlib import Path
from sw import *
from openpyxl import load_workbook

OLCULER = {"Genislik": "Genislik@Sketch1", "Yukseklik": "Yukseklik@Sketch1",
           "Delik": "Delik@Sketch1", "Kalinlik": "Kalinlik@Boss-Extrude1"}

def tablo_oku(yol):
    ws = load_workbook(yol, data_only=True).active
    satirlar = list(ws.iter_rows(values_only=True))
    basliklar = [str(b).strip() for b in satirlar[0]]
    return [dict(zip(basliklar, s)) for s in satirlar[1:] if s[0]]

swApp = baglan()
swModel = aktif_belge(swApp, swDocPART)
if not swModel.GetPathName:
    sys.exit("Şablon plakayı önce kaydet.")
klasor = Path(swModel.GetPathName).parent
cpm = swModel.Extension.CustomPropertyManager("")

params = {k: swModel.Parameter(v) for k, v in OLCULER.items()}
eksik = [OLCULER[k] for k, p in params.items() if p is None]
if eksik:
    sys.exit("Bulunamayan ölçüler: " + ", ".join(eksik))
ilk = {k: p.SystemValue for k, p in params.items()}      # şablon değerleri

for s in tablo_oku(klasor / "plakalar.xlsx"):
    for k, p in params.items():
        p.SystemValue = float(s[k]) / 1000
    swModel.EditRebuild3
    cpm.Add3("PozNo", swCustomInfoText, s["PozNo"], swCustomPropertyReplaceValue)

    yol = klasor / f'{s["PozNo"]}.sldprt'
    hata, uyari = ref_int(), ref_int()
    ok = swModel.Extension.SaveAs3(str(yol), swSaveAsCurrentVersion,
                                   swSaveAsOptions_Copy + swSaveAsOptions_Silent,
                                   bos_nesne(), bos_nesne(), hata, uyari)
    print(s["PozNo"], "kaydedildi" if ok else f"HATA {hata.value}")

for k, p in params.items():                               # şablona geri dön
    p.SystemValue = ilk[k]
swModel.EditRebuild3
  1. Şablon plakayı aç, betiği çalıştır. Her satır için ölçüler değişir, model yeniden oluşturulur, PozNo özelliği yazılır ve kopya olarak kaydedilir (swSaveAsOptions_Copy): açık belge şablon olarak kalır.
  2. Path(swModel.GetPathName).parent: şablonun klasörü. pathlib yol birleştirmeyi / ile yapar.
  3. hata.value sıfırdan farklıysa kayıt başarısızdır; kod numarası SolidWorks API yardımında swFileSaveError_e altında aranır.
  4. Bitince ölçüler şablon değerlerine geri döndürülür.

Konfigürasyon mu, ayrı dosya mı? Az sayıda varyant tek dosyada konfigürasyon olarak durabilir (Design Table). Varyantlar ayrı ayrı sipariş, revizyon ve teknik resim alıyorsa ayrı dosya daha yönetilebilirdir. Bu betik ikincisini yapıyor.

GÜN 04

Kodla parça oluşturmak

~5 saat · 0/5 kontrol

Hedef

Gün sonunda boş bir parçadan başlayıp kodla çizim yapacak, ekstrüzyon oluşturacak ve dört delikli bir ankraj plakasını tek fonksiyon çağrısıyla modelleyeceksin. Dosya: gun4.py.

1. Yeni parça ve düzlem seçimi (1 saat)

from sw import *

swApp = baglan()
sablon = swApp.GetUserPreferenceStringValue(swDefaultTemplatePart)
swModel = swApp.NewDocument(sablon, 0, 0, 0)
if swModel is None:
    sys.exit("Yeni parça açılamadı. Şablon: " + repr(sablon))

def ilk_duzlem(model):
    f = model.FirstFeature
    while f is not None:
        if f.GetTypeName2 == "RefPlane":
            return f
        f = f.GetNextFeature
    raise RuntimeError("Düzlem bulunamadı")

ilk_duzlem(swModel).Select2(False, 0)

# gun6.py · klasördeki bütün resimleri PDF'e
import pythoncom
from pathlib import Path
from win32com.client import VARIANT
from sw import *

TUR = {".sldprt": swDocPART, ".sldasm": swDocASSEMBLY, ".slddrw": swDocDRAWING}

def ac(app, yol):
    hata, uyari = ref_int(), ref_int()
    m = app.OpenDoc6(str(yol), TUR[yol.suffix.lower()], swOpenDocOptions_Silent, "", hata, uyari)
    if m is None:
        raise RuntimeError(f"açılamadı (hata {hata.value})")
    return m

def pdf_kaydet(app, m, hedef):
    sayfalar = [m.Sheet(ad) for ad in m.GetSheetNames]
    pdf = app.GetExportFileData(swExportPdfData)
    pdf.SetSheets(swExportData_ExportSpecifiedSheets,
                  VARIANT(pythoncom.VT_ARRAY | pythoncom.VT_DISPATCH, sayfalar))
    hata, uyari = ref_int(), ref_int()
    return m.Extension.SaveAs3(str(hedef), swSaveAsCurrentVersion, swSaveAsOptions_Silent,
                               pdf, bos_nesne(), hata, uyari)

swApp = baglan()
klasor = Path(r"C:\Proje\Resimler")
cikti = klasor / "PDF"
cikti.mkdir(exist_ok=True)

n, sorunlar = 0, []
for yol in sorted(klasor.glob("*.slddrw")):
    if yol.name.startswith("~$"):
        continue
    m = None
    try:
        m = ac(swApp, yol)
        if pdf_kaydet(swApp, m, cikti / (yol.stem + ".pdf")):
            n += 1
        else:
            sorunlar.append(f"{yol.name}: PDF yazılamadı")
    except Exception as e:
        sorunlar.append(f"{yol.name}: {e}")
    finally:
        if m is not None:
            swApp.CloseDoc(m.GetTitle)

print(n, "PDF oluşturuldu.")
for s in sorunlar:
    print("  ", s)
  • Sayfa listesi VT_ARRAY | VT_DISPATCH türünde VARIANT olarak verilmeli; düz Python listesi kabul edilmez.
  • PDF'ler resimlerin yanındaki PDF klasörüne yazılır; klasör yoksa oluşturulur.
  • Sonda açılamayan veya yazılamayan dosyaların listesi çıkar.

3. ProjeKontrol (1,5 saat)

Montajdaki her parça için şunları denetler ve sorunlu bileşenleri SolidWorks'te seçili bırakır, böylece ağaçta hemen görünür:

  • ProjeNo, PozNo, Malzeme özelliklerinden biri boş olanlar
  • Malzeme atanmamış parçalar
  • Aynı PozNo'yu taşıyan farklı dosyalar
# kontrol.py
from collections import defaultdict
from sw import *

GEREKLI = ("ProjeNo", "PozNo", "Malzeme")

def ozellik(model, konfig, ad):
    for k in (konfig, ""):
        v = [ref_str(), ref_str(), ref_bool(), ref_bool()]
        model.Extension.CustomPropertyManager(k).Get6(ad, False, *v)
        if v[1].value:
            return v[1].value
    return ""

def proje_kontrol(app):
    asm = aktif_belge(app, swDocASSEMBLY)
    asm.ResolveAllLightWeightComponents(False)
    asm.ClearSelection2(True)
    sorunlar, poz_dosya, sorunlu = [], defaultdict(set), []

    for c in asm.GetComponents(False) or ():
        yol = c.GetPathName
        if c.IsSuppressed or not yol.lower().endswith(".sldprt"):
            continue
        m, konfig = c.GetModelDoc2, c.ReferencedConfiguration
        if m is None:
            continue
        eksik = [a for a in GEREKLI if not ozellik(m, konfig, a)]
        if not m.GetMaterialPropertyName2(konfig, ref_str()):
            eksik.append("malzeme atanmamış")
        if eksik:
            sorunlar.append(f"{c.Name2}: {', '.join(eksik)}")
            sorunlu.append(c)
        poz = ozellik(m, konfig, "PozNo")
        if poz:
            poz_dosya[poz].add(yol.lower())

    for poz, dosyalar in poz_dosya.items():
        if len(dosyalar) > 1:
            sorunlar.append(f"{poz} {len(dosyalar)} farklı dosyada kullanılmış")

    for c in sorunlu:                                  # ağaçta seçili bırak
        c.Select4(True, bos_nesne(), False)
    return sorunlar

if __name__ == "__main__":
    s = proje_kontrol(baglan())
    print("\n".join(s) if s else "Sorun bulunmadı.")

  • Bazı virüs programları imzasız yeni .exe dosyalarını şüpheli bulabilir. Kurum içinde dağıtıyorsan BT ile konuş ya da ekibe .exe yerine .py + sanal ortam ver.
