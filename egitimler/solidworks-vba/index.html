SolidWorks VBA Eğitimi

SolidWorks kullanıcıları için 7 günlük yoğun makro programı. Hiç kod yazmamış olsan da ilk gün açık belgeyi okuyan bir makro çalıştırırsın. Hafta sonunda özellikleri dolduran, ölçü tablosundan parça ailesi üreten, sıfırdan plaka modelleyen, montajı sayan, yüzlerce çizimi PDF'e çeviren ve ekibine düğmeyle dağıtabileceğin bir Cephe Makro Kiti'n olur.

7 güngünde ~5 saatTürkçeKod örnekleri kopyalanabilir

Başlamadan önce

Kimler için

SolidWorks'ü iyi kullanan ve tekrar eden işleri (özellik doldurma, varyant üretme, metraj, PDF çıktısı) otomatikleştirmek isteyen cephe, metal ve makine tasarımcıları. Programlama bilgisi gerekmez. Örnekler bu sitedeki SolidWorks eğitiminin plaka ve montajlarını kullanır.

Gerekenler

  • SolidWorks (Windows). VBA editörü kurulumla birlikte gelir.
  • SolidWorks eğitimindeki ankraj plakası ve bir montaj (yoksa 4. günde makro kendisi oluşturur).
  • 5-6. günler için Excel ve birkaç teknik resim dosyası.

GÜN 01

Makro ortamı ve VBA temelleri

~5 saat · 0/5 kontrol

Hedef ve makroların yeri

Gün sonunda SolidWorks'te makro kaydedip düzenleyebilecek, VBA editörünü kullanabilecek ve açık belgeyi okuyan ilk makronu yazmış olacaksın. Süre yaklaşık 5 saat. Dosya: gun1.swp.

SolidWorks'ün içinde VBA (Visual Basic for Applications) gelir. Makrolarla SolidWorks API'sine (programlama arayüzüne) erişirsin: özellik yazmak, ölçü değiştirmek, parça oluşturmak, montajdaki parçaları saymak, yüzlerce çizimi PDF'e çevirmek. Cephe işinde en çok zaman kazandıran işler bunlardır.

Not: Menü adları İngilizce arayüze göre, parantez içinde Türkçe karşılıklarıyla yazıldı. Kodlar her iki dilde de aynı çalışır.

1. Makro kaydetmek (1 saat)

  1. Bir parça aç. Tools > Macro > Record (Araçlar > Makro > Kaydet).
  2. Bir ölçüye çift tıklayıp değerini değiştir, Rebuild (Yeniden oluştur) yap.
  3. Tools > Macro > Stop ile durdur, kayit1.swp olarak kaydet.
  4. Tools > Macro > Edit ile aç. Kaydedilen kodda swApp, Part, SelectByID2, EditRebuild3 gibi satırlar görürsün.

Kaydedici öğrenmek için iyi bir başlangıçtır ama ürettiği kod genellikle kırılgandır: seçimleri ekran koordinatlarıyla ve nesne adlarıyla yapar. Bu hafta kodu baştan, sağlam yazmayı öğreneceğiz.

2. VBA editörü (1 saat)

Tools > Macro > New (Araçlar > Makro > Yeni) ile gun1.swp oluştur. VBA editörü açılır.

Bölüm Ne işe yarar
Project Explorer (sol üst) Modüller ve formlar. Kod Module1 içinde
Kod penceresi Yazdığın kod
Immediate penceresi (Ctrl+G) Debug.Print çıktıları, anlık deneme
Locals penceresi Adım adım çalıştırırken değişken değerleri
Tools > References Kullanılan kütüphaneler. SolidWorks type library ve constant type library yeni makroda zaten işaretlidir
Kısayol İşlev
F5 Makroyu çalıştır
F8 Satır satır çalıştır (hata ayıklama)
F9 Kesme noktası (breakpoint) koy
Ctrl+Space Otomatik tamamlama

Tools > Options > Require Variable Declaration kutusunu işaretle. Her yeni modülün başına Option Explicit eklenir: tanımlanmamış değişken kullanırsan VBA hata verir ve yazım hataları baştan yakalanır.

3. VBA temelleri (1,5 saat)

Option Explicit

Sub Deneme()
    Dim genislik As Double
    Dim adet As Long
    Dim kod As String
    Dim tamam As Boolean

    genislik = 1500
    adet = 4
    kod = "P-" & Format(7, "000")          ' "P-007"
    tamam = (genislik * adet > 5000)

    Debug.Print kod, genislik * adet, tamam
    If tamam Then
        MsgBox "Toplam genişlik: " & genislik * adet & " mm"
    End If

    Dim i As Long
    For i = 1 To 3
        Debug.Print "Aks " & i & ": " & (i - 1) * 1500
    Next i
End Sub

4. İlk SolidWorks makrosu (1 saat)

Option Explicit
Dim swApp As SldWorks.SldWorks

Sub main()
    Set swApp = Application.SldWorks

    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then
        MsgBox "Açık belge yok."
        Exit Sub
    End If

    Dim tur As String
    Select Case swModel.GetType
        Case swDocPART:     tur = "Parça"
        Case swDocASSEMBLY: tur = "Montaj"
        Case swDocDRAWING:  tur = "Teknik resim"
    End Select

    MsgBox "Belge : " & swModel.GetTitle & vbCrLf & _
           "Tür   : " & tur & vbCrLf & _
           "Yol   : " & swModel.GetPathName
End Sub
  1. Bir parça aç, editörde imleç main içindeyken F5'e bas.
  2. Application.SldWorks: çalışan SolidWorks'ün kendisi. Her makro buradan başlar.
  3. swDocPART gibi adlar constant type library'den gelen sabitlerdir; sayı ezberlemeye gerek kalmaz.
  4. _ (boşluk + alt çizgi) uzun satırı alt satırda sürdürür.
  5. Belge hiç kaydedilmemişse GetPathName boş döner.

Gün sonu kontrolü (15 dk)

Hepsini işaretleyebiliyorsan 2. güne geçebilirsin.

Bonus: Makroya belgenin birimlerini de yazdır. İpucu: swModel.GetUserPreferenceIntegerValue(swUnitsLinear) sonucu swMM ise milimetredir.

GÜN 02

Nesne modeli ve özel özellikler

~5 saat · 0/6 kontrol

Hedef

Gün sonunda SolidWorks nesne modelini okuyabilecek, belgelere özel özellik (custom property) yazıp okuyan ve kütle bilgisini özelliğe aktaran bir makron olacak. Süre yaklaşık 5 saat. Dosya: gun2.swp.

1. Nesne modeli (1,5 saat)

API'de her şey nesnelerin içindedir. Bir işi yapmak için doğru nesneye inmen gerekir.

Nesne Ne verir Nasıl alınır
SldWorks Uygulama: belge aç, yeni belge, ayarlar Application.SldWorks
ModelDoc2 Her belgenin ortak yüzü: kaydet, yeniden oluştur, ölçüler swApp.ActiveDoc
PartDoc / AssemblyDoc / DrawingDoc Belge türüne özel işler Set swPart = swModel
ModelDocExtension Seçim, kaydetme, kütle, özellikler swModel.Extension
CustomPropertyManager Özel özellikler swModel.Extension.CustomPropertyManager("")
FeatureManager Unsur (feature) oluşturma swModel.FeatureManager
SketchManager Çizim (sketch) oluşturma swModel.SketchManager

Set swPart = swModel gibi atamaya tür dönüştürme denir: aynı belge, farklı bir arayüzden görülür. Sadece belge gerçekten o türdeyse çalışır; önce GetType ile kontrol et.

API yardımı: Help > API Help (Yardım > API Yardımı). Bir yöntemin bütün argümanları ve örnekleri burada. Bu hafta en çok açacağın sayfa.

2. Özel özellikler (2 saat)

Özel özellikler, malzeme listesinin (BOM) ve teknik resim antetinin veri kaynağıdır. Cephe projesinde her parçada aynı alanların doğru dolu olması gerekir: proje no, poz no, malzeme, yüzey, tasarımcı.

Option Explicit
Dim swApp As SldWorks.SldWorks

Sub main()
    Set swApp = Application.SldWorks
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then Exit Sub

    Dim cpm As SldWorks.CustomPropertyManager
    Set cpm = swModel.Extension.CustomPropertyManager("")   ' "" = belge geneli

    cpm.Add3 "ProjeNo", swCustomInfoText, "C-2026-014", swCustomPropertyReplaceValue
    cpm.Add3 "Yuzey", swCustomInfoText, "RAL 7016 mat", swCustomPropertyReplaceValue
    cpm.Add3 "Tasarimci", swCustomInfoText, "E.Ü.", swCustomPropertyReplaceValue

    ' bütün özellikleri listele
    Dim adlar As Variant, i As Long
    Dim deger As String, cozulmus As String, cozuldu As Boolean, bagli As Boolean
    adlar = cpm.GetNames
    If Not IsEmpty(adlar) Then
        For i = 0 To UBound(adlar)
            cpm.Get6 adlar(i), False, deger, cozulmus, cozuldu, bagli
            Debug.Print adlar(i), "=", cozulmus
        Next i
    End If
End Sub
  1. CustomPropertyManager("") belge geneli özellikleri verir. Konfigürasyona özel özellik için konfigürasyon adını ver: CustomPropertyManager("Varsayılan").
  2. Add3: yoksa ekler; swCustomPropertyReplaceValue ile varsa değerini değiştirir.
  3. Get6 iki değer döndürür: yazılan değer (deger, ör. "SW-Mass@Parca.SLDPRT") ve hesaplanmış sonuç (cozulmus, ör. 2.35). Liste ve antet için genellikle çözülmüş değer gerekir.
  4. API'den gelen diziler 0'dan başlar; UBound son indeksi verir. Hiç özellik yoksa GetNames boş (Empty) döner; IsEmpty kontrolü bu yüzden var.
  5. Özellik adlarında Türkçe karakter kullanabilirsin ama bu adları Excel ve ERP tarafında da kullanacaksan ASCII (Yuzey) daha güvenlidir.

3. Kütle ve malzeme (1 saat)

Sub KutleYaz()
    Set swApp = Application.SldWorks
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then Exit Sub
    If swModel.GetType <> swDocPART Then MsgBox "Parça aç.": Exit Sub

    Dim swPart As SldWorks.PartDoc
    Set swPart = swModel
    Dim db As String, malzeme As String
    malzeme = swPart.GetMaterialPropertyName2("", db)
    If malzeme = "" Then malzeme = "TANIMSIZ"

    Dim mp As SldWorks.MassProperty
    Set mp = swModel.Extension.CreateMassProperty
    Dim kg As Double
    kg = mp.Mass                       ' API birimi: kg

    Dim cpm As SldWorks.CustomPropertyManager
    Set cpm = swModel.Extension.CustomPropertyManager("")
    cpm.Add3 "Malzeme", swCustomInfoText, malzeme, swCustomPropertyReplaceValue
    cpm.Add3 "Agirlik", swCustomInfoText, Format(kg, "0.00") & " kg", swCustomPropertyReplaceValue

    MsgBox malzeme & " · " & Format(kg, "0.00") & " kg"
End Sub
  1. Bir modülde birden çok Sub olabilir. Çalıştırmak için imleci ilgili Sub'ın içine koyup F5'e bas.
  2. swApp modülün başında tanımlı olduğu için bütün Sub'larda kullanılabilir.
  3. Malzeme atanmamış parçada kütle 1000 kg/m³ yoğunlukla hesaplanır; TANIMSIZ uyarısı bu yüzden önemli.
  4. Bu sayı, değiştikçe kendiliğinden güncellenmez. Canlı değer istersen özelliğin değerini metin yerine bağlantı olarak yaz: """SW-Mass@" & swModel.GetTitle & """".

Gün sonu kontrolü (15 dk)

Hepsini işaretleyebiliyorsan 3. güne geçebilirsin.

Bonus: Özellik adlarını ve varsayılan değerlerini bir dizi olarak tanımla (Array("ProjeNo", "Yuzey", "Tasarimci")), bir döngüyle yaz. Var olan özellikleri ezmemek için swCustomPropertyOnlyIfNew seçeneğini dene.

GÜN 03

Ölçüler ve parça ailesi

~5 saat · 0/6 kontrol

Hedef

Gün sonunda bir parçanın ölçülerini adlarıyla okuyup değiştiren ve bir ölçü tablosundan parça ailesi üreten (her satır için ayrı dosya kaydeden) makron olacak. Süre yaklaşık 5 saat. Dosyalar: plaka.sldprt, gun3.swp.

1. Hazırlık: adlandırılmış ölçüler (1 saat)

  1. 200 x 150 mm, 10 mm kalın, köşelerinde kenardan 30 mm içeride 4 adet Ø14 delik olan bir ankraj plakası modelle (SolidWorks eğitiminin 2. günündeki plaka).
  2. Çizimdeki ölçülere tıkla, sol paneldeki Primary Value (Birincil Değer) kutusunda adı değiştir: Genislik, Yukseklik, Delik, Kenar. Ekstrüzyon derinliği: Kalinlik.
  3. Tam ad, ölçü adı @ unsur adı biçimindedir: Genislik@Sketch1 (Türkçe arayüzde Genislik@Çizim1). Ekstrüzyon ölçüsü: Kalinlik@Boss-Extrude1 (Kalinlik@Ekstrüzyon1).

Adı verilmemiş ölçüler D1, D2… diye gelir. Makroların uzun yaşaması için ölçülere anlamlı ad vermek en önemli alışkanlıktır.

2. Ölçü okumak ve yazmak (1,5 saat)

Option Explicit
Dim swApp As SldWorks.SldWorks

Function OlcuAl(swModel As SldWorks.ModelDoc2, ad As String) As SldWorks.Dimension
    Set OlcuAl = swModel.Parameter(ad)
    If OlcuAl Is Nothing Then MsgBox "Ölçü bulunamadı: " & ad
End Function

Sub main()
    Set swApp = Application.SldWorks
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then Exit Sub

    Dim d As SldWorks.Dimension
    Set d = OlcuAl(swModel, "Genislik@Sketch1")
    If d Is Nothing Then Exit Sub

    Debug.Print "Eski genişlik: "; d.SystemValue * 1000; " mm"
    d.SystemValue = 250 / 1000        ' API birimi: metre
    swModel.EditRebuild3
End Sub

En önemli kural: API, arayüzde hangi birim seçili olursa olsun uzunlukları metre, açıları radyan cinsinden kullanır. 250 mm için 0.25 yazılır. Kodda her zaman / 1000 ve * 1000 ile açıkça çevir.

Yöntem İşlev
swModel.Parameter("ad@unsur") Ölçü nesnesini verir (yoksa Nothing)
d.SystemValue Değer, metre. Okunur ve yazılır
d.SetSystemValue3 deger, swSetValue_InThisConfiguration, Empty Sadece aktif konfigürasyonda değiştir
swModel.EditRebuild3 Modeli yeniden oluştur
swModel.ForceRebuild3 False Zorla yeniden oluştur

Function bir değer döndürür; değeri fonksiyon adına atayarak verir. Nesne döndürüyorsa Set FonksiyonAdı = ... kullanılır.

3. Parça ailesi üretmek (2 saat)

Hedef: aynı plakadan farklı ölçülerde dosyalar üretmek (PL-200x150.sldprt, PL-250x200.sldprt…). Bu işi Design Table ile de yapabilirsin. Makro yolu ise dosyaları ayrı ayrı ve özellikleri dolu olarak üretir.

Sub Aile()
    Set swApp = Application.SldWorks
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then Exit Sub

    ' genişlik, yükseklik, kalınlık, delik (mm)
    Dim tablo As Variant
    tablo = Array(Array(200, 150, 10, 14), _
                  Array(250, 200, 12, 18), _
                  Array(300, 200, 15, 18))

    Dim klasor As String
    klasor = Left(swModel.GetPathName, InStrRev(swModel.GetPathName, "\"))

    Dim i As Long, s As Variant, ad As String
    Dim errs As Long, warns As Long, ok As Boolean
    Dim cpm As SldWorks.CustomPropertyManager
    Set cpm = swModel.Extension.CustomPropertyManager("")

    For i = 0 To UBound(tablo)
        s = tablo(i)
        swModel.Parameter("Genislik@Sketch1").SystemValue = s(0) / 1000
        swModel.Parameter("Yukseklik@Sketch1").SystemValue = s(1) / 1000
        swModel.Parameter("Kalinlik@Boss-Extrude1").SystemValue = s(2) / 1000
        swModel.Parameter("Delik@Sketch1").SystemValue = s(3) / 1000
        swModel.EditRebuild3

        ad = "PL-" & s(0) & "x" & s(1) & "x" & s(2)
        cpm.Add3 "PozNo", swCustomInfoText, ad, swCustomPropertyReplaceValue
        ok = swModel.Extension.SaveAs3(klasor & ad & ".sldprt", swSaveAsCurrentVersion, _
                 swSaveAsOptions_Copy + swSaveAsOptions_Silent, Nothing, Nothing, errs, warns)
        Debug.Print ad, IIf(ok, "kaydedildi", "HATA " & errs)
    Next i
End Sub
  1. Array(Array(...)): iç içe dizi; her satır bir ölçü takımı. s(0) genişlik, s(1) yükseklik.
  2. swSaveAsOptions_Copy: açık belge orijinal adıyla kalır, sadece bir kopya diske yazılır. Döngü bu sayede hep aynı modelle devam eder.
  3. Kalınlık ölçüsünün unsur adı arayüz diline bağlıdır: Türkçe arayüzde Kalinlik@Ekstrüzyon1. FeatureManager ağacında unsurun adını kontrol et.
  4. SaveAs3 SolidWorks 2020 ve sonrasında vardır; eski sürümlerde SaveAs (beşinci argümansız) kullanılır.
  5. Ailenin sonunda orijinal plakayı kaydetmeden kapat ya da ölçüleri eski değerine döndür.

Gün sonu kontrolü (15 dk)

Hepsini işaretleyebiliyorsan 4. güne geçebilirsin.

Bonus: Tabloyu koda yazmak yerine bir CSV'den oku (6. gündeki Open ... For Input ve Split). Böylece ailenin ölçülerini Excel'de yönetirsin.

GÜN 04

Makroyla parça oluşturmak

~5 saat · 0/5 kontrol

Hedef

Gün sonunda boş bir parça açıp çizim ve ekstrüzyonla delikli ankraj plakasını sıfırdan oluşturan, özelliklerini yazıp kaydeden bir makron olacak. Böylece model hazırlamadan, sadece ölçü vererek parça üretebileceksin. Süre yaklaşık 5 saat. Dosya: gun4.swp.

1. Yeni belge ve düzlem seçimi (1 saat)

Dim tpl As String
tpl = swApp.GetUserPreferenceStringValue(swDefaultTemplatePart)
Dim swModel As SldWorks.ModelDoc2
Set swModel = swApp.NewDocument(tpl, 0, 0, 0)
If swModel Is Nothing Then MsgBox "Şablon açılamadı: " & tpl: Exit Sub

swDefaultTemplatePart: Tools > Options > Default Templates'te tanımlı parça şablonu. Şirket şablonun buradaysa makro onu kullanır.

Düzlemi seçmek: Kaydedici SelectByID2("Front Plane", "PLANE", ...) yazar; bu satır Türkçe arayüzde ("Ön Düzlem") çalışmaz. Dilden bağımsız yol: ağaçtaki ilk referans düzlemi bulmak. Standart şablonlarda ilk düzlem Ön düzlemdir.

Function IlkDuzlem(swModel As SldWorks.ModelDoc2) As SldWorks.Feature
    Dim f As SldWorks.Feature
    Set f = swModel.FirstFeature
    Do While Not f Is Nothing
        If f.GetTypeName2 = "RefPlane" Then
            Set IlkDuzlem = f
            Exit Function
        End If
        Set f = f.GetNextFeature
    Loop
End Function

GetTypeName2 unsurun türünü verir (RefPlane, ProfileFeature, Extrusion…); türler arayüz dilinden bağımsızdır. Unsur adları (Name) ise dile ve kullanıcıya göre değişir.

2. Çizim ve ekstrüzyon (2,5 saat)

Option Explicit
Dim swApp As SldWorks.SldWorks

Function PlakaOlustur(g As Double, y As Double, t As Double, _
                      d As Double, e As Double) As SldWorks.ModelDoc2
    ' ölçüler mm
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.NewDocument(swApp.GetUserPreferenceStringValue(swDefaultTemplatePart), 0, 0, 0)
    If swModel Is Nothing Then Exit Function

    IlkDuzlem(swModel).Select2 False, 0

    Dim sm As SldWorks.SketchManager
    Set sm = swModel.SketchManager
    sm.InsertSketch True                      ' çizim aç
    sm.AddToDB = True                         ' yakalama/ilişki yok, doğrudan geometri
    sm.CreateCornerRectangle 0, 0, 0, g / 1000, y / 1000, 0

    Dim k As Variant
    For Each k In Array(Array(e, e), Array(g - e, e), Array(g - e, y - e), Array(e, y - e))
        sm.CreateCircleByRadius k(0) / 1000, k(1) / 1000, 0, d / 2000
    Next k
    sm.AddToDB = False
    sm.InsertSketch True                      ' çizimi kapat

    swModel.FeatureByPositionReverse(0).Select2 False, 0   ' az önceki çizim
    Dim ext As SldWorks.Feature
    Set ext = swModel.FeatureManager.FeatureExtrusion2(True, False, False, _
        swEndCondBlind, 0, t / 1000, 0, False, False, False, False, 0, 0, _
        False, False, False, False, True, True, True, swStartSketchPlane, 0, False)
    If ext Is Nothing Then MsgBox "Ekstrüzyon oluşturulamadı.": Exit Function

    swModel.ShowNamedView2 "", swIsometricView
    swModel.ViewZoomtofit2
    Set PlakaOlustur = swModel
End Function

Sub main()
    Set swApp = Application.SldWorks
    Dim m As SldWorks.ModelDoc2
    Set m = PlakaOlustur(200, 150, 10, 14, 30)
    If m Is Nothing Then Exit Sub

    Dim ad As String
    ad = "PL-200x150x10"
    m.Extension.CustomPropertyManager("").Add3 "PozNo", swCustomInfoText, ad, swCustomPropertyReplaceValue
    Debug.Print "Oluşturuldu: "; ad
End Sub
  1. IlkDuzlem fonksiyonu (1. bölüm) aynı modülde olmalı. Çalıştır: yeni bir parçada dikdörtgen ve 4 daireden oluşan çizim, 10 mm ekstrüzyonla delikli plakaya dönüşür. İçteki kapalı konturlar otomatik delik olur.
  2. AddToDB = True: geometriyi otomatik ilişki ve yakalama olmadan veritabanına doğrudan ekler. Yoksa SolidWorks yeni daireyi yakındaki bir çizgiye yapıştırabilir. İşin sonunda False yapmayı unutma.
  3. FeatureByPositionReverse(0): ağaçtaki son unsur. Az önce kapatılan çizimi adını bilmeden seçer.
  4. FeatureExtrusion2'nin 23 argümanı vardır. Önemli olanlar: 1. (True = tek yön), 4. (swEndCondBlind = kör), 6. (derinlik, metre), 18. (True = gövdeleri birleştir). Geri kalanlar taslak açısı, ince unsur, ikinci yön gibi seçeneklerdir; API Help'te tek tek açıklanır.
  5. Çizim tam tanımlı değildir (ölçü ve ilişki yok). Model değişmeyecekse sorun değil; parametrik kalması gerekiyorsa ölçü ekleme (swModel.AddDimension2) ya da 3. gündeki şablon parça yaklaşımı daha uygundur.

3. Kaydetmek (45 dk)

1. Bileşenleri dolaşmak (1,5 saat)

Dim swAssy As SldWorks.AssemblyDoc
Set swAssy = swModel                       ' önce GetType = swDocASSEMBLY kontrolü
Dim comps As Variant
comps = swAssy.GetComponents(False)        ' False = bütün seviyeler, True = sadece üst seviye

Dim i As Long, c As SldWorks.Component2

GetComponents(False) alt montajların kendilerini de listeler. Sadece parçaları saymak için dosya uzantısına bak.

2. Saymak: Dictionary (1,5 saat)

VBA'da anahtar-değer listesi için Scripting.Dictionary kullanılır. Ek referans gerekmesin diye CreateObject ile açarız (geç bağlama).

Option Explicit
Dim swApp As SldWorks.SldWorks

Sub main()
    Set swApp = Application.SldWorks
    Dim swModel As SldWorks.ModelDoc2
    Set swModel = swApp.ActiveDoc
    If swModel Is Nothing Then Exit Sub
    If swModel.GetType <> swDocASSEMBLY Then MsgBox "Montaj aç.": Exit Sub

    Dim swAssy As SldWorks.AssemblyDoc
    Set swAssy = swModel
    swAssy.ResolveAllLightWeightComponents False   ' özellik okumak için

    Dim adet As Object
    Set adet = CreateObject("Scripting.Dictionary")

    Dim comps As Variant, i As Long, c As SldWorks.Component2, anahtar As String
    comps = swAssy.GetComponents(False)
    If IsEmpty(comps) Then Exit Sub
    For i = 0 To UBound(comps)
        Set c = comps(i)
        If Not c.IsSuppressed And Not c.ExcludeFromBOM Then
            If LCase(Right(c.GetPathName, 7)) = ".sldprt" Then
                anahtar = c.GetPathName & "|" & c.ReferencedConfiguration
                adet(anahtar) = adet(anahtar) + 1
            End If
        End If
    Next i

    CsvYaz swModel, adet
End Sub
  1. adet(anahtar) = adet(anahtar) + 1: anahtar ilk kez görüldüğünde değeri boştur (Empty), Empty + 1 = 1 olur. Python kursundaki get(..., 0) + 1 kalıbının VBA hali.
  2. Anahtar dosya + konfigürasyon: aynı profil dosyasının 3000 ve 3200 mm konfigürasyonları ayrı satır olur.
  3. ResolveAllLightWeightComponents: büyük montajda yavaştır ama bileşen özelliklerini okumak için gerekir.

3. CSV ve Excel'e yazmak (1,5 saat)

Sub CsvYaz(swModel As SldWorks.ModelDoc2, adet As Object)
    Dim yol As String
    yol = Left(swModel.GetPathName, InStrRev(swModel.GetPathName, ".")) & "adetler.csv"

    Dim f As Integer, k As Variant, p As Variant, dosya As String
    f = FreeFile
    Open yol For Output As #f
    Print #f, "DOSYA;KONFIG;POZ;ADET"
    For Each k In adet.Keys
        p = Split(k, "|")
        dosya = Mid(p(0), InStrRev(p(0), "\") + 1)
        Print #f, dosya & ";" & p(1) & ";" & OzellikOku(p(0), p(1), "PozNo") & ";" & adet(k)
    Next k
    Close #f
    MsgBox adet.Count & " farklı parça yazıldı:" & vbCrLf & yol
End Sub

Function OzellikOku(yol As String, konfig As String, ad As String) As String
    Dim m As SldWorks.ModelDoc2
    Set m = swApp.GetOpenDocumentByName(yol)
    If m Is Nothing Then Exit Function
    Dim deger As String, coz As String, cozuldu As Boolean, bagli As Boolean
    m.Extension.CustomPropertyManager(konfig).Get6 ad, False, deger, coz, cozuldu, bagli
    If coz = "" Then m.Extension.CustomPropertyManager("").Get6 ad, False, deger, coz, cozuldu, bagli
    OzellikOku = coz
End Function
  1. Open ... For Output: dosyayı yazmak için açar (varsa üzerine yazar). FreeFile boş bir dosya numarası verir. Her zaman Close ile kapat.
  2. VBA dosyaya Windows'un ANSI kodlamasıyla yazar; Türkçe Excel'de çift tıkla düzgün açılır. Ayırıcı noktalı virgül.
  3. GetOpenDocumentByName: montaj açıkken bileşen belgeleri de bellektedir; ayrıca açmaya gerek yoktur.
  4. OzellikOku önce konfigürasyona özel özelliğe, yoksa belge geneline bakar.

Doğrudan Excel'e:

Toplu işlemler

~5 saat · 0/6 kontrol

Hedef

Gün sonunda bir klasördeki bütün dosyaları sırayla açıp işleyen toplu (batch) makroların olacak: tüm teknik resimleri çok sayfalı PDF'e çevirmek ve tüm parçalarda özel özellikleri güncellemek. Süre yaklaşık 5 saat. Dosya: gun6.swp.

1. Klasördeki dosyaları dolaşmak (1 saat)

Dim klasor As String, ad As String
klasor = "C:\Proje\Cizimler\"            ' sonunda \ olmalı

Dir ilk çağrıda kalıba uyan ilk dosyayı, argümansız çağrıldıkça sıradakileri verir; dosya kalmayınca boş metin döner. Döngünün içinde başka bir Dir çağırma (ör. klasör kontrolü); sıra bozulur. Klasör kontrolünü döngüden önce yap.

Kullanıcıya klasör seçtirmek:

Function KlasorSec() As String
    Dim sh As Object, k As Object
    Set sh = CreateObject("Shell.Application")
    Set k = sh.BrowseForFolder(0, "Klasör seç", 0)
    If Not k Is Nothing Then KlasorSec = k.Self.Path & "\"
End Function

2. Toplu PDF (2 saat)

Option Explicit
Dim swApp As SldWorks.SldWorks

Sub main()
    Set swApp = Application.SldWorks
    Dim klasor As String
    klasor = KlasorSec()
    If klasor = "" Then Exit Sub
    If Dir(klasor & "PDF", vbDirectory) = "" Then MkDir klasor & "PDF"

    Dim ad As String, n As Long, hata As String
    Dim swModel As SldWorks.ModelDoc2
    Dim errs As Long, warns As Long
    ad = Dir(klasor & "*.slddrw")
    Do While ad <> ""
        Set swModel = swApp.OpenDoc6(klasor & ad, swDocDRAWING, swOpenDocOptions_Silent, "", errs, warns)
        If swModel Is Nothing Then
            hata = hata & ad & " (açılamadı)" & vbCrLf
        Else
            If PdfKaydet(swModel, klasor & "PDF\" & Left(ad, InStrRev(ad, ".") - 1) & ".pdf") Then
                n = n + 1
            Else
                hata = hata & ad & " (PDF yazılamadı)" & vbCrLf
            End If
            swApp.CloseDoc swModel.GetTitle
        End If
        ad = Dir
    Loop
    MsgBox n & " PDF oluşturuldu." & IIf(hata = "", "", vbCrLf & "Sorunlar:" & vbCrLf & hata)
End Sub

Function PdfKaydet(swModel As SldWorks.ModelDoc2, yol As String) As Boolean
    Dim swDraw As SldWorks.DrawingDoc
    Set swDraw = swModel
    Dim adlar As Variant, sayfalar() As Object, i As Long
    adlar = swDraw.GetSheetNames
    ReDim sayfalar(UBound(adlar))
    For i = 0 To UBound(adlar)
        Set sayfalar(i) = swDraw.Sheet(adlar(i))
    Next i

    Dim pdf As SldWorks.ExportPdfData
    Set pdf = swApp.GetExportFileData(swExportPdfData)
    pdf.SetSheets swExportData_ExportSpecifiedSheets, sayfalar

    Dim errs As Long, warns As Long
    PdfKaydet = swModel.Extension.SaveAs3(yol, swSaveAsCurrentVersion, _
                    swSaveAsOptions_Silent, pdf, Nothing, errs, warns)
End Function
  1. OpenDoc6 ile swOpenDocOptions_Silent: dosya açılırken çıkan uyarı pencerelerini bastırır; toplu işte makronun beklemesini önler.
  2. ExportPdfData ve SetSheets: teknik resmin bütün sayfalarını tek PDF'e yazar. Bu ayar verilmezse sadece etkin sayfa çıkabilir.
  3. Her dosya işlendikten sonra CloseDoc ile kapatılır; yüzlerce dosyada bellek dolmaz.
  4. Hatalar biriktirilip sonda tek mesajla gösterilir: makro bir dosyada takılıp kalmaz.
  5. swApp.CloseDoc swModel.GetTitle: Windows dosya uzantılarını gizliyorsa başlık uzantısız gelir; çoğu durumda yine de doğru belgeyi kapatır. Sorun yaşarsan swApp.CloseDoc swModel.GetPathName dene.

3. Toplu özellik güncelleme (1,5 saat)

Proje numarası değişti ve 300 parçada güncellenmesi gerekiyor:

Sub OzellikGuncelle()
    Set swApp = Application.SldWorks
    Dim klasor As String
    klasor = KlasorSec(): If klasor = "" Then Exit Sub

    Dim ad As String, n As Long
    Dim swModel As SldWorks.ModelDoc2, errs As Long, warns As Long
    ad = Dir(klasor & "*.sldprt")
    Do While ad <> ""
        Set swModel = swApp.OpenDoc6(klasor & ad, swDocPART, swOpenDocOptions_Silent, "", errs, warns)
        If Not swModel Is Nothing Then
            swModel.Extension.CustomPropertyManager("").Add3 "ProjeNo", swCustomInfoText, _
                "C-2026-021", swCustomPropertyReplaceValue
            If swModel.Save3(swSaveAsOptions_Silent, errs, warns) Then n = n + 1
            swApp.CloseDoc swModel.GetTitle
        End If
        ad = Dir
    Loop
    MsgBox n & " parça güncellendi."
End Sub

Dikkat: Toplu kaydetme geri alınamaz. İlk denemeyi bir kopya klasörde yap. PDM (vault) altındaki dosyalarda önce check-out gerekir; makro check-out edilmemiş dosyaya yazamaz.

Private Sub cmdOlustur_Click()

        If Val(Replace(kutu.Text, ",", ".")) <= 0 Then
            MsgBox "Bütün ölçüler pozitif sayı olmalı.", vbExclamation
            kutu.SetFocus
            Exit Sub
        End If
    Next kutu
    If 2 * Val(txtE.Text) <= Val(txtD.Text) Then
        MsgBox "Kenar mesafesi delik çapına göre çok küçük.", vbExclamation
        Exit Sub
    End If

    PlakaOlustur Sayi(txtG), Sayi(txtY), Sayi(txtT), Sayi(txtD), Sayi(txtE)
    Unload Me
End Sub

Private Sub cmdIptal_Click()
    Unload Me
End Sub

Private Function Sayi(k As Object) As Double
    Sayi = Val(Replace(k.Text, ",", "."))
End Function

Sub main()

2. Hata yönetimi ve hız (1 saat)

Sub main()
    On Error GoTo Hata
    Set swApp = Application.SldWorks
    swApp.CommandInProgress = True          ' API çağrılarını hızlandırır

    ' ... asıl iş ...

Temiz:
    swApp.CommandInProgress = False
    Exit Sub
Hata:
    MsgBox "Hata " & Err.Number & ": " & Err.Description, vbCritical
    Resume Temiz
End Sub
  1. On Error GoTo Hata: hata olursa makro çökmek yerine Hata: etiketine atlar.
  2. Resume Temiz: hatadan sonra temizlik bölümüne döner; ayarlar her durumda eski haline gelir (AutoLISP kursundaki *error* mantığı).
  3. CommandInProgress = True: SolidWorks'e bir API işinin sürdüğünü söyler; çok sayıda çağrı yapan makrolar belirgin hızlanır.
  4. Büyük işlerde ekran güncellemesini kapat: swModel.ActiveView.EnableGraphicsUpdate = False, sonunda True.
