GÜN 01

Web ve HTML

~4 saat · 0/4 kontrol

Hedef

Gün sonunda bir web sayfasının nasıl çalıştığını, HTML, CSS ve JavaScript'in görevlerini, çalışma ortamını ve bir hesap aracının HTML iskeletini bileceksin. Süre yaklaşık 4 saat.

Bu kurs hakkında: Tarayıcıda çalışan küçük mühendislik araçları yapmayı öğretir: hesaplayıcılar, dönüştürücüler, listeler. Kurs boyunca tek bir araç büyür: girdiği ölçü ve cam katmanlarından alanı, birim ağırlığı ve toplam ağırlığı hesaplayan, listeyi kaydeden, CSV indiren, paylaşılabilir bağlantı üreten ve yayımlanan bir Cam Ağırlığı aracı. Sitedeki araçların çoğu da bu yapıdadır: tek bir HTML dosyası, sunucu gerektirmez, telefonda da çalışır.

1. Web nasıl çalışır? (45 dk)

  1. Tarayıcı bir HTML dosyası ister (bir sunucudan ya da diskten).
  2. HTML sayfanın içeriğini ve yapısını tanımlar: başlık, giriş kutuları, tablo.
  3. CSS görünümü tanımlar: renk, boşluk, yerleşim, telefon uyumu.
  4. JavaScript davranışı tanımlar: girdileri okur, hesaplar, sonucu yazar.

Üçü aynı dosyada olabilir. Küçük araçlar için bu en pratik yoldur: tek dosya, kopyala-yapıştır, her yerde çalışır.

2. Çalışma ortamı (45 dk)

  1. Editör: Visual Studio Code. Eklenti olarak bir canlı önizleme (ör. Live Server) işini kolaylaştırır: kaydettiğinde tarayıcı yenilenir.
  2. Tarayıcı: Chrome ya da Edge; F12 ile geliştirici araçları (DevTools): Elements (sayfa yapısı), Console (hatalar ve denemeler), Network.
  3. Telefon görünümü: DevTools'ta cihaz simgesi (Ctrl+Shift+M) ile sayfayı telefon boyutunda gör.
  4. Klasör: Her araç bir .html dosyası; ortak dosyalar (ikon, ortak CSS) yanında.

3. HTML'in temeli (1 saat)

HTML etiketlerden oluşur: <etiket özellik="değer">içerik</etiket>.

<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Cam Ağırlığı</title>
</head>
<body>
  <main>
    <h1>Cam Ağırlığı</h1>
    <p>Merhaba!</p>
  </main>
</body>
</html>
Parça Görevi
<!DOCTYPE html> Modern HTML olduğunu söyler
lang="tr" Dil; ekran okuyucu ve tireleme için
charset="utf-8" Türkçe karakterlerin doğru görünmesi için şart
viewport Telefonda sayfanın küçültülmüş masaüstü gibi görünmemesi için şart
<main>, <section>, <h1> Anlamlı (semantik) yapı

4. Form elemanları (1 saat)

Bir hesap aracının kalbi giriş kutularıdır:

<label for="en">En (mm)</label>
<input id="en" type="number" min="1" value="1500" inputmode="decimal">

<label for="katman">Katmanlar (mm)</label>
<input id="katman" type="text" value="8+6">

<label for="sistem">Sistem</label>
<select id="sistem">
  <option value="stick">Stick</option>
  <option value="unitized">Unitized</option>
</select>
  1. id: JavaScript'in elemanı bulacağı benzersiz ad.
  2. label for: Etiketi kutuya bağlar; etikete dokununca kutu seçilir, ekran okuyucu ne sorulduğunu okur.
  3. type="number": Telefonda sayı klavyesi açar. inputmode="decimal" ondalık klavyeyi ister.
  4. value: Varsayılan değer. Araç açılır açılmaz bir sonuç göstermek için mantıklı bir varsayılan koy.

Alıştırma: En, boy, katmanlar ve adet için dört giriş kutusu ve sonuç için beş satırlık (alan, toplam kalınlık, birim ağırlık, bir cam, toplam) boş bir bölüm içeren sayfayı yaz. Kursun bitmiş örneği: Cam Ağırlığı örnek aracı. Kaynağını görmek için açıp Ctrl+U'ya bas.

GÜN 02

CSS

~4 saat · 0/5 kontrol

Hedef

Gün sonunda CSS ile aracını düzenleyebileceksin: seçiciler, kutu modeli, flex ve grid yerleşim, CSS değişkenleri, açık-koyu tema ve telefon uyumu. Süre yaklaşık 4 saat.

1. Seçiciler ve kurallar (45 dk)

body      { font: 16px/1.5 system-ui, sans-serif; }   /* etiket */
.kart     { border: 1px solid #d9dee5; }              /* sınıf: class="kart" */
#toplam   { font-size: 1.6rem; }                      /* id */
input:focus { outline: 2px solid #2463b0; }           /* durum */

Kural: Görünüm için sınıf kullan; id'yi JavaScript için ayır.

2. Kutu modeli (45 dk)

Her eleman bir kutudur: içerik → padding (iç boşluk) → border (kenar) → margin (dış boşluk).

* { box-sizing: border-box; }   /* genişlik, padding ve kenarı içersin */
.kart { padding: 16px; margin-bottom: 16px; border-radius: 10px; }

box-sizing: border-box olmadan width: 100% ve padding birlikte kutuyu taşırır. Her projenin ilk satırı olsun.

3. Yerleşim: flex ve grid (1 saat)

Grid, giriş kutularını telefonda alt alta, geniş ekranda yan yana dizmenin en kısa yoludur:

.alanlar {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 12px;
}

Bu tek kural: en az 140 px genişliğinde, sığdığı kadar sütun. Telefonda 2, masaüstünde 4 sütun olur; media query bile gerekmez.

Flex tek sıra içindir (butonlar, başlık çubuğu):

.butonlar { display: flex; gap: 8px; flex-wrap: wrap; }

4. Değişkenler ve koyu tema (1 saat)

Renkleri bir yerde tanımla, her yerde kullan:

:root {
  --bg: #f6f7f9; --panel: #fff; --fg: #1d232b; --ac: #2463b0; --line: #d9dee5;
}
@media (prefers-color-scheme: dark) {
  :root { --bg: #0f141b; --panel: #171e27; --fg: #e6eaf0; --ac: #e8b04a; --line: #2a3441; }
}
body  { background: var(--bg); color: var(--fg); }
.kart { background: var(--panel); border: 1px solid var(--line); }

Telefonun ya da bilgisayarın koyu modu açıksa araç kendiliğinden koyu olur.

5. Telefon için ince ayarlar (15 dk)

  1. Gövde metni en az 16 px olsun; iOS daha küçük kutularda sayfayı yakınlaştırır.
  2. Dokunma hedefleri (buton, kutu) yaklaşık 40-44 px yüksekliğinde olsun.
  3. max-width ile içeriği geniş ekranda okunur genişlikte tut: main { max-width: 640px; margin: 0 auto; }
  4. Sayıların hizalı görünmesi için: font-variant-numeric: tabular-nums;

GÜN 03

JavaScript temelleri

~4 saat · 0/6 kontrol

Hedef

Gün sonunda JavaScript'in temellerini bileceksin: değişkenler, sayılar ve metinler, fonksiyonlar, koşullar, döngüler, diziler ve nesneler; Türkçe sayı biçimlerinin tuzakları ve konsolla deneme. Süre yaklaşık 4 saat.

1. Konsol (30 dk)

F12 → Console. Her satırı burada deneyebilirsin:

2 + 3            // 5
1500 / 1000      // 1.5
"8+6".split("+") // ["8", "6"]

Hata olduğunda kırmızı mesaj ve satır numarası buradadır. Bir şey çalışmıyorsa ilk bakılacak yer konsoldur.

2. Değişkenler ve tipler (1 saat)

const YOGUNLUK = 2.5;       // değişmeyecek: const
let toplam = 0;             // değişecek: let
const ad = "Cam";           // metin (string)
const katlar = [8, 6];      // dizi (array)
const cam = { en: 1500, boy: 2500 };   // nesne (object)

En sık tuzak: metin ile sayı. Giriş kutusundan gelen değer her zaman metindir:

"1500" + 1          // "15001"  (metin birleştirme!)
Number("1500") + 1  // 1501
parseFloat("1,5")   // 1        (virgülden sonrası gitti!)
parseFloat("1,5".replace(",", "."))   // 1.5

Türkçe kullanıcılar virgül yazar. Okurken virgülü noktaya çevir:

const sayi = (s) => parseFloat(String(s).replace(",", "."));

3. Fonksiyonlar (1 saat)

Fonksiyon, girdi alıp çıktı veren bir kutudur. Hesabı ekrandan ayrı bir fonksiyonda tutmak, onu test etmeyi ve yeniden kullanmayı kolaylaştırır:

function hesapla(en, boy, kat, adet) {
  const alan = (en / 1000) * (boy / 1000);          // m²
  const kalinlik = kat.reduce((a, b) => a + b, 0);   // mm
  const birim = kalinlik * YOGUNLUK;                 // kg/m²
  const tek = alan * birim;                          // kg
  return { alan, kalinlik, birim, tek, toplam: tek * adet };
}

hesapla(1500, 2500, [8, 6], 1)
// { alan: 3.75, kalinlik: 14, birim: 35, tek: 131.25, toplam: 131.25 }

Kontrol: 8 + 6 mm yalıtım camı 14 × 2,5 = 35 kg/m²; 1,5 × 2,5 m'lik cam 3,75 × 35 = 131,25 kg.

4. Koşullar, döngüler, dizi işlemleri (1 saat)

if (!(en > 0)) { hata = "En pozitif bir sayı olmalı."; }

for (const k of [8, 6]) { console.log(k); }

[8, 6].map((k) => k * 2.5)          // [20, 15]   her elemana uygula
[8, 6].reduce((a, b) => a + b, 0)    // 14         topla
["8", "x"].map(sayi).some(isNaN)     // true       biri hatalı mı?

!(en > 0) yazmak en <= 0 yazmaktan daha güvenlidir: NaN (geçersiz sayı) için de doğru çalışır.

5. Sayıyı Türkçe göstermek (15 dk)

(131.25).toFixed(1)                          // "131.3"  (nokta)
(131.25).toLocaleString("tr-TR", { minimumFractionDigits: 1, maximumFractionDigits: 1 })
// "131,3"   (virgül; binlerde nokta: 1.234,5)

GÜN 04

DOM ve olaylar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda sayfayı JavaScript'le canlandıracaksın: elemanları bulmak, girdileri okumak, her değişiklikte yeniden hesaplamak, hataları göstermek ve sonucu yazmak. Araç bu günün sonunda çalışır. Süre yaklaşık 4 saat.

1. Script nereye? (15 dk)

<script> etiketini </body>'den hemen önce koy: sayfa elemanları yüklendikten sonra çalışır.

2. Elemanları bulmak ve yazmak (1 saat)

Tarayıcı HTML'i bir ağaca (DOM) çevirir. JavaScript bu ağaçta eleman bulur ve değiştirir:

const $ = (id) => document.getElementById(id);

$("en").value                    // kutudaki değer (metin)
$("toplam").textContent = "131,3 kg";   // elemana metin yaz
document.querySelectorAll("input")      // bütün giriş kutuları

Sonuç yazarken textContent kullan. innerHTML kullanıcıdan gelen metni HTML olarak yorumlar; hem hataya hem güvenlik açığına yol açabilir.

3. Olaylar (1 saat)

Kullanıcı bir şey yaptığında (yazdı, tıkladı) tarayıcı bir olay üretir:

document.querySelectorAll("input").forEach((el) =>
  el.addEventListener("input", guncelle)   // her tuşta yeniden hesapla
);
$("kaydet").addEventListener("click", () => { /* ... */ });

input olayı her tuşta tetiklenir; ayrı bir "Hesapla" butonuna gerek kalmaz. Küçük araçlar için en iyi kullanıcı deneyimi budur.

4. Oku → doğrula → hesapla → yaz (1,5 saat)

function oku() {
  return { en: sayi($("en").value), boy: sayi($("boy").value),
           kat: $("katman").value.split("+").map(sayi), adet: sayi($("adet").value) };
}

function guncelle() {
  const g = oku();
  const hatalar = [];
  if (!(g.en > 0)) hatalar.push("En pozitif bir sayı olmalı.");
  if (!(g.boy > 0)) hatalar.push("Boy pozitif bir sayı olmalı.");
  if (g.kat.some((k) => !(k > 0))) hatalar.push("Katmanları 8+6 gibi yaz.");
  if (!(g.adet >= 1)) hatalar.push("Adet en az 1 olmalı.");
  $("hata").textContent = hatalar.join(" ");
  if (hatalar.length) return null;

  const s = hesapla(g.en, g.boy, g.kat, g.adet);
  $("alan").textContent = bicim(s.alan, 2) + " m²";
  $("toplam").textContent = bicim(s.toplam) + " kg";
  // ... diğer satırlar
  return { ...g, ...s };
}

guncelle();   // sayfa açılınca bir kez

Dört kural:

  1. Hesap fonksiyonu (hesapla) ekrana dokunmaz; ekran fonksiyonu (guncelle) hesap yapmaz.
  2. Hatalı girdide sessiz kalma: ne yanlış, nasıl düzeltilir, yaz.
  3. Hatalı girdide eski sonucu yanlış bir sayıyla değiştirme; ya bırak ya da "–" göster.
  4. Birimi her sonuçta yaz.

5. Erişilebilirlik dokunuşları (15 dk)

<p class="hata" id="hata" role="alert"></p>
<section class="kart" aria-live="polite"> ... sonuçlar ... </section>

role="alert" ve aria-live, ekran okuyuculara değişen metni okutur.

GÜN 05

Veri ve paylaşım

~4 saat · 0/5 kontrol

Hedef

Gün sonunda aracına hafıza ve paylaşım ekleyeceksin: hesapları listeye ekleyip tarayıcıda saklamak, tablo üretmek, CSV indirmek, paylaşılabilir bağlantı üretmek ve bir JSON veri dosyası okumak. Süre yaklaşık 4 saat.

1. Liste ve tablo (1 saat)

let liste = [];

function listeyiCiz() {
  $("liste").innerHTML = "";               // tabloyu boşalt
  for (const r of liste) {
    const tr = document.createElement("tr");
    for (const h of [`${r.en} × ${r.boy}`, r.katman, r.adet, bicim(r.toplam)]) {
      const td = document.createElement("td");
      td.textContent = h;                  // güvenli yazım
      tr.append(td);
    }
    $("liste").append(tr);
  }
}

2. localStorage: tarayıcıda saklamak (1 saat)

localStorage, verileri o tarayıcıda, o sitede metin olarak saklar. Nesneleri JSON'a çevirerek saklarsın:

const ANAHTAR = "cam-agirligi-liste";
try { liste = JSON.parse(localStorage.getItem(ANAHTAR)) || []; } catch (e) { liste = []; }

function sakla() {
  try { localStorage.setItem(ANAHTAR, JSON.stringify(liste)); } catch (e) {}
}

Bilmen gerekenler:

  1. Veri yalnızca o cihazda ve o tarayıcıda durur; başka cihazda görünmez, tarayıcı verisi silinirse gider.
  2. Gizli pencerede ya da bazı ortamlarda erişim hata verebilir; bu yüzden try/catch.
  3. Anahtarı araca özel yap (cam-agirligi-liste); aynı sitedeki araçlar aynı depoyu paylaşır.
  4. Önemli veriyi yalnızca burada tutma; CSV ile dışa aktarma imkânı ver.

3. CSV indirmek (45 dk)

$("csv").addEventListener("click", () => {
  const satirlar = [["en", "boy", "katman", "adet", "kg"],
                    ...liste.map((r) => [r.en, r.boy, r.katman, r.adet, r.toplam.toFixed(1)])];
  const metin = satirlar.map((s) => s.join(";")).join("\n");
  const blob = new Blob(["﻿" + metin], { type: "text/csv;charset=utf-8" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = "cam-agirligi.csv";
  a.click();
  URL.revokeObjectURL(a.href);
});

Türkçe Excel için iki püf: Ayırıcı olarak noktalı virgül kullan (Türkçe Excel virgülü ondalık sayar) ve başa BOM (﻿) ekle ki Türkçe karakterler bozulmasın.

4. Paylaşılabilir bağlantı (45 dk)

Girdileri adres çubuğuna koyarsan bağlantıyı gönderdiğin kişi aynı hesabı görür: cam-agirligi.html?en=1500&boy=2500&katman=8%2B6&adet=1

// Açılışta adresten oku
const p = new URLSearchParams(location.search);
for (const k of ["en", "boy", "katman", "adet"]) if (p.has(k)) $(k).value = p.get(k);

// Bağlantı üret ve kopyala
const q = new URLSearchParams();
for (const k of ["en", "boy", "katman", "adet"]) q.set(k, $(k).value);
const url = location.origin + location.pathname + "?" + q;
await navigator.clipboard.writeText(url);

URLSearchParams, + gibi özel karakterleri kendisi kodlar (%2B).

5. JSON veri dosyası okumak (30 dk)

Profil ya da cam listesi gibi verileri ayrı bir dosyada tutabilirsin:

const yanit = await fetch("camlar.json");
const camlar = await yanit.json();     // [{ "ad": "4+16+4", "katman": [4, 4] }, ...]

fetch dosyayı sunucudan ister; HTML dosyasını diskten çift tıklayarak açarsan çoğu tarayıcıda çalışmaz. Canlı önizleme sunucusuyla (1. gün) ya da yayımlanmış sitede dene. Veri küçükse doğrudan script içinde bir dizi olarak tutmak daha basittir.

GÜN 06

Çizim ve çıktı

~4 saat · 0/5 kontrol

Hedef

Gün sonunda aracına çizim ekleyebileceksin: SVG ile ölçekli şema ve ölçü çizgisi, canvas'a kısa bakış, yazdırma sayfası ve PDF. Süre yaklaşık 4 saat.

1. SVG nedir? (45 dk)

SVG, HTML gibi etiketlerle yazılan vektör çizimdir: <rect>, <line>, <circle>, <path>, <text>. Keskindir, büyütülünce bozulmaz, CSS ile renklendirilir. Bu kursun bütün şemaları da SVG'dir.

<svg viewBox="0 0 220 220" width="220" height="220">
  <rect x="62" y="30" width="96" height="160" fill="none" stroke="currentColor"/>
</svg>

viewBox, çizimin kendi koordinat sistemidir. stroke="currentColor" çizgiyi metin rengiyle çizer; koyu temada kendiliğinden açık renk olur.

2. Parametrik çizim (1,5 saat)

Camı girdiğin ölçülere göre, kutuya sığacak şekilde çiz:

function cizim(en, boy) {
  const W = 220, H = 220, pay = 30;
  const olcek = Math.min((W - 2 * pay) / en, (H - 2 * pay) / boy);
  const w = en * olcek, h = boy * olcek;
  const x = (W - w) / 2, y = (H - h) / 2;
  return `<svg viewBox="0 0 ${W} ${H}" width="${W}" height="${H}" role="img" aria-label="Cam ${en} × ${boy} mm">
  <rect x="${x}" y="${y}" width="${w}" height="${h}" fill="none" stroke="currentColor"/>
  <line x1="${x}" y1="${y + h + 12}" x2="${x + w}" y2="${y + h + 12}" stroke="currentColor"/>
  <text x="${W / 2}" y="${y + h + 26}" text-anchor="middle" font-size="11">${en}</text>
  <line x1="${x - 12}" y1="${y}" x2="${x - 12}" y2="${y + h}" stroke="currentColor"/>
  <text x="${x - 16}" y="${H / 2}" text-anchor="middle" font-size="11"
        transform="rotate(-90 ${x - 16} ${H / 2})">${boy}</text>
</svg>`;
}

// guncelle() içinde:
$("cizim").innerHTML = cizim(g.en, g.boy);

1500 × 2500 cam için ölçek 0,064 olur ve cam 96 × 160 birimlik bir dikdörtgen olarak ortalanır. Burada innerHTML kullanmak güvenlidir, çünkü içine yalnızca sayıya çevrilmiş değerler giriyor.

Ölçek kuralı: İki yöndeki ölçekten küçüğünü seç (Math.min); böylece uzun kenar da kutuya sığar ve oranlar bozulmaz.

5. Çevrimdışı çalışma: PWA (45 dk)

Bir PWA (Progressive Web App), telefona uygulama gibi eklenip internet yokken de açılabilen bir web sitesidir. İki parçası vardır:

  1. Manifest (manifest.webmanifest): ad, ikon, renk; "Ana ekrana ekle" için.
  2. Service worker (sw.js): dosyaları önbelleğe alıp çevrimdışı sunan küçük bir betik.
<link rel="manifest" href="/manifest.webmanifest">
<script>
  if ("serviceWorker" in navigator && location.protocol === "https:")
    addEventListener("load", () => navigator.serviceWorker.register("/sw.js").catch(() => {}));
</script>

Dikkat: Service worker eski dosyaları önbellekte tutabilir; araç güncellendiğinde önbellek sürümünü değiştirmeyi unutma, yoksa kullanıcı eski sürümü görür. Bu sitenin sayfaları da bu yöntemi kullanır.
