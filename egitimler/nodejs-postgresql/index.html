1. Node.js nedir? (30 dk)

Node.js, JavaScript'i tarayıcının dışında, doğrudan bilgisayarda ya da sunucuda çalıştıran bir ortamdır. Chrome'un JavaScript motoru V8'i kullanır ve ona tarayıcıda olmayan yetenekler ekler: dosya okuyup yazmak, ağ bağlantısı açmak, veritabanına bağlanmak, başka programları çalıştırmak.

Tarayıcıdaki JavaScript ile farkı:

Tarayıcı Node.js
Erişebildikleri Sayfa (DOM), window, fetch Dosyalar, ağ, işletim sistemi, process
Erişemedikleri Diskteki dosyalar (güvenlik gereği) Sayfa, document, window
Modül sistemi <script type="module"> ES modülleri (import) ya da eski CommonJS (require)
Tipik kullanım Arayüz API sunucusu, komut satırı aracı, derleme araçları

Node.js'in en güçlü yanı olay döngüsüdür: tek bir iş parçacığıyla çalışır ama bir dosya okunmasını ya da veritabanı cevabını beklerken durmaz, başka isteklere bakar. Bu yüzden aynı anda binlerce bağlantıyı az kaynakla yönetebilir.

4. Modüller: import ve export (45 dk)

Kodu dosyalara bölüp birbirinden kullanırız. Hesap fonksiyonlarını ayrı bir dosyaya koyalım:

export const KDV = 0.20;

export function tutar(adet, birimFiyat) {
  return adet * birimFiyat;
}

export function kdvli(t) {
  return Math.round(t * (1 + KDV) * 100) / 100;
}

export default function tl(sayi) {
  return sayi.toLocaleString("tr-TR", { minimumFractionDigits: 2, maximumFractionDigits: 2 }) + " TL";
}

import tl, { tutar, kdvli, KDV } from "./hesap.js";

const t = tutar(48, 1250);
console.log("tutar:", tl(t));
console.log(`KDV %${KDV * 100} dahil:`, tl(kdvli(t)));

5. Dosyalar ve async/await (1 saat)

Dosya okumak, ağdan veri almak, veritabanını sorgulamak zaman alan işlerdir. Node.js bunları beklerken durmaz; işlem bitince sonucu bir Promise (söz) ile verir. await bir Promise'in sonucunu bekler ve sadece async fonksiyonların içinde (ya da ES modülünün en üst seviyesinde) kullanılır.

import fs from "node:fs/promises";
import path from "node:path";

const klasor = "veri";
await fs.mkdir(klasor, { recursive: true });

const siparisler = [
  { no: "S-1001", malzeme: "Isıcam", adet: 120 },
  { no: "S-1002", malzeme: "Silikon", adet: 60 },
];
const yol = path.join(klasor, "siparisler.json");
await fs.writeFile(yol, JSON.stringify(siparisler, null, 2), "utf-8");

const okunan = JSON.parse(await fs.readFile(yol, "utf-8"));
const toplam = okunan.reduce((t, s) => t + s.adet, 0);
console.log(`${yol}: ${okunan.length} sipariş, toplam ${toplam} adet`);

const dosyalar = await fs.readdir(klasor);
console.log("klasörde:", dosyalar);

node dosyalar.js

veri/siparisler.json: 2 sipariş, toplam 180 adet
klasörde: [ 'siparisler.json' ]
  • path.join yolu işletim sistemine uygun ayraçla birleştirir (Windows'ta \, Linux'ta /).
  • JSON.stringify(nesne, null, 2) okunur girintili JSON yazar.

Paralel bekleme: Birbirinden bağımsız işleri sırayla değil aynı anda başlatıp Promise.all ile hepsini beklemek çok daha hızlıdır:

const bekle = (ms, deger) => new Promise(coz => setTimeout(() => coz(deger), ms));

let t0 = Date.now();
await bekle(300, "a");
await bekle(300, "b");
console.log("sırayla:", Math.round((Date.now() - t0) / 100) * 100, "ms");

t0 = Date.now();
const sonuc = await Promise.all([bekle(300, "a"), bekle(300, "b")]);
console.log("paralel:", Math.round((Date.now() - t0) / 100) * 100, "ms", sonuc);

try {

} catch (e) {
  console.log("okunamadı:", e.code);
}

Hedef

Gün sonunda HTTP'nin istek–yanıt mantığını, yöntemleri ve durum kodlarını bilecek; Express ile rotaları, URL parametrelerini ve JSON gövdeyi kullanan küçük bir REST API yazacak, ara katman (middleware) ve merkezi hata işleyici ekleyecek ve API'yi curl ile deneyebileceksin. Süre yaklaşık 4 saat.

1. HTTP: istek ve yanıt (45 dk)

Tarayıcı, mobil uygulama ya da başka bir program sunucuya bir istek (request) gönderir, sunucu bir yanıt (response) döner. İsteğin dört parçası vardır:

  • Yöntem (method): ne yapılmak istendiği.
  • Yol (path): hangi kaynak, örneğin /siparisler/12.
  • Başlıklar (headers): ek bilgiler, örneğin Content-Type: application/json.
  • Gövde (body): gönderilen veri (sadece POST, PUT, PATCH'te).
Yöntem Anlamı Örnek
GET Oku GET /siparisler
POST Yeni oluştur POST /siparisler + gövde
PUT / PATCH Tamamen / kısmen güncelle PATCH /siparisler/12 + gövde
DELETE Sil DELETE /siparisler/12

Yanıt bir durum koduyla başlar:

Kod Anlamı
200 OK Başarılı
201 Created Yeni kayıt oluşturuldu
204 No Content Başarılı, gövde yok (silme)
400 Bad Request İstek hatalı (eksik alan, yanlış tip)
404 Not Found Kaynak yok
409 Conflict Çakışma (aynı numara zaten var)
500 Internal Server Error Sunucuda beklenmeyen hata

REST, bu yöntemleri kaynaklarla (siparişler, projeler) tutarlı biçimde kullanan bir API tasarım tarzıdır.

3. Rotalar, parametreler ve JSON gövde (1 saat)

Şimdi bellekte tutulan bir sipariş listesiyle tam bir REST kaynağı yazalım (yarından sonra veritabanına taşıyacağız):

import express from "express";

const app = express();
app.use(express.json());

let siparisler = [
  { id: 1, malzeme: "Isıcam", adet: 120, durum: "üretim" },
  { id: 2, malzeme: "Silikon", adet: 60, durum: "teslim" },
];
let sonId = 2;

app.get("/siparisler", (req, res) => {
  const { durum } = req.query;
  res.json(durum ? siparisler.filter(s => s.durum === durum) : siparisler);
});

app.get("/siparisler/:id", (req, res) => {
  const s = siparisler.find(x => x.id === Number(req.params.id));
  if (!s) return res.status(404).json({ hata: "Sipariş bulunamadı" });
  res.json(s);
});

app.post("/siparisler", (req, res) => {
  const { malzeme, adet } = req.body ?? {};
  if (!malzeme || !Number.isInteger(adet) || adet <= 0) {
    return res.status(400).json({ hata: "malzeme ve pozitif tam sayı adet gerekli" });
  }
  const yeni = { id: ++sonId, malzeme, adet, durum: "yeni" };
  siparisler.push(yeni);
  res.status(201).json(yeni);
});

app.patch("/siparisler/:id", (req, res) => {
  const s = siparisler.find(x => x.id === Number(req.params.id));
  if (!s) return res.status(404).json({ hata: "Sipariş bulunamadı" });
  Object.assign(s, req.body);
  res.json(s);
});

app.delete("/siparisler/:id", (req, res) => {
  const once = siparisler.length;
  siparisler = siparisler.filter(x => x.id !== Number(req.params.id));
  res.status(siparisler.length < once ? 204 : 404).end();
});

app.listen(3000, () => console.log("hazır"));
  • app.use(express.json()) gelen JSON gövdeyi ayrıştırıp req.body'ye koyar. Unutulursa req.body boş gelir.
  • :id yolun değişken parçasıdır, req.params.id ile okunur. Her zaman metindir; sayıya çevirmek gerekir.
  • ?durum=üretim gibi sorgu parametreleri req.query'dedir.
  • res.status(kod) durum kodunu ayarlar; .end() gövdesiz yanıt bitirir.

4. Ara katman (middleware) (45 dk)

Ara katman, istek rotaya ulaşmadan önce (ya da sonra) çalışan fonksiyondur: (req, res, next) => { ... }. İşini bitirince next() çağırıp isteği sıradakine iletir. express.json() da bir ara katmandır. Kendi günlük (log) ara katmanımızı yazalım ve rotaları ayrı bir dosyaya, bir Router'a taşıyalım:

import { Router } from "express";

const r = Router();
const liste = [{ id: 1, malzeme: "Isıcam", adet: 120 }];

r.get("/", (req, res) => res.json(liste));
r.get("/:id", (req, res, next) => {
  const s = liste.find(x => x.id === Number(req.params.id));
  if (!s) return next({ durum: 404, mesaj: "Sipariş bulunamadı" });
  res.json(s);
});
r.get("/hata/dene", () => {
  throw new Error("beklenmeyen bir şey oldu");
});

export default r;

import express from "express";
import siparisler from "./siparisler.js";

const app = express();
app.use(express.json());

app.use((req, res, next) => {
  const t0 = Date.now();
  res.on("finish", () => console.log(`${req.method} ${req.originalUrl} ${res.statusCode} ${Date.now() - t0 < 50 ? "hızlı" : "yavaş"}`));
  next();
});

app.use("/siparisler", siparisler);

app.use((req, res) => res.status(404).json({ hata: `Yol yok: ${req.method} ${req.path}` }));

app.use((err, req, res, next) => {
  const durum = err.durum ?? 500;
  if (durum === 500) console.error("HATA:", err.message);

1. İlişkiler ve yabancı anahtar (1 saat)

Dünkü siparisler tablosunda malzeme_id vardı ama veritabanı bunun gerçekten var olan bir malzemeyi gösterip göstermediğini bilmiyordu: malzeme_id = 99 yazsak kabul ederdi. Yabancı anahtar (FOREIGN KEY) bu bağı veritabanına söyler.

Bugün şemayı baştan, üç tabloyla kuruyoruz: bir projenin birçok siparişi, bir malzemenin birçok siparişi olabilir. Bu bire-çok (one-to-many) ilişkidir; “çok” tarafına (sipariş) “bir” tarafın id'si yazılır.

DROP TABLE IF EXISTS siparisler, malzemeler, projeler;

CREATE TABLE projeler (
  id    integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  kod   text NOT NULL UNIQUE,
  ad    text NOT NULL,
  sehir text NOT NULL
);

CREATE TABLE malzemeler (
  id          integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  kod         text NOT NULL UNIQUE,
  ad          text NOT NULL,
  birim       text NOT NULL DEFAULT 'adet',
  birim_fiyat numeric(10,2) NOT NULL CHECK (birim_fiyat >= 0),
  stok        integer NOT NULL DEFAULT 0 CHECK (stok >= 0)
);

CREATE TABLE siparisler (
  id         integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  proje_id   integer NOT NULL REFERENCES projeler(id) ON DELETE CASCADE,
  malzeme_id integer NOT NULL REFERENCES malzemeler(id) ON DELETE RESTRICT,
  adet       integer NOT NULL CHECK (adet > 0),
  durum      text NOT NULL DEFAULT 'yeni'
             CHECK (durum IN ('yeni', 'üretim', 'teslim', 'iptal')),
  olusturma  timestamptz NOT NULL DEFAULT now()
);

2. JOIN: tabloları birleştirmek (1 saat 15 dk)

INNER JOIN iki tablodan sadece eşleşen satırları getirir:

SELECT s.id, p.kod AS proje, m.ad AS malzeme, s.adet,
       s.adet * m.birim_fiyat AS tutar, s.durum
FROM siparisler s
JOIN projeler   p ON p.id = s.proje_id
JOIN malzemeler m ON m.id = s.malzeme_id
WHERE s.durum <> 'iptal'
ORDER BY tutar DESC;

Rotaların içine SQL serpiştirmek yerine bütün sipariş sorgularını tek bir modülde toplarız. Böylece SQL bir yerde olur, test etmek ve değiştirmek kolaylaşır:

import { pool } from "./db.js";

const SECIM = `
  SELECT s.id, p.kod AS proje, m.kod AS malzeme, s.adet,
         s.adet * m.birim_fiyat AS tutar, s.durum
  FROM siparisler s
  JOIN projeler p   ON p.id = s.proje_id
  JOIN malzemeler m ON m.id = s.malzeme_id`;

export async function listele({ durum, proje } = {}) {
  const kosullar = [], degerler = [];
  if (durum) { degerler.push(durum); kosullar.push(`s.durum = $${degerler.length}`); }
  if (proje) { degerler.push(proje); kosullar.push(`p.kod = $${degerler.length}`); }
  const where = kosullar.length ? " WHERE " + kosullar.join(" AND ") : "";
  return (await pool.query(SECIM + where + " ORDER BY s.id", degerler)).rows;
}

export async function getir(id) {
  const { rows } = await pool.query(SECIM + " WHERE s.id = $1", [id]);
  return rows[0] ?? null;
}

export async function ekle({ projeKod, malzemeKod, adet }) {
  const { rows } = await pool.query(
    `INSERT INTO siparisler (proje_id, malzeme_id, adet)
     SELECT p.id, m.id, $3 FROM projeler p, malzemeler m
     WHERE p.kod = $1 AND m.kod = $2
     RETURNING id`,
    [projeKod, malzemeKod, adet]
  );
  return rows[0] ? getir(rows[0].id) : null;
}

export async function teslimEt(id) {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows } = await client.query(
      "UPDATE siparisler SET durum = 'teslim' WHERE id = $1 AND durum IN ('yeni', 'üretim') RETURNING malzeme_id, adet",
      [id]
    );
    if (rows.length === 0) throw Object.assign(new Error("Teslim edilecek sipariş yok"), { durum: 409 });
    await client.query("UPDATE malzemeler SET stok = stok - $1 WHERE id = $2", [rows[0].adet, rows[0].malzeme_id]);
    await client.query("COMMIT");
    return getir(id);
  } catch (e) {
    await client.query("ROLLBACK");
    throw e;
  } finally {
    client.release();
  }
}
  • listele filtreleri isteğe bağlıdır; koşulları ve değerleri birlikte biriktirip $1, $2 numaralarını sırayla üretiyoruz. Değerler yine SQL'e birleştirilmiyor, sadece yer tutucu numaraları.
  • ekle proje ve malzemeyi kodla alıyor; id'leri tek bir INSERT … SELECT ile buluyor. Kod yoksa hiçbir satır eklenmez ve null döner.
  • İşlem için havuzdan tek bir bağlantı (client) almak şarttır: BEGIN, UPDATE ve COMMIT aynı bağlantıda çalışmalı. pool.query her seferinde farklı bir bağlantı kullanabilir.
  • finally içindeki client.release() bağlantıyı havuza geri verir. Unutulursa havuz bir süre sonra tükenir ve uygulama donar.

2. Doğrulama: zod ile şema (1 saat)

Dün adet: 0 gönderince veritabanı İngilizce bir CHECK hatası döndürdü. Daha kötüsü, adet: "beş" ya da hiç olmayan alanlar da veritabanına kadar gidiyordu. Kural: dışarıdan gelen her veri, kullanılmadan önce doğrulanır. Veritabanı kısıtları son savunma hattıdır, ilk değil.

Elle if (typeof adet !== "number" || ...) yazmak hızla çirkinleşir. zod, verinin nasıl görünmesi gerektiğini bir şema olarak tanımlamanı sağlar:

import { z } from "zod";

export const yeniSiparis = z.object({
  projeKod: z.string({ error: "projeKod metin olmalı" })
    .regex(/^P-\d{3}$/, "projeKod P-123 biçiminde olmalı"),
  malzemeKod: z.string({ error: "malzemeKod metin olmalı" })
    .regex(/^[A-Z]{3}-\d{2}$/, "malzemeKod ABC-12 biçiminde olmalı"),
  adet: z.number({ error: "adet sayı olmalı" })
    .int("adet tam sayı olmalı")
    .positive("adet 0'dan büyük olmalı")
    .max(10000, "adet en fazla 10000 olabilir"),
});

export const listeSorgusu = z.object({
  durum: z.enum(["yeni", "üretim", "teslim", "iptal"], { error: "durum geçersiz" }).optional(),
  proje: z.string().optional(),
  sayfa: z.coerce.number().int().min(1).default(1),

3. Hata yönetimini toplamak (45 dk)

Bütün hataların tek bir biçimde dönmesini istiyoruz: { hata: "mesaj", ayrintilar?: [...] }. Bunun için kendi hata sınıfımızı ve PostgreSQL kodlarını HTTP'ye çeviren bir hata işleyici yazalım:

export class ApiHatasi extends Error {
  constructor(durum, mesaj, ayrintilar) {
    super(mesaj);
    this.durum = durum;
    this.ayrintilar = ayrintilar;
  }
}

export function dogrula(sema, veri) {
  const r = sema.safeParse(veri);
  if (!r.success) {
    throw new ApiHatasi(400, "Geçersiz veri",
      r.error.issues.map(i => ({ alan: i.path.join("."), mesaj: i.message })));
  }
  return r.data;
}

const PG_KODLARI = {
  "23505": [409, "Bu kayıt zaten var"],
  "23503": [409, "İlişkili kayıt bulunamadı ya da kullanımda"],
  "23514": [400, "Veri bir kuralı ihlal ediyor"],
  "22P02": [400, "Geçersiz değer biçimi"],
};

export function hataIsleyici(err, req, res, next) {
  if (err instanceof ApiHatasi) {
    return res.status(err.durum).json({ hata: err.message, ayrintilar: err.ayrintilar });
  }
  if (err.type === "entity.parse.failed") {
    return res.status(400).json({ hata: "Gövde geçerli JSON değil" });
  }
  if (PG_KODLARI[err.code]) {
    const [durum, mesaj] = PG_KODLARI[err.code];
    return res.status(durum).json({ hata: mesaj });
  }
  console.error(err);
  res.status(500).json({ hata: "Sunucu hatası" });
}

export async function listele({ durum, proje, sayfa = 1 } = {}) {
  const kosullar = [], degerler = [];
  if (durum) { degerler.push(durum); kosullar.push(`s.durum = $${degerler.length}`); }
  if (proje) { degerler.push(proje); kosullar.push(`p.kod = $${degerler.length}`); }
  const where = kosullar.length ? " WHERE " + kosullar.join(" AND ") : "";
  degerler.push(SAYFA_BOYU, (sayfa - 1) * SAYFA_BOYU);
  const sql = `${SECIM}${where} ORDER BY s.id LIMIT $${degerler.length - 1} OFFSET $${degerler.length}`;
  return (await pool.query(sql, degerler)).rows;
}

export async function getir(id) {
  const { rows } = await pool.query(SECIM + " WHERE s.id = $1", [id]);
  if (!rows[0]) throw new ApiHatasi(404, "Sipariş bulunamadı");
  return rows[0];
}

export async function ekle({ projeKod, malzemeKod, adet }) {
  const { rows } = await pool.query(
    `INSERT INTO siparisler (proje_id, malzeme_id, adet)
     SELECT p.id, m.id, $3 FROM projeler p, malzemeler m
     WHERE p.kod = $1 AND m.kod = $2 RETURNING id`,
    [projeKod, malzemeKod, adet]);
  if (!rows[0]) throw new ApiHatasi(400, "Proje ya da malzeme kodu bulunamadı");
  return getir(rows[0].id);
}

export async function teslimEt(id) {
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    const { rows } = await client.query(
      "UPDATE siparisler SET durum = 'teslim' WHERE id = $1 AND durum IN ('yeni', 'üretim') RETURNING malzeme_id, adet",
      [id]);
    if (!rows[0]) throw new ApiHatasi(409, "Teslim edilecek sipariş yok");
    const stok = await client.query(
      "UPDATE malzemeler SET stok = stok - $1 WHERE id = $2 AND stok >= $1 RETURNING stok",
      [rows[0].adet, rows[0].malzeme_id]);
    if (!stok.rows[0]) throw new ApiHatasi(409, "Stok yetersiz");
    await client.query("COMMIT");
    return getir(id);
  } catch (e) {
    await client.query("ROLLBACK");
    throw e;
  } finally {
    client.release();
  }
}

2. Veritabanı göçleri (1 saat)

Şimdiye kadar şemayı DROP TABLE + CREATE TABLE ile kurduk. Canlı bir veritabanında bu olmaz: tablolar gerçek veriyle doludur. Şema zamanla ekleyerek değişir (yeni sütun, yeni tablo, yeni görünüm). Bu değişiklikleri numaralı dosyalar hâlinde tutup her ortamda (senin bilgisayarın, test, sunucu) aynı sırayla ve bir kez uygulamaya göç (migration) denir.

CREATE TABLE projeler (
  id    integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  kod   text NOT NULL UNIQUE,
  ad    text NOT NULL,
  sehir text NOT NULL
);

CREATE TABLE malzemeler (
  id          integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  kod         text NOT NULL UNIQUE,
  ad          text NOT NULL,
  birim       text NOT NULL DEFAULT 'adet',
  birim_fiyat numeric(10,2) NOT NULL CHECK (birim_fiyat >= 0),
  stok        integer NOT NULL DEFAULT 0 CHECK (stok >= 0)
);

CREATE TABLE siparisler (
  id         integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  proje_id   integer NOT NULL REFERENCES projeler(id) ON DELETE CASCADE,
  malzeme_id integer NOT NULL REFERENCES malzemeler(id) ON DELETE RESTRICT,
  adet       integer NOT NULL CHECK (adet > 0),
  durum      text NOT NULL DEFAULT 'yeni'
             CHECK (durum IN ('yeni', 'üretim', 'teslim', 'iptal')),
  olusturma  timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX siparisler_proje_idx ON siparisler (proje_id);
CREATE INDEX siparisler_malzeme_idx ON siparisler (malzeme_id);

CREATE VIEW proje_ozet AS
SELECT p.kod, p.ad, p.sehir,
       count(s.id) FILTER (WHERE s.durum <> 'iptal')                  AS siparis,
       count(s.id) FILTER (WHERE s.durum IN ('yeni', 'üretim'))       AS acik,
       coalesce(sum(s.adet * m.birim_fiyat) FILTER (WHERE s.durum <> 'iptal'), 0) AS tutar
FROM projeler p
LEFT JOIN siparisler s ON s.proje_id = p.id
LEFT JOIN malzemeler m ON m.id = s.malzeme_id
GROUP BY p.id;

FILTER (WHERE ...) bir toplama fonksiyonunu sadece koşula uyan satırlara uygular; aynı sorguda farklı koşullu sayımlar yapmanın en temiz yoludur.

import { pool } from "./db.js";
import { ApiHatasi } from "./hatalar.js";

export async function listele() {
  return (await pool.query("SELECT * FROM proje_ozet ORDER BY kod")).rows;
}

export async function ozet(kod) {
  const proje = (await pool.query("SELECT * FROM proje_ozet WHERE kod = $1", [kod])).rows[0];
  if (!proje) throw new ApiHatasi(404, "Proje bulunamadı");
  const { rows } = await pool.query(
    `SELECT m.kod, m.ad, m.birim, sum(s.adet) AS adet, sum(s.adet * m.birim_fiyat) AS tutar
     FROM siparisler s
     JOIN projeler p   ON p.id = s.proje_id
     JOIN malzemeler m ON m.id = s.malzeme_id
     WHERE p.kod = $1 AND s.durum <> 'iptal'
     GROUP BY m.id ORDER BY tutar DESC`, [kod]);
  return { ...proje, malzemeler: rows };
}

Bu kez sum(s.adet) integer üzerinde toplandığı için PostgreSQL sonucu bigint döndürür; db.js'teki tip çevirici sayesinde JavaScript'e sayı olarak gelir.

Uygulamanın iki parçası var: Node.js sunucusu ve PostgreSQL veritabanı. İkisi için de ücretsiz başlangıç planı olan servisler var (planlar ve sınırlar sık değişir, kaydolmadan önce güncel koşullara bak):

Veritabanı (örnek: Neon ya da Supabase)

  1. Hesap aç, yeni bir proje (veritabanı) oluştur.
  2. Panelde verilen bağlantı adresini kopyala: postgres://kullanici:parola@...neon.tech/santiye?sslmode=require. Bulut veritabanları genellikle SSL ister; adres sonundaki sslmode=require bunu sağlar.
  3. Kendi bilgisayarından bir kez göç ve tohum çalıştır: DATABASE_URL="..." npm run goc, ardından psql "..." -f tohum.sql.

Sunucu (örnek: Render ya da Railway)

  1. Kodu GitHub'a gönder (.env gitmiyor, .gitignore sayesinde).
  2. Serviste “New Web Service” → GitHub deposunu seç.
  3. Build komutu: npm ci. Başlatma komutu: npm start.
  4. Ortam değişkenleri bölümüne DATABASE_URL ekle. PORT'u servis kendisi verir; kodumuz process.env.PORT'u okuduğu için ek ayar gerekmez.
  5. Sağlık kontrolü yolu olarak /api/saglik gir: servis uygulamanın ayakta olduğunu buradan anlar.
