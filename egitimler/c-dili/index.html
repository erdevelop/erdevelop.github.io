1. C nerede? (30 dk)

C, 1972'de Bell Laboratuvarları'nda Unix işletim sistemini yazmak için geliştirildi. Yarım asırdır en çok kullanılan dillerden biridir, çünkü donanıma çok yakındır, çok hızlıdır ve neredeyse her işlemci için bir C derleyicisi vardır.

  • İşletim sistemleri: Linux çekirdeği, Windows ve macOS'un çekirdek bölümleri.
  • Gömülü sistemler: Çamaşır makinesi, otomobil beyinleri, Arduino, sensörler.
  • Diğer dillerin altyapısı: Python yorumlayıcısının kendisi (CPython) C ile yazılmıştır.
  • Veritabanları ve ağ yazılımları: SQLite, PostgreSQL, Nginx.

C öğrenmek, belleğin, işaretçilerin ve derlemenin gerçekte nasıl çalıştığını anlamanı sağlar. Bu bilgi her dilde işine yarar.

3. İlk program (1 saat)

merhaba.c:

#include <stdio.h>

int main(void) {
    printf("Merhaba C!\n");
    printf("2 + 3 = %d\n", 2 + 3);
    return 0;
}

Merhaba C!
2 + 3 = 5

Derle ve çalıştır:

gcc -std=c17 -Wall -o merhaba merhaba.c
./merhaba            (Windows'ta: merhaba.exe)

Satır satır:

  1. #include <stdio.h> standart giriş-çıkış kütüphanesini ekler; printf buradan gelir.
  2. Her C programı main fonksiyonundan başlar. int sonucun bir tam sayı olacağını söyler.
  3. Süslü parantezler { } bir blok oluşturur; her ifade noktalı virgülle biter.
  4. \n satır sonudur; printf kendiliğinden satır atlamaz.
  5. %d bir tam sayının yerini tutar; değer virgülden sonra verilir.
  6. return 0; işletim sistemine "sorunsuz bitti" der.

Python'dan farklı olarak C derlenen bir dildir: program çalışmadan önce bütünüyle makine koduna çevrilir.

GÜN 02

Tipler ve printf

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C'nin temel tiplerini ve bellekte kapladıkları yeri bilecek, printf biçim belirteçlerini doğru kullanabilecek, scanf ile girdi alabilecek, tam sayı bölmesi ve taşma tuzaklarından kaçınabileceksin. Süre yaklaşık 4 saat.

1. Temel tipler (1 saat)

C'de her değişkenin tipi önceden bildirilir ve değişmez. Tip, değişkenin bellekte kaç bayt yer kaplayacağını ve nasıl yorumlanacağını belirler.

#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int adet = 42;
    double fiyat = 12.5;
    char harf = 'A';
    bool stokta = true;

    printf("adet=%d fiyat=%.2f harf=%c stokta=%d\n", adet, fiyat, harf, stokta);
    printf("int %zu, double %zu, char %zu bayt\n", sizeof(int), sizeof(double), sizeof(char));
    printf("'A' harfinin kodu: %d\n", harf);
    return 0;
}

adet=42 fiyat=12.50 harf=A stokta=1
int 4, double 8, char 1 bayt
'A' harfinin kodu: 65
Tip Ne tutar Tipik boyut printf
int Tam sayı (yaklaşık ±2,1 milyar) 4 bayt %d
long long Büyük tam sayı 8 bayt %lld
double Ondalıklı sayı 8 bayt %f, %.2f
char Tek karakter (aslında küçük bir sayı) 1 bayt %c
bool true / false (stdbool.h) 1 bayt %d
size_t Boyut ve sayaç (sizeof sonucu) 8 bayt %zu
  • char aslında bir sayıdır: 'A' 65'tir. Tek tırnak tek karakter, çift tırnak metindir.
  • Boyutlar platforma göre değişebilir; emin olmak için sizeof kullan.

2. printf biçimleri (45 dk)

#include <stdio.h>

int main(void) {
    double pi = 3.14159265;
    int no = 7;
    printf("[%f] [%.2f] [%8.3f]\n", pi, pi, pi);
    printf("[%d] [%5d] [%-5d] [%05d]\n", no, no, no, no);
    printf("[%s] [%x] [%%]\n", "metin", 255);
    return 0;
}

[3.141593] [3.14] [   3.142]
[7] [    7] [7    ] [00007]
[metin] [ff] [%]

%8.3f: en az 8 karakterlik alan, virgülden sonra 3 basamak. - sola yaslar, 0 boşlukları sıfırla doldurur, %x onaltılık yazar, %% yüzde işaretinin kendisidir.

Uyarı: Biçim belirteci ile değerin tipi uyuşmazsa (örneğin %d ile double yazdırmak) sonuç tanımsızdır: anlamsız sayılar görürsün. -Wall bunu yakalar.

3. Aritmetik tuzakları (1 saat)

#include <stdio.h>
#include <limits.h>

int main(void) {
    int a = 7, b = 2;
    printf("%d %d\n", a / b, a % b);
    printf("%.1f\n", (double)a / b);
    printf("%.1f\n", a / b * 1.0);

    int buyuk = INT_MAX;
    printf("INT_MAX = %d\n", buyuk);
    long long guvenli = (long long)buyuk + 1;
    printf("+1 (long long) = %lld\n", guvenli);
    return 0;
}

3 1
3.5
3.0
INT_MAX = 2147483647
+1 (long long) = 2147483648
  1. Tam sayı bölmesi: İki int bölünürse sonuç int olur. Birini (double) ile dönüştürmek (cast) gerekir.
  2. Üçüncü satırda dönüşüm çok geç yapıldı: önce 7 / 2 = 3 hesaplandı, sonra 1.0 ile çarpıldı.
  3. Taşma: int'in alabileceği en büyük değer 2.147.483.647'dir. INT_MAX + 1 işaretli tam sayıda tanımsız davranıştır; program her şeyi yapabilir. Büyük değerler için long long kullan.

GÜN 03

Kontrol yapıları

~4 saat · 0/5 kontrol

Hedef

Gün sonunda C'de if, else, switch ile karar verebilecek, for, while ve do-while döngüleri yazabilecek, break ve continue kullanabilecek ve C'nin "sıfır yanlış, diğer her şey doğru" kuralını bileceksin. Süre yaklaşık 4 saat.

1. if ve else (1 saat)

#include <stdio.h>

int main(void) {
    int stok = 4;
    int esik = 10;

    if (stok == 0) {
        printf("Tükendi\n");
    } else if (stok < esik) {
        printf("Az kaldı: %d\n", stok);
    } else {
        printf("Yeterli\n");
    }

    int cift_mi = (stok % 2 == 0);
    printf("Çift mi? %d\n", cift_mi);
    printf("%s\n", stok > 0 && stok < esik ? "sipariş ver" : "bekle");
    return 0;
}

Az kaldı: 4
Çift mi? 1
sipariş ver
  • Koşul parantez içinde yazılır.
  • C'de karşılaştırmalar int üretir: doğru 1, yanlış 0. Ve tersine: 0 yanlış, sıfırdan farklı her değer doğrudur.
  • && (ve), || (veya), ! (değil).
  • koşul ? a : b tek satırlık koşuldur (üçlü işlem).

C'nin en klasik hatası: if (stok = 0) yazmak. Tek = atamadır: stok'a 0 atar, sonuç 0 olduğu için koşul hep yanlış çıkar ve stok bozulur. -Wall bu satır için uyarı verir.

2. switch (45 dk)

Bir değişkenin birçok sabit değerden hangisi olduğuna göre dallanmak için:

#include <stdio.h>

int main(void) {
    char secim = 'b';
    switch (secim) {
        case 'a':
            printf("Ekle\n");
            break;
        case 'b':
        case 'B':
            printf("Listele\n");
            break;
        default:
            printf("Bilinmeyen seçim\n");
    }
    return 0;
}

Listele

Her case'in sonunda break unutma. Unutursan program bir sonraki case'e "düşer" ve onu da çalıştırır. Bazen bilerek kullanılır (yukarıdaki 'b' ve 'B' gibi), ama çoğu zaman bir hatadır. switch sadece tam sayı ve karakterle çalışır, metinlerle çalışmaz.

3. Döngüler (1,5 saat)

#include <stdio.h>

int main(void) {
    /* for: başlangıç; koşul; adım */
    int toplam = 0;
    for (int i = 1; i <= 100; i++) {
        toplam += i;
    }
    printf("1..100 toplamı: %d\n", toplam);

    /* while: koşul doğru olduğu sürece */
    double para = 1000;
    int ay = 0;
    while (para < 2000) {
        para *= 1.03;
        ay++;
    }
    printf("%d ayda %.2f\n", ay, para);

    /* do-while: en az bir kez çalışır */
    int n = 0;
    do {
        printf("n=%d ", n);
        n += 3;
    } while (n < 10);
    printf("\n");
    return 0;
}

1..100 toplamı: 5050
24 ayda 2032.79
n=0 n=3 n=6 n=9
  • i++, i'yi 1 artırır; toplam += i, toplam = toplam + i demektir.
  • for içinde tanımlanan i sadece döngü içinde yaşar.
  • do-while koşulu sonda kontrol eder: menüler gibi "en az bir kez göster" durumları için uygundur.
  • /* ... */ çok satırlı, // tek satırlık yorumdur.

Fonksiyonlar ve işaretçiler

~4 saat · 0/5 kontrol

Hedef

Gün sonunda fonksiyon tanımlayıp prototip yazabilecek, C'nin argümanları değerle geçirdiğini bilecek, adres ve işaretçi kavramlarını anlayıp & ve * işlemlerini kullanabilecek, işaretçiyle bir fonksiyondan dışarıdaki değişkeni değiştirebileceksin. Süre yaklaşık 4 saat.

1. Fonksiyonlar (1 saat)

#include <stdio.h>

int main(void) {

    printf("%.2f\n", kdv_dahil(249.9, 10));
    return 0;
}

double kdv_dahil(double tutar, double oran) {
    return tutar * (1 + oran / 100);
}

1200.00
274.89
  • Fonksiyonun dönüş tipi, adı ve parametreleri belirtilir. Hiçbir şey döndürmeyecekse dönüş tipi void'dur.
  • C derleyicisi dosyayı yukarıdan aşağı okur. main, aşağıda tanımlanan bir fonksiyonu çağırıyorsa yukarıda prototipi (sadece imzası) olmalıdır. Prototipler genelde başlık dosyalarına (.h) yazılır (7. gün).

2. Değerle geçirme (30 dk)

C'de fonksiyona verilen argümanların kopyası gider. Fonksiyon içinde değiştirmek dışarıdakini etkilemez:

#include <stdio.h>

void artir(int x) {
    x = x + 1;
    printf("içeride: %d\n", x);
}

int main(void) {
    int sayi = 5;
    artir(sayi);
    printf("dışarıda: %d\n", sayi);
    return 0;
}

içeride: 6
dışarıda: 5

Peki bir fonksiyonun dışarıdaki değişkeni değiştirmesi gerekiyorsa? (Dünkü scanf tam olarak bunu yapıyordu.) Cevap: işaretçiler.

3. Adres ve işaretçi (1,5 saat)

Her değişken bellekte bir adreste durur. İşaretçi (pointer), başka bir değişkenin adresini tutan değişkendir.

Yazım Anlamı
int *p; p, bir int'in adresini tutan işaretçi
&x x'in adresi
*p p'nin gösterdiği yerdeki değer (adresi "takip et") 
#include <stdio.h>

int main(void) {
    int stok = 40;
    int *p = &stok;

    printf("stok = %d\n", stok);
    printf("*p   = %d\n", *p);
    *p = 25;                         /* p'nin gösterdiği yere yaz */
    printf("stok = %d\n", stok);
    printf("p == &stok ? %d\n", p == &stok);
    printf("işaretçi boyutu: %zu bayt\n", sizeof p);
    return 0;
}

stok = 40
*p   = 40
stok = 25
p == &stok ? 1
işaretçi boyutu: 8 bayt

*p = 25 dediğimizde stok değişti, çünkü p, stok'un adresini tutuyor. Adreslerin kendisini printf("%p", (void*)p) ile görebilirsin; her çalıştırmada farklı çıkar.

4. İşaretçiyle değiştirmek: swap (45 dk)

#include <stdio.h>

void takas(int *a, int *b) {
    int gecici = *a;
    *a = *b;
    *b = gecici;
}

void min_max(const int *dizi, int n, int *enk, int *enb) {
    *enk = *enb = dizi[0];
    for (int i = 1; i < n; i++) {
        if (dizi[i] < *enk) *enk = dizi[i];
        if (dizi[i] > *enb) *enb = dizi[i];
    }
}

int main(void) {
    int x = 3, y = 8;
    takas(&x, &y);
    printf("x=%d y=%d\n", x, y);

    int notlar[] = {72, 85, 64, 91, 58};
    int en_kucuk, en_buyuk;
    min_max(notlar, 5, &en_kucuk, &en_buyuk);
    printf("min=%d max=%d\n", en_kucuk, en_buyuk);
    return 0;
}

x=8 y=3
min=58 max=91
  • Fonksiyona adres verdik (&x); fonksiyon *a ile o adrese yazdı.
  • min_max iki sonucu birden "döndürmek" için iki çıkış işaretçisi kullanıyor. C'de birden fazla sonuç döndürmenin yaygın yolu budur.
  • const int *dizi: fonksiyon diziyi okuyacak ama değiştirmeyecek; derleyici bunu denetler.

5. NULL ve tehlikeler (15 dk)

Hiçbir yeri göstermeyen işaretçiye NULL atanır. NULL bir işaretçinin gösterdiği yeri okumak ya da yazmak programı çökertir (segmentation fault).

int *p = NULL;
if (p != NULL) {
    printf("%d\n", *p);
}

İşaretçi hataları C'deki en yaygın ve en tehlikeli hatalardır: başlatılmamış işaretçi, NULL'a erişim, artık geçerli olmayan bir adrese erişim. Altın kurallar:

  1. İşaretçiyi tanımlarken başlat (= NULL ya da geçerli bir adres).
  2. Kullanmadan önce NULL kontrolü yap.
  3. Bir fonksiyonun yerel değişkeninin adresini asla döndürme; fonksiyon bitince o değişken yok olur.

Alıştırma: Bir tam sayıyı işaretçiyle alıp basamaklarını ters çeviren (1234 → 4321) void ters_cevir(int *n) fonksiyonu yaz.

GÜN 05

Diziler ve metinler

~4 saat · 0/4 kontrol

Hedef

Gün sonunda C'de dizi tanımlayıp işleyebilecek, dizi ile işaretçi arasındaki ilişkiyi bilecek, metinlerin aslında sonu \0 ile biten char dizileri olduğunu anlayacak, string.h fonksiyonlarını ve güvenli metin işlemeyi (snprintf) öğreneceksin. Süre yaklaşık 4 saat.

1. Diziler (1 saat)

#include <stdio.h>

int main(void) {
    int notlar[5] = {72, 85, 64, 91, 58};
    int n = sizeof notlar / sizeof notlar[0];

    int toplam = 0;
    for (int i = 0; i < n; i++) toplam += notlar[i];
    printf("adet=%d ortalama=%.1f\n", n, (double)toplam / n);

    notlar[2] = 70;
    for (int i = 0; i < n; i++) printf("%d ", notlar[i]);
    printf("\n");

    double matris[2][3] = {{1, 2, 3}, {4, 5, 6}};
    printf("matris[1][2] = %.0f\n", matris[1][2]);
    return 0;
}

adet=5 ortalama=74.0
72 85 70 91 58 
matris[1][2] = 6
  • Dizinin boyutu derleme anında bilinir ve değişmez.
  • Öğe sayısı: sizeof dizi / sizeof dizi[0]. Bu yöntem sadece dizinin tanımlandığı yerde çalışır (birazdan nedenini göreceğiz).
  • C sınır kontrolü yapmaz. notlar[5] ya da notlar[100] yazarsan derleyici çoğu zaman uyarmaz; program başka bir değişkenin belleğini okur ya da bozar. C'deki güvenlik açıklarının büyük kısmı buradan çıkar.

2. Dizi ve işaretçi (1 saat)

Bir dizinin adı, çoğu ifadede ilk öğesinin adresine dönüşür. Bu yüzden dizi[i] aslında *(dizi + i) demektir:

#include <stdio.h>

double ortalama(const int *d, int n) {      /* int d[] ile aynı */
    int t = 0;
    for (int i = 0; i < n; i++) t += d[i];
    return (double)t / n;
}

int main(void) {
    int a[] = {10, 20, 30, 40};
    int *p = a;
    printf("%d %d %d\n", a[1], *(a + 1), p[1]);
    printf("ortalama: %.1f\n", ortalama(a, 4));
    printf("main içinde sizeof a = %zu\n", sizeof a);
    return 0;
}

20 20 20
ortalama: 25.0
main içinde sizeof a = 16

Bir diziyi fonksiyona verdiğinde sadece ilk öğenin adresi gider; fonksiyon dizinin kaç öğeli olduğunu bilemez. Bu yüzden C'de diziyle birlikte uzunluğu da parametre olarak verilir (n). Fonksiyon içinde sizeof d yazsaydın 16 değil, işaretçi boyutu olan 8 çıkardı.

3. Metinler: char dizileri (1 saat)

C'de ayrı bir metin tipi yoktur. Metin, sonunda '\0' (sıfır baytı) bulunan bir char dizisidir:

#include <stdio.h>
#include <string.h>

int main(void) {
    char sehir[] = "Bursa";
    printf("%s: %zu karakter, %zu bayt\n", sehir, strlen(sehir), sizeof sehir);

    char ad[20];
    strcpy(ad, "Ali");                 /* kopyala (dikkat: taşma kontrolü yok) */
    strcat(ad, " Veli");               /* sona ekle */
    printf("%s (%zu)\n", ad, strlen(ad));
    printf("karşılaştır: %d\n", strcmp("elma", "elma"));

    char mesaj[32];
    int adet = 3;
    snprintf(mesaj, sizeof mesaj, "%s %d adet aldı", ad, adet);
    printf("%s\n", mesaj);
    return 0;
}

Bursa: 5 karakter, 6 bayt
Ali Veli (8)
karşılaştır: 0
Ali Veli 3 adet aldı
  • "Bursa" 5 harf ama 6 bayt: sondaki \0 metnin nerede bittiğini gösterir.
  • Metinler == ile karşılaştırılmaz (adresleri karşılaştırır); strcmp kullanılır ve eşitse 0 döndürür.
  • strlen her seferinde \0'ı bulana kadar sayar: O(n).

4. Güvenli metin işleme (45 dk)

strcpy ve strcat hedef dizinin boyutunu bilmez. Hedef 20 bayt, kaynak 50 baytsa fazlası belleğin başka yerlerine yazılır: tampon taşması (buffer overflow). Bu, tarih boyunca en çok istismar edilen güvenlik açıklarından biridir.

Riskli Güvenli alternatif
strcpy(hedef, kaynak) snprintf(hedef, sizeof hedef, "%s", kaynak)
strcat(hedef, ek) snprintf ile yeniden oluşturmak ya da kalan boyutu hesaplamak
gets(tampon) Asla kullanma (standarttan kaldırıldı); fgets(tampon, sizeof tampon, stdin)
scanf("%s", tampon) scanf("%19s", tampon) (boyut − 1 sınırıyla)

snprintf en fazla verilen boyut kadar yazar ve her zaman \0 ile bitirir:

#include <stdio.h>

int main(void) {
    char kisa[8];
    int istenen = snprintf(kisa, sizeof kisa, "%s", "Eskişehir Büyükşehir");
    printf("[%s] istenen=%d\n", kisa, istenen);
    return 0;
}

[Eskişe] istenen=24

Metin kesildi ama bellek bozulmadı. Dönüş değeri, sığsaydı yazılacak uzunluktur; tampon boyutundan büyük ya da ona eşitse kesilme olmuştur.

Türkçe karakter notu: UTF-8'de ş, ı, ü gibi harfler 2 bayttır. strlen("Eskişehir") 9 değil 10 döndürür, ve yukarıda kesme bir harfin tam ortasına denk gelebilir. C, metinleri harf olarak değil bayt olarak görür.

GÜN 06

struct, bellek ve dosyalar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda struct ile kendi veri tiplerini tanımlayabilecek, malloc ve free ile çalışma anında bellek ayırıp geri verebilecek, bellek sızıntısını bilecek ve dosyaya yazıp dosyadan satır satır okuyabileceksin. Süre yaklaşık 4 saat.

1. struct (1 saat)

Bir ürünün adı, fiyatı ve stoğu birbirine ait bilgilerdir. struct, bunları tek bir tipte toplar:

#include <stdio.h>

typedef struct {
    char ad[32];
    double fiyat;
    int stok;
} Urun;

double stok_degeri(const Urun *u) {
    return u->fiyat * u->stok;
}

int main(void) {
    Urun u = {"Kalem", 12.5, 40};
    printf("%s: %.2f TL x %d = %.2f\n", u.ad, u.fiyat, u.stok, stok_degeri(&u));

    Urun liste[] = {{"Defter", 45.0, 25}, {"Silgi", 7.0, 3}};
    for (int i = 0; i < 2; i++) {
        liste[i].stok += 10;
        printf("%s yeni stok: %d\n", liste[i].ad, liste[i].stok);
    }
    printf("sizeof(Urun) = %zu\n", sizeof(Urun));
    return 0;
}

Kalem: 12.50 TL x 40 = 500.00
Defter yeni stok: 35
Silgi yeni stok: 13
sizeof(Urun) = 48
  • typedef ile struct {...} yerine kısaca Urun yazabiliyoruz.
  • Alanlara değişkenle . (u.fiyat), işaretçiyle -> (u->fiyat) ile erişilir. u->fiyat, (*u).fiyat demektir.
  • Büyük struct'ları fonksiyonlara işaretçiyle ver: değerle verirsen bütün struct kopyalanır.
  • sizeof(Urun) 32 + 8 + 4 = 44 değil 48'dir: derleyici, işlemcinin hızlı okuyabilmesi için alanların arasına dolgu baytları ekler.

2. Dinamik bellek: malloc ve free (1,5 saat)

Şimdiye kadarki değişkenler yığında (stack) duruyordu: boyutları derleme anında belli ve fonksiyon bitince otomatik siliniyor. Kaç ürün olacağını ancak program çalışırken öğreniyorsan, belleği öbekten (heap) istersin:

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    double *fiyatlar = malloc(n * sizeof *fiyatlar);
    if (fiyatlar == NULL) {
        fprintf(stderr, "Bellek ayrılamadı\n");
        return 1;
    }
    for (int i = 0; i < n; i++) fiyatlar[i] = 10.0 * (i + 1);

    n = 8;                                         /* büyüt */
    double *yeni = realloc(fiyatlar, n * sizeof *yeni);
    if (yeni == NULL) { free(fiyatlar); return 1; }
    fiyatlar = yeni;
    for (int i = 5; i < n; i++) fiyatlar[i] = 0;

    double toplam = 0;
    for (int i = 0; i < n; i++) toplam += fiyatlar[i];
    printf("%d fiyat, toplam %.1f\n", n, toplam);

    free(fiyatlar);
    fiyatlar = NULL;
    return 0;
}

8 fiyat, toplam 150.0
Fonksiyon Görevi
malloc(bayt) Belirtilen kadar bellek ayırır, adresini döndürür (içi rastgele)
calloc(adet, boyut) Ayırır ve sıfırlar
realloc(p, yeni_bayt) Büyütür ya da küçültür; gerekirse taşır
free(p) Belleği geri verir

Kurallar:

  1. malloc başarısız olabilir: dönüşünü NULL için kontrol et.
  2. malloc ile aldığın her baytı bir kez free et. Etmezsen bellek sızıntısı olur: uzun çalışan programlar zamanla bütün belleği tüketir.
  3. free ettiğin belleği bir daha kullanma (use-after-free) ve iki kez free etme. free'den sonra işaretçiyi NULL yapmak bunu önlemeye yardım eder.

Bellek hatalarını bulmak için derlerken -fsanitize=address -g ekle (Linux ve macOS'ta): program, hatanın tam satırını söyler. Linux'ta Valgrind da aynı işi görür.

3. Dosyalar (1 saat)

#include <stdio.h>
#include <string.h>

int main(void) {
    FILE *f = fopen("urunler.csv", "w");
    if (!f) { perror("açılamadı"); return 1; }
    fprintf(f, "Kalem;12.5;40\n");
    fprintf(f, "Defter;45;25\n");
    fprintf(f, "Silgi;7;3\n");
    fclose(f);

    f = fopen("urunler.csv", "r");
    if (!f) { perror("açılamadı"); return 1; }
    char satir[128];
    double toplam = 0;
    while (fgets(satir, sizeof satir, f)) {
        char ad[32];
        double fiyat;
        int stok;
        if (sscanf(satir, "%31[^;];%lf;%d", ad, &fiyat, &stok) == 3) {
            printf("%-8s %6.2f x %d\n", ad, fiyat, stok);
            toplam += fiyat * stok;
        }
    }
    fclose(f);
    printf("toplam: %.2f\n", toplam);
    return 0;
}

Kalem     12.50 x 40
Defter    45.00 x 25
Silgi      7.00 x 3
toplam: 1646.00
  • fopen kipleri: "r" oku, "w" yaz (siler), "a" sona ekle; ikili dosyalar için "rb", "wb".
  • fopen başarısız olursa NULL döner; perror nedenini yazar ("No such file or directory").
  • fgets en fazla verilen boyut kadar, satır satır okur; dosya bitince NULL döner.
  • sscanf bir metinden değer okur. %31[^;] "noktalı virgüle kadar, en fazla 31 karakter" demektir.
  • Açtığın her dosyayı fclose ile kapat.

GÜN 07

Proje ve sonraki adımlar

~4 saat · 0/5 kontrol

Hedef

Gün sonunda haftanın konularını birleştiren envanter özeti programını yazmış, programı başlık ve kaynak dosyalarına bölmüş, make ile derlemiş olacak; GDB ile hata ayıklamanın temellerini ve C'den sonra nereye gidebileceğini bileceksin. Süre yaklaşık 4 saat.

1. Envanter özeti (1,5 saat)

Bütün dil eğitimlerinde aynı proje: beş ürünün toplam stok değerini, kategoriye göre toplamları ve stoğu azalan ürünleri bulmak.

#include <stdio.h>
#include <string.h>

typedef struct {
    const char *ad;
    const char *kategori;
    double fiyat;
    int stok;
} Urun;

typedef struct {
    const char *ad;
    double toplam;
} KatToplam;

int main(void) {
    Urun urunler[] = {
        {"Kalem", "kırtasiye", 12.5, 40},
        {"Defter", "kırtasiye", 45.0, 25},
        {"Kulaklık", "elektronik", 850.0, 5},
        {"Mouse", "elektronik", 320.0, 12},
        {"Çay", "gıda", 95.0, 30},
    };
    int n = sizeof urunler / sizeof urunler[0];

    double toplam = 0;
    KatToplam kat[10];
    int k = 0;
    for (int i = 0; i < n; i++) {
        double deger = urunler[i].fiyat * urunler[i].stok;
        toplam += deger;
        int j = 0;
        while (j < k && strcmp(kat[j].ad, urunler[i].kategori) != 0) j++;
        if (j == k) { kat[k].ad = urunler[i].kategori; kat[k].toplam = 0; k++; }
        kat[j].toplam += deger;
    }

    /* kategorileri ada göre sırala (eklemeli sıralama) */
    for (int i = 1; i < k; i++) {
        KatToplam x = kat[i];
        int j = i - 1;
        while (j >= 0 && strcmp(kat[j].ad, x.ad) > 0) { kat[j + 1] = kat[j]; j--; }
        kat[j + 1] = x;
    }

    printf("Toplam stok değeri: %.2f TL\n", toplam);
    for (int i = 0; i < k; i++) printf("%s: %.2f\n", kat[i].ad, kat[i].toplam);
    for (int i = 0; i < n; i++)
        if (urunler[i].stok < 10) printf("Az stok: %s (%d)\n", urunler[i].ad, urunler[i].stok);
    return 0;
}

Toplam stok değeri: 12565.00 TL
elektronik: 8090.00
gıda: 2850.00
kırtasiye: 1625.00
Az stok: Kulaklık (5)

Python'da dict ile iki satırda yapılan "kategoriye göre toplam" işi, C'de küçük bir arama ve sıralama yazmayı gerektirdi. C'nin standart kütüphanesi küçüktür; bu hem gücü (her şeyi kontrol edersin) hem de zahmetidir. Sıralama için stdlib.h'deki qsort fonksiyonunu da kullanabilirdin.

2. Çok dosyalı program ve make (1 saat)

Büyük programlar birçok dosyaya bölünür:

urun.h (arayüz: ne var?)

urun.c (uygulama: nasıl çalışıyor?)

#include "urun.h"

main.c içinde #include "urun.h" yazıp fonksiyonu kullanırsın. #ifndef ... #endif (include guard), başlığın aynı dosyaya iki kez eklenmesini önler. Derleme:

gcc -std=c17 -Wall -c urun.c

CFLAGS = -std=c17 -Wall -g

envanter: main.o urun.o
    $(CC) main.o urun.o -o envanter

clean:
    rm -f *.o envanter

(Makefile'da komut satırları boşlukla değil sekme karakteriyle başlamalıdır.) Büyük projelerde CMake daha yaygındır ve Visual Studio ile de çalışır.
