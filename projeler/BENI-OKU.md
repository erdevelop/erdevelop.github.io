# projeler/ — sitedeki fotoğraflar

## Klasör düzeni
- `projeler/*.jpg` → **orijinaller** (senin koyduğun dosyalar). GitHub'a gönderilmez (.gitignore).
- `projeler/web/` → sitede büyük görüntüleyicide açılan küçültülmüş kopyalar (uzun kenar 1600 px).
- `projeler/thumb/` → listedeki küçük resimler.
